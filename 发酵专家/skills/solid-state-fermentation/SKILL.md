# 五级递进固态发酵（SSF）动力学模型（双入口技能）

引擎：`scripts/ssf.py`（本技能目录内）。
事实来源：`references/五级模型方程与案例.md`（方程、参数、案例、判据）。

## 范围（先判断，别用错技能）

本技能只管**好氧固态发酵**：制曲、产酶、产酸、制酒。

| | 本技能 | `lignocellulose-conversion` |
|---|---|---|
| 对象 | 好氧固态发酵（制曲、产酶、产酸、制酒） | 纤维质物料的厌氧/好氧转化（青贮、堆肥、果渣饲料） |
| 主线 | 物理瓶颈链（空间→水活度→传热→传质→混菌） | 可降解性链（糖→酸度→纤维分级→劣变→腐熟） |
| pH | 不建模（受控） | **是状态变量，也是核心输出** |
| 底物 | 可溶/易降解（淀粉、糖） | **部分可降解（NDF/ADF/ADL）** |
| 典型问题 | "能不能长起来、会不会过热" | "能不能存住、会不会烂、纤维能降多少" |

**一句话判定**：问"这堆料是要**长东西**（本技能），还是要把它**转化掉/保存住/腐熟掉**（另一技能）？"

## 规则约束（必须遵守）

1. **只使用**本技能/原始文档给出的方程、参数与案例，**不新增任何动力学机制**。
2. **模型必须手动选择** `--scale 1..5`；用户未指定时先询问，不擅自替用户选型。
3. 严格按照下方触发词模板**路由分发**：命中"计算/预测/扫描"进【入口一】，命中"案例/演示"进【入口二】。
4. 文档未给出的数值使用**明确标注的演示默认值**，可用 `--set key=value` 覆盖。
5. **浓度基准是 g/g 干基质（DM），不是 g/L**。报 g/L 前必须先问含水率，并说明换算依据。
6. 若用户描述的是**液态/深层发酵**（游离水、搅拌罐、溶氧电极），不要用本技能，
   改用 `fermentation-knowledge` 或 `chemostat-dynamics`。
7. 若用户提到**青贮、堆肥、果渣、NDF/ADF/ADL、pH 下降、梭菌**，改用 `lignocellulose-conversion`。

## 模型选择面板

| Scale | 模型 | 真实示范体系 |
|---|---|---|
| 1 | 基础分批 SSF（Logistic 空间限制 + Luedeking–Piret 产物） | 米曲霉麸皮制曲产蛋白酶 |
| 2 | 水活度限制 SSF（a_w 线性抑制） | 黑曲霉麸皮产果胶酶 |
| 3 | 传热限制 SSF（产热 − 散热，温度反馈） | 里氏木霉填充床产纤维素酶 |
| 4 | 传质限制 SSF（床层深度 → 供氧下降，O₂ 限制） | 黑曲霉厚层产柠檬酸 |
| 5 | 混菌共发酵 SSF（糖化–发酵耦合，乙醇抑制） | 米曲霉 + 酿酒酵母（小曲/酒曲） |

> 递进主线是 SSF 的**物理瓶颈链条**：空间容量 → 水分/水活度 → 传热 → 传质 → 混菌。
> 这不是恒化模型的"抑制类型"递进，不要混用。

## 入口一：模型预测计算

> 必须带 `--scale`；参数用 `--set key=value` 覆盖（可重复）。

```bash
S=/home/caiq/MyAgents/发酵专家/skills/solid-state-fermentation/scripts/ssf.py

python3 $S list                                       # 列出模型面板与案例
python3 $S params --scale 1                           # 查看某 Scale 的参数与"演示默认值"
python3 $S simulate --scale 1 --tend 48 --out x1.png  # 时程仿真
python3 $S simulate --scale 3 --tend 96 --set hA=4    # 散热变差 → 看床温与产率
python3 $S simulate --scale 4 --set H=10              # 床层变薄 → 看供氧恢复
python3 $S profile  --scale 4 --min 2 --max 40 --n 10 --out depth.png   # 床层深度扫描
python3 $S profile  --scale 3 --min 1 --max 20 --n 10 --out hA.png      # 散热系数扫描
python3 $S control  --scale 4                         # 控制要点（Scale 4 另附文档控制案例）
```

- `simulate`：时程积分（LSODA 自适应）。返回各状态终点，并自动给出**峰值床温 / 最低氧浓度 /
  残糖诊断**结论。
- `profile`：**仅 Scale 3/4**。Scale 4 扫描床层高度 `H`，输出 `kLa_eff`、`T_peak`、
  `O2_min`、`f_O2`、`P_final`，用于放大方案选床层；Scale 3 扫描**有效散热系数 `hA`**
  （本模型把 `hA` 当输入参数，床层深度通过 `hA` 体现，需按反应器标定）。
- `control`：按模型给出控制要点；Scale 4 附文档"过程控制实际案例"。

### 常用 `--set` 键

| 用途 | 键 |
|---|---|
| 生长 | `mu_max` `Xm` `mu1` `Xm1` `mu2` `Xm2` |
| 水分 | `aw` `aw_min` |
| 温度 | `Tmin` `Topt` `Tmax` `YQ` `hA` `Ceff` `Tamb` `T0` |
| 供氧 | `kLa0` `Href` `H` `O2star` `KO2` `Yox` `mO2` `O20` |
| 糖化/发酵 | `khkE` `Ks` `Ygs` `Yxg` `Ypg` `bp` `Pcrit` |
| 初值 | `S0` `X0` `G0` `X10` `X20` `P0` |

## 入口二：案例 Demo 演示

```bash
python3 $S demo --scale 3 --outdir ssf_demo
python3 $S demo --all --profile --outdir ssf_demo
```

- 每个 Scale 打印：菌种/体系、参数（含演示默认值）、**文档控制结果**、仿真终点，并输出曲线 PNG。
- **Scale 2** 自动附**水活度对照**（$a_w=0.99$ vs $0.90$），展示 $f_{a_w}$ 的杠杆。
- **Scale 3** 自动附**床层对照**（5 cm/$h_A=24$ vs 30 cm/$h_A=3$），展示传热放大瓶颈。
- **Scale 4** 自动附**床层对照**（5 cm vs 30 cm）与（`--profile` 时）深度扫描图。
- **Scale 5** 自动附**乙醇抑制对照**（$P_{crit}=0.12$ vs 放开抑制），量化抑制代价。

## 输出规范

- 默认中文；浓度单位标 **g/g DM（干基质）**，温度 ℃，时间 h，`kLa` 用 h⁻¹。
- 图表坐标用英文（避免缺字），关键结论用中文文字说明。
- 引用参数/案例时注明来自文档哪个 Scale；演示默认值须显式标注。
- **必须提醒**：给出的参数是量级演示值，真实设计须以实测 $\mu_{max}$、$X_m$、$Y_Q$、$h_A$、
  $k_La$ 标定；不得直接当作生产处方。
- 涉及 $g/L$ 或 $\%v/v$ 时，先问含水率再换算，并注明是近似换算。
