# 五级递进纤维质物料转化模型（双入口技能）

引擎：`scripts/fiber.py`（本技能目录内）。
事实来源：`references/五级模型方程与案例.md`（方程、参数、案例、判据）。

## 这个技能管什么

**纤维质物料**的三条转化路线：**青贮（保存）→ 纤维降解（可消化性）→ 堆肥（肥料化）/ 果渣饲料（饲料化）**。

与 `solid-state-fermentation` 的分工（**先判断，别用错**）：

| | `solid-state-fermentation` | 本技能 |
|---|---|---|
| 对象 | 好氧固态发酵（制曲、产酶、产酸、制酒） | 纤维质物料的厌氧/好氧转化 |
| 主线 | 物理瓶颈链（空间→水活度→传热→传质→混菌） | 可降解性链（糖→酸度→纤维分级→劣变→腐熟） |
| pH | 不建模（受控） | **是状态变量，也是核心输出** |
| 底物 | 可溶/易降解（淀粉、糖） | **部分可降解（NDF/ADF/ADL）** |
| 典型问题 | "能不能长起来、会不会过热" | "能不能存住、会不会烂、纤维能降多少" |

## 规则约束（必须遵守）

1. **只使用**本技能/原始文档给出的方程、参数与案例，**不新增任何动力学机制**。
2. **模型必须手动选择** `--scale 1..5`；用户未指定时先询问，不擅自替用户选型。
3. **铁律：不可溶膳食纤维必须拆成 NDF/ADF/ADL 三组分，不能当作单一底物。**
   用户说"纤维占比大"时，先要求 NDF/ADF/ADL（或至少 NDF 与 ADL），再用 Scale 2。
   把 NDF 当单一 $S$ 会把"木质素高"和"半纤维素高"混为一谈——这是本领域最容易犯的建模错误。
4. **浓度基准是 g/g 干基质（DM），不是 g/L**。报 g/L 前必须先问含水率，并说明换算依据。
5. 配比不固定时，**先用 `mix` 折算成参数**，不要手工估算。
6. 文档未给出的数值使用**明确标注的演示默认值**，可用 `--set key=value` 覆盖。
7. 若用户问的是**好氧制曲/产酶/产酒**，改用 `solid-state-fermentation`；
   若问的是**液态/深层发酵**，改用 `fermentation-knowledge` 或 `chemostat-dynamics`。

## 入口一：模型预测计算

> 必须带 `--scale`；参数用 `--set key=value` 覆盖（可重复）。

```bash
S=/home/caiq/MyAgents/发酵专家/skills/lignocellulose-conversion/scripts/fiber.py

python3 $S list                                        # 面板与案例
python3 $S params --scale 2                            # 参数与"演示默认值"

# —— 标准工作流：配比 → 参数 → 仿真 ——
python3 $S mix --straw 0.3 --grass 0.7                 # 鲜重配比折算 DM/WSC/NDF/ADF/ADL
python3 $S simulate --scale 1 --set DM=0.418 --set WSC0=0.1021 --out silage.png
python3 $S simulate --scale 3 --set DM=0.418 --set WSC0=0.1021 --out silage_q.png
python3 $S simulate --scale 2 --set H0=0.2711 --set C0=0.3384 --set L0=0.0489 --out fiber.png
python3 $S simulate --scale 4 --tend 720 --out compost.png
python3 $S simulate --scale 5 --out pomace_feed.png
python3 $S control  --scale 3
```

- `simulate`：时程积分（LSODA）。自动给出该 Scale 的**专项诊断结论**
  （酸封判定 / 纤维降解率 / 品质分型 / 腐熟度 / 蛋白增量）。
- `mix`：**必用**。把物料配比折算成 `DM / WSC0 / H0 / C0 / L0`，输出可直接粘贴的 `--set`。
- `control`：按模型给出控制要点；Scale 3 附青贮品质控制案例。

### 常用 `--set` 键

| 用途 | 键 |
|---|---|
| 青贮（1/3） | `DM` `WSC0` `pH0` `BC` `pH50` `wpH` `pH50L` `wpHL` `pHCI` `wpHC` `DM50` `wDM` `Yla` `muC` `Ybu` |
| 纤维（2） | `H0` `C0` `L0` `fHdig` `fCdig` `kH` `kC` `alphaL` `E0` `pH` |
| 堆肥（4） | `OM0` `OMres` `kOM` `Topt` `Tmax` `YQ` `hA` `Ceff` `kGI` `GI0` `kLa` |
| 果渣饲料（5） | `PEC0` `IDF0` `PR0` `ANF0` `B0` `kP` `kI` `kA` `Ypx` `PRmax` |

## 入口二：案例 Demo 演示

```bash
python3 $S demo --scale 2 --outdir fiber_demo
python3 $S demo --all --outdir fiber_demo
```

- 每个 Scale 打印：体系、参数（含演示默认值）、**文档控制结果**、仿真终点，并输出曲线 PNG。
- **Scale 1** WSC 对照（能否酸封）；**Scale 2** ADL 对照（木质素屏蔽）；
  **Scale 3** 优质/劣质青贮对照；**Scale 4** 堆体大小对照（能否进杀菌区）；
  **Scale 5** 果胶起点对照（快变量对蛋白富集的驱动）。

## 输出规范

- 默认中文；浓度单位标 **g/g DM（干基质）**，温度 ℃，时间 h，pH 无量纲。
- 报纤维时**必须给出 H / C / L 三组分**，不能只报 NDF 总量。
- 图表坐标用英文（避免缺字），关键结论用中文文字说明。
- 引用参数/案例时注明来自文档哪个 Scale；演示默认值须显式标注。
- **必须提醒**：参数是量级演示值，真实设计须以实测值标定——尤其
  `alphaL`、`fHdig`、`fCdig`、`hA`（堆体）、`Ypx`（补氮）五项，直接套用会严重失真。
- 涉及 g/L 或 %v/v 时，先问含水率再换算，并注明是近似换算。
- 青贮品质分级（pH/丁酸/氨态氮）与堆肥腐熟判据，均须注明"以现行标准为准"。

## 典型场景的标准回答路径

**"秸秆和麦苗做青贮，能不能成？"**
1. `mix --straw x --grass y` → 得 DM / WSC / NDF / ADF / ADL
2. 判 DM 是否 30%–35%、WSC 是否 ≥ 8%–10%（`mix` 会直接提示）
3. `simulate --scale 3` → 看 pH 终点、丁酸、分型
4. 若不达标，给出干预：混秸秆提 DM / 加糖蜜 / 接种 LAB / 压实密封

**"果渣做肥料要多久腐熟？"**
1. `simulate --scale 4 --tend 720` → 看峰值温度、OM 降幅、GI 过 0.8 的时间
2. 若峰值 < 55 ℃：加大堆体（等效于降低 `hA`）、调 C/N 到 25–30、含水率 55%–65%

**"果渣做饲料，纤维能降多少？"**
1. `simulate --scale 5` → 果胶降解率 vs IDF 降解率、真蛋白增量、抗营养因子脱除
2. 强调 $k_P \gg k_I$：果胶是快变量（天级），IDF 是慢变量（周级），必须分阶段设计
3. 需要 IDF 上限时另跑 `simulate --scale 2`
