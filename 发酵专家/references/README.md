# 发酵专家知识库 · 参考资料索引

> 本目录为**发酵专家**的参考资料库，收录发酵工程（菌种—培养基—发酵—动力学—下游—合规）的结构化知识文件。
> 文件由网络公开资料与通用教材/标准整理，**标准限量与工艺数值一律以现行有效版本/小试实测为准**。
> 标准复核入口：国家标准全文公开系统 `https://openstd.samr.gov.cn`；食品安全国家标准 `https://sppt.cfsa.net.cn`；国家药监局 `https://www.nmpa.gov.cn`。

| 子目录 | 内容 | 许可 |

| 内容 | 路径 | 说明 |
|---|---|---|

## 六、原文获取与核验

- **收录原则**：法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T/NY/T、药典等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
