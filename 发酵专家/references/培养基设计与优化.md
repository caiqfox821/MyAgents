# 培养基设计与优化

> 整理范围：培养基组分与作用、碳氮比、工业原料、灭菌条件、配方优化方法与典型配方。
> 主要依据：工业发酵培养基设计通用教材/综述；微生物营养学公开资料。
> 说明：配方为示例框架，实际浓度须按菌株与产物小试确定；葡萄糖等还原糖灭菌条件需特别控制。

## 一、培养基组分与作用

| 类别 | 代表物质 | 作用 | 典型浓度（g/L，参考） |
|---|---|---|---|
| 碳源 | 葡萄糖、蔗糖、糖蜜、淀粉、纤维素、甘油、乳清 | 供能、构成细胞与产物骨架 | 10–80（补料可更高） |
| 氮源（有机） | 酵母粉、蛋白胨、玉米浆（CSL）、豆粕、牛肉膏 | 氨基酸/多肽/生长因子 | 5–30 |
| 氮源（无机） | 硫酸铵、氯化铵、硝酸盐、尿素、氨水 | 速效氮/补料碱 | 0.5–10 |
| 磷源 | 磷酸二氢钾/磷酸氢二钾 | 核酸/能量代谢、缓冲 | 0.5–5 |
| 硫/镁 | MgSO₄·7H₂O、硫酸盐 | 辅因子、膜稳定 | 0.2–1 |
| 钾/钠 | KCl、NaCl | 渗透压、酶活 | 0.5–5 |
| 微量元素 | Fe、Mn、Zn、Cu、Co、Mo、B | 辅因子/酶活性 | mg/L 级 |
| 生长因子 | 维生素（B族、生物素）、氨基酸、嘌呤嘧啶 | 营养缺陷型必需 | μg–mg/L |
| 前体/诱导物 | 苯丙氨酸、玉米浆、乳糖、IPTG | 定向合成/诱导表达 | 视体系 |
| 消泡剂 | 硅油、聚醚、植物油 | 抑泡 | 0.1–1（mL/L） |
| 缓冲/ pH 调节 | CaCO₃、磷酸盐、氨水、NaOH | 稳定 pH | 视需要 |

## 二、碳氮比（C/N）

- C/N 影响菌体生长与产物分配：
  - **高 C/N**：利于积累含碳产物（多糖、脂类、有机酸、乙醇），但可能氮限制。
  - **低 C/N**：利于菌体生长（单细胞蛋白、酶），过量氮可能抑制次级代谢。
- 需按产物阶段调整（生长阶段低 C/N，生产阶段高 C/N 或限制性补料）。
- 常用指标：C/N 质量比或摩尔比，须注明基准（如葡萄糖碳含量按 40% 计）。

## 三、工业原料与替代碳氮源

| 原料 | 特点 | 注意 |
|---|---|---|
| 糖蜜（甘蔗/甜菜） | 廉价碳源、含生物素与矿物质 | 批次波动、需稀释/预处理、含抑制物 |
| 淀粉/玉米粉 | 需糖化（酶解）成还原糖 | 液化-糖化工艺、黏度 |
| 玉米浆（CSL） | 廉价有机氮、含生物素/氨基酸 | 成分波动、易染菌、色深 |
| 豆粕/棉籽粕 | 植物蛋白氮源 | 抗营养因子、需粉碎/酶解 |
| 乳清/糖蜜废水 | 乳糖/副产物利用 | 盐分、COD 高 |
| 木质纤维素水解液 | 可再生碳源 | 抑制物（糠醛、5-HMF、乙酸、酚类）需脱毒 |
| 废弃油脂/甘油 | 脂质/生物柴油副产 | 用于 PHA、脂质发酵 |

> 工业培养基设计须兼顾**成本、可得性、批次稳定、下游易分离、废水负荷**。

## 四、培养基灭菌

| 物料 | 推荐条件 | 说明 |
|---|---|---|
| 一般培养基（无糖） | 121 ℃, 15–20 min | 湿热灭菌 |
| 含葡萄糖/还原糖 | 115 ℃, 10–20 min 或过滤除菌 | 高温易焦化、生成抑制物（类黑精、5-HMF） |
| 磷酸盐/钙盐 | 分开灭菌 | 避免沉淀（如 Ca₃(PO₄)₂） |
| 热敏组分（维生素、抗生素、前体） | 0.22 μm 过滤除菌 | 无菌添加 |
| 尿素/氨水 | 过滤除菌或单独配制 | 高温分解 |
| 油脂/消泡剂 | 单独灭菌 | 影响传热 |

- **灭菌失活与灭菌保证的平衡**：高温长时灭菌保证高但营养破坏多；连消（高温短时）平衡更佳。
- **F₀** 值用于表征灭菌强度；培养基灭菌常以特定温度-时间组合（如 121 ℃/20 min）为基准。
- 灭菌后需冷却至接种温度，避免热损伤种子。

## 五、培养基优化方法

| 方法 | 说明 | 适用 |
|---|---|---|
| 单因素（OFAT） | 逐个变量 | 初筛、确定范围 |
| Plackett–Burman | 筛选显著因子 | 多因素降维 |
| 响应面（RSM：CCD、BBD） | 建立二次模型、寻最优 | 关键因子优化 |
| 正交/均匀设计 | 高效多因素 | 配方筛选 |
| 人工神经网络 + 遗传算法 | 非线性拟合+全局寻优 | 复杂体系 |
| 代谢流/模型驱动 | 通透量分析定向补料 | 提高得率与强度 |

优化目标函数示例：产物浓度、比产率、得率 Yp/s、生产强度（g/(L·h)）、成本。

## 六、典型配方框架（示例，须按菌株调整）

### 6.1 细菌（如芽孢杆菌/大肠杆菌产酶或重组蛋白）

- 碳源：葡萄糖 10–30；氮源：酵母粉 5–15 + 蛋白胨 5–15；或 (NH₄)₂SO₄ 2–5
- MgSO₄·7H₂O 0.5；KH₂PO₄ 1–3；K₂HPO₄ 2–6；微量元素 1 mL/L；pH 7.0
- 补料：葡萄糖/甘油 + 氨水调 pH（兼供氮）

### 6.2 酵母（高密度/乙醇）

- 碳源：葡萄糖/糖蜜/蔗糖（15–40）；氮：酵母粉/硫酸铵/尿素；KH₂PO₄ 1–3；MgSO₄·7H₂O 0.5
- 微量元素与维生素（生物素等）；pH 4.5–5.5；乙醇发酵可加酵母提取物/氮源

### 6.3 丝状真菌 / 固态曲

- 固态基质：麸皮、米糠、豆粕、玉米芯等，含水 40%–70%
- 液体种子：葡萄糖 + 蛋白胨/酵母粉；无机盐；pH 5–6
- 产酶/有机酸：诱导底物（如淀粉、纤维素、油脂）按产物选择

### 6.4 乳酸菌 / 益生菌

- 碳源：葡萄糖/乳糖；氮源：酵母粉、蛋白胨、牛肉膏；生长因子（维生素、氨基酸）
- 碳酸钙缓冲（产酸体系）；严格厌氧/微需氧；pH 5–6.5
