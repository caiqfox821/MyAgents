# 发酵工程基础与工艺参数

> 整理范围：微生物培养基础、关键过程参数、氧传递、培养方式、灭菌与染菌控制、生物反应器与放大。
> 主要依据：发酵工程通用教材与行业实践；生物反应器工程（搅拌罐/气升式/固态）公开资料；工艺放大准则（恒 kLa、恒 P/V、恒叶端线速度）。
> 说明：文中"典型区间"为工程经验参考值，实际须按菌株、产物和设备通过小试确定；标注"待核实"处需以设备手册或权威文献复核。

## 一、微生物生长与代谢基础

### 1.1 生长曲线分期

| 时期 | 特征 | 工程意义 |
|---|---|---|
| 迟滞期（lag） | 细胞适应环境、合成酶系，数量不明显增加 | 缩短迟滞期可提高设备利用率；种子种龄过老会延长或跳过 |
| 对数期（log） | 比生长速率 μ 恒定最大，代谢旺盛 | 收获菌体、表达产物常在此期或末期启动 |
| 稳定期 | 营养限制/抑制物累积，生长≈死亡 | 次级代谢产物（抗生素、毒素、多糖）主合成期 |
| 衰亡期 | 死亡速率>生长 | 及时放罐，避免自溶与产物降解 |

### 1.2 比生长速率与倍增时间

- 比生长速率：`μ = (1/X)·(dX/dt)`，单位 h⁻¹
- 对数期：`X = X₀·e^(μ·t)`
- 倍增时间：`td = ln2 / μ ≈ 0.693 / μ`

### 1.3 代谢调控基本概念

- **初级代谢**：生长必需（氨基酸、核苷酸、有机酸、乙醇）。
- **次级代谢**：非生长必需，多在稳定期（抗生素、色素、生物碱）。
- **分解代谢阻遏（葡萄糖效应）**：易利用碳源抑制难利用碳源酶系，补料可缓解。
- **反馈抑制/阻遏**：末端产物抑制关键酶，工业上常用抗反馈突变株或解除调控。
- **溢流代谢**：供氧/供能不足时碳流转向副产物（乙酸、乳酸、乙醇、杂醇）。

## 二、关键过程参数

| 参数 | 符号/单位 | 典型范围（经验） | 控制要点 |
|---|---|---|---|
| 温度 | ℃ | 细菌 30–37；酵母 28–32；霉菌 25–30；嗜热 45–60 | 影响酶活、选择性；发酵热需冷却 |
| pH | — | 细菌 6.5–7.5；酵母 4.5–5.5；霉菌 5–6 | 影响酶活/解离；用酸、碱或生理缓冲 |
| 溶氧 | DO % 或 mg/L | 好氧 20%–40% 饱和度（临界氧以上） | 通过通气/搅拌/富氧控制，勿低于临界氧 |
| 通气量 | vvm（V气/V液/min） | 0.5–2（高密度可>2） | 提高 kLa，但增加泡沫与逃液 |
| 搅拌转速 | rpm | 按叶端线速度与剪切确定 | 提高混合与 kLa，注意剪切损伤 |
| 罐压 | MPa/bar | 0.02–0.1 | 提高氧分压与 C*，但影响 CO₂ 溶解 |
| 泡沫 | — | — | 消泡剂（硅油/聚醚）或机械消泡；过量消泡剂抑制氧传递 |
| 补料速率 | F (L/h) | 由 μ 与 Yx/s 决定 | 维持底物低浓度，避免阻遏与副产物 |

> 温度/ pH/ DO 的"最佳值"因产物而异：生产菌体与生产代谢物常需不同控制策略（如青霉素的"两阶段"温度与补糖策略）。

## 三、氧传递（好氧发酵核心）

### 3.1 氧传递速率

`OTR = kLa · (C* − CL)`

- `OTR` 体积氧传递速率 [mol O₂/(L·h)]
- `kLa` 体积氧传递系数 [h⁻¹]（或 s⁻¹）
- `C*` 操作条件下液相饱和氧浓度 [mol/L]
- `CL` 实际液相氧浓度 [mol/L]

供氧能力必须 ≥ 菌体耗氧速率（OUR），否则 DO 触底、转为厌氧、产副产物。

### 3.2 影响 kLa 的因素

| 因素 | 趋势 |
|---|---|
| 通气量 ↑ | kLa ↑（但高气量造成气泛/液泛） |
| 搅拌功率 ↑ | kLa ↑（接近 P/V 的 0.4–0.7 次方关系） |
| 液位/装液量 ↓ | kLa ↑ |
| 黏度/菌丝体 ↑ | kLa ↓（非牛顿流体、成团） |
| 表面活性物质（消泡剂、蛋白） | 降低或改变 kLa |
| 盐/固形物 | 降低氧溶解度 C* |

### 3.3 常用放大准则（择一或组合）

1. **恒 kLa**：保证供氧一致，最常用于好氧发酵。
2. **恒 P/V**（单位体积搅拌功率）：保证混合强度，但剪切与大罐小罐不一致。
3. **恒叶端线速度**（`πND`）：控制剪切，适合菌丝体/细胞/剪切敏感体系。
4. **恒雷诺数/恒混合时间**：特定体系参考。

> 放大不是单一准则的机械套用：须同时校核 kLa、剪切、混合时间、传热与液位。建议采用"**缩放**（scale-down）"在实验规模复现大罐的局部梯度。

## 四、培养方式

| 方式 | 特点 | 适用 |
|---|---|---|
| 分批（batch） | 一次性投料，组分随时间变化 | 初筛、生长偶联产物 |
| 补料分批（fed-batch） | 中途流加限制性底物，控制 μ 与副产物 | 高密度、次级代谢、重组蛋白（主流） |
| 连续（chemostat） | 恒 D=F/V，达到稳态 | 生理研究、连续生产、定向进化 |
| 灌流（perfusion） | 截留细胞、连续去除产物 | 高密度哺乳动物细胞 |
| 固态（SSF） | 无(或极低)游离水，基质即载体 | 霉菌、曲、堆肥、饲料 |
| 高密度 | 补料+富氧+截留，可达极高细胞密度 | 菌体/酶/重组蛋白 |

### 4.1 补料策略

- **恒速补料**：简单，适合维持期。
- **指数补料**：`F(t) = (μ·X₀·V₀ / (Yx/s·Sf))·e^(μt)`，维持恒定 μ。
- **DO-stat**：DO 回升即补（菌体耗糖，糖耗尽→DO 升）。
- **pH-stat**：以 pH 变化（如产酸）触发补料。
- **呼吸商（RQ）控制**：以 O₂/CO₂ 尾气在线数据调控补糖速度。

### 4.2 连续培养要点

- 稀释率 `D = F/V`；稳态时 `μ = D`。
- 临界稀释率 `Dc`，超过则细胞被洗出（washout）。
- 长期运行需防范杂菌与噬菌体污染、菌株变异。

## 五、灭菌与染菌控制

### 5.1 湿热灭菌

- 常用条件：**121 ℃, 20 min**（培养基、器具）；含糖/氨基培养基高温易焦化，宜 **115 ℃, 15–20 min** 或分消（糖单独过滤除菌）。
- 灭菌效果以 **F₀** 值衡量：以 121 ℃ 为基准的等效灭菌时间；营养破坏与灭菌保证需折中。
- 连续灭菌（连消）：高温短时（如 135 ℃ 数秒）有利保留营养。
- 空气除菌：深层过滤（玻璃纤维/PTFE 滤芯），定期完整性测试。
- 补料/取样管路：蒸汽灭菌、无菌连接；发酵罐 SIP。

### 5.2 染菌识别与对策

| 迹象 | 可能来源 | 对策 |
|---|---|---|
| pH/DO 异常波动、产气 | 细菌（乳酸菌、芽孢杆菌） | 复盘灭菌 F₀、检查冷却盘管渗漏 |
| 培养液变浑浊、发酸 | 杂菌污染 | 倒罐消毒、全面灭菌 |
| 产率骤降、菌体自溶 | 噬菌体（细菌/放线菌） | 换抗性菌株、轮换菌种、环境消毒 |
| 泡沫异常增多 | 杂菌或蛋白质累积 | 镜检确认，调整消泡与灭菌 |
| 无菌试验阳性 | 操作/密封/过滤器 | 更换过滤器、检查接种口与轴封 |

> 染菌排查顺序：**培养基灭菌 → 空气系统 → 补料/取样 → 设备渗漏（盘管）→ 种子带菌 → 操作**。

## 六、生物反应器与放大

### 6.1 常见反应器

| 类型 | 混合/传质 | 剪切 | 典型用途 |
|---|---|---|---|
| 机械搅拌罐（STR） | 强 | 高 | 通用好氧/厌氧、放线菌、真菌 |
| 气升式/鼓泡塔 | 中 | 低 | 剪切敏感、大体积、废水处理 |
| 填充床/流化床 | 视设计 | 低 | 固定化细胞/酶、厌氧 |
| 光生物反应器 | 视光路 | 低 | 微藻、光合菌 |
| 固态发酵罐（浅盘/转鼓/卧式桨） | 弱（受热传导限制） | 低 | 霉菌固态发酵 |
| 一次性（single-use） | 中 | 低 | 疫苗、细胞治疗、GMP 生物药 |

### 6.2 过程分析技术（PAT）与智能发酵

- 在线传感器：温度、pH、DO、罐压、泡沫、尾气 O₂/CO₂（计算 RQ）。
- 光谱/软测量：近红外、拉曼、介电谱、在线活细胞/生物量。
- 数据驱动：机理模型 + 机器学习混合建模，用于批次优化与实时放行。
- 自动化：PID、串级、前馈、MPC；补料与 pH/DO 联动。

### 6.3 放大关键校核清单

- [ ] kLa 与 OUR 匹配，DO 不低于临界氧
- [ ] 剪切对菌丝/细胞的影响（叶端线速度）
- [ ] 混合时间与补料点分布（防止局部过浓）
- [ ] 传热面积与冷却能力（发酵热峰值）
- [ ] 泡沫/逃液与罐有效装液系数（一般 60%–75%）
- [ ] 无菌与 CIP/SIP 可行性
- [ ] 放大前后代谢流与副产物谱对比

## 七、能耗与绿色制造

- 搅拌与通气是主要能耗项；通过降低转速+富氧/微气泡、优化补料可节能。
- 尾气与发酵尾水资源化（如乙醇回收、沼气、蛋白/多糖回收）兼顾经济与环境效益（详见《下游分离纯化与膜分离.md》与《标准规范与法规.md》）。
- 关注碳足迹核算与清洁生产审核要求。
