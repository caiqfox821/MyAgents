# 液态发酵、固态发酵与酿造/生物制造工艺

> 整理范围：液态（ submerged）与固态（SSF）发酵工艺、传统酿造（酱油、食醋、白酒、黄酒、啤酒）与典型生物制造产品（氨基酸、有机酸、酶、益生菌、生物乙醇等）。
> 主要依据：发酵工程与酿造学公开教材/综述；国家标准对产品的定义性要求（判定以现行版本为准）。
> 说明：工艺参数为经验区间，规模化前须中试；产品合规见《标准规范与法规.md》。

---

## 一、液态发酵（Submerged Fermentation）

### 1.1 过程框架

1. 种子扩培（见《菌种选育与保藏.md》）
2. 灭菌、接种
3. 发酵控制（T/pH/DO/补料/消泡）
4. 放罐（依产物：菌体/胞外产物/胞内产物）
5. 下游（见《下游分离纯化与膜分离.md》）

### 1.2 关键控制策略

- **两阶段策略**：生长阶段（适宜温度、充足氮源、高 DO）→ 生产阶段（温度/ pH 调整、限制性补料、诱导）。
- **副产物抑制**：控制残糖、供氧与补料，减少乙酸/乳酸/杂醇溢流。
- **高密度发酵**：指数补料 + 富氧 + 高 kLa；注意代谢热与渗透压。

## 二、固态发酵（Solid-State Fermentation, SSF）

### 2.1 特征与优缺点

| 优点 | 缺点 |
|---|---|
| 接近自然生境、酶系丰富 | 传热/传质差、易局部过热 |
| 水耗/能耗低、基质廉价（麸皮、秸秆） | 放大困难、参数难均一 |
| 产物浓度高、下游简化 | 易染菌、取样与在线监测难 |
| 适合霉菌、产孢、酶、次级代谢物 | 基质预处理与灭菌要求高 |

### 2.2 关键参数

| 参数 | 典型范围 | 说明 |
|---|---|---|
| 含水率/水活度 | 40%–70%；aw 0.9–0.98 | 过高易结块缺氧，过低抑制生长 |
| 基质粒度与孔隙率 | 视设计 | 影响通气与散热 |
| 温度 | 25–35 ℃（产热可达更高） | 需翻料/通风/夹套控温 |
| 通气/通风 | 间歇或连续 | 供氧并带走热量与 CO₂ |
| 接种 | 孢子悬液/种子 | 均匀性是关键 |
| 初始 pH | 4–6（霉菌偏酸） | 抑制杂菌 |
| 周期 | 2–15 天 | 视产物 |

### 2.3 反应器类型

- 浅盘/托盘（laboratory/传统）
- 转鼓式、卧式桨式、填充床、流化床、气相双动态（压力脉动）等。
- 放大瓶颈：**热量与氧的移除**、均匀性。

### 2.4 典型 SSF 应用

- 曲（米曲、酱油曲、酒曲）、固态食醋、白酒固态发酵
- 产酶（纤维素酶、蛋白酶、淀粉酶）、有机酸、次级代谢物
- 发酵饲料、生物农药、菌肥、食用菌栽培

### 2.5 定量建模（独立技能 `solid-state-fermentation`）

固态发酵的动力学仿真、水活度限制、产热与床层过热、供氧限制与床层深度放大扫描、
混菌糖化–发酵耦合，用独立技能 **`solid-state-fermentation`**（五级递进模型）。
浓度基准为 g/g 干基质。本节的参数区间可直接作为该模型的输入区间。

### 2.6 纤维质物料的厌氧/好氧转化（独立技能 `lignocellulose-conversion`）

青贮、堆肥、果渣饲料化这三条路线是**另一套物理**（厌氧、pH 是状态变量、底物部分可降解），
用独立技能 **`lignocellulose-conversion`**（五级递进模型）：

| 路线 | Scale | 核心变量 |
|---|---|---|
| 青贮（保存） | 1、3 | WSC、乳酸/丁酸、**pH**、缓冲能力、干物质 |
| 纤维降解（可消化性） | 2 | **NDF / ADF / ADL**、木质素屏蔽、不可降解残余 |
| 堆肥（肥料化） | 4 | 有机质、堆温、氧、**腐熟度 GI** |
| 果渣饲料（饲料化） | 5 | 果胶、**IDF**、真蛋白、抗营养因子 |

**不可溶膳食纤维必须按 Van Soest 三组分（半纤维素/纤维素/木质素）拆分**，
不能当作单一底物——木质素在模型里是"屏蔽"而非"消耗"。
物料配比（秸秆:麦苗、果渣:秸秆）用该技能的 `mix` 子命令折算成模型参数。
详见 `skills/lignocellulose-conversion/references/五级模型方程与案例.md`。

## 三、传统酿造工艺

### 3.1 酱油

- 路线：**原料（豆粕/大豆+小麦）→ 蒸煮 → 制曲（米曲霉/酱油曲霉）→ 盐水发酵（酱醪/低盐固态或高盐稀态）→ 压榨/过滤 → 调配/灭菌 → 成品**。
- 关键：制曲温度/时间、盐水浓度（高盐稀态约 18–22 °Bé 级别，**待核实**）、发酵温度与周期（晒制/保温）、氨基酸态氮与风味形成。
- 微生物：米曲霉为主，鲁氏酵母、乳酸菌参与后期风味。

### 3.2 食醋

- 固态发酵：粮食 → 蒸煮 → 糖化/酒精发酵 → 醋酸发酵（麸皮/稻壳载体，醋酸菌）→ 陈酿/淋醋 → 灭菌。
- 液态（表面/深层）发酵：酒精 → 醋酸菌深层发酵（供氧关键）→ 过滤。
- 关键：醋酸菌供氧、酒精/乙酸浓度、温度（30–35 ℃）；产酸可形成菌膜。

### 3.3 白酒（中国白酒）

- 固态发酵：粮谷 → 蒸煮 → 加曲（大曲/小曲/麸曲）→ 固态发酵（窖池）→ 蒸馏 → 陈酿/勾调。
- 液态法/固液法另有工艺；香型（浓、清、酱、米、兼等）由原料、曲、工艺与微生物区系决定。
- 关键：制曲、入窖条件（水分、酸度、淀粉）、发酵温度与周期、蒸馏与摘酒。
- 微生物：霉菌（糖化）、酵母（发酵）、细菌/放线菌（风味，含己酸菌等）。

### 3.4 黄酒

- 糯米/大米 → 浸米 → 蒸饭 → 加曲/酒药 → 糖化发酵（前发酵/后发酵）→ 压榨 → 煎酒（灭菌）→ 陈酿。
- 关键：麦曲/酒药、温度、发酵周期；风味与氨基酸来自原料与微生物。

### 3.5 啤酒

- 麦芽 → 糖化 → 煮沸（加酒花）→ 冷却 → 接种酵母 → 主发酵 → 后发酵/贮酒 → 过滤/灌装。
- 关键：麦汁组成、酒花、酵母菌株（上面/下面发酵）、温度、双乙酰还原、CO₂ 与风味。

### 3.6 葡萄酒/果酒

- 破碎/压榨 → 前处理 → 接种酵母 → 酒精发酵 → 苹果酸-乳酸发酵（可选）→ 陈酿 → 澄清稳定 → 灌装。
- 关键：SO₂、酵母、温度、单宁与风味、防氧化。

> 酿造产品的分类、特征指标（如酱油氨基酸态氮、食醋总酸、白酒酒精度）与卫生限量以**现行标准**为准。

## 五、工艺设计与中试要点

1. 明确**产物定位**（胞内/胞外、初级/次级）→ 决定放罐时机与下游路线。
2. 小试确定培养基与参数区间 → 摇瓶/小罐 → **中试（约 10–100 L/数百 L）** → 工业放大。
3. 中试重点验证：kLa/剪切/混合、灭菌与无菌、下游收率、能耗与废水。
4. 记录完整批记录（见 `templates/README.md` 所列表单）。
