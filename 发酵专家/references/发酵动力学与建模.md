# 发酵动力学与建模

> 整理范围：菌体生长动力学、底物消耗与产物生成动力学、抑制模型、参数估计与物料衡算、示例计算。
> 主要依据：生物反应工程（Monod、Gompertz、Logistic、Luedeking–Piret、Pirt 等经典模型）与公开综述。
> 说明：各参数为模型符号，示例数值仅用于演算演示，实际以实验拟合为准。

---

## 一、生长动力学

### 1.1 Monod 模型（非抑制底物限制）

`μ = μmax · S / (Ks + S)`

- `μ` 比生长速率 [h⁻¹]；`μmax` 最大比生长速率 [h⁻¹]
- `S` 限制性底物浓度 [g/L]；`Ks` 半饱和常数 [g/L]

- `S ≫ Ks`：`μ ≈ μmax`（零级）；`S ≪ Ks`：`μ ≈ μmax·S/Ks`（一级）。

### 1.2 底物抑制（Andrews / Haldane）

`μ = μmax · S / (Ks + S + S²/Ki)`

- 适合甲醇、乙酸、苯酚等抑制性底物；存在最优 S。

### 1.3 产物抑制（线性/非竞争示例）

`μ = μmax · S / (Ks + S) · (1 − P/Pmax)`（经验形式，P 为产物）

### 1.4 Logistic 与 Gompertz（S 型生长曲线）

| 模型 | 表达式 | 参数 |
|---|---|---|
| Logistic | `X = A / (1 + (A/X₀ − 1)·exp(−μ·t))` | A 最大生物量；μ 速率；X₀ 初始 |
| 修正 Gompertz | `X = A·exp(−exp((λ − t)·μ/A + 1))` | λ 迟滞期；A 渐近最大；μ 最大比速率 |

- 两式均可拟合"迟滞—指数—稳定"全过程。
- 本项目 **`microbial-growth` 技能**实现了 **gompertz / logistic** 两模型，可计算给定时刻浓度并绘图（见下"脚本调用"）。

## 二、底物消耗动力学

### 2.1 得率系数

- 细胞对底物得率：`Yx/s = −ΔX / ΔS`（g 菌体/g 底物）
- 产物对底物得率：`Yp/s = ΔP / ΔS`（g 产物/g 底物）

### 2.2 含维持的底物消耗（Pirt）

`−dS/dt = (1/Yx/s)·dX/dt + ms·X`

- `ms` 维持系数 [g 底物/(g 菌体·h)]；高密/饥饿期占比增大。

---

## 三、产物生成动力学（Luedeking–Piret）

`dP/dt = α·dX/dt + β·X`

| 类型 | 条件 | 例子 |
|---|---|---|
| 生长偶联 | α>0, β≈0 | 初级代谢产物（乙醇在部分条件、菌体） |
| 部分偶联 | α>0, β>0 | 柠檬酸、部分酶 |
| 非生长偶联 | α≈0, β>0 | 次级代谢产物（抗生素、毒素） |

- 参数 α、β 由 `dP/dt` 对 `dX/dt` 与 X 多元回归求得。

---

## 四、反应器物料衡算

### 4.1 分批

- 细胞：`dX/dt = μX`
- 底物：`dS/dt = −(1/Yx/s)·μX − ms·X`
- 产物：`dP/dt = α·μX + β·X`

### 4.2 补料分批

- 体积变化：`dV/dt = F`
- 稀释项：`dX/dt = μX − (F/V)·X`；`dS/dt = −(1/Yx/s)μX − ms·X + (F/V)(Sf − S)`
- 指数补料维持恒定 μ：`F(t) = (μ·X₀·V₀ / (Yx/s·Sf))·e^(μt)`

### 4.3 连续培养

- 稳态：`μ = D = F/V`；`X = Yx/s·(Sf − S)`
- 临界稀释率 `Dc = μmax·Sf/(Ks + Sf)`；超过则洗出。

## 五、参数估计与拟合流程

1. **数据采集**：t、X（干重/OD/活菌数）、S（残糖/底物）、P（产物/效价）定时取样。
2. **数据清洗**：剔除异常点，换算统一单位与基准。
3. **模型选择**：依机理与曲线形状选 Monod/Logistic/Gompertz/Luedeking–Piret。
4. **初值设定**：用线性化或图形法估初值（如 μ 取对数期斜率）。
5. **非线性回归**：最小二乘/Levenberg–Marquardt；可用 Excel Solver、Python `scipy.optimize.curve_fit`、R `nls`。
6. **优度检验**：R²、调整 R²、RMSE、残差随机性。
7. **预测与验证**：独立批次验证，做敏感性分析。

### 关键参数含义速查

| 符号 | 含义 | 单位 |
|---|---|---|
| X₀ / A | 初始/最大生物量 | g/L |
| μ / μmax | 比生长速率/最大 | h⁻¹ |
| λ | 迟滞期 | h |
| Ks | 半饱和常数 | g/L |
| Yx/s、Yp/s | 得率系数 | g/g |
| α、β | 生长/非生长偶联系数 | — |
| ms | 维持系数 | g/(g·h) |

## 六、示例演算（假设值，仅演示）

设 Logistic：X₀=0.5、A=20 g/L、μ=0.4 h⁻¹。

- t=10 h：`X = 20 / (1 + (20/0.5 − 1)·e^(−0.4×10)) = 20 / (1 + 39·e^(−4)) ≈ 20/(1+0.714) ≈ 11.7 g/L`
- 倍增时间估算：`td = 0.693/μ ≈ 1.73 h`（对数早期）

> 上述数字为演示，不可直接用于生产处方。

### 补充：固态发酵动力学（独立技能 `solid-state-fermentation`）

固态发酵（SSF）是**近无水**的多孔基质体系，恒化模型的"均质、等温、无传质限制"三个假设全部失效，
不能直接套用。SSF 的递进主线是**物理瓶颈链条**：空间容量 → 水分/水活度 → 传热 → 传质 → 混菌。

用独立技能 **`solid-state-fermentation`**（`skills/solid-state-fermentation/`，双入口：预测计算 / 案例演示）。
含**五级递进模型**：

| Scale | 模型 | 新增机制 |
|---|---|---|
| 1 | 基础分批 SSF | Logistic 空间限制 + Luedeking–Piret 产物 |
| 2 | 水活度限制 | $\mu=\mu_{max}f_{a_w}(1-X/X_m)$ |
| 3 | 传热限制 | 产热−散热能量平衡 + Rosso 基数温度模型 |
| 4 | 传质限制 | 氧平衡 + $k_La_{eff}=k_La_0/(1+H/H_{ref})$ |
| 5 | 混菌共发酵 | 霉菌糖化（淀粉→还原糖）+ 酵母发酵（→乙醇，产物抑制） |

**关键差别**：浓度基准是 **g/g 干基质（DM）**，不是 g/L；SSF 起始底物通常过量，限制来自
孔隙空间（$X_m$）、水分、热量与氧，所以生长用 **Logistic** 而非 Monod。

方程、参数、真实体系案例与放大判据见该技能 `references/五级模型方程与案例.md`；脚本
`ssf.py` 提供 `simulate / profile / control / demo` 子命令（`profile` 做床层深度扫描）。

### 补充：纤维质物料转化动力学（独立技能 `lignocellulose-conversion`）

青贮、堆肥、果渣饲料化是**另一套物理**：厌氧、**pH 是状态变量**、底物是**部分可降解的固体**。
用独立技能 **`lignocellulose-conversion`**（`skills/lignocellulose-conversion/`）。
含**五级递进模型**：

| Scale | 模型 | 新增机制 |
|---|---|---|
| 1 | 青贮厌氧发酵 | LAB 产乳酸 + pH 自抑 + **缓冲能力 BC**（糖→酸→pH 的转换系数） |
| 2 | 纤维分级降解 | $H/C$ 分级速率 + **木质素屏蔽 $f_L=e^{-\alpha_L L}$** + 不可降解残余 |
| 3 | 青贮品质分型 | LAB vs 梭菌；**pH 门（4.6）+ 干物质门（28%）** 双重门控 |
| 4 | 苹果渣堆肥 | 有机质自热 + 耗氧 + **腐熟度 GI**（嗜热 $T_{opt}=55$ ℃） |
| 5 | 果渣饲料发酵 | **果胶（快）与 IDF（慢）双时间尺度** + 蛋白富集 + 抗营养因子脱除 |
| 6 | 多菌株共发酵 | 4 株菌共享底物池与**固定总承载量**，各自贡献不同酶活谱；碳平衡闭合 |

**核心约定**：不可溶膳食纤维必须按 **Van Soest NDF/ADF/ADL** 拆成
半纤维素 $H=\mathrm{NDF}-\mathrm{ADF}$、纤维素 $C=\mathrm{ADF}-\mathrm{ADL}$、木质素 $L=\mathrm{ADL}$；
木质素在模型里是"屏蔽"而非"消耗"。物料配比用 `mix` 子命令折算成参数。

方程、参数、真实体系案例与判据见该技能 `references/六级模型方程与案例.md`；脚本
`fiber.py` 提供 `list / params / simulate / control / mix / demo` 子命令。
