# 标准规范与法规（发酵相关）

> 整理范围：发酵食品、食品用菌种、发酵饲料、生物制造/药品、生物安全、菌种保藏与知识产权、环保与产业政策相关标准与法规索引。
> **重要提示**：标准与法规更新频繁，本文件仅作**索引与框架**；具体指标、限量、版本号与实施日期**一律以国家官方平台现行有效版本为准**。
> 复核入口：
> - 国家标准全文公开系统：`https://openstd.samr.gov.cn`
> - 国家卫生健康委 / 国家食品安全风险评估中心（CFSA）：`https://sppt.cfsa.net.cn`
> - 全国标准信息公共服务平台：`https://std.samr.gov.cn`
> - 国家药品监督管理局：`https://www.nmpa.gov.cn`

## 三、食品用菌种与"三新食品"

- **可用于食品的菌种名单**、**可用于婴幼儿食品的菌种名单**：由国家卫生健康委公告发布，使用须核对名单与菌株限定（**以最新公告为准**）。
- **新食品原料**（含菌种来源成分）：《新食品原料安全性审查管理办法》。
- **"三新食品"**：新食品原料、食品添加剂新品种、食品相关产品新品种。
- **益生菌**：菌株安全性评价、标签标识、活菌数声称合规；保健食品另按注册/备案管理。
- **转基因微生物**：涉及基因工程菌用于食品/饲料，须符合农业转基因生物安全评价与标识规定（**待核实具体目录与流程**）。
- 注意：传统发酵食品使用的菌种与商业化直投发酵剂（DVS）的合规差异。

## 五、生物制造、药品与 GMP

- **药品 GMP**：2010 年修订《药品生产质量管理规范》；无菌药品附录、生物制品附录等；发酵类原料药需符合无菌/洁净与工艺验证要求。
- **《中国药典》**：生物制品、抗生素、药用辅料等通用要求与检验方法。
- **抗生素发酵**：效价检定、有关物质、残留溶剂、无菌/热原等。
- **生物制品/细胞治疗**：遵循药典与相关技术指导原则。
- **合成生物学与生物制造**：关注工程菌的安全评价、放大的合规与监管动态。

## 七、环保、清洁生产与产业政策

- **水污染物排放**：发酵类/生物工程类制药工业水污染物排放标准（如 GB 21903、GB 21907 等，**编号待核实**）；食品行业废水按相应行业/综合标准。
- **《清洁生产促进法》**、行业清洁生产标准；能耗与碳足迹核算。
- **产业政策**：《"十四五"生物经济发展规划》（国家发展改革委）、《"十四五"推进农业农村现代化规划》等，鼓励生物制造、合成生物、绿色低碳。
- **历史经典产业**：发酵食品（酱油、食醋、白酒等）列入历史经典产业高质量发展相关政策（参见公共知识）。
- **碳达峰碳中和**：发酵企业需关注能耗、碳排放核算与减排路径。

## 八、合规工作清单（发酵项目）

- [ ] 确认产品类别与适用标准（产品标准 + GB 2760/2761/2762/2763 + 标签）
- [ ] 核对食品用菌种是否在允许名单、菌株鉴定与安全性资料
- [ ] 若为新原料/新添加剂，走"三新食品"审批
- [ ] 生产许可（SC）与 GB 14881 卫生规范
- [ ] 发酵饲料核对原料/添加剂目录
- [ ] 药品类核对 GMP、药典与注册要求
- [ ] 菌种保藏与知识产权（专利/转让）安排
- [ ] 环保：废水/废气/固废处理与排放标准、清洁生产审核
- [ ] 转基因/生物安全评价（如涉及）
- [ ] 建立批记录、追溯与偏差管理体系
