> **只读约定**：各私有库不得写入本目录；内容变更须在根 `EVOLUTION.md` 登记一行。

## 二、与各专家 `references/` 的关系

- **公共库**回答"政策/标准/指南原文与跨域方法"；**私有库**回答"领域专业细节"。
- 已建立 **L3 原著证据条目**的专家：营养、种植、发酵、食品加工、食品安全、育种、育苗、**毒理**（`毒理专家/references/证据条目与出处.md`，**104 条**）、**质谱**（`质谱专家/references/证据条目与出处.md`，**74 条**）。三份合计 **258 条**。
- 引用格式统一：指南/专著标 **`公共知识/书库 p.N`（PDF 物理页码）**，OA 文献标 **`PMCID §章节`**（不给页码，避免伪造）。
- 复现工具：`python3 公共知识/书库/tools/search_books.py "关键词" --context 1`、`read_page.py <书> <页>`。

## 三、注意

- 法规/标准/限量/指导值类数值**一律以官方现行文本为准**；本目录条目只提供方法学锚点与复核入口。
- 本环境 `webfetch` 工具不可用（全量 `Transport error`），书库取料走 shell + REST，详见 `书库/PROGRESS.md`「命令备忘」。
