## 一、危害表征与 HBGV 推导（WHO/FAO EHC 240 更新版 Ch5，2020）

| # | 证据条目 | 出处 |
|---|---|---|
| 1-1 | HBGV 计算式：**HBGV = POD / UF**；POD 可为 BMDL、NOAEL，仅在例外情形用 LOAEL | WHO/FAO EHC 240 Ch5，书库 **p.47** |
| 1-2 | **关键效应（critical effect）**＝与暴露最相关性别/种属/品系中 BMDL/NOAEL 最低的有害效应；其 POD 通常用于建立 HBGV。若某效应更严重，即使 POD 较高，也可能需用更大的 UF | 同上，**p.47** |
| 1-3 | 当种/品系特异性机制导致人类不相关时，该 BMDL/NOAEL **不得**用于建立 HBGV（例：CF-1 小鼠对 emamectin 的发育毒性源于 p-糖蛋白品系缺陷，WHO 2012） | 同上，**p.47** |
| 1-4 | 术语已由 "safety factor" 改为 **uncertainty factor (UF)**；"adjustment factor/assessment factor" 为等效词，部分机构将 "adjustment factor" 专用于**数据推导因子**；UF 需覆盖敏感人群亚组（含 12 周龄以上婴儿与幼儿） | 同上，**p.47** |
| 1-5 | **默认 UF = 100**：在无种属特异毒代/毒效数据时，由 IPCS(1999) 确立，＝**10（种间）× 10（种内/个体间）**；每个 10 同时涵盖毒动力学（TK）与毒效动力学（TD）两部分 | 同上，**p.48** |
| 1-6 | POD 来自**人类研究**时不再施加种间外推：可仅用默认 **UF = 10**（例：JMPR 1999 以人 AChE 抑制为基准设 chlorpyrifos 的 ARfD） | 同上，**p.48** |
| 1-7 | 若已在剂量调整阶段做**异速生长缩放（allometric scaling）**，则种间残余不确定性用 **2.5**（而非 10）叠加在缩放系数之上 | 同上，**p.48** |
| 1-8 | **附加 UF**（数据质量缺陷、缺少长期试验、以 LOAEL 代 NOAEL、短周期试验）由专家判断，**一般取 2–10** | 同上，**p.49** |
| 1-9 | 剂量-反应曲线**陡峭**可支持增大 UF，效应严重时更需如此（例：JMPR 为 emamectin benzoate 的 ADI 额外施加 **UF = 5**） | 同上，**p.49** |
| 1-10 | 应**优先用化学特异数据推导 CSAF**（种间/个体间的 TK/TD 差异）取代默认 10 倍因子；无合适数据时才回落到默认值 | 同上，**p.48** |

### 1.1 BMD/POD 方法学（Ch5 §5.3）

| # | 证据条目 | 出处 |
|---|---|---|
| 1-11 | BMR 定义须"可测量、视为有害、对人或模式动物相关"；**分级数据（quantal）默认 BMR＝10% 超额风险**，理由是多数动物试验样本量下的典型检验效力；NOAEL 处超额风险上限的中位数≈10%，故 **BMDL10 可作分级数据默认**（Allen 1994；Fowles 1999；Sand 2011） | EHC 240 Ch5，书库 **p.23** |
| 1-12 | 连续数据默认值**常用 5%**；NTP 大量连续终点再分析显示 **BMDL05 平均接近同一数据的 NOAEL**，多数数据集两者相差不超过一个数量级（Bokkers & Slob 2007）；胎重数据有类似结论（Kavlock 1995） | 同上，**p.23** |
| 1-13 | BMR 设定应遵循**三级顺序（Tier 1→3）**：Tier 1 已有共识生物学相关 BMR 则直接用；Tier 2 由风险评估者+统计学家+毒理学家+临床专家共同给出"有害性"定量定义（可用百分变化、SD、cut-point、point/hybrid 等表述方式；JECFA 曾以 β2-微球蛋白 cut-point 推导镉的 PTMI）；Tier 3 若无法界定有害 BMR，则**落在 BMD 框架之外**，可用 MOE 等其他途径 | 同上，**p.24** |
| 1-14 | Tier 3 情形下从剂量-反应曲线推出的"看似合理值"**不得用于建立 HBGV**（仅可用于 MOE 类风险表征）；BMR 及其不确定性须书面说明 | 同上，**p.25** |
| 1-15 | 模型适配前须先判**数据是否适于建模**（不满足则不可用 DRM）；分级与连续数据的响应量纲（百分率/SD 倍数/绝对值）决定 BMR 定义方式 | 同上，**p.23–24** |

> **对应工具**：`riskcalc.py hbgv --pod <BMDL> --uf 100`（条目 1-1/1-5）；`riskcalc.py sens --pod` 用于 BMDL10/BMDL05 敏感性比较（1-11/1-12）。

## 二、膳食暴露评估（WHO/FAO EHC 240 更新版 Ch6，2020）

| # | 证据条目 | 出处 |
|---|---|---|
| 2-1 | 膳食暴露基本式：**暴露 = Σ（食物中化学物浓度 × 食物消费量）**；结果可按单位体重换算以便跨人群比较 | EHC 240 Ch6，书库 **p.13** |
| 2-2 | "高消费个体"可用 **90/95/97.5/99 百分位**表示（消费者-only 或全人群分布）；样本量不足以稳健估计高分位数时，应**退让到较低分位（90 或中位数）** | 同上，**p.19** |
| 2-3 | 无个体记录时可用**膨胀因子**估高分位消费量：**2×均值≈P90，2.5×均值≈P95，3×均值≈P97.5**（WHO, 1985） | 同上，**p.19** |
| 2-4 | **规律消费者（brand-loyal）**：以消费者分布的**中位数/均值**表征，用于同一品牌/来源持续高浓度情形 | 同上，**p.19** |
| 2-5 | 方法选择采用**分级（tiered/stepwise）策略**：第一级用最少资源做筛查级估计，仅在需要精化时逐级加码 | 同上，**p.20–21** |
| 2-6 | **急（ARfD 相关）暴露**的浓度端值取分布高端：**97.5 百分位**（数据点不足则退到 90/95 百分位）；仅有集中趋势（均值/中位数）的监测数据**不适合**急性暴露评估 | 同上，**p.34** |
| 2-7 | **混合样（composite/pooled）**不能可靠反映单件食品最高残留，需施以**变异性因子（variability factor）**校正；已有个体分布数据时**不必**再施加（EFSA, 2019d） | 同上，**p.34** |
| 2-8 | **IESTI/NESTI**：自 1997 年（WHO 咨询）开发、JMPR 自 1999 年起应用；按**单个作物分别计算**，因同一餐/24 h 内不太可能对两种作物同时取大份量并以最高残留摄入；"大份量"＝**单人单日消费的 97.5 百分位**，多日记录不作个体平均 | 同上，**p.102–103** |
| 2-9 | **IESTI 三种情形**：**Case 1** 单位重 <**0.025 kg**（豌豆、葡萄等）或动物产品/谷物/油籽/豆类采后处理；**Case 2** 单件可能高于混合样——**2a** 单位重 < 大份量（苹果）、**2b** 单位重 > 大份量（西瓜）；**Case 3** 加工品经过散装/混合（乳、面粉、植物油、果汁）以 **STMR** 为代表值 | 同上，**p.103** |
| 2-10 | **默认变异性因子 = 3**：JMPR 2004 结论——因抽样与分析不确定性叠加的随机性，最佳默认值为各作物 VF 的均值；该值自 2003 年起被 JMPR 采用，仅用于 **Case 2a/2b** 公式；方程见 FAO/WHO 2013 | 同上，**p.103–104** |
| 2-11 | 国际层面委员会做评估时，如大份量与浓度数据来自多国，宜使用**各国产量调查的平均体重** | 同上，**p.103** |
| 2-12 | **GEADE**（全球估计急性膳食暴露，Boobis et al. 2017）：`GEADE = 97.5 百分位食物消费量（单人单日）× 各相关组织中最高残留 / 体重(kg)`；兽药 ARfD 少，但可按 IESTI Case 1（动物产品）/Case 3（乳品）做点估计 | 同上，**p.104** |
| 2-13 | 兽药残留评估还须考虑**生物可给性/生物可利用性**，以及注射部位残留；JECFA 与 CCRVDF 正在制定以微生物终点为基准的 ARfD 的注射部位残留指南 | 同上，**p.104** |
| 2-14 | **LOD/LOQ 以下结果的三种处理**：①置 0（**下界**估计）②置 LOD/LOQ（**上界**估计）③置其一半（**中界**估计，假定真值在 0–LOD/LOQ 均匀分布）；建议同时呈现三种并用于**敏感性分析** | 同上，**p.74–75** |
| 2-15 | **混合（hybrid）策略**（USEPA/USFDA）：某食品长期无检出则 <LOD 记 0；曾至少检出一次则 <LOD 记 ½LOD（或 LOD） | 同上，**p.75** |
| 2-16 | 左删失比例高时，替代值会显著影响均值与标准差；对"很可能存在"的物质（天然污染物、营养素）**应同时计算均值的双界**，二者差即该统计量的不确定性表达；若下界＜HBGV 而上界＞HBGV，**优先改用更灵敏方法的数据**，否则交由专家判断 | 同上，**p.75–76** |
| 2-17 | 删失数据可用**最大似然估计（MLE）或顺序统计量回归（ROS）**拟合均值/标准差，但多数方法要求假定分布形态 | 同上，**p.76** |
| 2-18 | **残留定义**：农药/兽药的**执法残留定义（以标志物为基准）常不同于风险评估所需定义**；向 JMPR/JECFA 提交的定义可不同（并涉及 ADI/ARfD 计算基础） | 同上，**p.31** |
| 2-19 | **加工因子**＝加工后浓度/加工前浓度之比（农药残留领域亦称 PF）；与通用浓缩/稀释因子、食品转化因子并列；单一国家推导的转化因子不应在国际评估中通用，除非有证据适用于所有纳入国家 | 同上，**p.73–74** |
| 2-20 | 食物消费数据来源体系：FAO 供给利用账户、**GEMS/Food 集群膳食（cluster diets）**、国家膳食调查、WHO GEMS/Food 份量数据库、GEMS/Food 污染物数据库（含递交国的"indicative value"元数据） | 同上，**p.4–6 目录、p.75** |
| 2-21 | **TTC 场景下暴露侧的四条口径（EFSA 食品侧 TTC 指南 §4.2，与条目 3-10/毒理 C-15 配套）**：①慢性暴露用常规膳食暴露评估方法，取结果的**分布高端（upper end of the distribution）**；②必须检查**亚群**——婴幼儿/儿童按体重计的膳食暴露常更高；③若结构提示**急性毒性**，须算**急性暴露（≤24 h）**，用**高百分位浓度值 × 高百分位消费量**；**数据不足以计算高百分位时，改用"报告的最大值"以保保守**；④先定暴露时长；未超过相关 TTC → "不良健康效应的概率低"，**超过 → 须专家判断是否需要改用非 TTC 途径** | EFSA. Guidance on the use of the Threshold of Toxicological Concern approach in food safety assessment. EFSA J 2019;17(2):e05708. DOI 10.2903/j.efsa.2019.5708 **PMC7009090** §4.2；全文 `公共知识/书库/papers/txt/PMC7009090.txt` |
| 2-22 | **暴露参数的地区差异必须交代来源（不可跨国照搬）**：儿童**土壤摄入率（SIR）中位数**——中国 **171.5 mg/d**、美国 **100 mg/d**、加拿大 **32.0 mg/d**（同一计算途径下差异归因于**生活方式**）；且同一地区不同**示踪法/年龄**取值不同。⇒ 用他国暴露因子（如 US EPA EFH）算中国人群暴露时，须注明参数来源与适用性，并做敏感性分析 | Quantitative Assessment of Environmental/Human Health Risks. MDPI Books, 2022（Book id 6396，CC BY 4.0）. 公共知识/书库 **p.67** |

## 三、TTC 与"无 HBGV 可用"时的风险表征（EHC 240 §4.5、§9.1.4.2 + EFSA/文献）

| # | 证据条目 | 出处 |
|---|---|---|
| 3-1 | **TTC 决策树（WHO 2015a 改编）**逐级判定：DNA 反应性致突变**0.0025 µg/kg bw/d（60 kg 成人＝0.15 µg/人/d）**→ 磷 carbamate/有机磷（AChE 抑制）**0.3 µg/kg bw/d（18 µg/人/d）**→ Cramer class III **1.5 µg/kg bw/d（90 µg/人/d）**→ class II **9 µg/kg bw/d（540 µg/人/d）**→ class I **30 µg/kg bw/d（1800 µg/人/d）**；低于对应阈值即"不视为安全性关切"，高于则"仅在有化学特异毒性数据时方可评估" | WHO/FAO EHC 240（2020 更新）§4.5 图，书库 **p.78** |
| 3-2 | DNA 反应性层 **0.0025 µg/kg bw/d** 由 Kroes 等 2004 提出，基于 **>730 种致癌物致癌 potency 分布**；该层假定终生每日暴露，短时程可支持更高暴露（Felter 2009；Dewhurst & Renwick 2013），药品杂质领域已被 ICH M7(2017) 采纳；Cefic-LRI 2020/Boobis 2017 正在更新该数据库 | 同上，**p.67** |
| 3-3 | 低于 TTC 的摄入量对应"**风险可忽略**"：终生癌症风险不超过 **1×10⁻⁶**，且该摄入量比后续各层（步骤 13/15/16/17）阈值**低 100 倍以上** | 同上，**p.78** |
| 3-4 | "基因毒层（genotox tier）"归属依据＝现有致突变试验数据 + **结构警示**（Toxtree、OECD QSAR Toolbox、Derek Nexus 等实现）；Ames 阳性致癌物平均强于 Ames 阴性（USFDA 评估） | 同上，**p.67** |
| 3-5 | **无 HBGV 可用时改用 MOE**：对遗传毒性+致癌性物质，理论上任何暴露都可能致瘤，故**不建立 HBGV**，以 MOE 做风险表征（EFSA SC 2005/2025） | EFSA. Update of the risk assessment on emerging and novel brominated flame retardants (BEH-TBB, BEH-TEBP, DBDPE). EFSA J 2026. **PMC13403159** §Assessment |
| 3-6 | **MOE 基准 100 的构成**：种间变异 10（＝**TK 4 × TD 2.5**）× 种内变异 10；数据库不足另加 **3（LOAEL→NOAEL）× 5（数据缺口）** ⇒ 该意见对 BEH-TBB/BEH-TEBP 取 **MOE ≥ 1500** 为"不产生健康关切"，对 DBDPE（关键效应数据较充分）取 **MOE ≥ 300** | 同上，**PMC13403159** §Assessment / Table 12–13 |
| 3-7 | 食品添加剂/加工助剂（酶）评估工作例：以 90 天大鼠 NOAEL（最高剂量组 1800 mg TOS/kg bw/d）÷ 暴露上界（P95 4.673 mg TOS/kg bw/d）⇒ **MOE ≥ 385**，判定无安全关切；另一酶以 NOAEL 866 ÷ P95 1.368 ⇒ **MOE ≥ 633** | EFSA. Safety evaluation of the food enzyme aspergillopepsin I（EC 3.4.23.18）. EFSA J 2026. **PMC13624930**；endo‑1,3(4)‑β‑glucanase **PMC13352140** |

## 八、快速核对清单（把本文件"用起来"的五条纪律）

1. **先分层，再定量**：判定危害→选 POD（优先 BMDL；分级 BMDL10 / 连续 BMDL05，条目 1-11/1-12）→定 UF（默认 100，逐项论证 4×2.5 / 10 / 附加 2–10，条目 1-5/1-8/3-6）→算暴露（P97.5 大份量、IESTI Case、上下中界，条目 2-8/2-9/2-14）→表征（HBGV 用 HQ、无 HBGV 用 MOE/TTC，条目 3-1/3-5/3-6）。
2. **报告双界与敏感性**：删失数据必须给 lower/upper（或 mid）双界与结论是否翻转（条目 2-14/2-16）；不确定性须以概率语言输出（条目 4-1/4-2/4-3）。
3. **数值不臆造**：任何 ADI/ARfD/MRL/GB 限量以官方现行值为准（本文件条目 3-7/5-1…5-3 是**个案 EFSA 结论**，不得移植到别的物质）。
4. **"通行标尺"先核库再用，引用必须带条件**：口头常用的 **MOE ≥ 10 000** 现已入库核实（EFSA SC 2025，*EFSA J* 23(8):e9606，条目 **3-11/3-12/3-13**），但它**只在"RP ＝ 动物研究 BMDL₁₀ ＋ 考虑总体不确定性"时成立**，且属**风险管理优先级**判断、**不排除减排措施**——把 10 000 当"安全倍数"或"合规线"即为误用。库内**仍未核实**的通行值，引用时须给出处或注明"**非本库核实、以现行官方意见为准**"。药品侧 **ICH M7 的 LTL 分档建立在 1×10⁻⁵** 风险基准与患者风险-获益上（**分档表已核 ICH M7(R2) 一级文本**：单杂质 Table 2＝**120/20/10/1.5**、多杂质 Table 3＝**120/60/30/5 µg/day**），与食品 DNA 反应层的 **1×10⁻⁶** 基准**不可互借**（条目 **6-6**，毒理 **C-17/C-21**）。
5. **QMRA 与化学风险评估不得互相套用**：条目 **5-8～5-12** 属**微生物**定量风险评价分支（生长模型参数、DR 模型版本、MCSS 概率化）；病原体的"感染概率"不得当作化学物的致癌风险相加，化学侧的 ADI/ARfD/MOE 口径也不适用于活菌危害——两条线共用**框架**（四步法、概率建模、敏感性分析），**不共用参数**。
