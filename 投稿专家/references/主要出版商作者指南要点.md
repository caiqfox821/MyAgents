# 主要出版商作者指南要点

> 用途：快速定位出版商级共性要求与查询入口。
> **警告**：以下仅为共性摘要，**不构成精确规则**。字数、格式、声明、模板等一律以目标期刊官网现行 Guide for Authors 为准，本文件不得作为最终依据。

## 一、查询入口（一级来源）

| 出版商 | 作者指南入口 |
|---|---|
| Elsevier | <https://www.elsevier.com/authors>（各刊 Guide for Authors） |
| Springer Nature | <https://www.springer.com/gp/authors-editors> |
| Wiley | <https://authorservices.wiley.com> |
| IEEE | <https://journals.ieeeauthorcenter.ieee.org> |
| Taylor & Francis | <https://authorservices.taylorandfrancis.com> |
| Frontiers | <https://www.frontiersin.org/guidelines/author-guidelines> |
| MDPI | <https://www.mdpi.com/authors> |
| Oxford / Cambridge | 各刊 Instructions to Authors |
| DOI 核验 | <https://www.crossref.org> |

## 二、常见共性要求（示例，须核验）

| 维度 | 常见要求 |
|---|---|
| 摘要 | 字数上限（常见 150–300 词）、是否结构化 |
| 关键词 | 常见 3–8 个 |
| Highlights | 部分刊要求 3–5 条、限字符 |
| Graphical Abstract | 部分刊选填或必填，有尺寸/格式要求 |
| 参考文献 | 编号制或作者-年份制，样式因刊而异 |
| 图表 | ≥300 dpi、TIFF/EPS/PDF、标题位置、单独上传 |
| 声明 | Data Availability、Conflict of Interest、Author Contributions、Ethics、Funding |
| 语言 | 英式/美式一致；语言不过关可能被退 |
| 投稿文件 | Cover Letter、正文、图表、补充材料是否分开 |
| 盲审 | 是否单/双盲，匿名化要求 |

## 三、文章类型

- 常见类型：Research Article、Review、Short Communication、Case Report、Perspective、Letter。
- 不同文章类型对字数、图表数、摘要格式要求不同，须分别核对。

## 四、开放获取与费用

- 区分订阅制 / 混合 / 完全 OA；APC 费用与许可（CC BY 等）以期刊页面为准。
- 基金/机构对 OA 的要求由作者确认。

## 五、使用方式

1. 先按期刊名定位官网 Guide for Authors。
2. 按本目录 `期刊规则Schema与检查类型.md` 抽取规则并绑定来源。
3. 出版商级页面仅作导航与共性参考，**不与官网冲突时以官网为准**。
