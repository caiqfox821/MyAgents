# 投稿材料模板与写作指南

> 用途：按期刊规则生成规范、克制、可核验的投稿材料。
> 总原则：语气正式简洁；不夸大结论、不编造数据/作者/DOI/页码/卷期；缺失信息用占位符。

## 一、Cover Letter

**结构**
1. 抬头与日期，致 Editor-in-Chief / 对应编辑。
2. 稿件标题、文章类型、投稿期刊。
3. 研究贡献与创新点（2–4 句，紧扣期刊范围）。
4. 与期刊的匹配性（为什么适合本刊读者）。
5. 声明：未一稿多投、全体作者同意、无利益冲突、数据真实。
6. 推荐/回避审稿人（占位符），通讯作者信息。
7. 结尾致谢。

**约束**：不承诺录用；不吹嘘"首次/重大突破"；推荐审稿人不得虚构。

## 二、Highlights

- 通常 3–5 条，每条遵守期刊字符限制（常见 ≤ 85 字符，以官网为准）。
- 每行一个完整要点，聚焦新方法/新发现/新应用，避免笼统。
- 使用动词开头，量化关键结果（不臆造数值）。

## 三、Graphical Abstract 说明

- 期刊要求时给**文字版设计建议**：核心流程/机理/结论的单图表达。
- 标注尺寸与分辨率要求（以官网为准），建议配色与元素布局。

## 四、声明类材料

| 声明 | 内容 | 注意 |
|---|---|---|
| Data Availability Statement | 数据存放位置、访问方式、限制 | 按作者选择生成不同版本；不虚构仓库/编号 |
| Conflict of Interest | 有无利益冲突 | 据实填写；无则声明 None |
| Author Contributions | 各作者贡献（CRediT 分类） | 由作者确认，不代填署名 |
| Funding | 基金名称与编号 | 用占位符，不编造 |
| Ethics Statement | 伦理审批与知情同意 | 真实性由作者负责 |
| Acknowledgement | 致谢对象与许可 | 不虚构 |

## 五、Response to Reviewers

**结构**
1. 总述：感谢意见，说明修改概况。
2. 逐条回复：原文意见 → 回复 → 修改说明 → 修改位置（页码/行号/章节）。
3. 未采纳意见：说明理由，保持尊重。

**原则**：逐条不遗漏；回复与修改一致；不争辩、不敷衍；标注修改位置便于核对。

## 六、Prompt 设计要点

> 你是一名外文期刊投稿编辑助手。请根据以下期刊作者指南规则和稿件内容，生成一份 Cover Letter。要求语气正式、简洁，不夸大结论，不编造数据，不虚构作者信息。如果某些信息缺失，用占位符标记，例如 [Corresponding Author]、[Funding Information]。

每个 Prompt 都加约束：
- 不编造 DOI、页码、卷期
- 不虚构作者、基金、伦理审批
- 不承诺录用
- 不确定规则必须标注来源
- 修改必须保留原文对照

## 七、待核实清单

- [ ] 各期刊 Highlights 字符上限与条数
- [ ] CRediT 作者贡献分类的完整定义
- [ ] 目标期刊对 Graphical Abstract 的尺寸/格式要求
- [ ] 常见数据仓库（如 Zenodo、Figshare）的引用规范
