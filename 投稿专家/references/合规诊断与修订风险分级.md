# 合规诊断与修订风险分级

> 用途：规范"诊断—修订—留痕—确认"闭环，确保每条改动可追溯、可回滚。

## 一、诊断流程

1. 读取期刊规则（含版本、来源）。
2. 读取稿件结构对象。
3. 逐条执行检查（`word_count` / `count` / `exists` / `regex` / `enum` 等）。
4. 生成诊断报告：规则、状态、说明、依据来源。

## 二、诊断报告示例

| 规则 | 状态 | 说明 |
|---|---|---|
| 摘要 ≤ 250 词 | 不合规 | 当前 312 词，需压缩 62 词 |
| 需要 Highlights | 缺失 | 稿件未提供 Highlights |
| 参考文献编号制 | 不合规 | 当前为作者-年份制 |
| 需要 Data Availability Statement | 缺失 | 未找到数据声明 |
| 图片分辨率 ≥ 300 dpi | 待确认 | 需用户上传原始图片文件 |

## 三、诊断等级

| 等级 | 含义 | 处理 |
|---|---|---|
| `must` | 必须修改，否则可能退回 | 强制提示，优先处理 |
| `should` | 强烈建议修改 | 建议采纳 |
| `optional` | 可选优化 | 供参考 |
| `uncertain` | 规则不明确 | 提请作者确认，标注来源 |

## 四、修订风险分级

### 低风险（可自动，仍需留痕）
- 参考文献格式转换
- 摘要字数压缩
- 关键词数量调整
- 标题大小写规范
- 英式/美式拼写统一
- 单位、符号、p 值格式统一
- 图表标题格式规范化
- 声明段落补全模板

### 中风险（半自动，需确认）
- 摘要重写
- Highlights 生成
- Graphical Abstract 文字说明
- Cover Letter 生成
- 段落顺序调整
- 引言逻辑压缩

### 高风险（只给建议，由作者决定）
- 方法部分改写
- 结果解释
- 结论强度
- 作者署名
- 伦理声明真实性
- 数据可用性描述

## 五、修订留痕

```json
{
  "change_id": "C001",
  "type": "reference_format",
  "original": "[1]",
  "revised": "(Smith et al., 2023)",
  "reason": "Food Control 采用 APA 第 7 版作者-年份制引用（官方 Guide，2026-10-05）",
  "risk": "low",
  "accepted": false
}
```

字段说明：`change_id` 唯一编号；`type` 变更类型；`original`/`revised` 原文对照；`reason` 依据（含规则来源）；`risk` 风险等级；`accepted` 是否被采纳（默认 false，待确认）。

## 六、回滚与确认

- 所有改动基于原文副本，保留原值，可一键回滚。
- 低风险自动修订也须用户确认后再定稿。
- 高风险修订只生成建议清单，不直接写入稿件。

## 七、交付前自检

- [ ] 每条诊断绑定规则来源与版本
- [ ] 每条改动有原文对照、理由、风险等级、采纳状态
- [ ] `uncertain` 项已提请确认
- [ ] 高风险项未擅自修改
- [ ] 修订记录随稿导出
