## 二、来源与可靠性说明

- **一级（权威）**：目标期刊官网 Guide for Authors、出版商 Author Hub、Crossref/DOI、COPE 出版伦理规范、ICMJE 作者与利益冲突规范。
- **二级（参考）**：第三方期刊数据库、投稿经验帖、机构投稿指南；仅作检索线索，最终规则须回归官网核验。
- 抓取内容须记录 `source_url`、抓取时间与版本号；官网与第三方冲突时**以官网为准**。

## 三、收录原则与核验约定

- 期刊作者指南属公开信息，可缓存摘要与规则条目，但**须标注来源 URL 与抓取时间**，并按 TTL 刷新。
- 不抓取付费墙后内容，不存储论文全文版权内容；遵守 `robots.txt`。
- 涉及字数、格式、伦理条款等精确要求时，先核对官网现行版本；无法访问时请用户粘贴指南文本并注明访问日期。
