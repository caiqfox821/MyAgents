# 投稿专家模板

放置可复用的投稿材料与检查模板（占位符用 `[...]` 标记，不得编造内容）。

- `Cover-Letter-template.md`：Cover Letter 结构模板
- `Response-to-Reviewers-template.md`：审稿意见逐条回复模板
- `投稿前检查清单-template.md`：提交前合规与伦理自检清单

后续可补充：
- Highlights 模板（含字符限制校验）
- Data Availability / Conflict of Interest / Author Contributions 声明模板
- Graphical Abstract 文字说明模板
- 期刊规则缓存条目模板（对应 `references/期刊规则Schema与检查类型.md`）
- 盲审版本匿名化检查表
