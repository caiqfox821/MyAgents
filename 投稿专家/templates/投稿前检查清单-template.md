# 投稿前检查清单模板

> 用法：投前逐项核对；每项标注依据（期刊规则来源）与状态。

## 一、期刊规则与来源
- [ ] 目标期刊全称 / ISSN / 出版商已确认
- [ ] Guide for Authors 已获取，记录 URL 与抓取时间
- [ ] 所用规则版本已记录

## 二、稿件结构
- [ ] 文章类型匹配（Research / Review / …）
- [ ] 标题、作者、单位、通讯作者完整
- [ ] 摘要符合字数与结构要求
- [ ] 关键词数量符合要求
- [ ] Highlights / Graphical Abstract（如要求）齐备
- [ ] 正文字数符合限制

## 三、格式与图表
- [ ] 参考文献样式符合（编号制 / 作者-年份制）
- [ ] 正文引用与文末列表一致，无缺项
- [ ] 图片格式与分辨率达标，标题位置正确
- [ ] 表格规范，编号连续
- [ ] 单位、符号、p 值格式统一
- [ ] 拼写风格（英式/美式）统一

## 四、声明与伦理
- [ ] Data Availability Statement
- [ ] Conflict of Interest Statement
- [ ] Author Contributions（CRediT）
- [ ] Funding
- [ ] Ethics / Consent（如适用）
- [ ] 无数据造假、无一稿多投、无虚构作者/审稿人

## 五、投稿文件与系统
- [ ] Cover Letter
- [ ] 正文、图表、补充材料按要求分开上传
- [ ] 盲审版本匿名化（如适用）
- [ ] 推荐/回避审稿人（如要求）
- [ ] 文件命名符合要求

## 六、修订留痕
- [ ] 所有改动有原文对照与理由
- [ ] 高风险项由作者确认
- [ ] 修订记录随稿归档

> 精确字数、格式与伦理条款以目标期刊官网现行 Guide for Authors 为准。
