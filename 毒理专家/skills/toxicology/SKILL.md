# 毒理学证据与危害表征技能

## 何时使用

- 需要**判定毒性证据**：某物质是否具有某类毒性、证据强度如何。
- 需要**推导健康指导值**：ADI/TDI/ARfD/PTWI 及其 UF 论证。
- 需要**做 BMD 建模**与模型选择/平均。
- 需要**关键效应判定**：不良 vs 适应性改变、最敏感终点。
- 需要**数据不足时的决策**：TTC、(Q)SAR、read-across。
- 需要**试验方案或数据质量评价**：OECD TG、GLP、Klimisch 分级。
- 需要**解读毒理报告/审评意见**。

**不适用（转交）**：
- 算暴露、算 HQ/MOE、做概率评估 → 公共技能 `risk-assessment`。
- 判 GB 限量合规、HACCP、处置建议 → 食品安全专家。
- 实测浓度与代谢物鉴定 → 检测/质谱专家。

## 六条硬规则

1. **可靠性先于结论**：每个关键研究先做可靠性分级（Klimisch 1~4）。3/4 级研究不得单独支撑 HBGV。
2. **区分不良与适应性**：肝酶升高、脏器重量变化可能是适应性；把适应性当关键效应会过度保守，反之会低估风险。此判断必须写明理由。
3. **NOAEL 不是首选**：有剂量-反应数据时优先 BMD/BMDL；用 NOAEL 须说明为何（数据点不足、模型不可识别）。
4. **UF 要论证，不要叠乘**：默认 100 倍是起点不是答案；每个子系数给依据；禁止"为稳妥再乘 10"。
5. **不得臆造数值**：ADI、TTC 阈值、TG 编号、IARC 分组必须核对现行版本并注明出处；不确定写"待核实"。
6. **区分动物剂量与人等效剂量**：跨种比较须做剂量校正（mg/kg bw/d、体表面积、PBTK）；不得把动物剂量直接当人剂量。
7. **HBGV 命名与用途一致**：农药/兽药/添加剂（有意使用）→ **ADI**；不可避免的污染物 → **TDI/PTWI/PTMI**；急性 → **ARfD**。不得把农药的指导值写成 TDI，也不得用 ARfD 代替 ADI。
8. **剂量组不足时表述要一致**：若判定"3 个剂量组不足以稳定拟合 BMD"，就**不得**同时称"BMD 可用"；结论须二者择一并给理由。
9. **引用必带页码或 PMCID**：凡给出 POD/BMR/UF/TTC/数据要求类结论，先查 `references/证据条目与出处.md` 的条目（T-/G-/E-/R-/N-/C-/A-），并**沿用其原始出处写法**——指南 `EHC 240 Ch5 书库 p.48`、文献 `PMC12871449 §Abstract`、专著 `Feature Papers in Drug Toxicity 书库 p.133`；条目未覆盖则回 `公共知识/书库/` 取证，不得臆造数值或章节号。

## 工作流

```
1 问题界定 → 2 证据检索与分级 → 3 关键效应 → 4 POD → 5 HBGV 或 MOE → 6 缺口与建议
```

### 1. 问题界定

| 要素 | 内容 |
|---|---|
| 物质 | 名称、CAS、异构体/盐型、纯度、相关代谢物 |
| 暴露 | 途径（口服/吸入/皮肤）、时长（急性/亚慢性/慢性）、人群 |
| 关注终点 | 遗传毒性/致癌/生殖发育/靶器官/致敏/内分泌 |
| 用途 | 筛查 / 推导 HBGV / 复核 / 试验设计 / 申报 |

### 2. 证据检索与分级

优先级：权威评估结论（JECFA/JMPR/EFSA/IPCS/IARC/IRIS/CFSA）→ GLP+OECD TG 原始研究 → 非规范研究 → 体外/计算毒理。

| Klimisch | 含义 | 用途 |
|---|---|---|
| 1 | 可靠（GLP/等效规范，方法充分） | 可支撑关键决策 |
| 2 | 基本可靠（有缺陷但不致命） | 可辅助，需说明局限 |
| 3 | 不可靠 | 仅参考，不支撑结论 |
| 4 | 无法评价（信息不足） | 不采用 |

### 3. 关键效应

候选排序依据：① 敏感性（最低剂量出现）；② 不良性（可逆？进展性？）；③ 与人类相关性（途径、代谢、机制）；④ 严重度。

**常见判断陷阱**：
- 把药理作用当毒性（如降压药的降压效应）。
- 把适应性诱导（肝 CYP 诱导、甲状腺激素清除增加）直接当不良。
- 忽略性别/品系差异导致的"最敏感组"。
- 只盯一个终点，漏检更敏感的终点（如仅看体重，漏看神经行为）。

### 4. POD

见 `references/02-剂量反应建模与健康指导值.md`。要点：

```
BMD 四步：定 BMR → 选模型族 → 拟合与比较 → 取最低 BMDL
BMR：连续资料 5%；动物二分资料常用 10%；人群大样本可用 1%
模型比较：似然比检验（对数似然差 > 1.92 ↔ P<0.05）+ 拟合优度 + 与全模型比较
多模型分歧 → 模型平均（model averaging）
```

### 5. HBGV 或 MOE

| 情形 | 产出 |
|---|---|
| 有阈值、关键效应明确 | ADI/TDI/ARfD = POD / UF |
| 无阈值（遗传毒性致癌等） | BMDL₁₀ + 用 MOE 表征（暴露侧交 `risk-assessment`） |
| 数据不足、结构无警示、暴露低 | TTC 筛查 |
| 数据完全缺失且有结构警示 | 不建议评估 → 提试验方案 |

### 6. 缺口与建议

明确列：缺哪个终点、缺什么剂量水平、缺哪种物种/途径、现有数据能否外推到关注人群。给出**最低必要试验组合**（避免"全套毒理"式浪费）。

## 输出规范

每条关键结论写成可核验的三元组：

```
【终点】遗传毒性（基因突变）
【结果】Ames 试验阴性（TA98/TA100/TA1535/TA1537，±S9）
【出处】OECD TG 471，GLP，报告编号 XXX，年份
【可靠性】Klimisch 1
【判定】不提示基因突变风险
```

**禁止**：只写"经评估安全"而不给终点、剂量与出处。

## 与 `risk-assessment` 的接口

| 本技能给 | 对方给 |
|---|---|
| POD（BMDL/NOAEL）及出处 | 暴露量（EDI/ESTI/IESTI） |
| HBGV（ADI/TDI/ARfD）及 UF 论证 | HQ/%ADI/超限概率 |
| 剂量-反应关系（无阈值物质） | MOE 计算与解读 |
| TTC 阈值与适用性判断 | 暴露是否接近阈值 |
| 证据权重与不确定性（毒理侧） | 暴露侧不确定性与敏感性 |

> 两侧**不得互相替代**：毒理不代算暴露，暴露不代判毒性。

## 交付前自检

- [ ] 物质标识完整（CAS、异构体、代谢物）
- [ ] 关键研究有可靠性分级
- [ ] 关键效应与适应性改变已区分并说明理由
- [ ] POD 类型与取值有出处；BMD 有模型比较
- [ ] UF 逐项论证（或引用机构论证）
- [ ] HBGV 标机构+年份+版本，或明确"自行推导"
- [ ] 动物剂量与人等效剂量已区分
- [ ] 数据缺口与最低必要试验已列
- [ ] 未把毒理结论外推为"合规"或"安全无风险"
