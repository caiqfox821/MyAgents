# 02 · 剂量-反应建模与健康指导值

> 依据：CFSA《食品中化学物健康指导值制定指南》（2023）、WHO/FAO EHC 240 Ch.5（2020 更新）、EFSA 关于 BMD 与 UF 的意见、US EPA BMDS 用户手册、RIVM PROAST 文档、JECFA/JMPR 实践。
> 具体数值（如某物质 ADI）**不在本文件**，须查权威评估报告并注明版本。

---

## 一、POD 的选择逻辑

```
有剂量-反应数据
   ├─ 数据点 ≥ 3 个剂量组、方差可估 → BMD 建模（首选）
   │     └─ 模型不可识别/拟合失败 → 退 NOAEL，说明理由
   ├─ 只有 NOAEL/LOAEL 报告值（文献二手） → NOAEL + 额外 UF
   └─ 无任何剂量-反应（仅病例/体外） → 不可定 POD → TTC/试验方案

POD 用途
   ├─ 有阈值 → HBGV = POD / UF
   └─ 无阈值 → 保留 BMDL（如 BMDL₁₀）供 MOE
```

---

## 二、NOAEL / LOAEL

| 项 | 定义 | 使用条件 |
|---|---|---|
| NOAEL | 未观察到不良作用的最高剂量 | 剂量设计合理、样本量足够、终点覆盖充分 |
| LOAEL | 观察到不良作用的最低剂量 | 无法得 NOAEL；须加额外 UF（通常 2~10） |
| NOEL | 未观察到**任何**作用的最高剂量 | 不等于 NOAEL（可能含适应性改变） |

**NOAEL 的三重依赖**（务必在报告中说明）：

1. 依赖**剂量间隔**：间隔越宽，NOAEL 越高（越不保守）。
2. 依赖**样本量**：样本小 → 检出效能低 → NOAEL 偏高。
3. 依赖**终点选择**：漏检终点 → NOAEL 偏高。

> 因此 JECFA/JMPR 已将 BMD 作为首选；用 NOAEL 时应解释为何不能建模。

## 三、BMD 建模（核心）

### 3.1 概念

| 术语 | 含义 |
|---|---|
| BMR | 基准反应水平（benchmark response），相对背景的特定改变量 |
| BMD | 引起 BMR 的剂量（点估计） |
| BMDL | BMD 的 95% **单侧**可信限下限 |
| BMDU | 上限（一般报告但不作 POD） |

### 3.2 BMR 选择

| 数据类型 | 默认 BMR | 说明 |
|---|---|---|
| 连续（计量）资料 | **5%**（相对背景均值或相对范围） | CFSA 默认；EFSA 常用 5% |
| 动物二分（计数）资料 | 1% / 5% / **10%** | 10% 最常用（统计效能足够） |
| 人群二分资料（样本量大） | 1% | 更保守 |

**BMR 与 BMDL 的关系**：BMR 越小，BMDL 越小（越保守），但统计不确定性越大（置信区间变宽）。**不得为"更好看"而调高 BMR。**

### 3.3 四步实操

```
第1步 数据检查
  - 剂量组数 ≥ 3（含对照）；每组样本量；方差是否齐性
  - 连续数据：个体值（优于仅均值±SD）
  - 二分数据：每组的 n 与事件数

第2步 选模型族
  连续：Hill、Power、Linear、Exponential、Polynomial（BMDS 的连续模型族）
  二分：Gamma、Logistic、Log-Logistic、Probit、Log-Probit、Weibull、Multistage、Dichotomous Hill
  嵌套/非嵌套视模型关系而定

第3步 拟合与模型选择
  - 拟合优度：p > 0.1（BMDS 常用判据，非绝对）
  - 似然比检验：增加参数是否显著改善（对数似然差 > 1.92 ↔ P<0.05）
  - 与"全模型（full model）"比较，无显著差异者纳入候选
  - 剔除：拟合差、参数不可识别、BMDL 远低于最低试验剂量且曲线不合理

第4步 取 BMDL
  - 候选模型中取**最低 BMDL**作为该数据集 POD
  - 多数据集（多终点/多物种/多性别）→ 取最低 BMDL，并结合生物学判断关键效应
  - 各终点 BMDL 相差 > 1 个数量级 → 回查数据/模型/BMR
```

### 3.4 模型平均（model averaging）

当多个模型均通过检验且 BMDL 差异显著时，按 AIC 权重加权（BMDS 与 PROAST 均支持）。**报告须列出参与平均的模型与权重。**

### 3.5 常见错误

| 错误 | 后果 |
|---|---|
| 只用默认模型（不比较） | POD 偏移，可能不保守 |
| 连续数据用 10% BMR | 不够保守 |
| 忽略方差异质性 | 权重错，BMDL 失真 |
| 数据点太少仍强行建模 | 不可识别，结果不可信 |
| 把"最低 BMDL"当"最敏感终点" | 概念混淆（统计 vs 生物学） |
| 未报告 BMDU | 无法判断不确定性宽度 |
| 用不同软件结果混用不说明 | 不可复现 |

### 3.6 工具

| 工具 | 来源 | 特点 |
|---|---|---|
| **BMDS**（Benchmark Dose Software） | US EPA | 免费、Windows、模型族全、支持模型平均 |
| **PROAST** | RIVM（R 包 / 网页版） | 支持协变量、嵌套模型、模型平均 |
| **drc / nls**（R） | CRAN | 灵活，需自行实现 BMDL |

> 报告须写明：软件与版本、模型、BMR、拟合优度、BMD/BMDL/BMDU、是否模型平均。

## 四、健康指导值（HBGV）

### 4.1 类型与适用

> **命名纪律**：农药/兽药/食品添加剂（有意使用）→ **ADI**；不可避免的污染物 → **TDI**；蓄积性 → **PTWI/PTMI**；急性 → **ARfD**。混用 ADI/TDI 属实质错误（同一物质两类值可能不同）。

| 类型 | 适用 | 时间尺度 | 备注 |
|---|---|---|---|
| ADI | 有意使用的化学物（添加剂、农兽药） | 终生每日 | — |
| TDI | 不可避免的污染物 | 终生每日 | — |
| PMTDI | 有蓄积性 | 每日 | "暂定/maximum"现多主张不再用 |
| PTWI | 蓄积、半衰期较长 | 每周 | 如铅 |
| PTMI | 蓄积强、半衰期长 | 每月 | 如镉 |
| ARfD | 有急性毒性 | 24 h 内 | 与 ADI 并列，不可互替 |

### 4.2 推导

```
HBGV = POD / UF_overall
```

**报告必须写**：POD 类型与值、UF 各子系数及依据、最终 HBGV、数据充分性、是否"暂定"。

### 4.3 ARfD 的特殊性

- ARfD 基于**急性**毒性终点（如神经毒性、急性胃肠损伤），不是 ADI/10。
- 需有单次给药的剂量-反应数据；无则不能设 ARfD。
- 与 ADI 可能相差数量级，**不可互相替代**。

## 五、不确定系数（UF）

### 5.1 默认分解

```
UF_overall = UF_A（种间）× UF_H（种内）× UF_S（其他）
            = 10 × 10 × 1 = 100
  UF_A = 4（毒代）× 2.5（毒效）
  UF_H = 3.16 × 3.16
```

### 5.2 调整表

| 情形 | 调整 | 依据 |
|---|---|---|
| POD 来自人体研究 | 去种间 10 | 无需跨种 |
| 已做异速生长校正 | 种间剩余 2.5 | 剩余毒效差异 |
| LOAEL 代替 NOAEL | ×2~10 | 起效点不确定 |
| 亚慢性 → 慢性 | ×2~10 | 时长外推 |
| 数据库不完整 | ×2~10 | 缺终点 |
| 有 TK/TD 数据 | 用 CSAF 替代默认子系数 | 化学物特异性 |

### 5.3 CSAF（化学物特异性调整系数）

用毒代/毒效数据**定量**替代默认 10 倍：

```
CSAF = 种间（基于 AUC 或 Cmax 比值）× 种内（基于变异分布，如 95% 覆盖）
```

**要求**：数据充分、模型合理、过程透明。**数据不足时不得用 CSAF "降低" UF。**

### 5.4 三条纪律

1. **UF 是科学判断，不是安全垫**：不得因"公众关注"临时加大。
2. **逐项论证**：写清每个子系数的取值理由。
3. **敏感性**：说明 UF 变动对 HBGV 的影响。

---

## 六、无阈值物质

```
MOE = POD / 暴露量
```

- 常用 BMDL₁₀（10% 肿瘤发生率下限）。
- MOE 的解读交 `risk-assessment`（表征侧），毒理侧负责**POD 与剂量-反应关系的可靠性**。
- 报告须写清：肿瘤部位、物种、性别、剂量-反应模型、BMDL₁₀ 与 BMDU。

---

## 七、数据不足的处理顺序

```
1. 有无结构相似物的充分数据？ → read-across（论证相似性）
2. 有无 (Q)SAR 可用预测？ → 检查适用域
3. 暴露是否足够低？ → TTC 筛查
4. 以上都不成立 → 提出最低必要试验组合
```

**禁止**：用"默认安全""经验值""同类均值"填补关键 POD。

## 八、速查

| 项 | 值/规则 |
|---|---|
| 默认 UF | 100（10 种间 × 10 种内） |
| 种间分解 | 毒代 4 × 毒效 2.5 |
| 种内分解 | 3.16 × 3.16 |
| 异速校正后种间 | 2.5 |
| BMR 连续 | 5% |
| BMR 动物二分 | 1/5/10%，常用 10% |
| BMR 人群二分 | 1% |
| 拟合优度判据 | p > 0.1（BMDS 常用） |
| 似然比检验 | 对数似然差 > 1.92 ↔ P<0.05 |
| MOE 参照 | ≥10 000 → **low concern**（EFSA SC 2025，*EFSA J* 23(8):e9606；**须 RP＝动物 BMDL₁₀**；条目 3-11/3-12，G-17） |
| 时间单位换算 | PTWI/7、PTMI/30 |
