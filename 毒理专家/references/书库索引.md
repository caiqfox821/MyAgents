# 毒理专家 · 书库索引（`公共知识/书库/`）

> **为什么本专家不单独建书库？** 毒理与**风险评估（公共技能 `risk-assessment`）**、**质谱**共用同一批权威来源（WHO/FAO EHC 240、ICH M7(R2)、SANTE、OECD 指南、MDPI 毒理/分析专著）。
> `公共知识/` 是 `opencode.json` 里**唯一全局注册的公共 reference**（跨领域共享来源必须集中存放才能被所有专家检索）；
> 因此**原始全文放 `公共知识/书库/`，本目录只放"消化后的 L3 条目"**（`证据条目与出处.md`）。其他专家（发酵/食品加工/营养/育苗/育种/种植）的来源领域专属，故各自用私有 `references/books/`。

## 二、取证命令（所有页码可由这两条复现）

```bash
cd 公共知识/书库
python3 tools/search_books.py "Tier 1" --context 1        # 全库检索：书 | 物理页码 | 原文
python3 tools/read_page.py Detailed_Review_Paper_on_In_Vitro_Test_Addressing_Immunotoxicity_With 9   # 按物理页读
grep -o '.\{0,160\}NOAEL.\{0,160\}' papers/txt/PMC13379458.txt
```

**引用写法**：指南/专著标 `公共知识/书库 p.N`（PDF **物理页码**）；OA 文献标 `PMCID §章节`（不给页码，避免伪造）。

**行为纪律**：作答毒理问题时先查 `证据条目与出处.md`；条目不足则回原文取证；仍无证据即明确声明"**书库无此证据**"，**不得臆造 NOAEL/BMDL/UF 数值**。
