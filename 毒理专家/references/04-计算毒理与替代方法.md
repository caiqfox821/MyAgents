# 04 · 计算毒理与替代方法（NAMs）

> 依据：EFSA 关于 TTC 的意见、JECFA/JMPR TTC 应用实践、OECD (Q)SAR 验证原则、EChA read-across 评估框架（RAAF）、OECD AOP 框架、IPCS/WHO NAMs 路线图。
> **TTC 阈值与适用条件随版本更新**，使用前核对 EFSA/WHO 现行意见。

---

## 一、TTC（毒理学关注阈值）

### 1.1 定义与用途

TTC 是**基于结构的暴露阈值**：低于该摄入水平，即使没有该物质本身的毒理数据，其健康风险也可视为低关注。

**用途**：① 无数据物质筛查；② 风味物质/包装迁移物/新原料初筛；③ 优先级排序。
**不是**：安全线、合规限量、完整风险评估的替代。

### 1.2 Cramer 分类与阈值

| 类别 | 结构特征 | 阈值（µg/人·d） |
|---|---|---|
| I | 低毒性、经充分代谢解毒的简单结构 | 1800 |
| II | 中间（有活性基团但无强警示） | 540 |
| III | 明显毒性结构警示（如芳香胺、硝基、环氧化物） | 90 |
| 有机磷/氨基甲酸酯 | AChE 抑制类 | 18 |

**分类工具**：Toxtree（Cramer 规则）、OECD QSAR Toolbox。

### 1.3 TTC 不适用（必须排除）

| 排除对象 | 原因 |
|---|---|
| 遗传毒性/致癌物（有警示） | 无阈值，不能用 TTC |
| 金属与类金属（有机金属除外） | 蓄积、非阈值/器官特异 |
| 蛋白、肽、过敏原 | 免疫机制，非剂量-反应常规 |
| 高 potency 天然毒素（黄曲霉毒素、河豚毒素、二噁英类） | 需专属评估 |
| 内分泌活性物质（有明确警示） | 低剂量效应争议 |
| 已知有蓄积性的物质 | TTC 基于每日摄入，不适用 |
| 结构完全未知/混合物 | 无法分类 |

### 1.4 混合物与分组

- 一般按**各组分**分别判断，再考虑是否同机制累积。
- 未知组分按"最保守"处理（如按 Cramer III）。
- 不得把混合物总质量当单一致命物质套 TTC。

### 1.5 使用纪律

```
1 先确认结构明确、无排除条件
2 Cramer 分类（工具 + 专家复核）
3 暴露换算为 µg/人·d（注意体重口径：阈值是"每人每日"，不是"每 kg"）
4 比较：暴露 < 阈值 → 低关注（仍须声明局限）
   暴露 ≥ 阈值 → 需进一步毒理数据，不得下"安全"结论
```

> **常见致命错误**：把 µg/kg bw/d 直接与 µg/人·d 比较（差一个体重倍数，约 60 倍）。

## 二、(Q)SAR

### 2.1 OECD 五条验证原则

| 原则 | 要求 |
|---|---|
| 明确端点 | 预测什么（如 Ames 阳性、皮肤致敏） |
| 明确算法 | 模型类型与描述符 |
| 明确适用域 | 结构/性质范围 |
| 适当性评估 | 拟合优度、稳健性（外部验证） |
| 机理解释（尽可能） | 结构警示与生物学合理性 |

### 2.2 适用域（Applicability Domain）

- 落在训练集化学空间内 → 预测可信度较高。
- 域外 → 预测仅作参考，**不得单独支撑结论**。
- 报告须给：模型名称/版本、端点、预测结果、置信度、是否在域内。

### 2.3 常见误用

| 误用 | 纠正 |
|---|---|
| 只跑一个模型 | 至少两个互补模型 + 专家复核 |
| 忽略域外 | 明确标注"域外，仅供参考" |
| 把阴性预测当"无毒" | 阴性只表示"未提示"，不是排除 |
| 用阳性预测直接定危害 | 需实验确证或 read-across 支持 |

## 三、Read-across（交叉参照）

### 3.1 三种论证路径

| 路径 | 依据 | 强度 |
|---|---|---|
| **结构相似** | 相同官能团/骨架，同类代谢 | 中（需代谢论证） |
| **代谢相似** | 代谢为同一活性/无毒产物 | 较强 |
| **毒性相似（类比）** | 已有同类物的体内数据 | 中（需终点一致） |

### 3.2 论证要素（EChA RAAF 思路）

```
1 物质身份：结构、组成、杂质
2 相似性依据：结构/理化/代谢途径
3 数据矩阵：源物质有哪些终点数据，覆盖是否完整
4 趋势分析：同类物间毒性随结构变化的规律
5 不确定性：代谢差异、物种差异、暴露途径差异
6 结论：能否借用、借用哪个 POD、需要什么确证试验
```

**红线**：仅"名称相似/同类物质"不构成 read-across 依据；必须论证**为什么毒性可以类推**。

### 3.3 常见失败

- 忽略代谢差异（前体 vs 活性物）。
- 忽略杂质/异构体差异。
- 借用不同暴露途径的数据（吸入 → 口服）未做校正。
- 只借"有利"数据，不借不利数据（选择性引用）。

## 四、NAMs（新方法学）与 AOP

### 4.1 NAMs 类型

| 类型 | 例子 | 定位 |
|---|---|---|
| 体外细胞模型 | 肝细胞、Caco-2、3D 类器官 | 机制/代谢/转运 |
| 器官芯片 | 肝-肠芯片 | 多器官交互 |
| 计算模型 | (Q)SAR、PBPK、IVIVE | 预测/外推 |
| 组学 | 转录组/代谢组标志物 | 机制与剂量范围 |
| 不良结局路径（AOP） | 分子起始事件→关键事件→不良结局 | 整合证据 |

### 4.2 AOP 的作用

- 把**机制证据**串成因果链，支持跨物种/跨剂量外推。
- 用于判断"动物阳性是否人类相关"（如大鼠特异 MOA）。
- **局限**：AOP 描述的是通路，不等于定量剂量-反应；不能单独替代体内数据。

### 4.3 NAMs 的法规地位

现状（须核对最新法规）：多数司法辖区 NAMs 用于**支持/补充**，关键决策仍以体内数据或充分验证的替代方法为主；部分终点（皮肤/眼刺激、致敏、遗传毒性）已有接受的替代组合。
**报告必须说明**：所用 NAMs 是否被目标法规体系接受。

## 五、IVIVE 与 PBPK（用于外推）

```
体外测得固有清除率（CLint）→ 用生理参数放大 → 体内清除率 → PBPK 模拟组织浓度
```

**用途**：种间外推、途径外推、儿童/孕妇外推、剂量方案设计、减少动物。
**要求**：模型结构合理、参数有出处、做敏感性分析；**不得用未验证模型替代关键 POD**。

## 六、决策流程（数据不足时）

```
物质结构明确？
 ├─ 否 → 无法评估，需先定性
 └─ 是 → 有排除条件（遗传毒性警示/金属/蛋白/高 potency）？
      ├─ 是 → 不用 TTC → 需实验数据或专属评估
      └─ 否 → Cramer 分类 → 暴露（µg/人·d）
            ├─ 暴露 < 阈值 → 低关注（声明为筛查结论）
            └─ 暴露 ≥ 阈值 → read-across / (Q)SAR / 试验方案
```

## 七、速查

| 项 | 值/规则 |
|---|---|
| Cramer I / II / III | 1800 / 540 / 90 µg/人·d |
| 有机磷/氨基甲酸酯 | 18 µg/人·d |
| TTC 暴露单位 | **µg/人·d**（不是 /kg bw/d） |
| (Q)SAR 验证原则 | OECD 5 条 |
| Read-across 依据 | 结构 / 代谢 / 毒性相似，须论证 |
| 排除 TTC | 遗传毒性、金属、蛋白、高 potency、蓄积 |
| 报告必写 | 模型/工具名称与版本、适用域、局限 |
