# 01 · 毒理学基础与危害识别

> 依据：IPCS/WHO 毒理学原则、EHC 240 Ch.5、EFSA 危害评估指南、OECD 测试指南框架、GB 15193 系列（食品安全性毒理学评价程序）。
> 说明：本文件给**概念与判断框架**，不替代具体物质的权威评估结论。

---

## 一、毒理学的四个基本问题

1. **能不能引起损害**（hazard）——固有性质，与剂量无关。
2. **需要多少量**（dose-response）——决定风险大小的核心。
3. **怎么引起**（mode of action, MOA）——决定外推是否合理。
4. **谁更敏感**（susceptibility）——决定保护对象。

**关键区分**：

| 概念 | 含义 | 常见误用 |
|---|---|---|
| 危害（hazard） | 固有致病能力 | 把"有危害"说成"有风险" |
| 风险（risk） | 危害 × 暴露 × 易感性 | 不看暴露就下风险结论 |
| 安全性（safety） | 在特定使用条件下风险可接受 | 说成"零风险" |

## 二、毒代动力学（TK）：物质在体内做了什么

### 2.1 ADME 四步

| 步骤 | 关键问题 | 影响毒性的因素 |
|---|---|---|
| **吸收**（Absorption） | 经口/吸入/皮肤进入多少 | 溶解度、粒径、基质、首过效应、转运体 |
| **分布**（Distribution） | 到哪些器官、蓄积在哪 | 血浆蛋白结合、脂溶性、血脑/胎盘屏障、组织亲和力 |
| **代谢**（Metabolism） | 活化还是解毒 | CYP/UGT/SULT 等、多态性、种间差异、肠道菌群 |
| **排泄**（Excretion） | 多快清除 | 肾清除、胆汁排泄与肠肝循环、半衰期 |

### 2.2 毒代参数

| 参数 | 含义 | 毒理意义 |
|---|---|---|
| Cmax / AUC | 峰浓度 / 总暴露 | 与急性/慢性效应相关 |
| T½ | 半衰期 | 决定蓄积与评估时间单位（PTWI/PTMI） |
| 生物利用度 F | 进入体循环比例 | 经口剂量≠内暴露 |
| 清除率 CL | 单位时间清除体积 | 种间外推依据 |
| 蓄积系数 | 重复给药后蓄积程度 | 决定是否用 PTWI/PTMI |

**代谢活化**：部分物质本身无毒，代谢后生成活性中间体（如黄曲霉毒素 B1 → AFBO、对乙酰氨基酚 → NAPQI、亚硝胺 → 重氮离子）。**体外试验加/不加 S9 的差异就是为此设计。**

**种间差异的真实来源**：代谢酶表达与活性、转运体、肠道菌群、体型与代谢率。这就是种间 UF 取 10 的生物学基础，也是 PBPK 外推的价值所在。

### 2.3 PBPK 与 IVIVE（概念）

```
PBPK：把机体分成若干房室（肝、肾、脂肪、血…），用血流与分配系数描述浓度-时间
IVIVE：用体外（肝细胞/微粒体）测得的清除率，反推体内清除，替代部分动物试验
```

用途：种间外推、途径外推（吸入→口服）、敏感人群（儿童/孕妇）外推、剂量方案设计。
**局限**：参数不确定时输出不可靠；需说明模型结构与参数来源。

## 三、剂量-反应的基本形态

| 形态 | 含义 | 典型物质 | 评估路径 |
|---|---|---|---|
| **阈值型** | 低于阈值无效应 | 多数非致癌物、必需营养素 | HBGV（ADI/TDI） |
| **无阈值（线性）** | 任何剂量都有概率性风险 | 遗传毒性致癌物 | MOE、ILCR |
| **非线性/ hormesis** | 低剂量促进、高剂量抑制 | 部分重金属、内分泌干扰物 | 谨慎，需机制证据 |
| **U 型** | 缺乏与过量皆有害 | 硒、维生素 A、铁 | 需同时评两端（UL 与 RNI） |

**判断阈值与否的依据**：MOA 证据（是否有明确受体/酶抑制阈值、是否有 DNA 反应性）。**不能仅凭"是致癌物"就定无阈值**——非遗传毒性致癌物通常有阈值。

## 四、关键效应与环境（critical effect）

**关键效应**：在最低剂量出现、且具有不良意义、与人类相关的效应。它决定 POD。

### 4.1 不良 vs 适应性

| 表现 | 更可能是不良 | 更可能是适应性 |
|---|---|---|
| 肝酶（ALT/AST）升高 | 伴坏死/纤维化 | 单纯诱导、无结构损伤 |
| 肝脏重量增加 | 伴病理改变 | 单纯 CYP 诱导（可逆） |
| 甲状腺增生 | 伴肿瘤/功能低下 | TSH 反馈性增生 |
| 肾重量增加 | 伴管损伤/蛋白尿 | 单纯代偿 |
| 体重下降 | 伴摄食减少与功能损害 | 轻度、可逆 |

**判断要求**：结合组织病理、可逆性、剂量-反应斜率、是否进展为器质损伤。**报告须写明理由，不能一句"考虑为适应性"了事。**

### 4.2 最敏感终点怎么找

1. 同一试验内比较各终点 BMDL，取最低（注意统计与生物学双重判断）。
2. 跨试验/跨物种/跨性别比较，取最低有效剂量。
3. 关注**功能性终点**（神经行为、免疫、生殖）——常比形态学更敏感但更易被漏检。

### 4.3 暴露途径相关性

口服试验 → 膳食暴露（相关）；吸入试验 → 空气暴露（相关）；皮肤试验 → 职业/化妆品。
**用吸入 POD 评膳食暴露须做途径外推并说明**，不可直接套用。

## 五、易感人群

| 人群 | 敏感性来源 |
|---|---|
| 胎儿/婴幼儿 | 器官发育窗、血脑屏障未成熟、代谢酶不足、单位体重摄入高 |
| 儿童 | 发育中的神经系统、行为暴露、代谢差异 |
| 孕妇 | 生理改变（血容量、CYP 活性、肾清除） |
| 老年人 | 肾功能下降、多病共存、多药合用 |
| 遗传多态性人群 | 代谢酶/转运体变异（如 NAT2、CYP2D6、GSTM1） |
| 疾病人群 | 肝肾功能不全、营养状态差 |

**默认 UF 的种内 10 倍**就是对人群变异的一揽子保护，但**不能覆盖全部极端个体**；关键决策时应单列亚人群。

## 六、证据权重（WoE）

### 6.1 评估维度

| 维度 | 问题 |
|---|---|
| 质量 | 是否 GLP/OECD TG？剂量设计、样本量、统计方法是否恰当？ |
| 一致性 | 不同实验室/物种/性别结果是否一致？ |
| 剂量-反应 | 是否有单调或合理的剂量关系？ |
| 时相关系 | 效应是否先于/伴随暴露？ |
| 生物学合理性 | 是否有 MOA/AOP 支持？ |
| 人群相关性 | 代谢、途径、暴露水平是否可比？ |

### 6.2 常见误判

| 误判 | 纠正 |
|---|---|
| "多数研究阴性 → 无危害" | 可能是效能不足；看阳性研究的质量与剂量 |
| "一项阳性研究 → 有危害" | 看是否可重复、剂量是否相关、是否在适用域内 |
| "体外阳性 → 体内有害" | 需考虑暴露浓度是否可达、代谢活化/解毒 |
| "高剂量阳性 → 低剂量也危险" | 需 MOA 与低剂量外推依据 |
| "IARC 2B → 很可能致癌" | 2B 是"可能"，证据有限；表述须准确 |

### 6.3 结论措辞分级

| 证据强度 | 建议措辞 |
|---|---|
| 充分 | "已有充分证据表明……" |
| 较强但有限 | "证据提示……，但存在局限（……）" |
| 有限/不一致 | "现有证据不一致/有限，无法确定……" |
| 不足 | "缺乏可用数据，无法评估" |

## 七、生物标志物（简述）

| 类型 | 例子 | 用途 |
|---|---|---|
| 暴露标志物 | 血/尿中母体或代谢物、加合物 | 内暴露评估（优于外暴露推算） |
| 效应标志物 | 酶抑制（AChE）、DNA 加合物、氧化应激 | 早期效应 |
| 易感性标志物 | 基因多态性、酶活性 | 亚人群识别 |

**注意**：检出生物标志物 ≠ 有健康损害；需与剂量-反应和临床意义结合。
