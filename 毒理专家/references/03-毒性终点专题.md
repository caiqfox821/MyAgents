## 一、遗传毒性

### 1.1 三类损伤与对应试验

| 损伤类型 | 代表性试验 | OECD TG（需核对版本） |
|---|---|---|
| **基因突变** | 细菌回复突变（Ames） | TG 471 |
| | 哺乳动物细胞 HPRT 基因突变 | TG 476 |
| | 哺乳动物细胞 TK 基因突变 | TG 490 |
| **染色体结构/数目异常** | 体外染色体畸变 | TG 473 |
| | 体外微核 | TG 487 |
| | 体内微核（骨髓/外周血） | TG 474 |
| | 体内染色体畸变（骨髓） | TG 475 |
| **DNA 损伤/修复** | 彗星试验（体内/体外） | TG 489（体内） |
| | 程序外 DNA 合成（UDS） | 历史方法，现少用 |

### 1.2 标准测试组合（策略而非固定清单）

```
第一步：细菌回复突变（Ames，±S9）  ← 覆盖点突变
第二步：哺乳动物细胞体外试验（染色体畸变 或 微核 或 TK）  ← 覆盖结构/数目异常
第三步（必要时）：体内试验（微核/彗星/染色体畸变）  ← 解决体外阳性或暴露相关性问题
```

**判读要点**：

| 情形 | 处理 |
|---|---|
| 体外阳性、体内阴性 | 可能为体外特异性（代谢/浓度不可达）→ 结合暴露判断 |
| 体内阳性 | 提示体内遗传毒性风险 → 通常按无阈值处理（MOE） |
| 仅 Ames 阳性 | 需确认是否为哺乳动物相关性（如某些硝基化合物） |
| 全阴性 | 降低但不排除遗传毒性（终点覆盖有限） |

**常见陷阱**：不加 S9 就判阴性（漏掉需代谢活化的物质）；浓度未达细胞毒性上限（假阴性）；只用一种细胞系。

### 1.3 遗传毒性阳性的评估含义

- 遗传毒性阳性 → **不必然**是致癌物，但提示需要致癌试验/更强证据。
- 遗传毒性致癌物（DNA 反应性）→ 通常**按无阈值**处理（MOE）。
- 非遗传毒性致癌物 → 通常**有阈值**，可推导 HBGV。

## 二、致癌性

### 2.1 证据来源层级

```
人群流行病学（充分） > 长期动物试验（2 年，TG 451/453） > 短期/中期试验 > 结构警示/机制
```

| 试验 | OECD TG | 要点 |
|---|---|---|
| 致癌性试验 | TG 451 | 2 年，多剂量组，组织病理全覆盖 |
| 慢性与致癌联合 | TG 453 | 常用，节省动物 |
| 新生大鼠/转基因模型 | TG 495 等 | 机制研究/筛查，不替代常规致癌试验 |

### 2.2 IARC 分类（表述必须准确）

| 组 | 含义 | 常见误读 |
|---|---|---|
| 1 | 对人类致癌 | — |
| 2A | 很可能对人类致癌（证据较强） | 不等于"确定致癌" |
| 2B | 可能对人类致癌（证据有限） | 不等于"低风险" |
| 3 | 现有证据无法分类 | **不等于"不致癌"** |

> IARC 评的是**危害（hazard）**，不是**风险（risk）**。写"被 IARC 列为 2B，因此该食品有风险"是**逻辑错误**——需结合暴露。

### 2.3 MOE 在致癌评估中的应用

```
MOE = BMDL₁₀ / 暴露量
```

- 需交代：肿瘤部位、物种/性别、模型、BMDL₁₀ 与 BMDU。
- 参照值 **10 000** 已由本库核实：EFSA SC《Statement on the use and interpretation of the MOE approach》（*EFSA J* **23(8):e9606**，2025）——**≥10 000（RP 须为动物 BMDL₁₀）→ low concern ＝ 风险管理优先级低**，且**不排除减排措施**；10 000 ＝ 100（种间＋种内）×100（细胞周期/DNA 修改变异＋RP 类型与低剂量外推未知）⇒ **用 T25/NOAEL/LOAEL 时不得套用**。本库既有口径仍须并列：MOE 系**相对比较**、非绝对值（Ch5 p.74，G-11）；解读须结合人群相关性、MOA、暴露不确定性（公共库条目 **3-11/3-12/3-13**、毒理 **G-17/G-18**）
- 对遗传毒性致癌物，MOE 优于 ILCR（后者依赖线性外推假设）。

### 2.4 非遗传毒性致癌（阈值型）

典型：甲状腺（TSH 介导）、膀胱（结石/沉淀）、肝（过氧化物酶体增殖）、肾（α2u-球蛋白，雄性大鼠特异）。

**关键判断**：该 MOA 是否**人类相关**。大鼠特异机制（如 α2u-球蛋白）不宜直接外推到人——**这是"试验阳性但人群风险低"的最主要来源**。

## 三、生殖与发育毒性（DART）

| 终点 | 试验 | OECD TG |
|---|---|---|
| 发育毒性（致畸） | 大鼠/兔胚胎-胎仔发育毒性 | TG 414 |
| 生殖筛选 | 生殖/发育毒性筛选 | TG 421 / 422 |
| 两代生殖 | 两代繁殖毒性 | TG 416 |
| 扩展一代 | 扩展一代生殖毒性（含神经/内分泌终点） | TG 443 |
| 幼龄动物 | 幼龄毒性 | TG 213（大鼠）等 |

### 3.1 关键概念

| 概念 | 含义 |
|---|---|
| 发育毒性的四个表现 | 死亡、畸形、生长迟缓、功能缺陷 |
| 敏感窗 | 器官形成期最敏感（着床后至硬腭闭合） |
| 母体毒性 | 需区分"直接胚胎毒性"与"母体介导" |
| NOAEL（母体）/ NOAEL（发育） | **分别给出**，取更敏感者作 POD |
| 内分泌干扰 | 需关注低剂量效应与窗口期暴露 |

**判断陷阱**：把母体毒性导致的胎仔体重下降当直接发育毒性；只用一种物种（兔与大鼠敏感性差异大）；忽略功能终点（行为、免疫、生殖能力）。

### 3.2 DART 阳性的评估含义

- 发育毒性阳性 → 通常设**发育毒性 NOAEL**，可能需单独的 ARfD（孕期/育龄妇女）。
- 需说明：剂量-反应、物种一致性、是否人类相关机制。

## 四、靶器官毒性

| 系统 | 常用指标 | 典型物质/情形 |
|---|---|---|
| **肝** | ALT/AST、ALP、胆红素、组织病理、肝重 | 多数外来物首过器官 |
| **肾** | BUN/肌酐、尿蛋白、肾小管损伤标志物（KIM-1、β2-MG） | 重金属（Cd、Hg）、NSAIDs |
| **神经** | 行为（功能观察组合 FOB）、神经病理、AChE 抑制 | 有机磷、丙烯酰胺、甲基汞 |
| **免疫** | 免疫器官重量、抗体斑形成（PFC）、NK 活性 | 真菌毒素、TCDD |
| **内分泌** | 甲状腺激素/TSH、性激素、肾上腺 | 高氯酸盐、PBDEs、内分泌干扰物 |
| **呼吸** | 病理、肺功能、过敏 | 吸入颗粒、霉菌 |
| **心血管** | 心重、病理、血压 | 部分药物/污染物 |
| **血液** | 血常规、骨髓 | 苯、部分真菌毒素 |

### 4.1 器官特异性判断要点

- **剂量-反应单调性** + **一致性**（多物种/多性别） + **机制支持**（如 AChE 抑制 + 胆碱能症状）。
- **可逆性**：停药后恢复提示适应性/可逆损伤；不可逆提示器质损伤。
- **安全边际**：该器官效应出现的剂量与人群暴露的距离（MOE/HQ 的生物学基础）。

## 五、局部毒性与致敏

| 终点 | 试验 | OECD TG |
|---|---|---|
| 皮肤刺激/腐蚀 | 体外重建皮肤/体内 | TG 439 / 404 |
| 眼刺激/腐蚀 | 体外/体内 | TG 437/438/492 / 405 |
| 皮肤致敏 | 局部淋巴结试验（LLNA）、豚鼠试验、体外替代 | TG 442A/442B/429 / 406 |
| 光毒性 | 3T3 NRU | TG 432 |

**要点**：致敏是**阈值型但个体差异极大**；有致敏性不等于"在该用量下必然致敏"。食品中主要关注**蛋白过敏原**（非化学致敏），后者属另一评价体系（过敏原性评估）。

## 六、微生物与生物毒素

### 6.1 微生物剂量-反应（QMRA）

| 模型 | 形式 | 特点 |
|---|---|---|
| 指数模型 | `P = 1 − exp(−r·D)` | 单菌独立、恒定感染概率 |
| Beta-Poisson | `P = 1 − (1 + D/β)^(−α)` | 菌株/宿主变异 |
| 阈值模型 | 低于某剂量 P=0 | 特定病原/情景 |

**要点**：微生物风险与化学物不同——**单次暴露即可致病**，无"终生每日可接受量"概念；评估单位是"每餐/每次事件的风险"。

### 6.2 生物毒素

| 毒素 | 主要终点 | 评估特点 |
|---|---|---|
| 黄曲霉毒素 B1 | 肝致癌（遗传毒性） | 无阈值，MOE；急性中毒（大剂量）另有 ARfD 类考虑 |
| 赭曲霉毒素 A | 肾毒性、肾致癌 | 有争议的阈值性；JECFA 曾用 PTWI |
| 脱氧雪腐镰刀菌烯醇（DON） | 急性呕吐、免疫 | 有 PMTDI，另有急性参考值 |
| 玉米赤霉烯酮 | 内分泌/生殖 | 有 PMTDI |
| 展青霉素 | 遗传毒性/免疫 | 有 PMTDI |
| 河豚毒素/贝类毒素 | 神经（钠通道） | 急性，需 ARfD 类指标 |
| 生物胺（组胺、酪胺） | 血管/神经 | 急性，个体差异大（MAOI 用药者） |

## 七、终点选择决策表

| 物质特征 | 必查终点 |
|---|---|
| 有结构警示（芳香胺、亚硝基、环氧化物） | 遗传毒性 + 致癌 |
| 计划用于育龄妇女/孕妇 | DART + 发育毒性 |
| 脂溶性、蓄积 | 慢性 + 神经 + 肝 |
| 金属/类金属 | 靶器官（肾/神经）+ 形态（价态） |
| 内分泌活性结构 | 内分泌 + DART（低剂量） |
| 蛋白/肽类 | 过敏原性 |
| 微生物 | QMRA 剂量-反应 |

## 八、报告写法（每终点）

```
【终点】90 天重复经口毒性（大鼠）
【关键发现】肝 ALT 升高（≥X mg/kg bw/d）、肝细胞肥大；无组织坏死
【判定】不良（剂量-反应明确、伴病理改变）
【POD】BMDL = Y mg/kg bw/d（BMR 5%，模型 Hill，BMDS 3.x）
【可靠性】Klimisch 1（GLP，OECD TG 408）
【局限】仅雄性、仅一个品系
```
