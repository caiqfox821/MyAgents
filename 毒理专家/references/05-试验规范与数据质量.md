# 05 · 试验规范与数据质量

> 依据：OECD Principles of Good Laboratory Practice（GLP）、OECD Test Guidelines（现行编号）、Klimisch 等（1997）可靠性分级、GB 15193 系列《食品安全性毒理学评价程序》、3R 原则（Replacement/Reduction/Refinement）。
> **测试指南编号与技术要求随版本更新**；引用前核对 OECD 官网（oecd.org/chemicalsafety/testing）与国标现行版本。

## 一、GLP（良好实验室规范）

### 1.1 十个要素

| 要素 | 要求 |
|---|---|
| 组织与人员 | 明确职责、培训记录 |
| 质量保证（QA） | 独立于试验执行 |
| 设施 | 分区、环境控制 |
| 仪器设备 | 校准、维护记录 |
| 受试物与对照物 | 标识、纯度、稳定性、留样 |
| 标准操作规程（SOP） | 覆盖全部关键操作 |
| 试验实施 | 按计划书执行，偏离须记录 |
| 结果报告 | 完整、可追溯 |
| 记录与保存 | 原始数据归档，可重建 |
| 总结报告 | 签署、QA 声明 |

**判读意义**：GLP 是**数据可信度的框架**，不等于"结果正确"。GLP 阳性/阴性仍需看设计（剂量、样本量、终点）。

### 1.2 非 GLP 数据怎么用

- 可用于**权重补充**，不用于关键 POD。
- 须标注"非 GLP"并说明缺陷（如无病理盲检、无剂量-反应）。

## 三、Klimisch 可靠性分级

| 等级 | 定义 | 判定要点 | 用途 |
|---|---|---|---|
| **1 可靠** | 无限制的可靠 | GLP/等效规范；方法符合指南；终点完整；统计恰当 | 可支撑关键决策 |
| **2 基本可靠** | 有限制的可靠 | 有偏离但不影响主要结论；或方法接近指南 | 可作权重补充，需说明局限 |
| **3 不可靠** | 不可靠 | 方法严重偏离、终点不全、剂量设计不合理 | 仅供参考，不作依据 |
| **4 无法评价** | 信息不足 | 细节缺失，无法判断 | 不采用 |

**评级纪律**：
- 逐研究评级，不得"整篇综述一并评级"。
- 评级须写理由（哪项缺陷、影响哪个结论）。
- 同一终点的多项研究，按等级分别列示，不做简单合并。

## 四、剂量设计与统计

| 项 | 要求 |
|---|---|
| 剂量组数 | ≥3 个剂量组 + 对照（OECD 常规） |
| 剂量间距 | 通常 2~3 倍；过高会漏低剂量效应 |
| 每组样本量 | 一般 ≥10（慢性/致癌更多） |
| 性别 | 通常雌雄各半；DART 需孕鼠 |
| 统计 | 连续数据 ANOVA + 事后检验；二分数据趋势检验（如 Cochran-Armitage） |
| 多重比较 | 需校正；报告须说明方法 |
| 盲检 | 病理应盲检（降低偏倚） |

**常见统计问题**：把"无统计学差异"当"无效应"（效能不足）；忽略剂量-反应趋势检验；多重比较未校正导致假阳性。

## 五、中国法规框架（食品安全性毒理学评价）

| 层级 | 内容 |
|---|---|
| **GB 15193 系列** | 食品安全性毒理学评价程序与方法（分若干部分：急性、遗传、90 天、致畸、致突变、慢性/致癌、代谢、生殖等） |
| **GB 15193.1** | 总则/程序（评价阶段划分） |
| **新食品原料/添加剂** | 依相应管理办法要求毒理资料 |
| **农药登记** | 依农药登记毒理学试验要求（与 GB 15193 不完全等同） |

**评价阶段（概念）**：
```
第一阶段：急性毒性 + 遗传毒性（体外）
第二阶段：遗传毒性（体内）+ 90 天喂养 + 代谢
第三阶段：生殖毒性 + 致畸
第四阶段：慢性 + 致癌
```
实际阶段与项目按**受试物用途、暴露水平、已有资料**调整，**不得机械照搬全套**。

> 具体条文与现行版本须核对国家标准全文公开系统（`openstd.samr.gov.cn`）。

## 六、3R 原则与伦理

| 原则 | 做法 |
|---|---|
| **替代**（Replacement） | 优先体外/计算/无脊椎模型 |
| **减少**（Reduction） | 合理设计、共享数据、避免重复试验 |
| **优化**（Refinement） | 麻醉/镇痛、环境丰富、 humane endpoints |

**申报与发表**：需提供伦理审批与动物福利声明。

## 七、数据质量核查清单

- [ ] 试验是否 GLP？非 GLP 是否说明缺陷？
- [ ] 是否符合 OECD TG 或等效国标？版本？
- [ ] 剂量组数、间距、样本量是否充分？
- [ ] 性别、物种、途径是否与评估目的匹配？
- [ ] 终点是否完整（含组织病理、功能终点）？
- [ ] 统计方法是否恰当（趋势检验、多重比较校正）？
- [ ] 是否盲检？是否有偏倚控制？
- [ ] 原始数据是否可追溯（报告编号、存档）？
- [ ] Klimisch 分级及理由是否写明？
- [ ] 是否存在选择性报告（只报显著结果）？
