# 中试放大与产线

> 整理范围：小试→中试→试产→量产流程与判定指标；放大准则；设备选型；产线平衡与 OEE；CIP/SIP 与卫生设计；能耗与水耗；中试批记录与工艺验证；常见放大问题排查。
> 主要依据：化工/食品工程放大理论与行业实践；设备厂商公开技术手册；GB 14881 卫生规范与 EHEDG、3-A 卫生设计理念（标准版本待核实）。
> 说明：文中规模、功率、时间、效率等为**经验/参考量级**，实际须按产品、设备与中试数据确定；标注"待核实"处需以设备手册或权威文献复核。

## 一、开发流程与放大概览

### 1.1 四阶段流程

| 阶段 | 规模（经验） | 目标 | 主要产出 |
|---|---|---|---|
| **小试（Lab）** | mL–L 级 | 配方筛选、工艺可行性、机理验证 | 配方雏形、工艺参数窗口、分析数据 |
| **中试（Pilot）** | 约 10–500 L/批（或 kg 级） | 验证放大效应、设备可行性、卫生与安全 | 中试批记录、物料/能量衡算、样品 |
| **试产（Trial）** | 接近量产规模的 1/5–1/2 | 产线联调、节拍与质量稳定、成本核算 | 工艺规程、检验标准、试产报告 |
| **量产（Commercial）** | 设计产能 | 稳定供货、成本/质量受控 | SOP、批记录、放行标准、持续改进 |

> 食品加工中试基地通常配备"**通用调配+杀菌+均质+灌装**"柔性单元，覆盖饮料/乳品/酱料等多品类验证（呼应新疆林果深加工项目的中试需求）。

### 1.2 阶段判定指标（Go/No-Go）

| 维度 | 小试→中试 | 中试→试产 | 试产→量产 |
|---|---|---|---|
| 配方 | 感官/稳定性达标 | 批次重现性好 | 成本可控、供应稳定 |
| 工艺 | 参数窗口明确 | 放大后关键指标一致 | 节拍达标、OEE 达标 |
| 质量 | 理化/微生物达标 | 全项检验合格 | 批间波动小 |
| 安全 | 危害识别完成 | HACCP 关键限值验证 | 体系运行有效 |
| 合规 | 添加剂/标签可满足 | 生产许可（SC）条件具备 | 全部合规文件就绪 |
| 经济 | — | 成本初步测算可行 | 投资回收/毛利达标 |

## 二、放大准则

### 2.1 常用准则

| 准则 | 数学表达 | 保持的物理量 | 适用/风险 |
|---|---|---|---|
| **恒单位体积功率** | `P/V = 常数` | 混合强度/湍流 | 通用；但剪切可能过大 |
| **恒剪切（恒叶端线速度）** | `πND = 常数` | 剪切速率 | 剪切敏感物料；混合可能不足 |
| **恒传热** | `U·A/V = 常数` | 单位体积传热能力 | 放热/换热主导；几何受限 |
| **恒混合时间** | `t_mix = 常数` | 混合均匀性 | 需要停留时间一致 |
| **恒雷诺数** | `Re = 常数` | 流态相似 | 小试到中试常用；大设备难满足 |
| **恒 kLa / 恒氧传递** | `kLa = 常数` | 供氧（发酵类） | 好氧体系 |

### 2.2 放大风险与"缩放"（Scale-down）

- 放大时**混合时间随体积增大而延长**、**剪切/传热/温度梯度**分布不均；单准则难以同时满足。
- 采用**相似准则组合 + scale-down 实验**：在实验室复现大设备的局部极值（高剪切、低 pH、温度峰、缺氧），验证配方/菌种耐受性。
- **几何相似**与**动态相似**通常不能兼得，需按关键过程（混合 vs 传热 vs 剪切）取舍。
- 关键：放大前后**同测关键指标**（粒径、黏度、反应/灭活程度、得率、感官）。

## 三、设备选型

| 单元 | 主要设备 | 选型要点 |
|---|---|---|
| 换热/杀菌 | 板式/管式换热器、刮板式、UHT 杀菌机、直接蒸汽喷射 | 黏度、含颗粒、结垢、热回收率、停留时间分布 |
| 均质 | 高压均质机、微射流 | 压力、流量、级数、耐腐蚀、CIP |
| 分离/浓缩 | 离心机、过滤机、膜装置、蒸发器/MVR | 固含、黏度、目标浓度、能耗 |
| 混合 | 搅拌罐、静态混合器、在线混合 | 流型、剪切、死区、清洁性 |
| 灌装 | 无菌灌装机、热灌装机、冷灌装、瓶/罐/袋 | 无菌等级、灌装精度、速度、包材适应性 |
| 包装 | 封口机、贴标/喷码、收缩/裹包、二次包装 | 密封完整性、节拍、气调能力 |
| 干燥 | 热风/喷雾/冻干/真空设备 | 进风温度、雾化、产能、余热回收 |
| 公用工程 | 锅炉/蒸汽、冰水机组、压缩空气、水处理、CIP 站 | 负荷匹配、冗余、能效、水质 |

### 3.1 选型决策要素

1. **物料特性**：黏度、固含、颗粒、pH、腐蚀性、热敏性。
2. **产能与弹性**：设计产能、最小/最大批量、换产便利性。
3. **质量与安全**：可清洁性、密封、材质（食品级 304/316L 不锈钢）。
4. **法规**：食品接触材料合规、卫生设计、防混料与可追溯。
5. **成本**：投资、运行（能耗/水/人工）、维护、备件。
6. **可扩展性**：模块化、预留接口（如项目预留功能性饮料/果干/罐头产线）。

## 四、产线平衡与 OEE

### 4.1 产线平衡

- **瓶颈工序**决定整线产能；按**节拍（takt time）**平衡各工位。
- 关键：**杀菌/灌装/包装**节拍匹配、缓冲罐/暂存减少停线、换产时间最小化（SMED）。
- 物料与能量衡算：`输入 = 产品 + 损耗 + 废水/废气/固废`；建立**物料平衡表**与**能量平衡表**。

### 4.2 OEE（Overall Equipment Effectiveness）

`OEE = 可用率 × 性能效率 × 良品率`

| 指标 | 含义 | 损失来源 |
|---|---|---|
| 可用率（Availability） | 实际运行/计划运行 | 故障、换产、清洗 |
| 性能效率（Performance） | 实际产量/理论产量 | 小停机、降速 |
| 良品率（Quality） | 合格品/总产出 | 废品、返工、灌装偏差 |

- 世界级 OEE 参考 **≈85%**（经验，因行业而异，**待核实**）；食品行业受清洗/换产影响常低于此。
- 改善方向：TPM、SMED、减少非计划停机、在线检测与 SPC。

## 五、CIP/SIP 与卫生设计

### 5.1 CIP（Clean-in-Place，就地清洗）与 SIP（Sterilization-in-Place，就地灭菌）

| 环节 | 典型条件（经验） | 说明 |
|---|---|---|
| 预冲洗 | 常温–温水 | 去除残料 |
| 碱洗 | NaOH 1%–3%，60–85 ℃ | 去有机污垢（油脂、蛋白） |
| 中间冲洗 | 水 | 去碱 |
| 酸洗 | 硝酸/磷酸 0.5%–2%，常温–70 ℃ | 去无机垢（乳石、水垢） |
| 终冲洗 | 纯水 | 去残留 |
| 消毒/SIP | 热水/蒸汽/化学消毒剂 | 蒸汽灭菌、热水 ≥ 85–90 ℃（经验） |

- **参数**：浓度、温度、流速（保证湍流，常 **>1.5 m/s** 经验，待核实）、时间、接触面积。
- **验证**：清洗后残留检测（ATP、蛋白/总有机碳 TOC、微生物涂抹）、电导率/温度记录。
- SIP 常用于无菌灌装系统与发酵/配料管路；注意**耐压、耐温、死角**。

### 5.2 卫生设计（Hygienic Design）

- 理念来源：**EHEDG**（欧洲卫生工程与设计组织）、**3-A Sanitary Standards**（美国 3-A 卫生标准）等（**待核实**具体文件编号）。
- 要点：
  - 食品接触面**光滑、耐蚀、无毒**（316L 等）。
  - **无死角、可排净**、避免裂缝/缝隙/螺纹暴露。
  - 管道坡度、圆角过渡、密封件合规（食品级、耐温）。
  - 区分**卫生区/非卫生区**，防止交叉污染。
  - 设备**可拆洗或 CIP/SIP**。
- 生产通用卫生要求见 **GB 14881**（**待核实**现行版本）。

## 六、能耗与水耗

| 工段 | 主要能耗 | 节能方向 |
|---|---|---|
| 杀菌/UHT | 蒸汽/电 | 热回收、余热利用、优化杀菌强度 |
| 蒸发/浓缩 | 蒸汽 | **MVR**、多效、余热回收 |
| 干燥 | 热风/电 | 热泵、余热回收、组合干燥 |
| 制冷/冷冻 | 电 | 高效压缩机、夜间蓄冷、负荷匹配 |
| 均质/泵/搅拌 | 电 | 变频、合理选型、减少压损 |
| CIP | 水/蒸汽/化学品 | 回收清洗液、优化循环、减少冲洗水量 |
| 公用工程 | 锅炉/冰水/空压 | 系统能效、冷凝水回收、泄漏管理 |

- 关键指标：**单位产品能耗（kW·h/kg 或 kW·h/L）**、**单位产品水耗（L/kg 或 L/L）**、**综合能耗**。
- 方向：能量集成（夹点分析）、余热回收、废水回用、清洁生产审核（见《标准规范与法规-食品加工.md》）。
- 碳足迹核算：范围 1/2/3 排放，配合国家"双碳"政策。

## 七、中试批记录与工艺验证

### 7.1 中试批记录要素

- [ ] 批号、日期、班次、操作人/复核人
- [ ] 原料批次、检验合格证明、投料量与顺序
- [ ] 关键工艺参数实时记录（温度/时间/压力/流量/转速/pH/°Brix 等）
- [ ] 设备编号、清洁状态（CIP/SIP 记录）
- [ ] 中间控制与成品检验数据（理化/微生物/感官）
- [ ] 偏差、异常与纠正措施
- [ ] 得率、物料平衡、能耗与水耗
- [ ] 留样与稳定性样品
- [ ] 审批与归档

### 7.2 工艺验证（Process Validation）

| 层级 | 内容 |
|---|---|
| **设计确认（DQ）** | 设备/工艺设计满足产品与法规要求 |
| **安装确认（IQ）** | 设备安装、材质、仪表校准符合规范 |
| **运行确认（OQ）** | 在设定参数范围内稳定运行（空载/水试） |
| **性能确认（PQ）** | 用实际物料在正常生产条件下连续批次验证（常 ≥3 批） |
| **持续工艺验证** | 上市后持续监控与趋势分析 |

- 验证内容：杀菌强度（F 值/热分布热穿透）、均质效果、灌装无菌/密封、混合均匀度、清洗验证。
- **HACCP** 关键控制点（CCP）须通过验证确认关键限值有效（与食品安全专家协作）。

## 八、常见放大问题排查表

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 放大后杀菌不足/过度 | 换热面积、停留时间分布、结垢 | 校核 F 值、热分布/热穿透、调整流量与温度 |
| 混合不均、局部过浓 | 混合时间不足、死区 | 调整搅拌/静态混合、改加料点、scale-down 验证 |
| 剪切损伤（乳液破乳、菌体损伤） | 泵/均质/搅拌剪切过大 | 降低叶端线速度、改泵型、调整顺序 |
| 传热不足、温度波动 | 传热面/流量不匹配 | 增加换热面积、优化冷却、刮板式 |
| 得率下降 | 残留、飞溅、干燥损失 | 物料平衡、回收、优化设备 |
| 灌装精度差 | 阀/流量/温度波动 | 校准、稳定供料、在线称重 |
| 封口泄漏 | 温度/压力/时间不当 | 参数优化、密封性检测 |
| CIP 不彻底 | 流速/浓度/温度/时间不足、死角 | 优化 CIP、卫生设计改造 |
| 能耗/水耗超预期 | 余热未回收、泄漏、过度清洗 | 热回收、泄漏管理、CIP 优化 |
| 批次间波动 | 原料波动、参数漂移、操作差异 | 原料标准化、SPC、SOP 培训 |
