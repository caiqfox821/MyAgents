# 配方设计与稳定体系

> 整理范围：饮料、乳品、烘焙、肉制品、调味品、功能食品的配方设计要点；甜味剂、酸度调节剂、增稠稳定剂、乳化剂、香精、色素、防腐剂选型；稳定体系（ζ 电位、粒径、HLB、流变）设计；清洁标签与减糖减盐；配方表模板与 GB 2760 合规提示。
> 主要依据：食品配方与食品添加剂应用通用教材与行业实践；GB 2760《食品安全国家标准 食品添加剂使用标准》、GB 7718 标签通则等（版本待核实）；企业公开配方设计资料。
> 说明：文中配方百分比与添加量为**示例/经验量级**，仅用于说明结构，实际须经小试—中试与感官验证，并严格按 GB 2760 的**食品类别、功能、最大使用量/残留量**执行；标注"待核实"处需以现行标准复核。

## 一、配方设计通用方法

### 1.1 设计流程

1. **产品定位**：品类、目标人群（儿童/健身/中老年/控糖）、消费场景（即饮/佐餐/户外）、价格带。
2. **营养与法规目标**：能量、蛋白、糖、钠、功能声称边界；确认所属 GB 2760 食品类别。
3. **骨架搭建**：主料（水/乳/谷物/肉/果蔬）→ 风味（甜/酸/咸/鲜/香）→ 质构（增稠/乳化/凝胶）→ 功能（营养/功能物）→ 保藏（酸度/防腐/杀菌配合）。
4. **稳定体系**：均质 + 亲水胶体 + 乳化剂 + pH/离子调控，解决分层、沉淀、析水、絮凝。
5. **工艺匹配**：配方耐热性（UHT/巴氏/罐藏）、耐剪切、耐酸、耐冻融。
6. **合规审查**：添加剂范围与限量、标签配料表、营养标签、声称（详见《标准规范与法规-食品加工.md》）。
7. **中试与感官**：小试筛选 → 中试放大 → 感官/消费者测试 → 稳定性/货架期。

| 甜味剂/糖 | | 甜度、质构、保水 | 高倍甜味剂、糖醇 | GB 2760 分类限量 |

## 二、分品类配方设计要点

### 2.1 饮料

| 子类 | 典型组成（示例，%） | 设计要点 | 稳定/工艺关键 |
|---|---|---|---|
| 碳酸饮料 | 糖 8–12、酸 0.1–0.3、香精、CO₂ | 甜酸比、杀口力、CO₂ 溶解度 | 低温碳酸化、耐压包装；防腐剂 + 低 pH |
| 果汁/果汁饮料 | 果汁 10–100、糖、酸 | 原果汁含量、糖酸比、色泽 | 酶解澄清/均质、灭酶、脱气；NFC 需冷链 |
| 茶饮料 | 茶提取液、糖/代糖、酸、抗氧化剂 | 防沉淀、防褐变、保香 | 澄清（膜/离心）、VC/异抗坏血酸钠护色 |
| 植物蛋白饮料 | 豆/燕麦/坚果乳 + 糖 + 稳定剂 | 蛋白沉淀、豆腥味、口感 | 高压均质、调整 pH 远离等电点、亲水胶体（结冷胶/微晶纤维素） |
| 功能/电解质 | 糖、电解质、维生素、功能物 | 渗透压、口感、功能剂量 | 等渗约 250–340 mOsm/kg（经验，待核实） |
| 本草 RTD | 提取物、代糖、酸 | 苦味掩蔽、澄清、稳定 | 环糊精/甜味剂掩苦、膜澄清、UHT |

- **糖酸比**是风味核心：一般果汁 Brix/酸 ≈ 8–15（因品类而异，需感官定）。
- **护色抗氧化**：维 C、异抗坏血酸钠、茶多酚、焦亚硫酸盐（限用，待核实）。
- **防腐**：低 pH（<4.6）配合山梨酸钾/苯甲酸钠；但需符合 GB 2760 分类与限量。

### 2.2 乳品

| 子类 | 组成（示例） | 设计要点 | 工艺关键 |
|---|---|---|---|
| 液态奶（巴氏/UHT） | 生乳 100 或标准化 | 蛋白/脂肪标准化、风味 | 均质 15–25 MPa、巴氏/UHT |
| 酸奶/发酵乳 | 乳 + 菌种 + 糖（可选） | 酸度、黏度、活菌数 | 杀菌、接种（嗜热链球菌+保加利亚乳杆菌）、发酵至 pH 4.2–4.6 |
| 乳饮料 | 乳（≥30% 或按标准） + 水 + 糖 + 稳定剂 | 防蛋白沉淀、口感 | 调 pH、稳定剂（CMC/果胶）、均质、杀菌 |
| 奶酪 | 乳 + 菌种 + 凝乳酶 + 盐 | 蛋白/脂肪比、水分、盐 | 凝乳、排乳清、压榨、成熟 |
| 调制乳/含乳饮料 | 乳 + 风味 + 功能 | 与乳饮料界定按标准 | 稳定体系与杀菌 |

- **酸奶稳定**：果胶/明胶/淀粉/琼脂调节黏度与抗析水；发酵后搅拌型 vs 凝固型工艺不同。
- **蛋白沉淀控制**：调 pH 远离等电点（酪蛋白 pI ≈ 4.6），加 CMC/果胶/结冷胶提供静电+空间稳定。
- 乳品生产卫生规范见 GB 12693（**待核实**，见标准文件）。

### 2.3 烘焙

| 子类 | 关键配料 | 设计要点 |
|---|---|---|
| 面包 | 面粉、水、酵母、盐、糖、油、改良剂 | 面筋形成、发酵产气、保软、抗老化（淀粉回生） |
| 蛋糕 | 面粉、蛋、糖、油、膨松剂/乳化剂 | 乳化充气、体积、组织细腻、保湿 |
| 饼干 | 面粉、糖、油、膨松剂 | 酥脆/韧性、延展、水分控制 |

- **抗老化（控淀粉回生）**：乳化剂（单甘酯、蔗糖酯、DATEM）、酶（α-淀粉酶、木聚糖酶）、亲水胶体。
- **面团性能**：氧化剂/还原剂、盐、糖、油的相互作用；高纤维/全麦配方需增水与胶体。
- **减糖减油**挑战：糖影响上色、保湿、结构；替代需配合保湿剂（甘油、山梨醇）与胶体。
- 丙烯酰胺控制（高温烘焙美拉德）关注（**待核实**限量与工艺）。

### 2.4 肉制品

| 子类 | 关键配料 | 设计要点 |
|---|---|---|
| 香肠/乳化肠 | 瘦肉、脂肪、冰水、盐、磷酸盐、腌制剂、淀粉/大豆蛋白 | 蛋白溶出、乳化稳定、保水保油、弹性 |
| 火腿/腌肉 | 肉、盐、亚硝酸盐/硝酸盐、抗坏血酸盐 | 发色、抑菌（肉毒）、风味、保水 |
| 调理肉 | 肉、调味、裹粉/腌渍液 | 嫩化、保水、冷冻稳定 |

- **亚硝酸盐**：发色、抑肉毒、抗氧化；用量与残留须严格按 GB 2760/相应标准（**待核实**），并可用抗坏血酸钠/异抗坏血酸钠促进发色、减少亚硝胺。
- **保水保油**：磷酸盐、食盐、大豆蛋白/卡拉胶/淀粉；斩拌温度控制（≤ 10–12 ℃ 经验）。
- **乳化肠稳定**：蛋白—脂肪界面膜，盐溶蛋白提取是关键；避免破乳出油。
- 肉制品卫生规范（如 GB 19303 等，**待核实**）。

### 2.5 调味品

| 子类 | 关键组成 | 设计要点 |
|---|---|---|
| 酱类（豆酱/果酱/沙拉酱） | 主料、糖/盐、酸、增稠剂 | 稠度、风味、保藏（高盐/高糖/酸化） |
| 复合调味料 | 盐、糖、增味剂、香辛料、酵母抽提物 | 鲜味协同（呈味核苷酸+谷氨酸）、风味层次 |
| 液体调味汁 | 水、盐、糖、酸、增稠、防腐 | 悬浮、防分层、pH 控制 |
| 番茄酱/果酱 | 果浆、糖、酸、果胶 | 凝胶强度、色泽、非酶褐变 |

- **鲜味协同**：MSG（谷氨酸钠）+ 5′-肌苷酸/鸟苷酸（I+G）有显著增效。
- **增味/减盐**：酵母抽提物、水解植物蛋白、氯化钾（带苦味）、香辛料、鲜味肽。
- **果酱凝胶**：糖—果胶—酸三元体系，凝胶 pH 与可溶性固形物（°Brix）决定胶凝。
- 传统发酵调味品见《发酵专家/references/发酵工程基础与工艺参数.md》。

### 2.6 功能食品

- **配方逻辑**：功能因子（维生素、矿物质、膳食纤维、多酚、益生菌、功能肽、ω-3）+ 载体基质 + 保护体系。
- **稳定性**：活性物怕热/光/氧/酸，采用**微胶囊化、包埋、避光包装、冷藏**。
- **剂量与声称**：功效剂量须有依据；保健功能声称须符合注册/备案或普通食品不得虚假声称（**待核实**）。
- **益生菌**：活菌数、耐酸耐胆盐、货架期存活性；包埋与冻干保护剂（海藻糖、脱脂乳）。
- **合规边界**：普通食品 vs 保健食品 vs 特殊医学用途配方食品的管理差异（详见标准文件）。

## 三、配料功能与选型

### 3.1 甜味剂

| 类型 | 代表 | 甜度（蔗糖=1，经验） | 特点 |
|---|---|---|---|
| 营养型糖 | 蔗糖、果葡糖浆、葡萄糖 | 0.7–1.0 | 提供质构/褐变/保湿，热量高 |
| 糖醇 | 山梨醇、木糖醇、赤藓糖醇、麦芽糖醇 | 0.5–1.0 | 低热量、防龋；过量致腹泻 |
| 高倍甜味剂 | 阿斯巴甜、安赛蜜、三氯蔗糖、甜菊糖苷、罗汉果苷 | 数十–数百倍 | 零/低热量；后苦/金属味 |
| 天然甜味蛋白 | 索马甜、莫奈林 | 极高 | 用量小、成本高（待核实许可） |

- **复配**可改善甜味曲线与后味（如三氯蔗糖+甜菊糖苷+赤藓糖醇）。
- 甜味剂使用须符合 **GB 2760** 的食品类别与限量，注意部分品种的**热不稳定性**（阿斯巴甜高温水解）。

### 3.2 酸度调节剂

| 酸 | 酸味特征 | 应用 |
|---|---|---|
| 柠檬酸 | 清爽、快速 | 饮料、果酱、糖果 |
| 苹果酸 | 滞留、尖酸 | 果味饮料、糖果 |
| 乳酸 | 柔和、发酵感 | 乳饮料、肉制品 |
| 酒石酸 | 尖锐 | 葡萄/果味 |
| 磷酸 | 强酸、可乐特征 | 可乐类碳酸饮料 |
| 醋酸 | 刺激性、防腐 | 调味、腌渍 |
| 缓冲盐（柠檬酸钠等） | 调节 pH/缓冲 | 稳定 pH、螯合 |

- 酸不仅调味，还通过**降低 pH** 影响防腐、色泽、凝胶与蛋白稳定性。

### 3.3 增稠稳定剂（亲水胶体）

| 胶体 | 来源/类型 | 特性 | 典型应用 |
|---|---|---|---|
| 果胶（Pectin） | 柑橘/苹果 | 高酯凝胶需糖酸；低酯需钙；蛋白饮料稳定 | 果酱、酸奶、酸性乳饮料 |
| CMC（羧甲基纤维素钠） | 纤维素衍生物 | 增稠、耐酸、蛋白稳定 | 乳饮料、冰淇淋 |
| 黄原胶（Xanthan） | 微生物发酵 | 高黏、耐酸热盐、假塑性强 | 酱料、饮料、无麸质烘焙 |
| 卡拉胶（Carrageenan） | 红藻 | κ/ι/λ 型，κ 需钾凝胶、ι 需钙 | 乳品、果冻、肉制品 |
| 结冷胶（Gellan） | 微生物发酵 | 悬浮力强、透明 | 悬浮饮料、植物奶 |
| 琼脂/明胶 | 藻类/动物 | 凝胶/口感 | 果冻、软糖、酸奶 |
| 淀粉/变性淀粉 | 植物 | 增稠、稳定、抗冻融 | 酱料、肉制品、烘焙 |
| 微晶纤维素 MCC | 纤维素 | 悬浮、抗沉降 | 植物奶、饮料 |

- 选择依据：**pH、离子强度、温度、剪切、冻融、口感（清爽/糊口）**。
- 复配常优于单一：黄原胶+结冷胶（悬浮）、果胶+CMC（酸乳稳定）。

### 3.4 乳化剂与 HLB

| 乳化剂 | HLB（经验） | 主要用途 |
|---|---|---|
| 单甘酯（GMS） | 3–4 | W/O、抗淀粉老化 |
| 蔗糖酯（SE） | 5–16 | 广谱 O/W、饮料、烘焙 |
| 吐温（Tween） | 11–16 | O/W 乳化 |
| 司盘（Span） | 2–9 | W/O 乳化 |
| 卵磷脂 | 3–8 | O/W、天然清洁标签 |
| DATEM | 8–10 | 烘焙面团强化 |
| PGPR | 1–3 | 巧克力降黏 |

**HLB 混合法则**：`HLB_mix = Σ(质量分数_i × HLB_i)`；目标乳液所需 HLB 由实验确定。

### 3.5 香精、色素、防腐剂

| 类别 | 选型要点 | 合规提示 |
|---|---|---|
| 香精 | 水溶/油溶/乳化/粉末；耐热性、头香/体香/底香 | 按 GB 2760 香料名单与用量 |
| 色素 | 天然（花青素、甜菜红、姜黄、β-胡萝卜素、叶绿素）vs 合成（诱惑红等） | 天然色素耐光/热/pH 差；须按 GB 2760 限量 |
| 防腐剂 | 山梨酸/钾、苯甲酸/钠、丙酸钙、乳酸链球菌素、纳他霉素 | 依赖 pH、水相分配；严格按分类限量 |

- **防腐"栅栏"**：低 pH + aw 降低 + 防腐剂 + 冷链 + 包装气氛协同，单靠防腐剂不可靠。

## 四、稳定体系设计

### 4.1 稳定性评价指标

| 指标 | 含义 | 目标（经验） |
|---|---|---|
| **ζ 电位**（Zeta potential） | 颗粒表面电荷，静电排斥强度 | 绝对值 >30 mV 较稳定（经验，待核实） |
| **粒径分布** | D50/D90、多分散指数 PDI | 乳液 0.1–1 μm；PDI 越小越均一 |
| **HLB** | 乳化剂亲水亲油平衡 | 匹配油相所需值 |
| **流变** | 黏度、剪切变稀、屈服应力 | 悬浮需屈服应力 > 重力 |
| **离心/静置稳定性** | 分层、沉淀、析水率 | 加速离心无分层 |
| **显微观察** | 絮凝、聚并、Ostwald 熟化 | 无异常聚集 |

### 4.2 失稳机理与对策

| 失稳现象 | 机理 | 对策 |
|---|---|---|
| 乳析/沉降 | 密度差、重力 | 增稠、减小粒径、均质 |
| 絮凝 | 静电/桥联作用 | 提高 ζ 电位、空间位阻胶体 |
| 聚并 | 界面膜破裂 | 增强界面膜（蛋白+乳化剂复配） |
| Ostwald 熟化 | 小滴溶解、大滴长大 | 使用低溶解度油相、界面膜 |
| 相分离/析水 | 凝胶网络收缩 | 优化胶体配比、离子/pH |
| 蛋白沉淀 | 等电点、热变性 | 调 pH、加稳定剂、控制热处理 |

### 4.3 设计步骤（以酸性乳饮料为例）

1. 确定蛋白含量与目标 pH（如 pH 3.8–4.2）。
2. 选稳定剂：**果胶/CMC**（防酪蛋白沉淀），必要时结冷胶悬浮。
3. 溶解顺序：稳定剂先与糖干混后溶解，避免结块；再与乳混合。
4. 酸添加：**缓慢、低温、高剪切**下加酸，避免局部等电点沉淀。
5. 均质（15–25 MPa）→ 杀菌（UHT/巴氏）→ 灌装。
6. 验证：离心稳定性、粒径、ζ 电位、感官、货架期。

## 五、清洁标签与减糖减盐

### 5.1 清洁标签（Clean Label）

- **原则**：配料表简短、消费者可识别、减少人工添加剂、尽量"天然/少加工"。
- **替代策略**：
  - 增稠乳化：果胶、卵磷脂、淀粉、蛋白替代合成胶体/乳化剂。
  - 防腐：栅栏技术、杀菌强化、气调包装、发酵抑菌替代或减少防腐剂。
  - 色素/香精：天然色素与天然香精。
- **注意**：天然不等于安全，且可能带来稳定性、成本与法规差异（如天然色素稳定性差）。

### 5.2 减糖（Sugar Reduction）

| 方法 | 说明 | 挑战 |
|---|---|---|
| 高倍甜味剂复配 | 零/低热量补甜 | 后苦、质构缺失 |
| 糖醇/稀有糖 | 部分替代、保湿 | 腹泻阈值、成本 |
| 纤维替代 | 提供体积/口感（菊粉、聚葡萄糖） | 风味与耐受 |
| 多感官（香气/酸/增稠） | 增强甜感知觉 | 效果有限 |

### 5.3 减盐（Sodium Reduction）

| 方法 | 说明 |
|---|---|
| 逐步降盐 | 循序渐进改变口味习惯 |
| 咸味增强剂/鲜味协同 | 酵母抽提物、MSG+I+G、呈味肽 |
| 替代盐（KCl/MgCl₂） | 降钠但带苦/金属味，需复配掩蔽 |
| 结构/形态优化 | 盐晶体细化提高咸感、表面施盐 |

> 营养标签（GB 28050）对"低糖/无糖/低钠"等**营养声称**有明确条件，须核对标准（**待核实**）。

## 六、法规注意（GB 2760 等）

- **GB 2760 使用原则**：添加剂须"在允许的食品类别、以允许的功能、不超过最大使用量/残留量"；同一功能添加剂复配时关注**比例之和 ≤ 1**等规则。
- **带入原则**：添加剂可由配料带入，但须符合相应规定，不能超范围/超量。
- **标签**：配料表按 GB 7718 递减排序；添加剂标示方式（功能类别+具体名称或国际编码 INS 号）以现行标准为准（**待核实**）。
- **营养标签**：GB 28050 规定强制标示内容（能量、蛋白、脂肪、碳水、钠）与营养声称条件。
- **香精香料**：按 GB 2760 允许名单与用量；不得掩盖缺陷。
- **"三新食品"**：新食品原料、添加剂新品种、相关产品新品种须经审批后方可使用（详见《标准规范与法规-食品加工.md》）。
- **特殊食品**：保健食品、婴配、特医食品另有注册/备案与配方要求。

**待核实清单**：
1. GB 2760 中各添加剂在**具体食品类别**的最大使用量/残留量（含复配规则）。
2. 各类甜味剂、糖醇的**甜度系数、ADI、耐受量**具体数值。
3. 电解质饮料**等渗渗透压**（mOsm/kg）的公认范围。
4. 各亲水胶体在目标体系的**推荐添加量与复配比例**。
5. 乳化剂 HLB 数值的**准确取值**及其与油相匹配的定量方法。
6. 营养声称（低糖/无糖/低钠等）的**现行阈值条件**。
7. 天然色素的允许来源、色价与限量（现行公告为准）。
8. 保健食品/特医食品配方的注册备案要求。
