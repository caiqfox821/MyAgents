## 四、来源与可靠性说明

- **一级（权威）**：国家卫健委/CFSA、市场监管总局、国家标准全文公开系统、农业农村部及权威教材/综述。
- **二级（参考）**：行业媒体、企业科普资料；具体数值须回归一级来源或实测。
- **数值免责**：文中"典型/参考区间"为工程经验量级，配方与工艺须经小试—中试验证。
- 各文件均设 **"待核实"标注与清单**；涉及限量、检验方法与禁用清单时，以现行 GB 标准正文为准。

## 五、收录原则与核验约定

- 法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T、NY/T、QB/T 等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- 涉及**限量值、食品添加剂使用、检验方法、禁限用清单、标准版本号**时不得臆造，须声明"以现行标准正文为准"；需要精确数值/条文时，先向用户索取该标准 PDF 或联网核验后再收录。
