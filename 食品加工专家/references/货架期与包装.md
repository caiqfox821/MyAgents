# 货架期与包装

> 整理范围：货架期影响因素、栅栏技术与预测微生物、加速货架期试验（ASLT）与实时试验、感官与理化衰减评价、包装阻隔与货架期匹配、目标货架期设定与验证。
> 主要依据：食品保藏与货架期预测通用教材与行业实践；Arrhenius/Q₁₀ 动力学、预测微生物学（Gompertz、D/z 值）；GB 7718/GB 28050 对保质期的标注要求（版本待核实）。

## 一、影响货架期的因素

### 1.1 内在因素（食品本身）

| 因素 | 作用 | 典型控制方向 |
|---|---|---|
| **水分活度 aw** | 决定微生物可利用水；影响化学反应与质构 | 干燥/浓缩/加糖盐降低 aw；多数细菌 aw >0.9，多数霉菌/酵母 >0.6–0.7（精确阈值因菌种，待核实） |
| **pH** | 决定微生物谱与防腐剂效能 | 低 pH（<4.6）抑制肉毒梭菌；酸化延长货架期 |
| **可滴定酸/缓冲力** | 影响酸味与微生物抑制 | 有机酸（未解离态抑菌更强） |
| **氧化底物** | 脂肪、色素、维生素、风味物的氧化 | 抗氧化剂、充氮、避光、除氧 |
| **酶活** | 内源酶（脂肪酶、多酚氧化酶、蛋白酶）致劣变 | 漂烫灭酶、热处理、钝化 |
| **微生物初始菌数** | 直接决定达到腐败阈值的时间 | 原料卫生、杀菌、无菌灌装 |
| **营养成分/氧化还原电位** | 影响微生物生长与氧化反应 | 调控 Eh、添加还原剂 |
| **质构/组织结构** | 决定水分迁移、冰晶损伤、回生 | 配方（胶体/乳化剂）、工艺 |

### 1.2 外在因素（环境与包装）

| 因素 | 作用 | 控制方向 |
|---|---|---|
| **温度** | 微生物生长与化学反应速率的主要驱动（Q₁₀、Arrhenius） | 冷链、避热、UHT 常温品 |
| **相对湿度** | 决定粉状/干制品的吸湿或失水 | 阻湿包装、干燥剂 |
| **氧气** | 氧化酸败、褐变、好氧菌/霉菌生长 | 真空/充氮、除氧剂、阻氧包装 |
| **光照（尤其 UV/可见）** | 光氧化、色素/维生素降解 | 避光包装、铝箔、深色瓶 |
| **机械力** | 振动、挤压破坏结构/封口 | 结构设计、缓冲包装 |
| **包装阻隔性** | 决定 O₂/H₂O 侵入速率 | 选材（见第四节） |
| **微生物再污染** | 灌装/封口缺陷 | 无菌灌装、封口检测 |

## 二、栅栏技术与预测微生物

### 2.1 栅栏技术（Hurdle Technology）

- 概念：多种温和抑菌因子**协同**，让微生物无法跨越多个"栅栏"，实现**温和加工 + 长货架期**。
- 常见栅栏：**温度（冷链/热处理）、aw、pH、氧化还原电位、防腐剂、竞争菌群、气调包装、辐照、HPP**。
- 优点：减轻单一强处理对品质的破坏；典型如**中湿食品（IMF）、即食肉、酸性乳饮料**。
- 原则：栅栏组合必须对**目标菌**有效，并考虑协同/拮抗与消费者可接受度。

### 2.2 预测微生物学

**（1）灭活动力学**（与《加工单元操作.md》一致）：

`lg(N/N₀) = −t / D`；`D₂ = D₁ · 10^((T₁−T₂)/z)`

**（2）生长动力学**：

- **指数模型**：`N(t) = N₀ · e^(μ·t)`；`td = ln2/μ`。
- **Logistic / Gompertz 模型**（描述迟滞期—指数期—稳定期）：

`lg N(t) = A + C · exp{−exp[−B(t−M)]}`（修正 Gompertz）

| 参数 | 含义 |
|---|---|
| A | 初始菌数对数值 lg N₀ |
| C | 最大生长量（稳定期与初始之差，对数级） |
| B | 指数期相对生长速率（与 μ 相关） |
| M | 达到最大生长速率的时间 |
| λ（迟滞期 lag） | 由 A、B、C、M 换算 |
| μ_max | 最大比生长速率 |

- **平方根模型（Ratkowsky）**：`√μ ∝ (T − T_min)`，用于描述温度对 μ 的影响并求**最低生长温度**。
- 预测微生物软件（如 ComBase、Pathogen Modeling Program 等，**待核实可用性**）可估算货架期与风险，但**必须用实际产品验证**（食品基质、菌株、竞争菌群差异大）。

### 2.3 微生物腐败判定

- **腐败阈值**：以菌落总数、特定腐败菌（SSO）、感官/理化指标达到不可接受水平的时间为货架期终点。
- 常见目标菌：嗜冷菌（冷藏）、乳酸菌、酵母/霉菌（酸性/高糖）、芽孢（常温）。
- 致病菌（沙门、单增李斯特、金葡、大肠杆菌 O157 等）不以"生长到某数"为货架期指标，而应**不检出/低于限量**（见食品安全专家知识库）。

## 三、加速货架期试验（ASLT）与实时试验

### 3.1 温度依赖：Arrhenius 与 Q₁₀

- **Arrhenius 方程**：`k = A · e^(−Ea/(R·T))` → `ln k = ln A − Ea/(R·T)`
  - k：反应速率常数；Ea：活化能（J/mol）；R：气体常数 8.314 J/(mol·K)；T：绝对温度（K）。
  - 由 ln k 对 1/T 作图为直线，斜率 = −Ea/R。
- **Q₁₀**：`Q₁₀ = (k_T+10)/k_T`；`货架期比 ≈ Q₁₀^(ΔT/10)`。
  - 化学反应 Q₁₀ ≈ 2–3；微生物生长 Q₁₀ ≈ 2–4（经验，待核实）。
- 用途：由高温（加速）数据外推低温（常温/冷藏）货架期；**前提是劣变机理在温度区间内不变**。

### 3.2 ASLT 设计

| 步骤 | 内容 |
|---|---|
| 1 选指标 | 选择**限速劣变指标**（微生物、氧化、色泽、风味、质地、维生素） |
| 2 定终点 | 感官/理化/微生物不可接受阈值 |
| 3 设温度梯度 | 常用 3–4 个温度（如 25/35/45 ℃ 或 30/40/50 ℃），至少高于储藏温度 |
| 4 定时取样 | 覆盖整个劣变过程，足够数据点 |
| 5 建模型 | 用 Arrhenius/Q₁₀ 或线性回归求速率常数、活化能 |
| 6 外推 | 计算目标温度下货架期 |
| 7 验证 | 与实时试验对比，修正模型 |

- **加速系数**：如 Q₁₀=2 时，37 ℃ 下 1 个月 ≈ 22 ℃ 下 2 个月（示例，须实测）。
- **注意**：
  - 高温可能**改变劣变机理**（如微生物谱变化、非酶褐变主导、脂肪氧化路径改变）→ 外推失真。
  - 微生物劣变在加速温度下受"最适生长温度"影响，**不能用简单 Q₁₀ 外推**。
  - 需注明加速温度、时间、模型与置信区间。

### 3.3 实时试验（货架期验证）

- 在实际储运条件下（常温、冷藏、货架光照/温度波动）进行，是**最终判定依据**。
- 设计：**至少覆盖目标货架期**（如目标 12 个月则做满 12 个月），多批次（建议 ≥3 批）。
- 记录：温度/湿度/光照日志，定期取样测感官、理化、微生物。
- 与 ASLT 结果互证；标准要求"保质期由企业根据产品特性确定并负责"（GB 7718 相关，**待核实**）。

### 3.4 感官与理化衰减评价

| 维度 | 指标 | 方法 |
|---|---|---|
| 感官 | 色泽、香气、滋味、质构、外观 | 描述性分析（QDA）、差别检验、消费者接受度（9 分制） |
| 理化 | 酸价/过氧化值、TBARS、总酸、pH、水分、aw、色泽 ΔE、维生素 | 按 GB 5009 系列方法（待核实） |
| 微生物 | 菌落总数、酵母/霉菌、乳酸菌、目标腐败菌/致病菌 | GB 4789 系列 |
| 微观 | 粒径、晶体、分层 | 显微、激光粒度 |

- **色泽 ΔE**（CIELAB）常作为客观衰减指标；**过氧化值/TBARS**表征脂肪氧化。
- 建议建立"**货架期终点综合评分卡**"：多指标加权 + 感官阈值。

## 四、包装与货架期匹配

### 4.1 包装功能与选材

| 功能 | 需求 | 常用材料/结构 |
|---|---|---|
| **阻氧** | 防氧化、防好氧菌霉变 | EVOH、PVDC、镀铝/铝箔、高阻隔膜；多层复合 |
| **阻水（阻湿）** | 防吸潮/失水 | PE、PP、镀铝；干制品关键 |
| **避光** | 防光氧化/维生素降解 | 铝箔、遮光膜、深色/琥珀瓶 |
| **耐热** | 杀菌/热灌装/UHT | PP、PET、玻璃、金属罐、耐高温蒸煮袋 |
| **耐压/耐 CO₂** | 碳酸饮料 | PET、玻璃、铝罐 |
| **耐油/耐酸** | 酱料、酸性食品 | PET、PP、玻璃、复合膜 |
| **密封完整性** | 防再污染 | 封口工艺 + 检漏（真空衰减、染料渗透） |

- **O₂ 透过率（OTR）、水蒸气透过率（WVTR）**是关键指标，须与**目标货架期**匹配（单位：cm³/(m²·24h·atm)、g/(m²·24h)）。
- 包装**面积/体积比**越大，单位产品透过量越高，货架期越短。

### 4.2 气调与活性包装

| 技术 | 原理 | 适用 |
|---|---|---|
| 真空包装（VP） | 抽真空隔绝 O₂ | 肉制品、熟食、奶酪 |
| 气调包装（MAP） | 充入 CO₂/N₂/O₂ 特定比例 | 生鲜肉、果蔬、烘焙、即食 |
| 充氮包装 | 替代 O₂ 防氧化 | 薯片、坚果、奶粉 |
| 除氧剂 | 化学吸收残余 O₂ | 烘焙、肉制品、干果 |
| 干燥剂 | 吸收水汽 | 干制品、粉体、药品 |
| 乙烯吸收剂 | 延缓果蔬后熟 | 果蔬保鲜 |
| 抗菌活性包装 | 缓释抑菌物 | 易腐食品 |
| 可降解材料 | PLA、PBAT、淀粉基、纸基 | 环保需求；阻隔性/成本受限（待核实降解标准） |

- **MAP 气体比例**因产品而异（如生鲜红肉需高 O₂ 保持色泽，而熟食宜高 CO₂/N₂ 抑菌），**待核实**具体产品推荐比例。
- **可降解材料**须符合 GB 4806 系列食品接触材料要求与降解性能标准（**待核实**）。

### 4.3 包装与货架期匹配方法

1. 确定产品**限速劣变机理**（如氧化 vs 微生物 vs 吸湿）。
2. 估算允许的最大 O₂/H₂O 侵入量。
3. 根据包装**OTR/WVTR、面积/体积比、目标时间**选材。
4. 做**包装完整性 + 加速/实时储藏**验证。
5. 兼顾**成本、可回收性、货架陈列、法规标识**。

## 五、目标货架期设定与验证

### 5.1 设定原则

- 由**产品特性、工艺（杀菌强度）、包装、预期储运条件**综合决定。
- 类别参考（经验，**待核实**）：
  - 巴氏冷藏乳/果汁：数天–数周（冷链）。
  - UHT 常温乳/无菌果汁：数月（6–12 个月，因包装/温度）。
  - 罐头：长期（1–3 年，因产品）。
  - 冻品：数月–1 年以上（−18 ℃，注意冻烧）。
  - 干燥/粉体：数月至 1 年以上（阻湿避光）。
  - 新鲜果蔬：数天–数周（MAP/冷藏）。
- **保质期标注**须符合 GB 7718 要求，且**企业对保质期负责**（**待核实**标签具体规定）。

### 5.2 验证流程清单

- [ ] 明确产品类别、工艺、包装与储运条件
- [ ] 识别限速劣变指标与可接受阈值
- [ ] 制定 ASLT 与实时试验方案（温度梯度、取样频次、批次数）
- [ ] 微生物挑战试验（如适用，验证栅栏有效性）
- [ ] 包装完整性/阻隔性测试
- [ ] 感官与理化/微生物定期检测
- [ ] 数据建模（Arrhenius/Q₁₀ 或 Gompertz）与外推
- [ ] 实时数据验证并确定最终货架期
- [ ] 建立留样与市场反馈跟踪机制
- [ ] 标签、声称与法规复核
