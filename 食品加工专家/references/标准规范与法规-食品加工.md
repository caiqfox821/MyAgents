## 一、食品添加剂、污染物与微生物限量

| 标准（示例） | 主题 | 使用要点 |
|---|---|---|
| **GB 2760** | 食品添加剂使用标准 | 按**食品类别 + 功能 + 最大使用量/残留量**执行；带入原则；复配规则（如相同功能比例之和 ≤1） |
| **GB 2761** | 食品中真菌毒素限量 | 黄曲霉毒素、赭曲霉毒素、脱氧雪腐镰刀菌烯醇等 |
| **GB 2762** | 食品中污染物限量 | 铅、镉、汞、砷、锡、亚硝酸盐、苯并[a]芘等 |
| **GB 2763** | 食品中农药最大残留限量 | 原料农残合规（与种植/采购对接） |
| **GB 29921** | 预包装食品中致病菌限量 | 沙门、金葡、单增李斯特、大肠杆菌 O157 等 |
| GB 31650 等 | 食品中兽药最大残留限量（**编号待核实**） | 肉、乳、蛋原料 |

- 食品添加剂**新品种**须审批（见"三新食品"节）。
- 发酵食品还需关注**生物胺、氨基甲酸乙酯（EC）**等过程污染物（详见发酵专家与食品安全专家知识库）。

## 二、标签与营养标签

| 标准（示例） | 主题 | 要点 |
|---|---|---|
| **GB 7718** | 预包装食品标签通则 | 食品名称、配料表（递减排序）、净含量、日期、生产者、贮存条件、SC 编号、添加剂标示等 |
| **GB 28050** | 预包装食品营养标签通则 | 强制标示能量、蛋白、脂肪、碳水、钠；NRV%；营养声称条件 |
| GB 13432 | 预包装特殊膳食用食品标签 | 婴配、特医等（**待核实**） |
| GB 7718 问答/指南 | 标签释义 | 配料、日期、声称执行口径（**待核实**） |

- **营养标签**制作与 NRV% 计算详见《营养专家》知识库；本文件只作索引。
- **日期标示**：生产日期、保质期/保存期；"保质期由企业负责"，须有验证依据（见《货架期与包装.md》）。
- 标签**不得虚假/夸大**，功能声称受严格限制（普通食品不得宣称保健功能）。

## 三、生产通用卫生规范与食品类别卫生规范

| 标准（示例） | 主题 | 说明 |
|---|---|---|
| **GB 14881** | 食品生产通用卫生规范（食品 GMP 基础） | 厂区、厂房、设施、人员、卫生管理、记录等通用要求 |
| **GB 8950** | 罐头食品生产卫生规范（原"罐头厂卫生规范"，**名称/版本待核实**） | 罐头类专项要求 |
| GB 12693 | 乳制品良好生产规范（乳制品 GMP） | 乳制品生产专项要求 |
| GB 8951–GB 8957 等 | 白酒、啤酒、酱油、食醋、食用油、蜜饯、糕点等卫生规范（**编号待核实**） | 各食品类别生产卫生规范 |
| GB 12694–GB 12698 等 | 肉类、饮料、葡萄酒、果酒、黄酒生产卫生规范（**编号待核实**） | 饮料/酒类专项 |
| GB 19303、GB 19304、GB 20941 等 | 熟肉制品、包装饮用水、水产制品卫生规范（**待核实**） | 类别专项 |
| GB 17403、GB 17404 等 | 巧克力、膨化食品生产规范（**待核实**） | 类别专项 |

- **类别卫生规范**与 GB 14881 配合使用；产品标准另按具体 GB/GB/T 执行。
- 项目若为果蔬汁/饮料/乳品，优先核对**饮料、乳制品、罐头**对应规范（**以现行版本为准**）。

## 四、食品安全管理体系

| 体系/工具 | 全称/含义 | 作用 |
|---|---|---|
| **GMP** | Good Manufacturing Practice，良好生产规范 | 硬件与基础卫生条件 |
| **SSOP** | Sanitation Standard Operating Procedure，卫生标准操作程序 | 清洗消毒、用水、防交叉污染等日常卫生 |
| **HACCP** | Hazard Analysis and Critical Control Point，危害分析与关键控制点 | 系统识别/预防生物、化学、物理危害 |
| **ISO 22000** | 食品安全管理体系（Food Safety Management System） | 可认证的体系框架；整合 HACCP 与前提方案 |
| **FSSC 22000 / BRCGS / IFS** | 国际食品安全认证方案 | 供应链/客户要求（**待核实**） |

- **HACCP 七原则**：危害分析 → 确定 CCP → 建立关键限值 → 监控 → 纠偏 → 验证 → 记录。
- 与**前提方案（PRP/OPRP）**、SSOP 配合；关键限值须经**验证**（热分布/热穿透、微生物挑战等，见《中试放大与产线.md》）。
- 危害识别与限量判定与**食品安全专家**协作。

## 五、食品生产许可（SC）与监管

- **《食品生产许可管理办法》**（市场监管总局规章，**版本待核实**）：从事食品生产须取得**食品生产许可证（SC 编号）**；规定申请、审查、发证、变更、延续、监管。
- **许可类别目录**：按食品生产许可分类目录对应产品类别（**以现行目录为准**）。
- **审查通则/细则**：生产场所、设备设施、设备布局与工艺流程、人员、制度、试制产品检验等（**编号待核实**）。
- **日常监管**：监督检查、抽检监测、风险分级、追溯体系。
- **仅销售预包装食品**实行备案管理（《食品安全法》相关）。
- **标签上的 SC 编号**须与许可一致。

## 六、"三新食品"与清洁标签

### 6.1 "三新食品"

| 类型 | 含义 | 管理 |
|---|---|---|
| **新食品原料** | 无传统食用习惯的原料 | 安全性审查，公告后方可使用 |
| **食品添加剂新品种** | 未列入 GB 2760 的添加剂 | 审批后增补 |
| **食品相关产品新品种** | 新接触材料/添加剂等 | 审批 |

- 依据：《新食品原料安全性审查管理办法》等（**版本待核实**）。
- 使用须核对**允许名单、使用范围与限量**；涉及**转基因**另按相关法规（**待核实**）。

### 6.2 清洁标签（Clean Label）

- **非强制法规概念**，属市场/消费者导向；无统一定义。
- 常见做法：缩短配料表、使用消费者可识别配料、减少人工添加剂。
- **合规底线**：无论是否"清洁标签"，均须符合 GB 2760、GB 7718 等强制要求；"无添加"等表述须谨慎，避免误导（**待核实**具体执法口径）。

## 七、食品接触材料与包装

| 标准（示例） | 主题 |
|---|---|
| **GB 4806.1** | 食品接触材料及制品通用安全要求 |
| GB 4806.6 / GB 4806.7 | 塑料树脂 / 塑料材料及制品 |
| GB 4806.8 | 纸和纸板材料及制品 |
| GB 4806.9 | 金属材料及制品 |
| GB 4806.5 / GB 4806.4 / GB 4806.3 | 玻璃 / 陶瓷 / 搪瓷 |
| GB 4806.10 / GB 4806.11 | 涂料涂层 / 橡胶 |
| GB 9685 等 | 添加剂使用与迁移限量（**待核实**） |

- 要点：**材质合规、总迁移量与特定迁移量（SML）符合限量、符合预期使用条件（温度、油脂、酸性）**。
- 包装选材与货架期匹配见《货架期与包装.md》；可降解材料须同时满足食品接触与降解性能要求（**待核实**）。

## 九、合规工作清单（食品加工项目）

- [ ] 确认**产品类别**与适用产品标准、卫生规范
- [ ] 核对 **GB 2760** 添加剂范围与限量（含复配、带入原则）
- [ ] 核对 **GB 2761/2762/2763/29921** 等限量与致病菌要求
- [ ] 设计 **GB 7718 标签** 与 **GB 28050 营养标签**（与营养专家协作）
- [ ] 依 **GB 14881 + 类别卫生规范** 进行厂房与卫生设计
- [ ] 建立 **HACCP 计划**（危害分析、CCP、关键限值、监控、验证），必要时建 ISO 22000 体系
- [ ] 办理 **食品生产许可（SC）**，核对许可类别与标签编号
- [ ] 新原料/新添加剂核查是否属"**三新食品**"，必要时申报
- [ ] **食品接触材料**合规（GB 4806 系列、迁移限量）
- [ ] 进口食品核对**中文标签**与海关要求（如适用）
- [ ] 建立批记录、追溯、召回、留样与偏差管理
- [ ] 广告/声称合规审查（不得虚假、不得超范围功能声称）
- [ ] 环保：废水/废气/固废排放与清洁生产（**编号待核实**）

5. 营养标签强制标示项与**营养声称阈值**的现行规定。
6. **《食品生产许可管理办法》**与审查细则的最新版本。
7. **"三新食品"**与新食品原料的最新公告名单与申报流程。
8. **GB 4806 系列**食品接触材料的现行版本与迁移限量。
