# 科学报告写作模板

> 依据 IMRAD 结构与学术写作规范编制

## 一、报告类型速查表

| 类型 | 中文 | 适用场景 | 核心要素 |
|------|------|----------|----------|
| Research Report | 研究报告 | 课题研究、科研项目 | IMRAD + 基金资助 |
| Experiment Report | 实验报告 | 实验教学、实验记录 | 目的/原理/步骤/数据/结论 |
| Investigation Report | 调查报告 | 现场调查、社会调查 | 背景/方法/结果/分析/建议 |
| Technical Report | 技术报告 | 工程问题、技术方案 | 问题/方案/验证/结论 |
| Literature Review | 文献综述 | 学位论文综述、开题报告 | 现状/争议/空白/展望 |
| Feasibility Study | 可行性报告 | 项目立项、投资决策 | 市场/技术/经济/环境/风险 |
| Project Final Report | 结题报告 | 项目验收 | 任务完成/成果/经费/结论 |

## 二、IMRAD 标准结构

```
┌─────────────────────────────────────────────────┐
│  标题：准确、简洁、反映研究核心                   │
│  作者：姓名 + 单位 + 通讯作者 + ORCID            │
│  摘要：目的/方法/结果/结论（300字）+ 关键词       │
├─────────────────────────────────────────────────┤
│  1 引言（Introduction）                          │
│    1.1 研究背景与意义                            │
│    1.2 国内外研究现状（文献综述）                  │
│    1.3 研究问题与目的                            │
│    1.4 技术路线与创新点                          │
│                                                 │
│  2 材料与方法（Methods）                         │
│    2.1 研究对象/样本                             │
│    2.2 实验/调查设计                             │
│    2.3 数据采集与仪器                            │
│    2.4 数据分析方法                              │
│    2.5 质量控制（QA/QC）                         │
│                                                 │
│  3 结果（Results）                               │
│    3.1 描述性统计                                │
│    3.2 统计分析结果（配图表）                     │
│    3.3 灵敏度分析/不确定性分析（如需）             │
│    ※ 只陈述事实，不下结论                        │
│                                                 │
│  4 讨论（Discussion）                            │
│    4.1 结果解读与机制分析                        │
│    4.2 与前人研究对比                            │
│    4.3 研究局限性与不确定性                      │
│    4.4 应用前景与展望                            │
│                                                 │
│  5 结论（Conclusion）                            │
│    5.1 主要发现                                  │
│    5.2 结论                                      │
│    5.3 建议                                      │
├─────────────────────────────────────────────────┤
│  参考文献（GB/T 7714 或 APA）                    │
│  附录（原始数据、仪器信息、补充图表）              │
│  致谢（基金资助、合作者）                        │
└─────────────────────────────────────────────────┘
```

## 三、排版与字体规范（强制）

> **统一字体与颜色规范（本模板强制，2026-10 修订）**
> 1. **中文字体：宋体**；**英文、数字及西文符号：Times New Roman**。OOXML 须同时设置 `w:ascii`/`w:hAnsi`/`w:cs="Times New Roman"` 与 `w:eastAsia="宋体"`，避免中文字体被替换。
> 2. **文字颜色：全文纯黑 #000000**；禁用蓝色标题、主题色、渐变、阴影、艺术字与装饰性色块；超链接也用黑色。
> 3. **表格**：表头不加底纹、仅加粗；边框为黑色细线（0.5 pt，OOXML `w:sz="4"`）；禁用彩色边框与彩色填充。
> 4. **生成命令**：`pandoc 输入.md -o 输出.docx --from gfm --reference-doc=templates/reference-tnr-simsun.docx --no-highlight`。
> 5. **例外**：`doc-党政公文-template.md` 执行 GB/T 9704-2012（红头、仿宋/黑体/楷体），不适用本规范。

| 要素 | 字体 | 字号 | 行距 | 对齐/缩进 |
|------|------|------|------|-----------|
| 报告标题 | 宋体 加粗 | 小二（18pt） | 1.5 倍 | 居中，无缩进 |
| 一级标题（1 / 一、） | 宋体 加粗 | 四号（14pt） | 1.5 倍 | 左对齐，无缩进 |
| 二级标题（1.1 / （一）） | 宋体 加粗 | 小四（12pt） | 1.5 倍 | 左对齐，无缩进 |
| 三级标题（1.1.1 / 1.） | 宋体 | 小四（12pt） | 1.5 倍 | 左对齐，无缩进 |
| 正文 | 宋体 | 小四（12pt） | 1.5 倍 | 两端对齐，首行缩进 2 字符 |
| 表格文字 | 宋体 | 五号（10.5pt） | 单倍 | 单元格内不缩进 |
| 表头 | 宋体 加粗 | 五号（10.5pt） | 单倍 | 居中，无底纹 |
| 图表题注 | 宋体 | 五号（10.5pt） | 单倍 | 图题在下、表题在上，居中 |
| 参考文献 | 宋体 | 五号（10.5pt） | 1.25 倍 | 悬挂缩进 |
| 英文/数字 | Times New Roman | 随所在段落 | 随所在段落 | 与中文同一段落内混排 |

- 三线表：顶线与底线 1.5 pt、表头下线 0.75 pt，全部为**黑色**；不设竖线、不使用彩色底纹。
- 图表内文字同样遵守"中文宋体、英文 Times New Roman、全黑"；图形填充用黑白灰，不用彩色。

### 统计报告规范

| 检验类型 | 报告格式示例 |
|----------|-------------|
| t检验 | t(58) = 2.34, p = 0.023, Cohen's d = 0.62 |
| 方差分析 | F(2, 87) = 5.67, p = 0.005, η²p = 0.12 |
| 卡方检验 | χ²(3) = 11.25, p = 0.010 |
| 相关系数 | r(98) = 0.45, p < 0.001 |
| 非参数检验 | U = 124.5, p = 0.032 |
| 回归分析 | β = 0.32, t(95) = 3.45, p = 0.001, R² = 0.24 |

### 有效数字规则

| 测量精度 | 报告示例 | 说明 |
|----------|---------|------|
| 0.1 | 12.3 | 保留1位小数 |
| 0.01 | 12.34 | 保留2位小数 |
| 仪器精度 | 与仪器一致 | 不随意增减位数 |
| p值 | p = 0.034 | 保留3位小数 |
| 很小p值 | p < 0.001 | 不写p = 0.000 |

## 六、常见错误

| 错误 | 正确 |
|------|------|
| 结果部分写"这表明……" | 结果只**陈述**，讨论才**解读** |
| 摘要中引用图表 | 摘要**独立成篇**，不引用图表 |
| 统计只写p值 | 统计量 + 自由度 + p值 + 效应量 | 
| 图表编号混乱 | 全文连续编号，图表分开 |
| 引用格式不统一 | 全文统一为一种标准 |
| 结论提出新观点 | 结论只**总结**已有发现，不引入新信息 |
| 术语前后不一致 | 首次出现给全称+缩写，后续统一 |
| 使用"证明""一定" | 用"表明""提示""可能" |
