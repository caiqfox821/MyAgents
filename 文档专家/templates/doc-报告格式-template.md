# Simple Report

> 说明：本文件为纯格式模板，仅规定文档结构与样式，不含任何具体内容。占位符处需填入实际项目内容。

---

## 格式规范说明

| 项目 | 要求 |
| --- | --- |
| 标题 | 项目名称，宋体加粗、居中，三号字（16 pt） |
| 一级标题 | "一、二、三"编号，宋体加粗，三号字（16 pt），单倍行距 |
| 正文 | 宋体，小四或四号字（12–14 pt），首行缩进两字符，1.5 倍行距 |
| 表格 | 表头宋体加粗、**无底纹**；边框黑色细线 |
| 字体与颜色 | 中文**宋体**、英文与数字 **Times New Roman**、全文**纯黑** |
| 页边距 | 上3.7cm 下3.5cm 左2.8cm 右2.6cm（如需公文版式） |

> **统一字体与颜色规范（本模板强制，2026-10 修订）**
> 1. **中文字体：宋体**；**英文、数字及西文符号：Times New Roman**。OOXML 须同时设置 `w:ascii`/`w:hAnsi`/`w:cs="Times New Roman"` 与 `w:eastAsia="宋体"`，避免中文字体被替换。
> 2. **文字颜色：全文纯黑 #000000**；禁用蓝色标题、主题色、渐变、阴影、艺术字与装饰性色块；超链接也用黑色。
> 3. **表格**：表头不加底纹、仅加粗；边框为黑色细线（0.5 pt，OOXML `w:sz="4"`）；禁用彩色边框与彩色填充。
> 4. **生成命令**：`pandoc 输入.md -o 输出.docx --from gfm --reference-doc=templates/reference-tnr-simsun.docx --no-highlight`。样式基准文件 `reference-tnr-simsun.docx` 已内置上述字体与黑色样式；`--no-highlight` 用于去掉代码高亮的彩色。
> 5. **例外**：`doc-党政公文-template.md` 执行 GB/T 9704-2012（红头、仿宋/黑体/楷体），不适用本规范。
