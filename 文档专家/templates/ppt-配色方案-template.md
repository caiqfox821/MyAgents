# PPT 配色方案：白底 · 紫标题 · 黑正文

> 适用于 `模板_白底紫标题.pptx`（由 `ppt_template.py` 生成）

## 配色总览

| 角色 | 色值 | RGB | 用途 | 占比建议 |
|------|------|-----|------|----------|
| 背景色 | `#FFFFFF` | (255, 255, 255) | 页面底色 | ~70% |
| 主色（标题） | `#6B3FA0` | (107, 63, 160) | 标题、重点块、表头、章节页装饰 | ~15% |
| 强调色 | `#9B72CF` | (155, 114, 207) | 分隔线、项目符、图表点缀、序号 | ~8% |
| 卡片底色 | `#F3EEFA` | (243, 238, 250) | 卡片、表格隔行条纹 | ~5% |
| 正文色 | `#000000` | (0, 0, 0) | 正文文字 | — |
| 次要文字 | `#666666` | (102, 102, 102) | 说明、脚注、副标题 | — |
| 反白色 | `#FFFFFF` | (255, 255, 255) | 紫色块上的文字 | — |

## 使用规则

1. **一页内主色不超过 3 种**：白底 + 紫标题 + 黑正文，强调紫仅做点缀。
2. **紫色用于标题层级**：页面标题、卡片标题条、表头；不做大面积正文底色。
3. **正文保持纯黑** `#000000`，白底上对比度最高、最易读。
4. **次要信息用中灰** `#666666`（脚注、页码、来源），不要用浅灰大面积正文。
5. **图表配色**建议：`6B3FA0`、`9B72CF`、`C9B3E8`、`666666`（同色系深浅 + 灰）。

## python-pptx 常量定义

```python
from pptx.dml.color import RGBColor

PURPLE    = RGBColor(0x6B, 0x3F, 0xA0)   # 标题
PURPLE_LT = RGBColor(0x9B, 0x72, 0xCF)   # 强调/装饰
PURPLE_BG = RGBColor(0xF3, 0xEE, 0xFA)   # 浅紫卡片底
BLACK     = RGBColor(0x00, 0x00, 0x00)   # 正文
GRAY      = RGBColor(0x66, 0x66, 0x66)   # 次要文字
WHITE     = RGBColor(0xFF, 0xFF, 0xFF)   # 背景
```

## PptxGenJS 色值（无 `#` 前缀）

```javascript
const COLORS = {
  primary:  "6B3FA0",  // 标题
  accent:   "9B72CF",  // 强调
  cardBg:   "F3EEFA",  // 卡片底
  body:     "000000",  // 正文
  muted:    "666666",  // 次要文字
  bg:       "FFFFFF",  // 背景
};
```

## 字体规范

| 元素 | 字体 | 字号 | 加粗 |
|------|------|------|------|
| 封面主标题 | 微软雅黑 / Arial | 44pt | 是 |
| 页面标题 | 微软雅黑 / Arial | 26pt | 是 |
| 章节标题 | 微软雅黑 / Arial | 34pt | 是 |
| 副标题 | 微软雅黑 / Arial | 20pt | 否 |
| 正文 | 微软雅黑 / Arial | 14–15pt | 否 |
| 脚注/页码 | 微软雅黑 / Arial | 9pt | 否 |
