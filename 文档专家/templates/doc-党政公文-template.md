# 党政机关公文写作模板

> 依据 GB/T 9704-2012《党政机关公文格式》编制
>
> ⚠️ **本模板不适用"统一黑色 + 中文宋体 / 英文 Times New Roman"规则。** 公文必须执行国家标准：发文机关标志（红头）为**红色**小标宋体，正文为**仿宋_GB2312** 3 号，一级标题**黑体**，二级标题**楷体_GB2312**，红色分隔线。其余 6 个 Word 模板（报告格式、科学报告、内部报告、年中总结报告、项目报告、项目申报书格式）自 2026-10 起统一为"中文宋体 + 英文 Times New Roman + 全文纯黑"。

## 一、公文种类速查表

| 文种 | 行文方向 | 适用场景 | 关键词 |
|------|----------|----------|--------|
| 决议 | 下行 | 会议讨论通过的重大决策事项 | 会议通过、决定 |
| 决定 | 下行 | 重要事项部署、奖惩、机构调整 | 决定、授予 |
| 命令（令） | 下行 | 法律法规、强制措施、嘉奖 | 命令、令 |
| 公报 | 下行 | 重要事项、重大决策公布 | 公报、公布 |
| 公告 | 下行 | 向国内外宣布重要事项 | 公告、宣布 |
| 通告 | 下行 | 一定范围内公布应遵守事项 | 通告、周知 |
| 意见 | 下行/上行 | 对重要问题提出见解和处理办法 | 意见、建议 |
| **通知** | **下行** | **发布规章、传达事项、转发文件** | **通知、现将** |
| 通报 | 下行 | 表彰批评、传达情况 | 通报、表扬 |
| **报告** | **上行** | **汇报工作、反映情况、答复询问** | **报告、现将** |
| **请示** | **上行** | **请求指示、批准** | **请示、妥否** |
| 批复 | 下行 | 答复请示事项（一一对应） | 批复、收悉 |
| 议案 | 平行 | 向人大或常委会提出审议事项 | 提请审议 |
| **函** | **平行** | **不相隶属机关之间商洽工作** | **函、函告** |
| 纪要 | 内部 | 记载会议情况和议定事项 | 纪要、会议 |

## 二、标准格式要素

```
┌─────────────────────────────────────────┐
│  XXXXXXXX 文件                          │  ← 发文机关标志（红头，小标宋36pt，红色）
│  X发〔2026〕XX号                        │  ← 发文字号（仿宋16pt，居中）
│  ───────────────────────────────────    │  ← 红色分隔线
│  （签发人：XXX）                        │  ← 上行文专用（右对齐）
│    ↓ 空2行                              │
│  XXXXXXXX关于XXXXXX的通知               │  ← 标题（小标宋22pt，居中）
│    ↓ 空1行                              │
│  各有关单位：                           │  ← 主送机关（仿宋16pt，顶格）
│    ↓ 空1行                              │
│    根据……现将有关事项通知如下：          │  ← 正文（仿宋16pt，首行缩进2字符）
│                                         │
│  一、XXXXXXXX（黑体16pt）               │
│    （一）XXXXXXXX（楷体16pt）            │
│      1. XXXXXXXX（仿宋16pt）            │
│        （1）XXXXXXXX（仿宋16pt）         │
│                                         │
│  附件：1. XXXXXXXX                      │
│         2. XXXXXXXX                     │
│                                         │
│                                        │  ← 适当空行
│                            XXXXXXXX     │  ← 发文机关署名（右对齐）
│                          XXXX年XX月XX日  │  ← 成文日期（右空4字）
│                           （盖章）       │  ← 印章
│  ───────────────────────────────────    │
│  抄送：XXXXXXX                          │
│  ───────────────────────────────────    │
│  XXXXXXXX办公室       XXXX年XX月XX日印发 │  ← 版记
│  ───────────────────────────────────    │
│           — 1 —                         │  ← 页码（宋体14pt，居中）
└─────────────────────────────────────────┘
```

## 三、常用模板

```markdown

    根据[依据文件]，现将有关事项通知如下：

一、[一级标题]
（一）[二级标题]
1. [三级标题]
    [正文内容。]
2. [三级标题]
    [正文内容。]

二、[一级标题]
    [正文内容。]

[附件：[附件名称]]

[发文机关（盖章）]
[XXXX年XX月XX日]

（联系人：[姓名]；联系电话：[电话号码]）
```

```markdown
# [发文机关]关于[事项]的请示

[发文字号]

[签发人：[姓名]]

[主送机关]：

    因[原因/背景]，我单位拟[事项]。经研究，现就有关事项请示如下：

    [具体说明请示的主要内容。]

    [详细说明需要上级批准的理由和依据。]

    妥否，请批示。

[附件：[附件名称]]

[发文机关（盖章）]
[XXXX年XX月XX日]

（联系人：[姓名]；联系电话：[电话号码]）
```

### 模板3：函

```markdown
# [发文机关]关于[事项]的函

[发文字号]

---

[主送机关]：

    我单位因[原因]，拟[事项]。现将有关情况函告如下：

一、[事项说明]
    [详细说明需要对方知晓或协商的事项。]

    恳请支持为盼。

[发文机关（盖章）]
[XXXX年XX月XX日]

（联系人：[姓名]；联系电话：[电话号码]）
```

## 五、写作规范要点

1. **发文机关标志**：红色（R255, G0, B0），正文及标题均为黑色
2. **发文字号**：年份用六角括号〔〕，如：×府发〔2026〕15号
3. **标题**：三要素 = 发文机关 + 关于 + 事项 + 文种，如"×××关于×××的通知"
4. **主送机关**：顶格，标点用全角冒号，多个单位之间用顿号或逗号
5. **正文**：首行缩进2字符（汉字），引文需标注原文号
6. **附件说明**：正文下空1行，左空2字，顺序号用全角冒号，最后不加标点
7. **成文日期**：用阿拉伯数字，右空4字
8. **联系人**：附注位置，括注

## 六、常见错误

| 错误 | 正确 |
|------|------|
| 正文使用宋体 | 正文使用**仿宋_GB2312** 3号 |
| 标题使用黑体 | 标题使用**小标宋体** 2号 |
| 一级标题加粗仿宋 | 一级标题使用**黑体** |
| 年份用圆括号或方括号 | 年份用**六角括号**〔〕 |
| 日期用汉字 | 日期用**阿拉伯数字** |
| "一、"写成"一、" | 应为"**一、**"（全角顿号） |
| 行距为单倍行距 | 行距为**固定值28磅** |
| 页边距使用默认值 | 页边距设为**上37下35左28右26mm** |

## 七、生成 .docx 文件

使用 docx-js（Node.js `docx` 包）生成符合 GB/T 9704-2012 的公文。核心配置：

```javascript
const { Document, Packer, Paragraph, TextRun, AlignmentType,
        HeadingLevel, PageNumber, Header, Footer, PageBreak,
        TabStopPosition, TabStopType, convertInchesToTwip } = require('docx');

// 页边距（mm转twip：1mm = 56.7twip）
const MARGIN = {
  top: 37 * 56.7,     // 37mm
  bottom: 35 * 56.7,   // 35mm
  left: 28 * 56.7,     // 28mm
  right: 26 * 56.7,    // 26mm
};

// 正文段落
const bodyParagraph = (text) => new Paragraph({
  spacing: { line: 28 * 20, lineRule: "exact" }, // 28pt fixed
  indent: { firstLine: 2 * 16 * 20 }, // 缩进2字符
  children: [new TextRun({ text, font: "仿宋_GB2312", size: 16 * 2 })],
});

// 一级标题
const h1Paragraph = (text) => new Paragraph({
  spacing: { line: 28 * 20, lineRule: "exact" },
  children: [new TextRun({ text, font: "黑体", size: 16 * 2, bold: true })],
});

// 二级标题
const h2Paragraph = (text) => new Paragraph({
  spacing: { line: 28 * 20, lineRule: "exact" },
  children: [new TextRun({ text, font: "楷体_GB2312", size: 16 * 2 })],
});
```
