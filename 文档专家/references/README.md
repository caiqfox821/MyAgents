- 内置技能：`pptx`、`docx`、`official-document`、`scientific-report`、`xlsx`、`mindmap`
- 模板原件：`../templates/`（已从 `/home/caiq/project/template` 迁移为本地实体文件）
- 历史示例：`/home/caiq/project/examples`
- 常用生成库：
  - PPT：PptxGenJS（JS）、python-pptx（Python）
  - Word：docx-js（JS）、python-docx（Python）
  - 版式规范：GB/T 9704-2012（公文）、GB/T 7714（参考文献）

## 原文获取与核验

- **收录原则**：法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/T 9704、GB/T 7714 等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- **权威查询入口**：
  - 国家标准全文公开系统：<https://openstd.samr.gov.cn>
  - 全国标准信息公共服务平台：<https://std.samr.gov.cn>
  - 国家法律法规数据库：<https://flk.npc.gov.cn>
- **行为约定**：涉及**版式参数、引用格式、标准版本号**时不得凭本目录条目臆造，须声明"以现行标准正文为准"；需要精确条文/参数时，先向用户索取该标准 PDF 或联网核验，再单列收录并登记版本与实施日期。
