## 一、组培原理与优势

- **植物组织培养**（tissue culture / in vitro culture）：在无菌、受控条件下，利用植物细胞**全能性**（totipotency），通过**脱分化**（dedifferentiation，形成愈伤组织）与**再分化**（redifferentiation，成芽/成根/成胚）实现离体繁殖。
- 途径：**器官发生**（organogenesis，不定芽/不定根）与**体细胞胚胎发生**（somatic embryogenesis）。
- 优势：
  - 快速大量繁殖（快繁，micropropagation）；
  - 无性系保持、性状一致；
  - **脱毒复壮**（去除病毒/类病毒）；
  - 珍稀/难繁殖材料的扩繁；
  - 种质资源保存（离体保存、超低温保存）。

## 二、外植体选择与消毒

### 2.1 外植体（explant）选择

| 类型 | 特点 | 适用 |
|---|---|---|
| 茎尖/茎段 | 易启动、遗传稳定 | 快繁、脱毒 |
| 腋芽/顶芽 | 直接成苗 | 快繁 |
| 叶片 | 诱导愈伤/不定芽 | 部分观赏/林木 |
| 花药/花粉 | 单倍体育种 | 育种 |
| 胚/子叶/下胚轴 | 转化、体胚 | 遗传转化 |
| 根/块茎 | 特定物种 | 视物种 |

- 选材原则：**幼嫩、健壮、无病虫、生理活跃**；取材部位与季节影响启动率。

### 2.2 消毒流程（参考）

| 步骤 | 处理（参考） | 说明 |
|---|---|---|
| 预处理 | 流水冲洗 10–30 min，去泥 | 降低表面菌量 |
| 表面消毒 | 70%–75% 乙醇 10–60 s | 快速润湿，勿过长 |
| 主消毒 | 0.1% HgCl₂ 5–15 min 或 2% 次氯酸钠 10–20 min（含吐温 20） | 依外植体调整 |
| 冲洗 | 无菌水冲洗 3–5 次 | 去除残留消毒剂 |
| 接种 | 无菌条件切取、接种 | 超净台/层流罩 |

> 消毒剂浓度与时间是组培污染控制关键，**须按物种试验确定，过度消毒损伤外植体（待核实）**。

## 三、培养基

### 3.1 常用基础培养基

| 培养基 | 特点 | 常用 |
|---|---|---|
| MS（Murashige & Skoog） | 高盐、高无机营养，应用最广 | 多数双子叶、快繁 |
| 1/2 MS | 盐减半 | 生根、木本 |
| B5（Gamborg） | 低铵、适合某些科 | 豆科、细胞培养 |
| N6、Nitsch | 禾本科/花药 | 水稻、小麦 |
| WPM（Woody Plant Medium） | 木本专用 | 果树、林木 |
| White | 低盐 | 根培养 |

### 3.2 培养基组成

| 组分 | 代表 | 作用 |
|---|---|---|
| 大量元素 | NH₄NO₃、KNO₃、CaCl₂、MgSO₄、KH₂PO₄ | 氮磷钾钙镁硫 |
| 微量元素 | Fe-EDTA、Mn、Zn、Cu、Co、Mo、B、I | 酶辅因子 |
| 有机附加物 | 甘氨酸、烟酸、盐酸吡哆醇、盐酸硫胺素、肌醇 | 生长因子 |
| 碳源 | 蔗糖（20–30 g/L 常值）、葡萄糖 | 能源、渗透调节 |
| 凝固剂 | 琼脂（6–8 g/L）、Gelrite、植物凝胶 | 固化（液体培养不用） |
| pH | 5.6–5.9（灭菌前） | 影响凝固与养分 |

### 3.3 天然复合物与添加剂

- 椰子汁（CW）、香蕉泥、马铃薯汁、酵母提取物、水解酪蛋白（CH）等，用于难培养物种。
- 抗氧化剂：抗坏血酸（Vc）、聚乙烯吡咯烷酮（PVP）、活性炭（AC）抑制褐化。
- 抗生素：抑制内生菌（须评估对植物毒性）。

## 四、植物激素与分化调控

### 4.1 主要激素

| 类别 | 代表 | 主要作用 |
|---|---|---|
| 生长素（auxin） | IAA、IBA、NAA、2,4-D | 诱导根、愈伤、体胚 |
| 细胞分裂素（cytokinin） | 6-BA、KT、TDZ、ZT、2-iP | 诱导芽、增殖、打破顶端优势 |
| 赤霉素 | GA₃ | 伸长、萌发 |
| 脱落酸 | ABA | 体胚成熟、休眠 |
| 乙烯 | 乙烯利、ACC | 视体系 |

### 4.2 配比与途径（示意）

| 目标 | 生长素/细胞分裂素比 | 示例 |
|---|---|---|
| 愈伤诱导/脱分化 | 生长素偏高（2,4-D） | 2,4-D 1–3 mg/L |
| 不定芽/再分化 | 细胞分裂素偏高 | 6-BA 1–3 mg/L |
| 增殖（丛生芽） | 中等 CK + 低 auxin | 6-BA 1–2 mg/L + NAA 0.1–0.5 mg/L |
| 生根 | 生长素为主、低盐 | IBA/NAA 0.1–1 mg/L（或 1/2 MS） |

> 激素种类、浓度与配比对分化方向起决定作用，**须按物种与外植体做梯度试验**；TDZ 高效但易致玻璃化。

## 五、培养条件与继代管理

| 因子 | 参考值 | 说明 |
|---|---|---|
| 温度 | 22–26 ℃（多数）/ 25±2 ℃ | 依物种 |
| 光照强度 | 30–80 μmol·m⁻²·s⁻¹（组培常值） | 光自养/无糖可更高 |
| 光周期 | 12–16 h 光 / 8–12 h 暗 | 暗培养用于愈伤/生根前 |
| 湿度 | 容器内高湿（>90%） | 导致玻璃化风险 |
| 气体 | 通气、换气膜、CO₂ | 光自养培养关键 |

### 5.1 继代（subculture）

- 一般 3–5 周继代一次；过密/耗竭会黄化、老化。
- 控制继代代数，防止**体细胞变异**（somaclonal variation）与增殖率下降。

### 5.2 褐化（browning）控制

- 原因：酚类氧化、多酚氧化酶（PPO）作用；木本、含酚高物种严重。
- 对策：暗培养前处理、加抗坏血酸/PVP/活性炭、缩短切取暴露时间、勤换培养基、降低无机盐（1/2 MS）。

### 5.3 玻璃化（vitrification / hyperhydricity）控制

- 表现：苗透明、肿胀、脆弱，难成活。
- 诱因：高湿、低琼脂、高细胞分裂素、通气差、乙烯积累。
- 对策：提高琼脂/Gelrite 浓度、增加通气（换气膜）、降低 CK、提高蔗糖或光照、增加 CO₂（光自养）。

## 六、生根与炼苗移栽

| 阶段 | 措施 | 目标 |
|---|---|---|
| 生根培养 | 转入生根培养基（1/2 MS + IBA/NAA），或瓶外生根 | 形成健壮根系 |
| 开瓶炼苗 | 松开瓶盖 2–5 d，逐步降湿增光 | 适应外界 |
| 出瓶洗根 | 洗净琼脂（防霉） | 防污染 |
| 移栽 | 移入基质（蛭石/草炭+珍珠岩），保湿遮荫 | 高湿缓苗 |
| 过渡 | 逐步降湿、增光、通风 | 成活转常规育苗 |

- 移栽成活关键：**根系质量、洗根彻底、初期高湿、防霉、逐步炼苗**。

## 七、脱毒技术

> 植物病毒病难以化学治愈，脱毒（virus elimination）是获得无病毒种苗的核心。

| 方法 | 原理 | 说明 |
|---|---|---|
| 茎尖培养（shoot tip culture） | 病毒在分生组织分布少/无，取 0.1–1 mm 茎尖 | 最常用，脱毒率与茎尖大小成反比 |
| 热处理（thermotherapy） | 高温（如 35–40 ℃ 数周）抑制病毒复制 | 常与茎尖培养结合（热处理+茎尖） |
| 微体嫁接（micrografting） | 微茎尖嫁接于无菌砧木 | 木本（柑橘等）脱毒 |
| 化学治疗（chemotherapy） | 抗病毒剂（如利巴韦林）加入培养基 | 辅助，效果因病毒而异 |
| 花药培养/胚培养 | 获得无病毒后代（特定） | 视物种 |
| 冷冻疗法（cryotherapy） | 液氮处理，存活组织少带毒 | 新技术 |

- 组合策略最常见：**热处理 + 茎尖培养（0.2–0.5 mm）**提高脱毒率与成活率平衡。

## 八、病毒检测与脱毒苗验证

| 方法 | 原理 | 特点 |
|---|---|---|
| 指示植物接种（indicator plant） | 敏感植物显现症状 | 经典、直观、耗时 |
| ELISA（酶联免疫吸附） | 抗体检测病毒蛋白 | 快速、批量、灵敏度中等 |
| RT-PCR / qRT-PCR | 扩增病毒核酸 | 高灵敏，适合 RNA 病毒 |
| 分子杂交 / LAMP | 核酸识别/恒温扩增 | 特异性/快速 |
| 高通量测序（HTS） | 宏病毒组 | 广谱、发现新病毒 |

- **脱毒苗必须在组培增殖前与出圃前经检测验证**（阴性方可扩繁），并建立**无病毒母本/核心种质**。
- 检测应由**检测专家**按方法学验证与质控要求执行。

## 九、无糖组培（Sugar-free / Photoautotrophic micropropagation）

- 原理：用**CO₂ 替代蔗糖作碳源**，通过**光自养**让组培苗进行光合作用；需**高光照、高 CO₂、强制通风/换气、低湿度**的专用培养容器与系统。
- 优点：减少糖诱导的污染与玻璃化、苗更健壮、可直接过渡到自养、降低炼苗损失。
- 关键参数（视体系）：光强显著高于常规（可达数百 μmol·m⁻²·s⁻¹）、CO₂ 富集（如 1000–3000 μmol/mol 量级，**待核实**）、通气换气、温度与湿度控制。
- **本项目衔接**：可对接《燕窝果无糖组培优良种苗繁育及温室标准化种植技术研究技术开发合同》（`/home/caiq/MyAgents/育苗专家/references/燕窝果无糖组培优良种苗繁育及温室标准化种植技术研究技术开发合同.pdf`）中的无糖组培与温室种植技术内容，具体配方、光/CO₂ 参数以合同与试验数据为准。
