# 嫁接、扦插与压条

> 整理范围：嫁接原理与亲和性、砧木选择、嫁接方法（瓜类/茄果类/果树）、嫁接后愈合环境、成活判断与去萌；扦插（硬枝/嫩枝/叶插/根插、插穗、生根剂、基质、弥雾）、压条（高空/水平）、无性系保持与病毒风险。
> 主要依据：园艺植物繁殖学教材/综述、蔬菜嫁接育苗技术规程与果树嫁接技术资料、农业技术推广资料。
> 说明：文中参数为经验/参考量级，实际以本地试验、品种组合与现行标准为准；具体标准号标注"（待核实，以现行版本为准）"。

## 一、嫁接原理与亲和性

### 1.1 基本原理

- **嫁接**（grafting）：将**接穗**（scion，带芽/枝）与**砧木**（rootstock，带根）的形成层（cambium）紧密贴合，愈伤组织（callus）增生并分化**维管束桥**，恢复水分与养分输导，形成共生体。
- 愈合过程：隔离层形成 → 愈伤组织填充 → 维管束连接 → 成活。

### 1.2 亲和性（compatibility）

| 类型 | 说明 |
|---|---|
| 亲和（亲和性好） | 同种/近缘，愈合快、寿命长 |
| 不亲和/后期不亲和 | 愈合可，但长期生长不良、接口断裂（如某些异属组合） |
| 半亲和 | 需中间砧改善 |

- 影响亲和性的因素：**分类学亲缘、生理生化（酚类、激素）、解剖结构（维管束排列）、病毒/类病毒、环境**。
- 选配原则：**近缘选砧、目标性状优先（抗病/抗逆/矮化/促长）**，并先小试验证亲和与产量品质。

## 二、砧木选择

| 目标 | 砧木作用 | 示例方向（示意，具体品种待核实） |
|---|---|---|
| 抗土传病害 | 枯萎病、黄萎病、根结线虫、疫病 | 葫芦科用南瓜/葫芦类砧；茄科用野生茄/托鲁巴姆类 |
| 抗逆（低温/盐碱/涝/旱） | 扩大适应性 | 耐低温/耐盐砧木 |
| 矮化 | 控制树冠、便于密植 | 果树矮化砧（如苹果 M 系、梨/桃矮化砧，**待核实**） |
| 促长/增产 | 强大根系 | 南瓜砧用于西瓜/黄瓜 |
| 改善品质/抗裂 | 调节吸收 | 按作物试验 |

- 砧木与接穗**亲和**是前提；砧木抗性须与目标病害**生理小种**匹配。
- 嫁接种苗须关注**砧木纯度**（异株、杂种）与**带病/带毒**风险。

## 三、嫁接方法

### 3.1 常用方法对比

| 方法 | 特点 | 适用 |
|---|---|---|
| 劈接（cleft/splice graft） | 砧木劈口插入楔形接穗 | 果树、大苗 |
| 插接（insertion/slant graft） | 接穗插入砧木斜切口 | 瓜类（南瓜砧） |
| 靠接（approach graft） | 两株靠拢削面贴合，成活后断开 | 亲和性差/难接组合、果树 |
| 芽接（budding：T 形/嵌芽） | 单芽接于砧木 | 果树大量繁殖 |
| 舌接/切接/腹接 | 增加接触面 | 果树、苗木 |
| 套管嫁接（tube graft） | 用嫁接夹/套管固定 | 茄果类、黄瓜机械化嫁接 |
| 针接/机器人嫁接 | 机器切割+固定 | 工厂化育苗 |

### 3.2 作物示例

| 作物 | 常用方法 | 砧木方向 | 关键点 |
|---|---|---|---|
| 西瓜 | 插接/劈接/靠接 | 葫芦/南瓜类 | 防枯萎病、增强长势 |
| 黄瓜 | 插接/靠接 | 黑籽南瓜等 | 防枯萎病、耐低温 |
| 甜瓜 | 插接/劈接 | 南瓜/甜瓜专用砧 | 抗病、品质平衡 |
| 番茄 | 套管/劈接/针接 | 野生茄/抗病砧 | 抗枯萎、青枯、根结线虫 |
| 茄子 | 劈接/套管 | 托鲁巴姆等 | 抗黄萎、青枯 |
| 辣椒 | 劈接/套管 | 抗病砧 | 抗青枯、疫病 |
| 苹果/梨 | 芽接/枝接（劈接、舌接） | 矮化/抗性砧 | 矮化密植、抗病 |
| 柑橘 | 芽接/腹接 | 枳/香橙等 | 抗病、适应性 |
| 葡萄 | 劈接/芽接 | 抗性砧 | 抗根瘤蚜、线虫 |

> 上述砧穗组合为业界常用方向，**具体品种/砧木编号与适宜性以本地试验与育种专家提供的信息为准（待核实）**。

### 3.3 操作要点

- 刀具锋利、切口平整；**形成层对齐**（至少一侧对齐）。
- 操作快、避免切口氧化干燥；接穗随采随用或保湿冷藏。
- 固定：嫁接夹、套管、绑带；保湿防失水。
- 嫁接前砧木/接穗**消毒**，器械消毒防交叉感染。

## 四、嫁接后愈合环境管理

| 阶段 | 温度（℃） | 空气 RH | 光照 | 时间（参考） |
|---|---|---|---|---|
| 愈合前期（接口愈合） | 25–28（喜温） | 90%–95% | 遮光/弱光 | 2–4 d |
| 愈合中期 | 24–28 | 85%–90% | 逐渐见光 | 3–5 d |
| 成活期 | 22–28 | 70%–85% | 正常光照 | 3–7 d |
| 炼苗过渡 | 按作物 | 逐步降低 | 全光 | 3–5 d |

- 常用设施：**嫁接愈合室/小拱棚**，控温控湿、遮阳网/无纺布覆盖。
- 高温高湿促愈伤，但**须防霉**；逐渐通风降湿、增加光照（"三阶段"过渡）。
- 嫁接后**及时抹除砧木萌蘖**（去萌/除蘖），避免与接穗竞争。

### 成活判断

- 接穗**不失水萎蔫、芽萌动/新叶展开、叶色正常**；
- 接口愈合良好、无腐烂；
- 轻触接穗有支撑感（维管束连接）。

## 五、扦插繁殖

### 5.1 类型

| 类型 | 插穗 | 时期 | 适用 |
|---|---|---|---|
| 硬枝扦插（hardwood cutting） | 木质化枝 | 休眠期 | 葡萄、果树、杨柳 |
| 嫩枝/绿枝扦插（softwood cutting） | 半木质化枝 | 生长期 | 月季、茶、果树绿枝 |
| 叶插（leaf cutting） | 叶片/叶段 | 生长期 | 多肉、秋海棠、非洲紫罗兰 |
| 根插（root cutting） | 根段 | 休眠期 | 枣、李、部分宿根 |
| 叶芽/单芽扦插 | 单芽+叶 | 生长期 | 茶、葡萄 |

### 5.2 插穗规格与处理

- 长度：嫩枝 5–15 cm（3–5 节）、硬枝 10–20 cm；下切口靠近节（生根素集中）。
- 留叶：嫩枝留 1/3–1/2 叶或剪半，减少蒸腾；去除下部叶。
- 生根剂：**IBA**（吲哚丁酸）、**NAA**（萘乙酸），可单用或复配；浓度（参考）：嫩枝 500–2000 mg/L 速蘸（5–10 s）或 100–500 mg/L 浸泡数小时；硬枝可用高浓度速蘸（如 1000–5000 mg/L，**待核实**）。
- 激素剂型：粉剂、醇溶液、水溶液；注意避光、现配。

### 5.3 基质与环境

| 因子 | 目标（参考） | 说明 |
|---|---|---|
| 基质 | 蛭石、珍珠岩、蛭石+珍珠岩、河沙、椰糠 | 透气排水、低盐、无菌 |
| 温度（基质） | 18–25 ℃（生根适温常略高于气温） | 底温加热促根 |
| 空气温度 | 20–28 ℃ | 降低温差防萎蔫 |
| 湿度 | 空气 RH 85%–95%（弥雾/雾插） | 减少蒸腾 |
| 光照 | 散射光/控光，避免强光 | 保留光合又不萎蔫 |
| 弥雾（mist） | 间歇喷雾，叶面保持水膜 | 工厂化/难生根种 |

- **雾插/弥雾系统**：按光照/湿度自动间歇喷雾，是嫩枝扦插成活关键。
- 生根后逐步"炼苗"降湿、增光，再移栽。

### 5.4 影响生根的因素

- 母株年龄与营养（幼龄、健壮母株生根好）；采穗部位（中下部）；季节；温度；插穗含水量；病原。
- 难生根种可结合**刻伤、环剥、黄化处理、组培**。

## 六、压条繁殖

| 类型 | 操作 | 适用 |
|---|---|---|
| 高空压条（air layering） | 枝条环剥/刻伤，包湿润基质，生根后剪离 | 木本、难扦插种（荔枝、龙眼、橡皮树） |
| 水平压条（layering） | 枝条压入土中，生根后分株 | 苹果矮化砧、葡萄、醋栗 |
| 堆土压条（mound layering） | 基部堆土促萌生根 | 榅桲、砧木繁殖 |
| 先端压条（tip layering） | 枝端埋土 | 黑莓、悬钩子 |

- 高空压条要点：环剥宽度、保湿基质（水苔/椰糠）、包裹保湿、生根期（数周至数月）、剪离后炼苗。
- 压条繁殖**遗传性状与母株一致**，适合无性系保持。

---

## 七、无性系保持与病毒风险

- 无性繁殖（嫁接/扦插/压条/组培）**后代基因型与母株一致**，用于固定杂种优势、保持优良品种。
- **主要风险**：母株若带病毒/类病毒/病原，会**垂直传播**给全部无性后代，且逐代累积。
- 防控：
  - 建立**无病毒母本园/采穗圃**（经检测认证）。
  - 嫁接/扦插前对母株与接穗做**带毒检测**（见《组织培养与脱毒》）。
  - 工具消毒，避免汁液传播。
  - 组培脱毒 + 检测复壮，衔接**育种专家**与**检测专家**。
