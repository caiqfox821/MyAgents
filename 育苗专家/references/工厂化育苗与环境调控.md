# 工厂化育苗与环境调控

> 整理范围：育苗设施、环境目标（温/光/DLI/光周期/湿度/CO₂）、水肥一体化、基质温度与根区环境、通风除湿、病虫害绿色防控、炼苗、移栽成活与缓苗管理。
> 主要依据：设施园艺与工厂化育苗教材/综述、温室环境调控与无土栽培技术规范、农业技术推广资料。
> 说明：文中参数为经验/参考量级，实际按作物、品种、季节与设施条件调整；具体标准号标注"（待核实，以现行版本为准）"。

---

## 一、育苗设施

| 设施 | 特点 | 适用 |
|---|---|---|
| 日光温室（solar greenhouse） | 依赖太阳能、保温好、成本低 | 北方冬春育苗 |
| 连栋温室（multi-span greenhouse） | 面积大、环境均匀、可自动化 | 规模化商品苗 |
| 塑料大棚/中小拱棚 | 结构简单、成本低 | 保护地育苗、过渡 |
| 植物工厂 / 人工光育苗室 | 全人工光温湿、无季节限制 | 高附加值、种苗工厂 |
| 漂浮育苗（floating system） | 育苗盘飘于营养液、水分均匀 | 烟草、蔬菜、水稻 |
| 潮汐/潮汐灌溉苗床 | 底部给水、节水控病 | 穴盘苗规模化 |
| 嫁接愈合室 | 控温控湿遮光 | 嫁接苗愈合 |

- 关键配套：**加温、降温、通风、遮阳、补光、加湿/除湿、水肥、播种流水线、催芽室**。

## 二、环境目标参数

### 2.1 温度

| 阶段 | 昼温（℃） | 夜温（℃） | 备注 |
|---|---|---|---|
| 催芽/出苗 | 25–30（喜温）/18–22（冷凉） | 同昼或略低 | 按作物 |
| 幼苗期 | 22–28 | 15–20 | 拉大温差防徒长 |
| 成苗期 | 20–26 | 12–18 | 温差 6–10 ℃ |
| 炼苗期 | 接近移栽环境 | 逐步降温 | 硬化 |

- 根区温度常**略低于气温**利于壮苗；过低温抑制根系。

### 2.2 光照

| 指标 | 说明 | 参考 |
|---|---|---|
| 光强（PPFD） | 光合有效光量子通量密度，μmol·m⁻²·s⁻¹ | 幼苗 200–400，成苗 400–600（视作物） |
| 光周期 | 光照时长，h | 12–16 h |
| DLI（Daily Light Integral） | 日累积光量，mol·m⁻²·d⁻¹ | 蔬菜苗约 10–20（视作物，**待核实**） |
| 补光 | 阴天/冬季 LED/高压钠灯 | 按 DLI 缺口补 |
| 遮阳 | 夏季强光降温 | 遮阳网/涂层 |

- 判断补光量应基于**目标 DLI − 自然累积光量**，而非单纯时长。

### 2.3 湿度与 CO₂

| 因子 | 参考 | 调控 |
|---|---|---|
| 空气相对湿度 | 出苗 85%–95%；苗期 60%–75%；炼苗 50%–65% | 加湿/通风/除湿 |
| 基质含水量 | 见干见湿，按阶段 | 灌溉控制 |
| CO₂ 浓度 | 大气约 400 μmol/mol；可富集至 800–1000 μmol/mol（施用需谨慎，**待核实**） | CO₂ 施肥、通风 |

- 高湿 + 弱光 + 高温是**徒长与病害**的诱因组合，须协同调控。

## 三、水肥一体化

| 要素 | 说明 |
|---|---|
| EC | 出苗 0.5–1.0；成苗 1.0–2.0 mS/cm（按作物） |
| pH | 5.5–6.5（多数蔬菜） |
| 配方 | 育苗专用水溶肥（大量+微量元素），随苗龄调 N:P:K |
| 灌溉方式 | 顶部喷淋、底部潮汐/漂浮、滴灌、子母盆 |
| 频次/水量 | 少量多次、见干见湿；按基质含水量与天气 |
| 监测 | 定期测基质 EC/pH、灌溉液 EC/pH、排水 EC |

- 底部给水/潮汐灌溉可**减少叶面湿害与病害**，利于规模化。
- 施肥过量致 EC 升高烧根；不足致黄化、苗弱。**以基质 EC 与苗情反馈调整**。

## 四、基质温度与根区环境

- 根区（root zone）温度：多数作物 **18–25 ℃** 适宜；过低抑制吸水吸肥、过高易沤根。
- 调控手段：**底部加热线/加热垫、地热、水温调节、遮阳**。
- 根区氧气：基质通气孔隙与灌溉频率影响；过湿缺氧致烂根、猝倒。
- 根区 EC/pH 直接影响养分有效性，须与气温同等重视。

---

## 五、通风与除湿

- 目的：降温、排湿、补充 CO₂（大气）、减少叶面结露与病害。
- 方式：顶部/侧窗自然通风、循环风扇、强制通风、除湿机。
- 原则：**在保温与通风之间平衡**；早晨揭帘后通风排湿，避免"闷棚"。
- 叶面结露是灰霉、霜霉、细菌病害的重要诱因，应通过**温差管理与通风**降低。

## 六、病虫害绿色防控

| 措施 | 内容 |
|---|---|
| 基质消毒 | 蒸汽/太阳能/化学/生物消毒（见《基质与穴盘育苗》） |
| 种子/种苗消毒 | 温汤/药剂/等离子体（见《种子处理与催芽》） |
| 物理隔离 | 防虫网（40–60 目）、缓冲间、无病入口 |
| 诱杀监测 | 黄板（蚜虫/粉虱/斑潜蝇）、蓝板（蓟马）、性诱剂、杀虫灯 |
| 生物防治 | 天敌（瓢虫、捕食螨、小花蝽、丽蚜小蜂）、生防菌（木霉、芽孢杆菌、哈茨木霉） |
| 环境调控 | 控温控湿、通风、避免高湿 |
| 农业措施 | 无病基质、工具消毒、remove 病苗、轮换 |
| 化学防治 | 必要时低毒低残留药剂（须登记、按标签与安全间隔） |

- 坚持"**预防为主、综合防治（IPM）**"，优先物理/生物，减少化学用药，衔接**食品安全专家**源头风险控制。

## 七、炼苗（硬化，hardening）

| 因子 | 措施 | 目的 |
|---|---|---|
| 温度 | 逐步降低至接近田间 | 提高抗寒/抗热 |
| 水分 | 减少灌溉、控水 | 提高保水与抗旱、促根木质化 |
| 光照 | 增加光照/全光 | 提高光合与抗逆 |
| 营养 | 降低氮、增施磷钾 | 壮苗、避免柔嫩 |
| 通风 | 加大通风 | 适应外界 |

- 炼苗一般**出圃前 5–10 d**开始，逐步过渡，不可骤变。
- 炼苗不足 → 移栽后萎蔫、死苗；炼苗过度 → 苗木老化、生长停滞。

## 八、移栽成活与缓苗管理

| 环节 | 要点 |
|---|---|
| 苗龄/壮苗 | 适龄壮苗、根系完整、无病虫害 |
| 移栽时机 | 阴天/傍晚、避开高温强光 |
| 带坨/护根 | 基质坨完整、少伤根 |
| 深度 | 与育苗深度一致，嫁接口不埋入土 |
| 定根水 | 浇透定根水，使根土密接 |
| 缓苗期 | 遮荫、保湿、控温，缓苗后逐步见光追肥 |
| 衔接 | 与**种植专家**对接田间水肥、植保方案 |

- 缓苗期管理核心：**降温保湿遮荫、促新根、防病菌侵染**。
