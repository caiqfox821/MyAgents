# 种苗质量、检疫与标准

> 整理范围：壮苗标准与分级、种苗包装运输贮藏、产地检疫与调运检疫、无病毒/无病菌证明、嫁接苗/组培苗质量要求、食用菌菌种繁育与质量、标准索引与合规清单。
> 主要依据：种子苗木质量分级与种苗相关国家标准/行业标准公开要点、植物检疫条例与农业植物检疫技术资料、食用菌菌种管理办法与相关标准、农业技术推广资料。
> **重要提示**：本文件仅作**框架与索引**，标准号、年份、具体指标与限量**一律以国家官方平台现行有效版本为准**，文中凡不能逐一核实处均标注"（待核实，以现行版本为准）"，不臆造标准号与数值。

## 一、壮苗标准与分级

### 1.1 通用壮苗指标

| 指标 | 说明 | 测量 |
|---|---|---|
| 茎粗（茎基粗） | 反映健壮度，最常用 | 游标卡尺，mm |
| 株高 | 结合茎粗评价徒长 | 直尺，cm |
| 叶片数/叶面积 | 发育进程 | 计数/叶面积仪 |
| 根冠比（R/S，干重或鲜重比） | 根系发达程度 | 称量计算 |
| 根系 | 根量、根色、须根多少、盘根性 | 目测/称量 |
| 病虫害 | 无检疫性/主要病虫害 | 目检/检测 |
| 苗龄 | 与移栽期匹配，不过老 | d |
| 叶色/开展度 | 营养与生长状态 | 目测 |

### 1.2 分作物壮苗示例（参考量级，须按品种/标准核定）

| 作物 | 茎粗（mm） | 株高（cm） | 真叶数 | 备注 |
|---|---|---|---|---|
| 番茄 | 5–8 | 15–25 | 5–7 | 现蕾前、无徒长 |
| 黄瓜 | 5–8 | 10–20 | 3–5 | 节间短、根系好 |
| 辣椒 | 4–6 | 15–25 | 6–10 | 苗壮、无病 |
| 茄子 | 5–8 | 15–25 | 5–8 | 根系发达 |
| 西瓜（嫁接） | 5–8 | 10–20 | 3–4 | 嫁接口愈合好 |
| 叶菜 | 2–4 | 8–15 | 4–6 | 整齐、无黄化 |

> 上述数值为经验参考，**具体以对应作物育苗技术规程/种苗质量标准为准（待核实）**。

### 1.3 分级

- 按**茎粗、株高、叶数、根系、病虫害**等综合分级（一级/二级/三级或合格/不合格）。
- 分级应由企业质检按内控标准执行，并记录批次、等级、数量、检测数据。

## 二、种苗包装、运输与贮藏

| 环节 | 要求 |
|---|---|
| 包装 | 穴盘/育苗盘、纸箱/塑料筐，防挤压；标识品种、苗龄、等级、数量、产地、日期 |
| 保湿 | 根部基质保持湿润，必要时覆膜/保湿材料 |
| 防冻/防热 | 低温季节保温、夏季遮荫降温，避免失水与冻害 |
| 运输 | 通风、避免堆压与暴晒；远距离用冷藏/控温车（适度低温，防冻伤） |
| 贮藏 | 短期低温高湿贮藏，时间越短越好；贮期过长致黄化、徒长、根系老化 |
| 保鲜期 | 视作物与条件，一般数天（**具体以试验/标准为准，待核实**） |
| 检疫 | 跨区域调运须附产地检疫合格证/调运检疫证书 |

- 运前**控水炼苗**、运后**及时移栽与遮荫缓苗**。

## 三、产地检疫与调运检疫

### 3.1 基本制度

- 依据《植物检疫条例》及其实施细则（农业/林业）等法规（**待核实现行版本**），对种子、苗木及其他繁殖材料实施检疫。
- **产地检疫**：在种苗生长期间由植物检疫机构调查、检验，确认无检疫性有害生物后签发**产地检疫合格证**。
- **调运检疫**：调运前申请检疫，合格后签发**植物检疫证书（调运检疫证书）**，随货通行。

### 3.2 关键对象

- **检疫性有害生物**（全国/省级）：如检疫性线虫（根结线虫特定种）、细菌性病害（如某些溃疡病）、病毒/类病毒、检疫性害虫等（**具体名录以现行公告为准，不得臆造**）。
- 重点关注：**无病毒证明、无病菌证明**（尤其组培脱毒苗、嫁接苗、种薯/种球）。

### 3.3 合规流程（示意）

1. 种苗繁育单位登记/备案；
2. 生长期间产地检疫调查；
3. 调运前申请，抽样检验；
4. 合格签发检疫证书；不合格按规程处理（销毁/处理）；
5. 建立台账与追溯。

## 四、嫁接苗与组培苗质量要求

| 类型 | 质量要点 |
|---|---|
| 嫁接苗 | 砧穗亲和、接口愈合良好无缝/无腐烂；**嫁接口不埋土**；砧木萌蘖已除；砧木纯度；无带病/带毒；苗龄适中 |
| 组培苗 | 无污染（细菌/真菌）、无玻璃化/褐化、丛生芽正常、根系发达；**脱毒验证为阴性**；驯化炼苗充分、适应外界 |
| 扦插苗 | 生根良好、根系完整、无根腐；无病毒（经检测） |
| 脱毒苗 | 经 ELISA/RT-PCR 等检测确认不带目标病毒；来自无病毒核心种质 |

- 组培苗、脱毒苗应建立**批次检测档案**，衔接**检测专家**与**育种专家**。

## 五、食用菌菌种（母种→原种→栽培种）

### 5.1 菌种分级与扩繁

| 级别 | 来源 | 扩繁 | 用途 |
|---|---|---|---|
| 母种（一级种，stock culture） | 孢子/组织分离/保藏菌株 | 试管斜面/PDA | 保种、扩繁起点 |
| 原种（二级种，mother spawn） | 母种 | 谷粒/木屑/棉籽壳等基质瓶 | 扩繁栽培种 |
| 栽培种（三级种，commercial spawn） | 原种 | 袋/瓶装基质 | 直接播种栽培 |

### 5.2 无菌操作与质量控制

| 控制点 | 要求 |
|---|---|
| 无菌操作 | 超净台/接种箱、灭菌器械、快速操作、环境消毒 |
| 培养基灭菌 | 常规 121 ℃ 灭菌（时间按容器/基质，**待核实**） |
| 纯度 | 无杂菌（细菌/霉菌）、菌丝纯一；镜检+平板观察 |
| 活力 | 菌丝洁白浓密、生长快、无退化；转管恢复 |
| 菌龄 | 适龄使用（母种/原种/栽培种各有适宜菌龄，过老活力下降） |
| 保藏 | 低温（4 ℃）斜面短期、液氮/冻干长期；避免反复传代 |
| 出菇/出耳验证 | 必要时小试确认种性 |

- 菌种生产经营须遵守《食用菌菌种管理办法》及相关许可/标签规定（**待核实现行版本**），出售附**菌种合格证/标签**。

### 合规清单（种苗生产经营）

1. 种子/种苗生产经营许可与备案（按法规要求）；
2. 品种来源合法、标签规范（品种名称、产地、质量指标、检疫证号、日期）；
3. 建立**生产、检验、销售台账与可追溯体系**；
4. 跨区调运附**植物检疫证书**；
5. 组培脱毒苗附**检测报告**；
6. 遵守农药、肥料、生长调节剂使用与残留规定（衔接食品安全专家）；
7. 不合格种苗处理与召回程序。
