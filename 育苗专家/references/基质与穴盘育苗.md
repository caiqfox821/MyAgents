# 基质与穴盘育苗

> 整理范围：基质原料特性、配方与理化指标、基质消毒、穴盘规格与选用、播种深度与覆土、出苗期/幼苗期/成苗期水分-温度-光照管理、分苗、徒长控制、育苗肥。
> 主要依据：蔬菜/园艺育苗技术教材与综述、基质理化性质公开资料、无土栽培与工厂化育苗技术规范、农业技术推广资料。

## 一、基质原料特性

| 原料 | 来源/成分 | 主要优点 | 局限/注意 |
|---|---|---|---|
| 草炭（泥炭，peat） | 藓类残体 | 保水保肥、缓冲性好、CEC 高 | 不可再生资源、pH 偏低（3.5–4.5）、盐分与批次差异、须复配 |
| 椰糠（coconut coir） | 椰壳纤维 | 可再生、透气、持水、pH 5.5–6.5 | 含钠/氯需洗盐、CEC 较低、钾偏高、可能带病原需处理 |
| 蛭石（vermiculite） | 云母类矿物膨化 | 保水保肥、缓冲、轻 | 长期易压缩、价格较高 |
| 珍珠岩（perlite） | 玻璃质火山岩膨化 | 透气排水、惰性轻质 | 无保肥力、易漂浮、粉尘刺激 |
| 岩棉（rockwool） | 玄武岩熔融纤维 | 孔隙稳定、可控水气、工厂化 | 不可降解、需专业处置、pH 偏高须调 |
| 生物炭（biochar） | 生物质热解 | 改善通气、保肥、微生物载体 | 来源与 pH/盐分差异大、质量需控制 |
| 稻壳/稻壳炭 | 农业副产 | 透气、廉价 | 未腐熟竞氮、需炭化或腐熟 |
| 腐熟有机肥/蚯蚓粪 | 有机质 | 供肥、缓冲、微生物 | 必须充分腐熟、盐分与病原风险 |
| 河沙/砾石 | 矿物 | 排水、定植固定 | 重、无保肥 |
| 珍珠岩替代（浮石、陶粒） | 矿物/烧结 | 通气、可重复用 | 成本与清洗 |

> 育苗基质常用"**草炭 + 蛭石 + 珍珠岩**"复配，兼顾保水、通气与缓冲；椰糠在环保与稳定性上常替代部分草炭。

## 二、基质配方与理化指标

### 2.1 常用配方（体积比，示例）

| 用途 | 配方（体积比） | 说明 |
|---|---|---|
| 通用播种/育苗 | 草炭:蛭石:珍珠岩 = 3:1:1 或 2:1:1 | 保水透气均衡 |
| 扦插/需透气 | 草炭:珍珠岩 = 1:1 或 蛭石:珍珠岩 = 1:1 | 排水好、减少烂根 |
| 瓜类/茄果类 | 草炭:蛭石:珍珠岩 = 3:1:1 + 有机肥少量 | 供肥、长势强 |
| 叶菜/小粒种 | 草炭:蛭石 = 2:1 | 保水、利于小粒种 |
| 组培/穴盘苗出圃 | 椰糠:珍珠岩 = 3:1 | 环保、通气 |
| 漂浮育苗 | 草炭 + 蛭石 + 膨化珍珠岩/专用基质 | 需适配漂浮盘 |

### 2.2 关键理化指标（参考量级）

| 指标 | 参考范围 | 说明 |
|---|---|---|
| 容重（bulk density） | 0.2–0.6 g/cm³ | 过小易倒、过大压苗；按作物调整 |
| 总孔隙度 | 60%–85% | 保水+通气孔隙 |
| 通气孔隙 | 15%–30% | 过低易沤根 |
| 持水孔隙 | 40%–60% | 决定保水量 |
| pH | 5.5–6.5（多数蔬菜） | 草炭偏酸需调；岩棉偏高 |
| EC（电导率） | 出苗期 0.5–1.0 mS/cm；成苗期 1.0–2.0 mS/cm（参考） | 过高烧苗、过低缺肥 |
| CEC（阳离子交换量） | 草炭高、椰糠中、珍珠岩低 | 影响保肥与缓冲 |
| 有机质 | 视配方 | 过高易徒长/带菌 |

- **EC 与 pH 应实测**（1:1.5 或 1:2 水土比浸提，或饱和浸提法，方法以行业规程为准）。
- 草炭基质常加**石灰石/白云石**调 pH、加**复合肥/控释肥**起始养分。

## 三、基质消毒

| 方法 | 条件（参考） | 优点 | 注意 |
|---|---|---|---|
| 蒸汽消毒 | 60–80 ℃ 保持 30 min（视设备） | 无残留、广谱 | 能耗高、过度消毒破坏有益菌 |
| 太阳能消毒 | 夏季覆膜 7–30 d，地表 50–70 ℃ | 低成本、绿色 | 受天气限制、深层效果有限 |
| 化学消毒（甲醛/氯化苦/威百亩等） | 按产品标签 | 针对性强 | 残留、须充分挥发、合规使用 |
| 热水/热水淋洗 | 80 ℃ 以上 | 设备简单 | 能耗、基质结构影响 |
| 臭氧/紫外/微波 | 视设备 | 无残留 | 穿透有限、需试验 |
| 生物消毒（木霉、芽孢杆菌等） | 按产品 | 抑病促生 | 不能替代对重病菌的处理 |

> 消毒后应**回补有益微生物**，并检测致病菌（如猝倒病菌、疫霉）灭活效果。

## 四、穴盘规格与选用

| 常见规格（穴/盘） | 单穴容积（参考，mL） | 适用 |
|---|---|---|
| 32、50 穴 | 大（约 80–150） | 瓜类、茄果类大苗、嫁接苗 |
| 72 穴 | 中（约 30–50） | 番茄、茄、瓜类成苗 |
| 105、128 穴 | 中（约 15–30） | 叶菜、茄果类 |
| 200、288 穴 | 小（约 5–15） | 小粒种、叶菜、补苗 |
| 392 穴及以上 | 极小 | 组培瓶苗、小苗过渡 |

- 选型原则：**苗龄越长、根系越大、目标苗越壮 → 穴孔越大**；小孔盘育苗周期短、成本低但耐贮运差。
- 穴盘关键参数：穴孔形状（方/圆）、深度、底部排水孔、材质（PS 再生/新料）、是否可降解。
- 穴盘须清洗消毒（次氯酸钠/漂洗）后重复使用，或使用新盘降低病原。

## 五、播种深度与覆土

| 项目 | 原则/参考 | 说明 |
|---|---|---|
| 播种深度 | 一般为种子直径的 **3–5 倍**，或 0.5–1.5 cm（小粒种浅播） | 过深缺氧出苗难、过浅易干 |
| 覆土材料 | 蛭石/细基质，薄覆 | 蛭石透光保湿、便于出苗 |
| 覆盖保湿 | 覆膜/无纺布/蛭石 | 出苗后及时揭膜防徒长 |
| 镇压 | 轻压使种子与基质接触 | 小粒种不必压 |
| 播种密度 | 单粒定穴（精量）或撒播（分苗用） | 精量穴盘省苗、整齐 |

- 需光种子（如生菜、芹菜、部分花卉）宜**浅播或表面播**并保持光照。
- 出苗前避免强光直射导致高温灼伤，出苗后立即给光。

## 六、分阶段环境管理

### 6.1 出苗期（从播种到幼苗出土）

| 因子 | 目标（参考） | 调控 |
|---|---|---|
| 温度 | 喜温蔬菜 25–30 ℃；冷凉蔬菜 18–22 ℃ | 加温/遮阳/催芽室 |
| 湿度 | 基质湿润、空气 RH 85%–95% | 覆膜保湿、喷雾 |
| 光照 | 弱光/暗培养促出土，出土后立即见光 | 揭覆盖物、补光 |
| 水 | 保持表土湿润，忌积水 | 喷雾/底部给水 |

### 6.2 幼苗期（出土后至 2–3 真叶）

| 因子 | 目标（参考） | 关键措施 |
|---|---|---|
| 温度 | 昼 22–28 ℃、夜 15–20 ℃（拉大温差防徒长） | 控温、加强通风 |
| 光照 | 光强 200–400 μmol·m⁻²·s⁻¹，12–16 h 光周期 | 补光/遮阳，保证 DLI |
| 湿度 | 空气 RH 60%–75% | 通风除湿 |
| 水肥 | 控水促根，视情况低浓度育苗肥 | 见干见湿 |

- **分苗（移栽盘/假植）**：在子叶展开至 1–2 真叶期，将苗移入更大穴孔或营养钵，促发侧根、提高整齐度；分苗宜在阴天/傍晚，分后遮荫缓苗 2–3 d。

### 6.3 成苗期（3 真叶至出圃）

| 因子 | 目标（参考） | 关键措施 |
|---|---|---|
| 温度 | 昼 20–26 ℃、夜 12–18 ℃（温差 6–10 ℃） | 控温防徒长 |
| 光照 | 保证充足光强与 DLI（视作物） | 补光、清洁覆盖物 |
| 水肥 | 随苗龄提高 EC（见第八节） | 水肥一体化 |
| 空气 | 保持通风、CO₂ 可视设施补充 | 通风/CO₂ 施肥 |

## 七、徒长（徒长苗）控制

| 诱因 | 表现 | 对策 |
|---|---|---|
| 光照不足/密度过大 | 茎细长、叶薄色淡 | 增加光照、扩大间距、疏苗 |
| 温度偏高（尤其夜温） | 节间拉长 | 降夜温、拉大昼夜温差 |
| 氮肥/水分过多 | 旺长、根系弱 | 控水控氮、增施磷钾 |
| 湿度大通风差 | 组织柔嫩 | 加强通风除湿 |
| 播种过密 | 竞争徒长 | 精量播种、及时分苗 |

- **化学控长**：矮壮素（CCC，chlormequat）、多效唑（paclobutrazol）、烯效唑等（**须符合登记与残留要求，按标签/试验浓度使用，待核实**）。
- **物理控长**：控水、降温、强光、机械刺激（拨苗/风扰）、昼夜温差。

## 八、育苗肥与水分管理

### 8.1 随苗龄的 EC 与浓度（参考）

| 阶段 | EC（mS/cm） | 氮浓度（mg·L⁻¹ N，参考） | 说明 |
|---|---|---|---|
| 出苗期 | 0.5–0.8 | 50–100 | 主要靠基质起始养分 |
| 幼苗期 | 0.8–1.2 | 100–150 | 低浓度、少量多次 |
| 成苗期 | 1.2–2.0 | 150–200 | 提高钾比例、壮苗 |
| 炼苗期 | 略降或维持 | 降低氮 | 控水控氮、硬化 |

- 大量元素比例按作物调整（苗期 N:P₂O₅:K₂O 常为 1:0.5:1 至 1:0.5:1.5，**待核实**）。
- 微量元素用商品育苗专用配方（含 Fe、Mn、Zn、Cu、B、Mo），避免缺素。
- **灌溉原则**："见干见湿"、少量多次；底部给水或潮汐灌溉可减少叶面湿害、降低病害。

### 8.2 水质

- 灌溉水 EC、pH、钠/氯/碳酸氢根、硼等需检测；硬水/高盐水需处理或调整配方。
- 基质 pH 与灌溉水 pH 共同影响养分有效性。
