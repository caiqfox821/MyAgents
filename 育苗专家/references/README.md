# 育苗专家知识库 · 参考资料索引

> 本目录为**育苗专家**的参考资料库，收录从种子（繁殖体）到健壮种苗的结构化知识，以及项目案例。
> 文件由网络公开资料与通用教材/标准整理，**种苗质量标准、检疫要求、组培/嫁接技术规范一律以现行有效版本与本地试验为准**。
> 标准与法规复核入口：国家标准全文公开系统 <https://openstd.samr.gov.cn>；全国标准信息公共服务平台 <https://std.samr.gov.cn>；农业农村部 <http://www.moa.gov.cn>；国家林草局 <https://www.forestry.gov.cn>；国家法律法规数据库 <https://flk.npc.gov.cn>。

## 四、来源与可靠性说明

- **一级（权威）**：农业农村部、国家林草局、国家/行业种苗与组培标准、国家法律法规数据库、国家标准全文公开系统及权威教材。
- **二级（参考）**：育苗企业技术资料、行业媒体、百科；仅作检索线索，具体数值须回归一级来源或本地试验。
- 各文件均设 **"待核实"标注与清单**；涉及种苗质量标准、检疫要求、组培/嫁接技术规范、标准版本号时不得臆造。

## 五、收录原则与核验约定

- 法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T、NY/T、LY/T 等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- 需要精确数值/条文时，先向用户索取该标准 PDF 或联网核验，再单列收录并登记版本与实施日期。
