# 育苗知识技能

## 何时使用
育苗方案、种子处理、嫁接/扦插/组培、工厂化育苗、种苗质量与检疫、移栽成活相关任务。

## 育苗流程时间轴
播种前处理 → 播种/装盘 → 出苗期 → 幼苗期 → 分苗/移栽盘 → 成苗期 → 炼苗 → 出圃移栽
（各阶段标注温、光、湿、水肥目标）

## 繁殖方式选择
| 方式 | 适用 | 要点 |
|---|---|---|
| 播种育苗 | 大多数作物 | 种子活力、催芽、播种深度 |
| 嫁接育苗 | 抗病砧木/改良 | 砧穗亲和、嫁接方法、愈合 |
| 扦插育苗 | 无性系保持 | 插穗、生根剂、湿度 |
| 组织培养 | 脱毒/快速扩繁 | 外植体、培养基、脱分化/再分化 |
| 脱毒苗 | 病毒病严重作物 | 茎尖培养 + 病毒检测验证 |

## 种子处理
- 精选与活力测定、消毒（温汤/药剂）
- 浸种与催芽（温度、时间、露白标准）
- 引发（priming）、丸粒化/包衣

## 基质与环境
- 基质配方：草炭/蛭石/珍珠岩/椰糠，配比与 pH、EC
- 温度：发芽适温、昼/夜温差
- 光照：光强、光周期、补光（DLI）
- 湿度与通气：基质含水量、空气湿度
- 水肥：育苗肥浓度（EC、mg/L），随苗龄递增

## 苗期管理
- 徒长控制：控水控温、加大昼夜温差、矮壮素
- 病虫害绿色防控：基质消毒、通风、黄板、生物防治
- 炼苗（硬化）：降温、控水、增光，提高移栽成活

## 壮苗标准（示例，按作物调整）
- 茎粗、株高、叶片数/叶面积
- 根系发达、根冠比合理、无病虫害
- 苗龄适宜、无老化与徒长

## 种苗质量与检疫
- 分级标准、包装运输、保湿防冻
- 产地检疫、调运检疫、无病毒/无病菌证明
- 菌种（适用时）：母种→原种→栽培种，无菌操作与纯度

## 常见问题
| 现象 | 原因 | 对策 |
|---|---|---|
| 出苗不齐 | 种子活力/温湿不匀 | 精选、匀播、控温 |
| 徒长 | 光照弱/水肥多/温高 | 增光、控水、降温 |
| 立枯/猝倒 | 基质带菌/湿度大 | 消毒、通风、控湿 |
| 嫁接不成活 | 亲和差/愈合环境差 | 选亲和砧穗、控温湿 |
| 移栽死苗 | 未炼苗/伤根 | 炼苗、护根、遮荫缓苗 |
