# 谱图解析与未知物鉴定

## 一、从谱图到分子式

1. **精确质量**：由 HRMS 得母离子 m/z，扣除加合物质量得中性分子质量。
2. **分子式候选**：在 ppm 窗内枚举元素组合，约束条件：
   - **RDB（环加双键）** ≥ 0 且为整数（中性分子）；
   - **氮规则**：奇/偶质量与氮原子奇偶相关（对 CHNO）；
   - 与同位素簇一致（³⁴S、³⁷Cl、⁸¹Br 特征间距）。
3. **同位素簇判读**：M+1（¹³C 约 1.1%×碳数）、M+2（S/Cl/Br/Si）、M+4（多 Cl/Br）。
4. **候选排序**：结合 MS/MS 碎裂、保留时间、样品背景（代谢物/污染物/天然产物）。

## 二、碎裂规律要点

**常见中性丢失**

| 丢失 | 质量 | 提示 |
|---|---|---|
| H₂O | 18.0106 | 醇、酚、羧酸 |
| NH₃ | 17.0265 | 胺、酰胺、氨基酸 |
| CO | 27.9949 | 羰基、酚、醌 |
| CO₂ | 43.9898 | 羧酸、酯 |
| CH₂O | 30.0106 | 甲氧基、羟甲基 |
| HCN | 27.0109 | 含氮杂环、腈 |
| SO₃ / SO₂ | 79.96 / 63.96 | 磺酸、磺酸盐 |
| 糖基 | 162.05 / 146.06 | 糖苷（己糖/脱氧己糖） |
| HCl | 35.98 | 氯代物 |

**特征重排/断裂**
- **McLafferty 重排**：羰基 γ-H 迁移，醛/酮/酯/酰胺特征。
- **逆 Diels-Alder**：环己烯类。
- **苄基断裂**：芳环侧链（tropylium m/z 91 等）。
- **α-断裂**：胺、醚、羰基邻位。
- 质子/电荷迁移、氢重排：解释偶数/奇数电子离子。

**碎裂规律使用方法**：先定骨架（RDB、特征子结构），再用丢失与子离子确证取代基与官能团；MSⁿ 逐级碎裂定位官能团位置。

## 三、谱库检索

| 谱库 | 电离 | 适用 | 备注 |
|---|---|---|---|
| **NIST（EI）** | EI 70 eV | 挥发物、风味、农残、溶剂 | EI 可比性好，跨仪器匹配较可靠 |
| **mzCloud** | ESI MSⁿ | 药物、代谢物、污染物 | 分级 MSⁿ 谱，HRMS |
| **MassBank** | ESI/EI | 环境、代谢物、参考谱 | MassBank Europe/Japan；RDF 版可 SPARQL 查（见 `togomcp-sparql`） |
| **GNPS** | ESI MS² | 天然产物、微生物、分子网络 | 分子网络适合同系物发现 |
| 自建库 | 本仪器条件 | 目标物 | **条件一致**才能用，保留时间+离子比确证 |

> **EI 谱可跨仪器比较；ESI MS² 谱对 CE/NCE、仪器类型敏感**，跨库匹配分数须谨慎解读。

## 四、原位（in silico）解析工具

| 工具 | 输入 | 输出 | 备注 |
|---|---|---|---|
| **CFM-ID** | 结构 + MS² | 预测谱 → 打分 | 竞争碎裂模型 |
| **MetFrag** | 峰表 + 候选库 | 候选打分排序 | 可与 PubChem/ChEBI 联查 |
| **SIRIUS / CSI:FingerID** | MS¹/MS² | 分子式 + 结构指纹/候选 | 碎片树 + 机器学习 |
| **MS-FINDER** | EI/ESI 谱 | 分子式 + 候选 + 注释 | 多库整合 |

> 原位解析给出**候选**，不等于确证；须结合保留时间、标准品或正交证据，并标注可信度。

## 五、可信度分级（Schymanski 等，广泛采用）

| 等级 | 证据 |
|---|---|
| 1 | 标准品 + 谱库 + 保留时间一致（确证） |
| 2 | 与库/文献谱图高度匹配 |
| 3 | 有候选结构（原位解析等），缺标准品 |
| 4 | 仅到分子式/化合物类别 |
| 5 | 仅精确质量 |

## 六、组学数据处理要点

- **代谢组学**：XCMS / MS-DIAL / MZmine 做峰检测、对齐、归一化；注释分 tier（标准品 > 库匹配 > 原位解析）。
- **脂质组学**：LipidSearch / Lipostar / MS-DIAL；**双键与酰基链位置异构**需离子淌度或特殊碎裂（Paternò–Büchi）区分。
- **蛋白组学**：DDA 或 DIA；搜库（MaxQuant / FragPipe / DIA-NN），FDR ≤ 1%，PTM 定位打分；批次校正。
- **统计**：QC 样 PCA 判批次、FDR 校正、通路富集；报告注明预处理参数与阈值。

## 七、解析交付清单

1. 母离子 m/z、加合物形式、精确质量与 ppm。
2. 分子式候选与 RDB。
3. 主要碎片与中性丢失归属（表格化）。
4. 库匹配结果（库名、版本、分数）或原位解析候选与分数。
5. **可信度等级**与不确定之处（异构、共流出、缺标准品）。
6. 检索日期与数据库版本。
