# 质谱专家 · 书库索引（`公共知识/书库/`）

> **为什么本专家不单独建书库？** 质谱与**毒理**、**风险评估（公共技能 `risk-assessment`）**共用同一批权威来源（WHO/FAO EHC 240、ICH M7(R2)、SANTE、OECD 指南、MDPI 分析专著）。
> `公共知识/` 是 `opencode.json` 里**唯一全局注册的公共 reference**（跨领域共享来源必须集中存放才能被所有专家检索）；
> 因此**原始全文放 `公共知识/书库/`，本目录只放"消化后的 L3 条目"**（`证据条目与出处.md`，9 节 74 条）。其他专家（发酵/食品加工/营养/育苗/育种/种植）的来源领域专属，故各自用私有 `references/books/`。

## 二、取证命令（所有页码/PMCID 可由这两条复现）

```bash
cd 公共知识/书库
python3 tools/search_books.py "recovery rates" --context 1        # 全库检索：书 | 物理页码 | 原文
python3 tools/read_page.py LC_MS_MS_Method_for_Mycotoxin_Analysis 25
grep -o '.\{0,160\}MRM.\{0,160\}' papers/txt/PMC13573562.txt
```

**引用写法**：专著/指南标 `公共知识/书库 p.N`（PDF **物理页码**）；OA 文献标 `PMCID §章节`（不给页码，避免伪造）。

**行为纪律**：回答质谱方法/参数/合规问题时先查 `证据条目与出处.md` 并给页码或 PMCID；条目不足则回原文取证；仍无证据即声明"**书库无此证据**"，**不得臆造跃迁对、CE、LOQ、验收阈值或指南文件编号**。
