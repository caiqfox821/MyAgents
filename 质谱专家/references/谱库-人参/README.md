## 六、使用说明

**NIST MS Search / MassHunter**：直接打开 `library.msp` 作为用户谱库检索。

**MS-DIAL / MZmine / GNPS**：用 `library.mgf` 建立本地库或做谱库比对。

**自建脚本/编程**：读 `index.csv` + `raw/massbank/peaks.csv` 或直接解析 `library.mgf`。

> 建议：母离子过滤 + 加合物 + 极性 + 碰撞能量一致后再算相似度；MS² 库匹配置信度最高到 Schymanski Level 2。

## 七、如何补充自测（实验）谱图

把鉴定确证的实测 MS² 谱放入本库 `user/` 目录（`*.mgf` 或 NIST `*.msp` 均可），然后重跑：

```bash
cd <本库>/scripts
python3 build_library.py    # 自测谱以 source=User(实验) 并入 library.msp / .mgf / index.csv
python3 make_report.py      # 刷新覆盖率与说明
```
MSP 记录建议含：`Name`、`InChIKey`、`Formula`、`PrecursorMZ`、`Precursor_type`、`Ion_mode`、`Collision_energy`、`Num Peaks` 及峰表；名称与目标清单一致时自动归入该目标（也可写 `MATCHED_TARGET=` 指定）。

## 八、已知局限（务必阅读）

1. **稀有皂苷大量缺失**：Rk1/Rk3/Rh4/Rs1–Rs9/F4/Fa/Fc/Fe、三七皂苷 Notoginsenoside R1–R6、拟人参皂苷 F11、Vinaginsenoside R1、Majonoside R2、Ocotillol、苷元 PPD/PPT 等在 MassBank、GNPS、MoNA 中均未检索到实测 MS² 参考谱（详见覆盖表）。
2. **同分异构体无法仅凭 MS² 区分**：Rg1/Rf（C42H72O14, m/z 799.5）、Rg3/Rg2/F2（C42H72O13, m/z 783.5）——需色谱保留时间或标准品。
3. **MassBank 的 `ch_exact_mass` 字段不可靠**（部分为平均分子量），本库的质量已改由分子式重新计算（`ExactMass`），原始值保留在 `Comment` 中备查。
4. **前体 m/z**：MassBank 多数记录未给前体值，本库按加合物由分子式推算并在 MSP 中给出 `PrecursorMZ`；如与实际仪器条件不符请以原始 `Comment` 为准。
5. **强度标尺不同**：MassBank 为相对强度(%)；GNPS/MoNA 原始为绝对强度，本库已归一到基峰=100。
6. **无保留时间/CCS**：均为谱库（MS²）参考谱，不含 RT/CCS。
7. 多库合并存在**同化合物多来源重复**（保留各自来源记录，便于交叉验证）。
8. 本库**保留全部**参考谱（含少量低信息量记录，如仅 1–2 个碎片的谱）。可在 `index.csv` 中按 `n_peaks` 列过滤（如 `n_peaks>=5`）后使用，以获得更干净的子库。

## 九、补充说明与使用提示

### 人参皂苷碎裂与判读要点（定性参考，数值须以标准品/实测复核）

1. **皂苷糖基中性丢失**（ESI-MS² 通用）：葡萄糖 Glc 162、鼠李糖 Rha 146、阿拉伯糖/木糖 Ara/Xyl 132、葡萄糖醛酸 GlcA 176。正离子 `[M+H]⁺` 常见序贯脱糖；负离子 `[M–H]⁻` 亦易在糖苷键断裂，并常以 `[M+HCOO]⁻`（+45）、`[M+Na–2H]⁻`（+22）形式出现，做负离子检索时母离子加合物要一并考虑。
2. **苷元骨架离子**：PPD 型与 PPT 型苷元在 MS² 中各自出现特征甾核碎片（文献常见 m/z 约 407/425 与 405/423 一类），可用于快速区分 PPD/PPT 母核；**具体数值以实测或标准品比对为准**，本库不做断言。
3. **同分异构体对**（分子式相同，仅 MS² 难以区分，须靠色谱保留时间）：
   - Rg1 / Rf —— C42H72O14（m/z 799.5，正离子 [M+H]+ / 负离子 [M+HCOO]−）；
   - Rg3 / Rg2 / F2 —— C42H72O13（m/z 783.5）；
   - Rb1 / Rb2 / Rb3 / Rc 均 C53H90O22 或 C54H92O23 系列，亦需色谱分离。
4. **加工/降解关系**：加热、强酸或酶解会使原生皂苷逐级水解，生成次生皂苷（如 Rd→Rg3/Rh2→化合物K；Rg3/Rh2 脱水→Rk1/Rk3/Rg5 等）。做"炮制品/代谢物"研究时，这些次生皂苷常需自行合成标准品或从文献取谱。**本库中缺测的正是这一类稀有成分为主**（见覆盖表）。
5. **极性/加合物选择建议**：皂苷在负离子下背景更干净、`[M–H]⁻` 与 `[M+HCOO]⁻` 均可；正离子 `[M+Na]⁺` 常常响应强于 `[M+H]⁺`。做库检索时先按"极性 + 加合物 + 前体 ppm + CE"过滤，再算相似度。
