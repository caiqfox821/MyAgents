# 质谱方法开发、定量与验证

> 接受标准为**通行参考值**，不同标准/领域（农残、兽残、毒素、环境）要求不同，最终以适用的现行标准正文或判定规则为准。

## 一、方法开发流程

1. **明确目标与限量**：目标物清单、基质、限量水平（决定 LOQ 目标）。
2. **前端选择**：挥发性/极性 → GC 或 LC（见 `质谱仪器与电离方式.md`）。
3. **电离与离子化条件初调**：用标准品溶液（单标/混标）做 Full Scan，确定母离子与加合物。
4. **碎裂优化**：CE/NCE 阶梯扫描，记录最优值与碎裂谱。
5. **离子对确定**：选 2 对以上 MRM（定量离子 + 定性离子），核查离子比。
6. **色谱条件优化**：柱、梯度、流动相（挥发性盐）、保留时间与峰形。
7. **前处理与净化**：QuEChERS/SPE/LLE 等，目标是降基质效应至可接受并保证回收。
8. **基质效应评估与校正**（见第三节）。
9. **方法验证**：按第四节逐项确认。
10. **固化 SOP**：参数、校准、质控、判定规则写清，含仪器型号与 CE/NCE。

## 二、靶向定量设计（QqQ）

- **离子对**：定量通道 + ≥1 定性通道；确证需满足离子比容差与保留时间容差（按判定规则）。
- **Q1/Q3 扫描**：先各产物离子扫描挑强度高、特异性好的子离子。
- **驻留时间/周期**：平衡灵敏度与峰采集点（每峰 ≥ 8–12 点较稳妥）。
- **正负离子切换**：同一方法内分组切换，注意切换时间对峰的影响。

### 校准曲线
- **基质匹配标曲**优于纯溶剂标曲（尤其农残/兽残）。
- **加权回归**：低端用 1/x 或 1/x² 常改善 LOQ 附近准确性。
- 线性范围覆盖 LOD ~ 最高限量以上；r² 参考 **≥ 0.995**（部分标准要求更高或看残差）。

### 内标
- 优先**同位素内标**（每个目标物最好有对应 d/H/C 标记物）。
- 无同位素内标时用结构类似物，须评估其与目标物的**相对基质效应与回收**，且不得用于校正保留时间漂移以外的选择性差异。
- 内标加入时机：前处理最早可加入时（校正提取损失），或定容前（仅校正仪器波动）——**须在报告中说明**。

## 三、基质效应（关键环节）

**评估方法**
- 提取后加标法（post-extraction spiking）：`ME% = (基质标响应 − 溶剂标响应) / 溶剂标响应 × 100%`。
- 柱后注入法（post-column infusion）：观察离子抑制/增强区域。
- 判定：|ME%| ≤ 20% 通常视为可接受；±20–50% 需校正；> 50% 须改进方法。

**消除/校正对策**
1. 同位素内标（最有效）。
2. 基质匹配标曲。
3. 增强净化（SPE、d-SPE、GPC、免疫亲和）。
4. 稀释或降低进样量/基质载量。
5. 改变电离方式（ESI → APCI）或色谱条件使目标物避开抑制区。

## 四、方法验证参数与接受标准（参考）

| 参数 | 参考接受标准 |
|---|---|
| 专属性 | 空白基质无干扰；目标物峰纯度/离子比符合 |
| 线性与范围 | r² ≥ 0.995，覆盖 LOQ ~ 上限；残差随机 |
| 准确度（回收率） | 70–120%（痕量可放宽至 60–120%，依标准） |
| 精密度（重复性） | RSD ≤ 15%（痕量 ≤ 20%） |
| 中间精密度 | 不同日/不同浓度 RSD ≤ 20%（参考） |
| LOD/LOQ | S/N ≥ 3 / ≥ 10；或统计法（标曲截距 SD × 3.3 / 10） |
| 基质效应 | |ME%| ≤ 20%（或经内标校正后满足要求） |
| 耐用性 | 微小变动（流速、柱温、流动相 pH）下结果稳定 |
| 稳定性 | 样品/标液在规定储存条件下的稳定性 |

> 注意区分**验证（validation）**与**确认（verification/transfer）**：采用标准方法时做确认；自建方法做完整验证。

## 五、质控与数据完整性

- **批内质控**：试剂空白、基质空白、加标样（低/中/高）、平行样、穿插 QC 样。
- **质控图**：以 QC 样响应/浓度作 Westgard 规则监控趋势（1-2s、1-3s、2-2s、4-1s、10x）。
- **携带污染**：高浓度后进空白，评估残留 %，必要时插入洗针程序。
- **反馈**：连续超标 → 暂停检测，查仪器、标曲、前处理或污染源。
- **数据完整性**：ALCOA+（可归属、清晰、同步、原始、准确、完整、一致、持久、可用），原始谱图可溯源、可复算。

## 六、常用标准与判定规则（登记入口，正文为准）

- 农残：**GB 23200 系列**（如 GB 23200.121 LC-MS/MS 与 GC-MS/MS 多残留，GB 23200.113 等），NY/T 系列。
- 兽残/毒素/添加剂类：**GB 5009 系列**、GB 31650（兽药最大残留限量）及配套检测。
- 判定规则：欧盟 **SANTE** 文件（离子比容差、保留时间容差）为国际通行的定性/定量判定参考。
- 元素与形态：GB 5009 元素系列 + ICP-MS。

> 标准号与条款**不得臆造**；交付前核对现行有效版本与实施日期，或索取标准正文。
