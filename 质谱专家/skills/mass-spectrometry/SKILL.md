# 质谱方法学技能

## 何时使用

质谱方法开发与参数优化、谱图与碎片解析、未知物鉴定、靶向定量设计、组学数据（代谢/脂质/蛋白）处理、质谱质控与合规判定。

## 一、仪器与电离选型决策

### 1. 先按性质分流

| 目标物性质 | 首选前端 | 首选电离 |
|---|---|---|
| 极性、热不稳定、大分子、离子型 | LC / CE / IC | ESI、APCI、APPI |
| 挥发/半挥发、小分子、非极性 | GC | EI、CI、FI |
| 元素与形态 | LC/GC/IC | ICP、ESI |
| 固体表面、原位、成像 | 直接进样 | MALDI、DESI、DART |
| 大分子（蛋白/多糖/微生物） | 直接/MALDI | MALDI、ESI |

### 2. 再按**结论用途**选质量分析器

| 需求 | 推荐 | 理由 |
|---|---|---|
| 痕量**靶向定量**（多残留、毒素、激素） | **QqQ（MRM）** | 灵敏度与动态范围最优，选择性高 |
| **非靶向筛查**、未知物、精确质量 | **HRMS（Q-TOF / Orbitrap）** | ppm 级质量精度 + 全扫描回溯 |
| 结构解析、多级碎裂 | **IT / Q-LIT / IT-TOF** | MSⁿ 逐级碎裂 |
| 挥发物、风味、农残（GC 侧） | **GC-QqQ / GC-Q-TOF** | 与 EI 谱库互通 |
| 蛋白组（DDA/DIA） | **Orbitrap / Q-TOF / timsTOF** | 高分辨 + 高扫描速率 |
| 脂质/代谢组学 | **Q-TOF / Orbitrap** | 注释与同位素匹配 |
| 元素/形态 | **ICP-MS（+LC/GC 联用）** | 元素专属性 |
| 微生物/大分子鉴定 | **MALDI-TOF** | 指纹图谱 |

> **默认策略**：**定量用三重四极，鉴定用高分辨**。只有在需要同时定性+定量时才用 HRMS 全扫描+DIA（代价是灵敏度通常低于 MRM）。

## 二、采集模式速查

| 模式 | 用途 | 要点 |
|---|---|---|
| Full MS | 探查、分子量、同位素簇 | 先做全扫描再决定离子 |
| SIM | 已知目标定量（低分辨） | 选择性弱于 MRM |
| **MRM / SRM** | 靶向定量 | 两对以上离子对 + 离子比确证 |
| PRM | HRMS 靶向定量 | 高分辨 + 窄窗口 |
| **DDA** | 非靶向、建库 | 依赖母离子强度，易漏低丰度 |
| **DIA / SWATH** | 非靶向、可回溯 | 覆盖全，谱图解析难 |
| MSⁿ | 结构解析 | 逐级碎裂定骨架 |

## 三、参数优化要点

**ESI（最常用）**
- 极性：碱性 → 正离子（[M+H]⁺、[M+Na]⁺）；酸性 → 负离子（[M–H]⁻）；两性多试两侧。
- 关键参数：喷雾电压、鞘气/辅助气、脱溶剂温度、锥孔/毛细管电压（源内裂解）、碰撞气。
- 加合物判读：Na⁺/K⁺/NH₄⁺、二聚体 [2M+H]⁺，用精确质量与冗余离子判断。

**GC-EI**
- 70 eV 标准谱，与 NIST 库可比；先优化柱温程序与进样（分流/不分流、PTV）。
- 衍生化：硅烷化（TMS）、酰化、酯化，提高挥发性与响应。

**碎裂参数**
- CE 阶梯扫描（如 10–60 eV）挑最佳；HCD 用于 Orbitrap 通用碎裂；SID 调控源内裂解。
- 记录 CE/NCE 与仪器型号，否则谱图不可复现。

## 四、碎裂与谱图解析

1. **定母离子**：精确 m/z、同位素簇、加合物 → 分子式候选（结合 RDB、氮规则）。
2. **看中性丢失**：H₂O(18)、NH₃(17)、CO₂(44)、CH₂O、SO₃(80)、糖基(162/146)等。
3. **识别特征碎片与重排**：McLafferty、逆 Diels-Alder、苄基断裂、质子/电荷迁移。
4. **归属每个主要碎片**（给出结构式或丢失形式），脆弱键优先断裂。
5. **判可信度**（Schymanski 等）：

| 等级 | 含义 |
|---|---|
| 1 | 标准品 + 谱库 + 保留时间一致 |
| 2 | 谱库或文献谱图高度匹配 |
| 3 | 有候选结构（如原位解析），缺标准品 |
| 4 | 仅分子式/类别 |
| 5 | 仅精确质量 |

> 交付时必须给出**可信度等级**；只用精确质量不得宣称"确证"。

## 五、靶向定量

- **离子对设计**：至少 2 个 MRM 通道；残留监测用离子比确证（符合判定规则）。
- **校准**：基质匹配标曲，加权 1/x 常改善低端；覆盖 LOD 至上限。
- **内标**：优先**同位素内标**；无则结构类似物，需评估与目标物的相对响应。
- **基质效应**（关键）：后柱注入法或提取后加标计算 ME%；对策：同位素内标、基质匹配、稀释、SPE 净化、APCI 替代 ESI。
- **LOD/LOQ**：S/N ≥ 3/10，或用统计法（标曲截距标准偏差）；报告要注明方法与基质。
- **携带污染**：高浓度后跟空白，评估残留百分比。

## 六、未知物鉴定工作流

1. **精确质量** → 分子式候选（ppm、RDB、同位素）。
2. **HRMS 数据库筛查**（如 mzCloud、MassBank、GNPS、脂质/内源库）。
3. **MS/MS 谱库检索**：NIST、mzCloud、MassBank（EI 谱与 ESI MS² 分开）。
4. **原位裂解预测**：CFM-ID、MetFrag、SIRIUS/CSI:FingerID、MS-FINDER。
5. **正交确证**：保留时间（同族保留指数）、标准品、离子淌度 CCS、色谱行为。
6. **定可信度等级**并写明不确定之处（同分异构、共流出、缺标准品）。

> 查参考谱图与化合物结构可加载公共技能 **`togomcp-sparql`**：MassBank（`mb:MassSpectrum`、InChIKey 反查）、ChEBI/PubChem、LIPID MAPS/SwissLipids。注意：参考谱图受覆盖率限制，命中率低是设计使然，不能据"查不到"排除某一结构。

## 七、组学数据处理

- **代谢组学**：XCMS / MS-DIAL / MZmine（峰检测、对齐、归一化）；注释用 MS-DIAL 库 + 数据库 + 原位解析。
- **脂质组学**：LipidSearch / Lipostar / MS-DIAL；注意酰基链与双键位置异构（必要时用 Paternò–Büchi 或离子淌度）。
- **蛋白组学**：DDA（依赖 DDA 建库）或 DIA；搜库（MaxQuant/FragPipe/DIA-NN）、FDR ≤ 1%、PTM 定位；批次效应校正。
- 统计：QC 样 PCA 看批次、多重检验校正（FDR）、通路富集。

## 八、质控与合规

- **仪器性能核查**：质量校准（外标/内标）、灵敏度与峰形核查（如调谐液）、重复性（保留时间与响应）。
- **批内质控**：空白、加标、平行样、QC 样定点插入、质控图（Westgard）。
- **数据完整性**：ALCOA+，原始谱图可溯源、可复算。
- **判定规则**：按现行判定规则（如 SANTE 离子比与保留时间容差；GB 方法中的定性/定量要求）执行，**以标准正文为准**。

## 九、常见坑（排查顺序）

| 现象 | 常见原因 |
|---|---|
| 目标物无响应 | 极性/电离方式选错、源内裂解、加合物形式误判、pH 与流动相不兼容 |
| 响应波动大 | 喷雾不稳、基质效应、内标加入时机、柱效下降 |
| 定性假阳性 | 只用母离子、离子比不符、无标准品即宣称确证 |
| 定量偏低 | 基质抑制未校正、进样口吸附、衍生化不完全 |
| MS² 与库匹配差 | CE/NCE 不同、仪器类型不同（EI 可跨仪器、ESI 谱库需同条件） |
| 峰容量不足 | DDA 漏采、色谱分离差、动态范围超限 |
