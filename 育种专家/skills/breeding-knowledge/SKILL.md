# 育种知识技能

## 何时使用
品种选育、引种、杂交设计、分子育种、抗逆/品质育种、品种审定登记、制种与品种权相关任务。

## 育种途径速查
| 途径 | 适用 | 要点 |
|---|---|---|
| 选择育种 | 现有群体变异 | 系谱法/混合法，选择压 |
| 杂交育种 | 综合优良性状 | 亲本配合力、杂种优势 |
| 回交育种 | 转移单基因/寡基因 | 轮回亲本、背景回复 |
| 诱变育种 | 创造新变异 | 辐射/化学，突变体筛选 |
| 倍性育种 | 无籽/抗逆/大果 | 单倍体加倍、多倍体 |
| 远缘杂交 | 导入外源基因 | 克服不亲和、染色体工程 |
| 分子育种 | 定向选择 | MAS/QTL/GWAS/GS |
| 基因编辑 | 精准改良 | CRISPR/Cas，法规与安全评价 |

## 亲本选配原则
- 互补性：双亲优缺点互补
- 遗传距离：适度远缘，扩大分离
- 配合力：一般配合力（GCA）+ 特殊配合力（SCA）
- 目标性状遗传力：高遗传力性状早代选择

## 分子育种要点
- **MAS**：标记与目标基因连锁紧密，验证群体中有效性
- **QTL/GWAS**：群体规模、表型准确度、群体结构校正
- **GS**：训练群体、预测模型、预测准确度与轮次
- **基因编辑**：靶点设计、脱靶检测、世代纯合、法规合规

## 试验设计与选择
- 田间设计：随机完全区组（RCBD）、多点多年、重复与对照
- 选择指标：产量及构成因素、抗性分级、品质指标
- 数据：方差分析、遗传力、遗传增益估算

## 审定与保护
- **DUS 测试**：特异性（Distinctness）、一致性（Uniformity）、稳定性（Stability）
- **品种审定/登记**：区域试验 2–3 年、抗性鉴定、品质分析
- **植物新品种权**：申请、审查、授权与维权
- **制种**：雄性不育系/恢复系、隔离、去杂、纯度鉴定

## 关键计量
- 遗传力 `h² = Vg / Vp`
- 遗传增益 `ΔG = i · h² · σp`
- 选择强度 `i` 与选择比例对应
