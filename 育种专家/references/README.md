# 育种专家知识库 · 参考资料索引

> 本目录为**育种专家**的参考资料库，收录从种质资源到品种审定/制种的结构化知识，以及项目案例与技术报告模板。
> 文件由网络公开资料与通用教材/法规整理，**品种审定/登记条件、DUS 指南、种子质量标准与限量一律以现行有效版本为准**。
> 标准与法规复核入口：国家标准全文公开系统 <https://openstd.samr.gov.cn>；全国标准信息公共服务平台 <https://std.samr.gov.cn>；农业农村部 <http://www.moa.gov.cn>；国家林草局 <https://www.forestry.gov.cn>；国家法律法规数据库 <https://flk.npc.gov.cn>。

## 三、开放获取电子书库与关键文献（`books/`、`文献清单-育种.md`）

`books/` 收录**合法开放获取（CC BY）**的种质资源、分子/数量遗传、QTL/GWAS、MAS/基因组选择、基因编辑、抗病抗逆与品质育种、果树/蔬菜/食用菌/药用植物育种专著，共 **16 册**（MDPI Books，3990 页，约 718 MB），已接入全文检索。

| 入口 | 说明 |
|---|---|
| `books/README.md` | 电子书库总说明、使用示例、许可与合规 |
| `books/INDEX.md` | 全文索引：主题标签 + 书目表（16 册） |
| `books/catalog.json` | 结构化元数据（标题/年/页/许可/来源/标签/目录） |
| `books/tools/search_books.py` | 全书库多词 AND 全文检索（返回 书\|页码\|原文） |
| `books/tools/read_page.py` | 按页读取指定电子书原文 |

## 四、来源与可靠性说明

- **一级（权威）**：农业农村部及种业管理司、《种子法》《植物检疫条例》、国家作物种质资源库/圃、UPOV/ITPGRFA 官方文本、国家法律法规数据库、国家标准全文公开系统。
- **二级（参考）**：育种/资源学教材与综述、种业行业资料；仅作检索线索，具体数值须回归一级来源或实测。
- 各文件均设 **"待核实"标注与清单**；涉及 DUS 指南、审定/登记条件、种质检疫、标准版本号时不得臆造。

## 五、收录原则与核验约定

- 法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T、NY/T、品种审定/登记办法等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- 需要精确数值/条文时，先向用户索取该标准/办法 PDF 或联网核验，再单列收录并登记版本与实施日期。
