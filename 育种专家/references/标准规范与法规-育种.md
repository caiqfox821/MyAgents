## 一、法律与行政法规

| 名称 | 层级 | 与育种的关系 |
|---|---|---|
| 《中华人民共和国种子法》 | 法律 | 品种选育、审定/登记、生产经营、种子质量、品种权 |
| 《植物新品种保护条例》 | 行政法规 | 植物新品种权申请、审查、授权与保护 |
| 《农业转基因生物安全管理条例》 | 行政法规 | 转基因/工程育种的安全评价、标识与监管 |
| 《中华人民共和国生物安全法》 | 法律 | 生物资源与生物技术安全的上位依据 |
| 《植物检疫条例》 | 行政法规 | 种质资源与种苗进出境/调运检疫 |
| 《生物多样性公约》及《名古屋议定书》 | 国际条约 | 遗传资源获取与惠益分享（ABS） |
| 《粮食和农业植物遗传资源国际条约》（ITPGRFA） | 国际条约 | 粮食与农业植物遗传资源交换与惠益分享 |

> 上表名称应逐条在法规数据库核对**现行有效版本与修订情况**（**待核实**）。

## 二、品种审定、登记与备案

| 制度 | 主要对象 | 依据（待核实） |
|---|---|---|
| 主要农作物品种审定 | 主要农作物（如稻、小麦、玉米、棉花、大豆等） | 《主要农作物品种审定办法》（**待核实**） |
| 非主要农作物品种登记 | 列入登记目录的作物 | 《非主要农作物品种登记办法》（**待核实**） |
| 品种备案 | 地方规定的部分作物 | 地方性规定 |
| 林木良种审定/认定 | 林木良种 | 林草主管部门规定 |

- **主要农作物**的具体种类由法律/名录规定，**以现行规定为准**。
- 登记目录（入选作物种类）定期调整，**须核对最新目录**。
- **品种退出**：对已审定/登记但存在严重缺陷、退化或长期未推广的品种，按规定撤销/退出（**条件与程序待核实**）。

## 四、转基因与基因编辑安全管理

| 环节 | 依据方向（待核实） |
|---|---|
| 安全评价 | 《农业转基因生物安全管理条例》、农业转基因生物安全评价管理办法 |
| 分级管理 | 按安全等级与实验/试验阶段分级 |

| 进口/加工 | 进口安全证书、加工审批 |

## 九、合规工作清单（育种项目）

- [ ] 明确育种目标与目标生态区，确认适用**审定/登记**制度与目录。
- [ ] 种质资源来源合法，留存**来源凭证/协议**；境外引种办理**检疫审批**并隔离。
- [ ] 涉及遗传资源获取与利用，履行 **ABS/PIC-MAT** 或 ITPGRFA/SMTA 要求。
- [ ] 确定品种（系）命名规范，开展 **DUS** 测试与**真实性/纯度**鉴定。
- [ ] 完成**区域试验/生产试验**、抗性鉴定与品质分析，整理审定/登记材料。
- [ ] 若涉及转基因/基因编辑，先完成**安全评价并取得证书**，再衔接品种管理。
- [ ] 布局**植物新品种权**申请，厘清与亲本提供方、合作方的权属。
- [ ] 制种/扩繁符合**种子生产技术规程**与隔离要求，种子质量按现行标准检验。
- [ ] 种子包装、标签、经营符合《种子法》与标签规定。
- [ ] 建立**档案追溯**：系谱、试验数据、检测报告、审批文件、协议。
- [ ] 与**文档格式化专家**协作整理审定/登记/品种权申请材料。
