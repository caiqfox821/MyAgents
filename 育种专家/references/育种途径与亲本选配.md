# 育种途径与亲本选配

> 整理范围：选择育种（系谱法/混合法/单粒传/轮回选择）、杂交育种（单交/复交/回交/多系）、诱变育种、倍性育种、远缘杂交与染色体工程、群体改良；亲本选配原则、配合力（GCA/SCA）测试、杂种优势与优势群、雄性不育与自交不亲和；世代推进与年限估算。
> 主要依据：作物遗传育种学公开教材/综述；数量遗传学与配合力经典设计（Griffing、North Carolina 设计）；植物倍性与远缘杂交研究公开资料。
> 说明：剂量、回复代次、群体规模、年限等为经验/参考量级，实际以物种特性与实测为准；不确定处标注"待核实"。

---

## 一、育种途径总览

| 途径 | 适用情形 | 核心操作 | 代表作物/方向 |
|---|---|---|---|
| 选择育种 | 现有群体/群体内存在变异 | 单株/混合选择、系谱法、SSD | 自花授粉作物提纯、地方种改良 |
| 杂交育种 | 需综合多个优良性状 | 亲本选配、杂交、世代选择 | 主粮、蔬菜、果树等 |
| 回交育种 | 转移单基因/寡基因性状 | 轮回亲本回交 + 选择 | 抗病基因导入骨干品种 |
| 诱变育种 | 群体缺乏目标变异 | 物理/化学诱变 + 突变体筛选 | 花卉、果树、禾谷类 |
| 倍性育种 | 需无籽、大果、抗逆 | 单倍体加倍、多倍体诱导 | 西瓜、柑橘、马铃薯 |
| 远缘杂交 | 近缘种缺乏目标基因 | 胚拯救、染色体工程 | 小麦-黑麦、水稻-野生稻 |
| 群体改良 | 提升群体一般配合力 | 轮回选择 | 玉米、异花授粉作物 |
| 分子育种 | 定向聚合/加速选择 | MAS/QTL/GS/编辑 | 多作物（见 `分子育种与智能育种.md`） |

## 二、选择育种

### 2.1 途径对比

| 方法 | 英文/缩写 | 操作要点 | 优缺点 |
|---|---|---|---|
| 系谱法 | pedigree | F₂ 起单株选择、记录系谱、逐代优中选优 | 目标明确、可追溯；工作量大 |
| 混合法 | bulk | F₂–F₅ 混合种植，高代再单株选择 | 省工、保留变异；选择滞后 |
| 单粒传 | SSD（single seed descent） | 每株取 1 粒混合推进至高代 | 加速纯合、保留系谱；不进行表型选择 |
| 混合系谱法 | — | 早代混合、后期系谱 | 兼顾省工与选择 |
| 轮回选择 | recurrent selection | 对群体周期性选择与重组 | 提升群体配合力（见第八节） |

### 2.2 选择原则

- **目标性状遗传力高者早代选择**（如株高、熟期、粒形）；遗传力低者（产量、抗逆）宜高代/多环境。
- 保持足够**群体规模**（如 F₂ 群体数千—数万株量级，**因作物待核实**），防止优良基因丢失。
- 自花授粉作物经若干代自交趋于纯合；异花授粉作物注意保种与隔离。

## 三、杂交育种

### 3.1 杂交方式

| 方式 | 组合 | 适用 |
|---|---|---|
| 单交 | A × B | 双亲优良互补，最常见 |
| 三交 | (A × B) × C | 兼顾两亲优点再加第三亲 |
| 双交 | (A × B) × (C × D) | 综合四亲、扩大变异 |
| 顶交 | 与测验种杂交 | 配合力测定 |
| 多系杂交 | 多个亲本参与 | 广适应、缓冲风险 |

### 3.2 组合配置要点

- 母本选择：**易去雄/不育**、杂交结实率高、细胞质效应。
- 花期调节：分期播种、光温调控、错期父本，保证花期相遇。
- 杂交技术：去雄、套袋隔离、人工授粉、标记与记录。
- F₁ 真实性鉴定：形态标记、分子标记（SSR/SNP）。

## 四、回交与背景回复

### 4.1 基本框架

- 结构：**轮回亲本（recurrent parent，受体）× 供体亲本（donor，提供目标基因）→ F₁ → 与轮回亲本回交 n 代**。
- **背景回复率**（理论）：`1 − (1/2)^n`，n 为回交代数。

| 回交代数 n | 理论背景回复率 |
|---|---|
| 1 | 50% |
| 2 | 75% |
| 3 | 87.5% |
| 4 | 93.75% |
| 5 | 96.9% |
| 6 | 98.4% |

> 生产上常回交 **5–6 代**（**因作物与性状待核实**）；结合**前景选择**（目标基因标记）+ **背景选择**（全基因组标记）可显著缩短年限。

### 4.2 注意事项

- 每代须确认目标基因存在（接种鉴定或分子标记）。
- 避免**连锁累赘**（linkage drag）：目标基因附近供体片段过大，可用高代回交 + 标记辅助。
- 核基因组回交与细胞质遗传（雄性不育、叶绿体/线粒体）需分别处理。

## 五、诱变育种

### 5.1 诱变源

| 类别 | 代表 | 要点 |
|---|---|---|
| 物理-辐射 | γ 射线、X 射线、快/热中子、离子束 | 剂量-存活曲线，确定半致死剂量（LD₅₀ 附近） |
| 物理-紫外 | UV | 适用于微生物、离体材料 |
| 化学 | EMS、NaN₃、MNU、秋水仙素（倍性） | 需防护、控制浓度与处理时间 |
| 空间诱变 | 航天搭载 | 复合因素，突变谱较广 |
| 复合诱变 | 物理 + 化学 | 提高突变频率 |

### 5.2 突变体筛选

- 世代：M₁ 处理、M₂ 开始选择（多数隐性突变在 M₂ 显现）、M₃ 稳定。
- 筛选类型：**正向筛选**（抗性、耐逆、品质）、**负向筛选**（抗代谢类似物、耐产物）。
- 鉴定：表型 + 遗传验证（等位性测验）+ 定位/测序。
- 注意：多数突变为隐性、随机、低频；需足够 M₂ 群体。

## 六、倍性育种

### 6.1 单倍体与双单倍体

| 途径 | 方法 | 备注 |
|---|---|---|
| 花药/小孢子培养 | 离体诱导愈伤→植株 | 依赖基因型、易白化 |
| 远缘杂交染色体消除 | 如玉米诱导系诱导单倍体 | 玉米、小麦等高效 |
| 染色体加倍 | 秋水仙素处理 | 得双单倍体（DH）纯系 |
| 天然单倍体 | 偶发 | 频率低 |

- DH 意义：一代即纯合，**缩短育种周期、提高选择效率**，利于 GS 与 QTL 定位。

### 6.2 多倍体与 2n 配子

- 诱导：秋水仙素处理分生组织/种子/愈伤。
- 特点：器官增大、抗逆性可能增强、育性可能下降。
- **2n 配子**（未减数配子）：绕过减数分裂，用于有性多倍化与无籽育种。
- 体细胞融合：克服远缘不亲和，创制异源多倍体。

## 七、远缘杂交与染色体工程

### 7.1 主要障碍与对策

| 障碍 | 表现 | 对策 |
|---|---|---|
| 杂交不亲和 | 花粉不萌发/花粉管不伸入 | 混合授粉、蒙导、桥梁品种、激素处理 |
| 杂种不稔/不育 | F₁ 不结实或半不育 | 染色体加倍成双二倍体、回交 |
| 胚败育 | 幼胚早期死亡 | **胚拯救（embryo rescue）** 离体培养 |
| 染色体配对异常 | 减数分裂紊乱 | 附加系、代换系、易位系定向选育 |

### 7.2 染色体工程产物

- **异附加系**（addition line）：整条外源染色体。
- **异代换系**（substitution line）：外源染色体替代一对同源染色体。
- **易位系**（translocation line）：外源染色体片段易位到栽培种染色体（如 1BL/1RS）。
- **桥梁品种**：先与亲缘 intermedi ate 种杂交，再与栽培种杂交。

> 远缘材料须评估**遗传稳定性、育性、不良连锁**及**生物安全/检疫**风险。

## 八、群体改良（轮回选择）

| 方法 | 选择单位 | 重组方式 | 特点 |
|---|---|---|---|
| 半同胞轮回选择 | 半同胞家系 | 交替选择与重组 | 提升群体均值 |
| 全同胞轮回选择 | 全同胞家系 | 成对杂交 | 兼顾加性/显性 |
| S₁ / S₂ 家系选择 | 自交家系 | 高代重组 | 玉米等常用 |
| 相互轮回选择 | 两优势群 | 交互测验 | 提升双群配合力 |

- 核心指标：**群体均值提升 + 遗传方差维持 + 配合力提高**。
- 与 GS 结合：以预测值代替表型进行选择，缩短周期（见 `分子育种与智能育种.md`）。

## 九、亲本选配原则

| 原则 | 说明 |
|---|---|
| 性状互补 | 双亲优缺点互补，避免相同缺点叠加 |
| 遗传距离适度 | 适度远缘扩大分离；过远致育性/适应性问题 |
| 配合力高 | 优先选一般配合力高的骨干亲本（见第十节） |
| 目标性状遗传力 | 高遗传力性状可直接选择，低遗传力需高代/多环境 |
| 生态适应性 | 至少一方适应当地生态与栽培条件 |
| 品质与安全 | 避免不利品质/有毒性状连锁 |
| 生长势与繁殖力 | 保证杂交结实与后代繁殖 |

## 十、配合力与测试设计

### 10.1 配合力概念

- **一般配合力（GCA，general combining ability）**：亲本在多个组合中的平均表现，主要反映**加性效应**。
- **特殊配合力（SCA，specific combining ability）**：特定组合偏离 GCA 预测的部分，主要反映**非加性（显性/上位）效应**。
- 关系：`GCA = 亲本均值 − 群体均值`；`SCA = 组合实测 − 双亲 GCA 预测`。

### 10.2 常用设计

| 设计 | 结构 | 用途 |
|---|---|---|
| 双列杂交（Griffing） | 全部可能杂交 | 估计 GCA/SCA、遗传参数 |
| North Carolina II（NCII） | 两组亲本不完全双列 | 估计 GCA/SCA、配合力方差 |
| 不完全双列 | 部分组合 | 减少组合数 |
| 顶交 | 亲本 × 测验种 | 快速评价 GCA |
| 多系测交 | 多个测验种 | 评估杂种优势群 |

### 10.3 遗传增益

- 选择响应（遗传增益）：`ΔG = i · h² · σp`，或 `ΔG = i · σg² / σp`。
- 其中 `i` 为选择强度（源于选择比例）、`h² = Vg/Vp` 为遗传力、`σp` 为表型标准差。
- 提高 ΔG 途径：增大选择强度、提高遗传力（多点、重复、降低误差）、缩短周期。

## 十一、杂种优势、优势群与不育系

### 11.1 杂种优势

- 度量：**中亲优势**、**超亲优势**、**竞争优势**（对照优势）。
- 利用：杂交种（玉米、水稻、油菜、蔬菜等）、无性繁殖作物的杂种无性系。
- **优势群（heterotic group）**：将亲本划分为互补群，群间杂交优势强、群内弱。
- 商业化：需稳定的**不育系/恢复系**或人工去雄体系。

### 11.2 雄性不育与自交不亲和

| 体系 | 英文/缩写 | 要点 |
|---|---|---|
| 细胞质雄性不育 | CMS | 需保持系 + 恢复系，三系配套 |
| 细胞核雄性不育 | GMS | 需专门繁育技术 |
| 光温敏雄性不育 | PGMS/TGMS | 两系法；受光/温调控，制种风险 |
| 自交不亲和 | SI | 孢子体/配子体类型，用于十字花科制种 |
| 化学去雄 | CHA | 药剂诱导，受环境影响 |

> 制种体系设计详见 `品种审定登记与制种.md`。

## 十二、世代推进与年限估算（示例）

| 途径 | 传统年限（参考） | 加速方式 |
|---|---|---|
| 杂交育种至稳定品系 | 6–10 年 | 异地/温室加代、SSD、MAS |
| 回交导入（BC₅–BC₆） | 4–7 年 | 标记辅助前景+背景选择 |
| 诱变育种（M₂–M₅ 稳定） | 4–6 年 | 早期鉴定、定向筛选 |
| DH 育种 | 2–3 年得纯系 | 单倍体诱导 + 加倍 |
| GS 缩短周期 | 周期缩短约 30%–50%（**待核实**） | 预测选配、提前重组 |

> 以上为**经验量级**，实际取决于作物生育期、加代能力、生态区与目标性状；一年一季作物周期长，加代与分子选择是关键加速手段。
