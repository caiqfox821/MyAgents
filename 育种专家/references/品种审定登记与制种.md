# 品种审定登记与制种

> 整理范围：DUS 测试、区域试验与生产试验、品种审定与登记/备案、品种退出、植物新品种权、品种真实性与纯度分子鉴定；杂交制种体系、雄性不育/恢复系、光温敏不育、隔离、去杂去劣、花期调节、种子加工；种子质量指标。
> 主要依据：《种子法》《植物新品种保护条例》、《主要农作物品种审定办法》《非主要农作物品种登记办法》（版本待核实）；DUS 测试指南（UPOV/国内）；种子质量 GB 4404 系列、GB/T 16715 系列及分子鉴定相关标准（版本待核实）。
> 说明：审定年限、隔离距离、种子质量限量等为方向性/参考量级，**一律以现行办法与标准正文为准**；不确定处标注"（待核实，以现行版本为准）"。

## 一、DUS 测试

### 1.1 三性定义

| 指标 | 英文/缩写 | 含义 |
|---|---|---|
| 特异性 | Distinctness（D） | 与已知品种在至少一个性状上明显不同 |
| 一致性 | Uniformity（U） | 个体间相关性状表现一致 |
| 稳定性 | Stability（S） | 反复繁殖/种植后性状保持稳定 |

### 1.2 测试实施

- 依据：该作物 **DUS 测试指南（Test Guidelines, TG）**（编号与版本待核实）。
- **近似品种**（most similar varieties）：选作对比的最相近已知品种。
- 性状分类：质量性状、数量性状、假质量性状；观测方式（目测/测量）。
- 测试周期：通常 **至少 2 个独立生长周期**（**待核实，以指南为准**）。
- 标准品种：用于标定表达状态的参照品种。

### 1.3 与品种权、审定的关系

- DUS 是**植物新品种权实质审查**和**品种审定/登记**的重要依据。
- 申请品种权要求"**新颖性**"（申请前未商业化销售超过规定时限，**待核实**）。

## 二、区域试验与生产试验

### 2.1 试验体系

| 阶段 | 内容 | 年限（参考，待核实） |
|---|---|---|
| 品比试验（预试） | 本单位/多点比较 | 1–2 年 |
| 区域试验 | 跨生态区多点、统一对照 | 2–3 年 |
| 生产试验 | 接近大田生产条件、较大面积 | 1–2 年 |

### 2.2 设计要求

- **随机完全区组（RCBD）**，重复 ≥ 3，设统一对照品种。
- 多点（覆盖目标生态区）、多年，评价 **G×E 与适应性**。
- 观测：产量及构成因素、熟期、株型、抗性、品质。

### 2.3 配套鉴定

- **抗性鉴定**：主要病虫害人工接种/病圃鉴定。
- **品质分析**：按作物品质标准检测（如稻米、小麦、玉米品质指标）。
- **DNA 指纹**：真实性/一致性检测（见第五节）。

> 具体年限、点数、对照设置与抗性/品质鉴定项目**以现行审定办法与试验方案为准**。

## 三、品种审定与登记/备案

### 3.1 制度框架

| 制度 | 对象 | 依据（待核实） |
|---|---|---|
| 品种审定 | 主要农作物（稻、小麦、玉米、棉花、大豆等） | 《主要农作物品种审定办法》 |
| 品种登记 | 列入登记目录的非主要农作物 | 《非主要农作物品种登记办法》 |
| 品种备案 | 部分作物/地方规定 | 地方性规定 |
| 林木良种审定/认定 | 林木 | 林草主管部门规定 |

### 3.2 审定流程（示意）

```
选育单位申请 → 受理 → 区域试验/生产试验 → 抗性·品质·DUS 鉴定 → 专业委员会初审 → 公告审定 → 推广
```

- 分级：国家级审定（全国适宜）与省级审定（本省适宜）。
- **品种退出**：对已审定但存在重大缺陷、退化或长期未推广的品种，按规定撤销/退出（**具体条件待核实**）。

### 3.3 材料要点

- 选育报告、亲本来源与系谱、试验数据、抗性/品质鉴定报告、DUS 报告、种子样品。
- 命名规范、真实性声明、无知识产权争议声明。

## 四、植物新品种权

### 4.1 授权条件

- **新颖性**：申请日前未在境内/境外商业化销售超过规定时限（**待核实**）。
- **特异性、一致性、稳定性**：经 DUS 测试符合要求。
- **适当的名称**：符合命名规定。
- 属于**国家植物新品种保护名录**内的属/种（**名录版本待核实**）。
- 完成**实质审查**（书面审查 + 测试/现场考察）。

### 4.2 流程与保护

| 环节 | 内容 |
|---|---|
| 申请 | 提交申请书、说明书、照片、繁殖材料等 |
| 受理与初审 | 形式审查、新颖性初步审查 |
| 实质审查 | DUS 测试/考察 |
| 授权 | 颁发品种权证书、登记公告 |
| 保护期 | 自授权之日起，**藤本/林木/果树与其它作物保护期不同（待核实）** |
| 维权 | 侵权判定、行政/司法救济、品种权无效宣告 |

> 育种者可在授权前主张**临时保护**（**以现行条例为准**）。

### 4.3 品种权与其它权利

- 品种权 ≠ 专利：品种权保护繁殖材料及其收获物（按条例），专利保护技术方案。
- 利用他人授权品种作亲本需注意**实质性派生品种（EDV）**与权属约定（**待核实**）。

## 五、品种真实性与纯度分子鉴定

### 5.1 鉴定方法

| 方法 | 说明 |
|---|---|
| 田间种植鉴定 | 标准对照、形态性状鉴别，最直观 |
| 分子指纹 | SSR/SNP 位点组合，构建 DNA 指纹 |
| 品种真实性 | 与标准样品比对，判定是否同一品种 |
| 品种纯度 | 抽样检测，计算混杂比例 |

### 5.2 关键点

- 建立**标准样品库（DNA 指纹数据库）**作为比对基准。
- 位点选择需高多态、稳定、可重复；方法依现行标准（**编号待核实**）。
- 分子鉴定可作为田间鉴定的补充/加速手段，判定阈值以标准为准。

## 六、制种（种子生产）

### 6.1 杂交制种体系

| 体系 | 组成 | 特点 |
|---|---|---|
| 三系法 | 不育系（A）× 保持系（B）；恢复系（R）× 不育系 → 杂交种 | 需三系配套，恢复系选育难 |
| 两系法 | 光/温敏不育系（S）× 恢复系 | 免保持系，受光温条件制约 |
| 化学去雄 | 药剂诱导雄性不育 | 受环境影响，需筛选药剂 |
| 人工去雄 | 人工去除雄花 | 适用于大花作物 |

### 6.2 光温敏雄性不育

- 育性受**光周期/温度**调控：在特定条件下不育（用于制种）、在另一条件下可育（用于繁种）。
- 风险：**制种期异常低温/高温**导致育性波动，需严格选择制种地点与时窗。

### 6.3 隔离与去杂

| 措施 | 内容 |
|---|---|
| 空间隔离 | 按作物授粉方式设隔离距离（**具体米数待核实**） |
| 时间隔离 | 错期播种，花期不遇 |
| 障碍隔离 | 利用地形、林带、高秆作物 |
| 去杂去劣 | 苗期、花期、成熟期多次拔除杂株与劣株 |

> 隔离距离因**自花授粉、常异花授粉、异花授粉**及制种级别而异，须以**种子生产技术规程**为准。

### 6.4 花期调节与授粉

- 错期播种、调节亲本生育进程，保证**花期相遇**；必要时追肥/控水调控。
- 辅助授粉：人工、机械、蜜蜂/昆虫。
- 田间管理：肥水、病虫害防治，防止混杂。

### 6.5 种子加工

- 收获 → 脱粒 → 清选（风选/筛选/比重选）→ 干燥 → 精选分级 → 包衣/丸粒化 → 包装标识。
- 建立**批次追溯**与质量检验记录。

## 七、种子质量指标

| 指标 | 含义 | 备注 |
|---|---|---|
| 纯度 | 目标品种种子比例 | 分子/田间鉴定 |
| 净度 | 去除杂质后比例 | 清选质量 |
| 发芽率 | 规定条件下正常发芽比例 | 活力表征 |
| 水分 | 种子含水量 | 影响贮藏与活力 |
| 其它 | 健康度、千粒重、病虫害 | 视作物而定 |

- 判定依据：**GB 4404 系列（粮食作物）、GB/T 16715 系列（瓜菜）等**，以及各作物种子质量分级标准（**标准号、年份与限量一律待核实，以现行版本为准**）。
- 种子标签与经营须符合《种子法》与标签管理规定。

## 八、来源与待核实

- 一级（权威）：国家法律法规数据库、《种子法》《植物新品种保护条例》、农业农村部品种审定/登记办法与公告、UPOV 与国际种子联盟（ISF）公开文件、国家标准全文公开系统与全国标准信息公共服务平台。
- 二级（参考）：种业企业制种技术资料、行业综述；仅作检索线索。
- **待核实清单（优先）**：
  1. 各作物 DUS 测试指南编号、版本、测试周期与性状表。
  2. 主要农作物品种审定与非主要农作物登记的**现行目录、年限、程序与材料清单**。
  3. 植物新品种保护**名录版本、保护期限、新颖性时限、EDV 规则**。
  4. 各作物制种的**隔离距离**、去杂标准与生产技术规程编号。
  5. 种子质量 **GB 4404 / GB/T 16715 等标准的现行版本、分级与限量**。
  6. 品种真实性与纯度分子鉴定的**标准方法编号与判定阈值**。
  7. 品种退出的具体条件与程序。
