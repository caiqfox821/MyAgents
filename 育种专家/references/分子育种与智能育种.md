# 分子育种与智能育种

> 整理范围：分子标记类型、遗传图谱与 QTL 定位、关联分析（GWAS）、分子标记辅助选择（MAS/MABC）、基因组选择（GS）、基因组与泛基因组、高通量表型组、基因编辑、合成生物学底盘；智能育种五层架构与 DBTL 循环。
> 主要依据：分子育种与数量遗传学公开教材/综述；基因组选择经典文献（Meuwissen 等）与主流模型（RR-BLUP/GBLUP/Bayes）；《农业转基因生物安全管理条例》及基因编辑植物安全评价相关规定（版本待核实）；本目录 `breeding.md`（食药用菌智能育种）。
> 说明：标记密度、训练群体规模、预测准确度、脱靶率等为经验/参考量级，实际以实测与现行标准为准；不确定处标注"待核实"。

## 一、分子标记类型

| 标记 | 英文/缩写 | 特点 | 主要用途 |
|---|---|---|---|
| 限制性片段长度多态 | RFLP | 共显性、稳定、通量低 | 早期图谱 |
| 扩增片段长度多态 | AFLP | 多态高、显性、操作繁 | 多样性分析 |
| 简单序列重复 | SSR / 微卫星 | 共显性、多态高、易检测 | 指纹、MAS、多样性 |
| 单核苷酸多态 | SNP | 密度高、通量高、成本低 | GWAS、GS、芯片 |
| 插入缺失 | InDel | 共显性、易分型 | 标记开发、MAS |
| 拷贝数变异 | CNV | 结构变异 | 泛基因组、功能研究 |
| 竞争性等位特异 PCR | KASP | 低成本、高通量、灵活 | 靶向分型、前景选择 |
| 酶切扩增多态 | CAPS/dCAPS | 基于 SNP 转化 | 实验室小规模分型 |

> 标记选择取决于**通量需求、成本、物种基因组资源与目标分辨率**；SSR/KASP 适合少量位点，SNP 芯片/测序适合全基因组。

## 二、遗传图谱与 QTL 定位

### 2.1 遗传图谱构建

- 流程：作图群体 → 标记分型 → 连锁分析 → 标记排序与图距。
- 作图群体：F₂、BC₁、重组自交系（RIL）、双单倍体（DH）、回交自交系（BIL）、CP 群体。
- 图距单位：**厘摩（cM）**，1 cM ≈ 1% 重组率。
- 质量指标：标记数、平均图距、标记偏分离、覆盖度。

### 2.2 QTL 定位方法

| 方法 | 英文/缩写 | 特点 |
|---|---|---|
| 单标记分析 | — | 简单、分辨率低 |
| 区间作图 | IM | 估计 QTL 位置与效应 |
| 复合区间作图 | CIM | 校正背景遗传背景 |
| 完备区间作图 | ICIM | 提高检测功效 |
| 全基因组关联 | GWAS | 自然群体高分辨率（见第三节） |

- QTL 表示：QTL 名称、染色体、置信区间（常用 1-LOD 或 2-LOD 支持区间）、解释表型方差（PVE）、加性/显性效应。
- 局限：分辨率受群体大小与重组事件限制；需**多环境验证**与**精细定位/克隆**。

## 三、关联分析（GWAS）

### 3.1 关键要素

| 要素 | 说明 |
|---|---|
| 自然群体 | 来源广、变异丰富、重组历史长 |
| 连锁不平衡（LD） | LD 衰减决定分辨率；衰减快→分辨率高 |
| 群体结构 | 分层导致假阳性，需校正 |
| 亲缘关系 | 个体间亲缘导致假阳性 |
| 表型准确性 | 多环境、重复、最佳线性无偏预测（BLUP） |

### 3.2 统计模型

- 基础：GLM（含 Q 或 PCA 校正）。
- 主流：**混合线性模型（MLM）**，同时校正群体结构（Q）与亲缘关系（K）。
- 扩展：FarmCPU、BLINK、SUPER 等，提高效率与功效。
- 结果：显著位点、效应值、候选基因区间。

> GWAS 显著性阈值常用**置换检验或 Bonferroni/错误发现率（FDR）**控制；候选位点须**独立群体验证**。

## 四、MAS / MABC 与前景·背景选择

### 4.1 标记辅助选择（MAS）

- 前提：标记与目标基因**紧密连锁**（遗传距离小）或**功能标记**。
- 分类：前景选择（目标基因）、背景选择（遗传背景）。
- 适用：**单基因/寡基因、大效应、易鉴定**性状；多基因复杂性状 MAS 效率有限，宜 GS。

### 4.2 回交中的标记辅助（MABC）

| 选择类型 | 目标 | 标记策略 |
|---|---|---|
| 前景选择 | 保留目标基因 | 基因/紧密连锁标记 |
| 背景选择 | 加速轮回亲本回复 | 全基因组均匀标记 |
| 重组选择 | 打破连锁累赘 | 目标基因两侧标记 |

- 效果：相比传统回交，可**减少回交代数、缩短年限、减小连锁累赘**。

## 五、基因组选择（GS）

### 5.1 基本框架

```
训练群体（基因型 + 表型）→ 训练预测模型 → 对候选群体仅测基因型 → 预测育种值 → 选择
```

- 要素：**训练群体（training population）**规模与代表性、标记密度、表型质量、模型选择、**预测准确度（r）**。
- 预测准确度经验量级：多基因性状常 **0.3–0.7**（**待核实**，受群体/性状影响）。

### 5.2 常用模型

| 模型 | 英文/缩写 | 特点 |
|---|---|---|
| 岭回归 BLUP | RR-BLUP | 假设标记效应同方差、压缩 |
| 基因组 BLUP | GBLUP | 基于基因组关系矩阵 G |
| 贝叶斯 | BayesA/B/C/π、BayesR | 允许效应异方差、变量选择 |
| 机器学习/深度学习 | ML/DL | 非线性、大样本 |
| 多性状/多环境 | MT-GS、MEGS | 借力相关性状/环境 |

- 关系：RR-BLUP 与 GBLUP 在一定条件下等价；贝叶斯方法适合大效应位点。

### 5.3 实施要点

- 缩短育种周期：可在**苗期/早代**预测，实现提前选择与重组。
- 更新模型：每轮重新估计（**DBTL / 育种轮次闭环**）。
- 与 MAS 结合：大效应位点用标记，微效多基因用 GS。

## 六、基因组、泛基因组与重测序

| 类型 | 内容 | 价值 |
|---|---|---|
| 参考基因组 | 单一个体高质量组装与注释 | 定位、编辑、比较基础 |
| 泛基因组 | 多个体整合、含结构变异/PAV | 捕获种内缺失变异 |
| 重测序 | 群体全基因组测序 | 变异检测、GWAS、群体遗传 |
| 泛转录组 | 多个体/条件转录组 | 表达与调控 |

> 基因组质量指标：组装连续性（contig N50）、BUSCO 完整度、注释完整度；**细菌/真菌注意多核、杂合问题**（见 `breeding.md`）。

## 七、高通量表型组（HTPP）

| 平台 | 传感器/技术 | 可测性状 |
|---|---|---|
| 地面/温室 | RGB、多光谱、高光谱、热红外、叶绿素荧光 | 株型、叶面积、叶绿素、含水、温度、光合 |
| 无人机（UAV） | RGB/多光谱/激光雷达 LiDAR | 冠层覆盖、生物量、株高、倒伏 |
| 近地机器人 | 机械臂 + 多传感器 | 单株精细表型、考种 |
| 根系/地下 | X 射线 CT、根系扫描 | 根构型、根长、根体积 |
| 生理/成分 | 高光谱、拉曼、近红外（NIR） | 水分、蛋白、糖分、品质 |

- 常用植被指数：NDVI、NDRE、GNDVI 等。
- 关键：**表型标准统一、数据可重复、表型-基因型关联**；这是当前智能育种的**最薄弱环节**（见 `breeding.md` 核心判断）。
- 可承接**检测专家**的高光谱/近红外方法与数据。

## 八、基因编辑

### 8.1 技术类型

| 类型 | 英文 | 机制/特点 |
|---|---|---|
| CRISPR/Cas9 | — | 双链断裂，NHEJ 敲除 / HDR 替换 |
| Cas12/Cas13 | — | 靶向 DNA / RNA |
| 碱基编辑 | CBE / ABE | 不产生双链断裂，定点 C→T / A→G |
| Prime 编辑 | PE | 引导编辑，定点插入/替换，无需双链断裂 |
| 转录调控编辑 | CRISPRa/i | 激活/抑制表达 |

### 8.2 流程与关键点

1. 靶点设计与 sgRNA 选择（特异性、PAM、脱靶预测）。
2. 递送：农杆菌、基因枪、原生质体、病毒载体、核糖核蛋白（RNP）。
3. 编辑体（T₀/E₀）获得与鉴定。
4. **脱靶检测**：全基因组测序、GUIDE-seq、CIRCLE-seq、Sanger/靶向测序。
5. **世代纯合/分离**：选择无外源 DNA 的编辑纯合体，去除载体与标记。

### 8.3 法规与安全

- 依据《农业转基因生物安全管理条例》及基因编辑植物安全评价相关指南（**版本与分类办法待核实**）。
- 区分：**含外源基因**（按转基因管理）与**定点编辑不插入外源 DNA**（监管路径各国不同，见 `breeding.md` 案例）。
- 须做分子特征、表型、食品安全与环境安全评价，并按现行规定标识/审批。

## 九、合成生物学底盘

- 概念：将细胞（微生物、植物细胞）作为**底盘（chassis）**，重构代谢途径生产目标物。
- 应用：高值活性成分（萜类、生物碱）、功能蛋白、生物基材料。
- 与育种衔接：模糊"育种"与"生物制造"边界；异源表达可替代部分育种目标（见 `breeding.md` 路径 3）。
- 需与**发酵专家**协作进行途径工程与放大；与**食品安全专家**协作做安全性评价。

## 十、智能育种五层架构与 DBTL 循环

```
① 种质资源数字化 → ② 多组学测序与注释 → ③ 高通量表型组 → ④ AI 预测与基因组选择 → ⑤ 基因编辑/合成生物验证
   (种质库/表型库)     (WGS/GWAS/泛基因组)   (图像+传感器自动化)    (GS 模型/ML 选配)        (CRISPR 定向改良)
        └────────── 数据闭环：表型反哺模型，模型指导亲本选配与编辑靶点 ──────────┘
```

### 10.1 DBTL 循环

| 阶段 | 英文 | 内容 |
|---|---|---|
| 设计 | Design | 目标设定、亲本/靶点设计、模型预测 |
| 构建 | Build | 杂交/编辑/转化，创制材料 |
| 测试 | Test | 基因型 + 表型鉴定 |
| 学习 | Learn | 数据建模、更新预测、指导下一轮 |

### 10.2 技术路径选择

| 路径 | 内涵 | 周期/监管 | 适用 |
|---|---|---|---|
| 渐进式 | MAS/GWAS → GS → 全基因组预测选配 | 周期缩短、不触发转基因监管 | 多基因数量性状（产量/抗逆），**主流** |
| 跨越式 | CRISPR 定点编辑 | 单性状精准、受监管政策制约 | 单基因大效应性状 |
| 前瞻 | 合成生物学 + 异源表达 | 边界模糊 | 高值活性成分 |

> 智能育种核心：**数据闭环**（表型反哺模型、模型指导选配）与**自动化表型平台**，而非单一算法。详见 `breeding.md`。

## 十一、来源与待核实

- 一级（权威）：分子育种/数量遗传学经典文献（Meuwissen 等 GS 原文）、权威期刊综述、农业农村部转基因与品种管理相关规定、国家生物信息中心/公共基因组数据库。
- 二级（参考）：种业企业与测序平台技术资料、行业综述；仅作检索线索。
- **待核实清单**：
  1. SNP 芯片密度、测序深度与标记筛选阈值的物种专用参数。
  2. GWAS 显著性阈值与多重检验校正方法的推荐做法。
  3. GS 训练群体规模、标记密度与预测准确度的实证区间。
  4. 基因编辑植物的**具体安全评价流程、分级、标识与审批要求**（以现行规定为准）。
  5. 脱靶检测方法的灵敏度与判定标准。
  6. 高通量表型设备的校准规范与数据标准。
  7. `breeding.md` 中企业数据（市占率、周期缩短比例）的更新与出处核验。
