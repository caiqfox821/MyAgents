# 种质资源与引种驯化

> 整理范围：种质资源类型与来源、收集编目、保存方式、核心种质构建、表型与分子评价、遗传多样性与群体结构；引种原则（气候相似、光温反应、春化）、检疫隔离、驯化与风土适应；种质资源共享与知识产权。
> 主要依据：作物种质资源学与群体遗传学公开教材/综述；《中华人民共和国种子法》《植物检疫条例》及农业农村部种业管理相关规定（版本待核实）；国家作物种质资源库/圃公开技术资料；《粮食和农业植物遗传资源国际条约》（ITPGRFA）与《名古屋议定书》公开文本。
> 说明：文中样本比例、保存年限、群体规模等为经验/参考量级，实际以实测与现行标准为准；不确定处标注"待核实"。

## 一、种质资源类型与来源

### 1.1 资源类型

| 类型 | 英文/缩写 | 特点 | 育种价值 |
|---|---|---|---|
| 地方品种（农家品种） | landrace | 长期自然与人工选择、适应性强、遗传异质 | 抗逆/适应性/风味基因源 |
| 育成品种（改良种） | cultivar / improved | 遗传背景清楚、农艺性状优 | 直接亲本、骨干亲本 |
| 野生近缘种 | CWR（crop wild relatives） | 遗传多样性高、常含抗病抗逆等优异等位 | 远缘杂交导入外源基因 |
| 突变体 | mutant | 单基因/寡基因改变、表型突出 | 功能研究与性状改良 |
| 外引种质 | exotic / introduced | 跨生态区来源、拓宽遗传基础 | 扩大变异、打破连锁 |
| 遗传/作图材料 | NIL、RIL、DH、IL、CSSL | 重组自交系、双单倍体、近等基因系、导入系 | QTL 定位、精细定位 |
| 多倍体/特殊材料 | polyploid、2n gamete | 倍性变异、无籽/大果等 | 倍性育种、无性繁殖作物 |

### 1.2 来源渠道

- 国家及地方种质资源库/圃、种质资源平台。
- 科研院所、育种单位、种业企业交换或购买。
- 野外考察收集（原生境）、传统种植区农户收集。
- 境外引种（须经检疫审批与合规渠道，见第五节）。
- 人工创制：诱变、远缘杂交、基因编辑、合成生物学构建。

## 二、收集与编目

### 2.1 收集原则

- 优先收集**濒危与独特**的地方品种、野生近缘种及具特殊性状材料。
- 采集记录**生态地理信息**（经纬度、海拔、土壤、气候、伴生种）与**农艺/利用信息**。
- 无性繁殖作物采集芽/枝条/种苗，注意携带检疫性有害生物风险。
- 遵守**知情同意与惠益分享（ABS）**原则，必要时签订材料转移协议（MTA）。

### 2.2 编目与档案要素

| 项目 | 内容 |
|---|---|
| 身份信息 | 统一编号、名称、别名、来源国家/地区 |
| 采集信息 | 采集地点、时间、采集人、生境、经纬度海拔 |
| 生物学信息 | 学名、生育特性、繁殖方式、倍性、自交/异交 |
| 性状信息 | 主要农艺、抗性、品质初步鉴定数据 |
| 保存信息 | 保存方式、位置、入库时间、活力、更新批次 |
| 权属信息 | 提供者、协议、知识产权与使用限制 |

> 建议建立**纸质+电子双档案**并纳入统一数据库，编号唯一、可追溯。编目字段可参照国家作物种质资源描述规范（**具体字段与规程待核实**）。

## 三、保存方式

### 3.1 主要保存途径对比

| 方式 | 环境/温度 | 保存期（参考量级） | 适用对象 | 要点 |
|---|---|---|---|---|
| 种子库（长期库） | 低温低湿（如 −18 ℃ 级，待核实） | 数十年及以上 | 正常型种子 | 正负备份异地保存 |
| 中期保存 | 低温干燥 | 数年至数十年 | 工作/交换用 | 定期监测活力 |
| 超干燥保存 | 极低含水量 | 视物种而定 | 部分种子 | 避免过度干燥损伤 |
| 田间种质圃 | 自然/控管 | 年年维护 | 无性繁殖、多年生 | 占地大、易受灾害与病害 |
| 超低温保存 | 液氮（约 −196 ℃） | 长期 | 茎尖、胚、花粉、愈伤 | 需控制降温与解冻程序 |
| 离体（组培）保存 | 低温、限生长 | 数月—数年 | 无性繁殖作物 | 需定期继代、防变异 |
| 原位保护 | 原生境 | 长期 | 野生近缘及生境 | 与生态保护结合 |

### 3.2 活力与更新

- 定期检测**发芽率、含水量、活力**；当发芽率降至阈值（如 **85% 左右，待核实**）时启动繁殖更新。
- 更新时控制**群体有效大小**与授粉方式，防止遗传漂变与混杂。
- 异花授粉作物注意**隔离**；自交不亲和/雄性不育材料须专门繁种。

## 四、核心种质构建与评价鉴定

### 4.1 核心种质（core collection）

- 定义：以**最小样本数**代表整个种质资源**最大遗传多样性**的子集。
- 取样比例经验量级：约 **10%–20%** 材料可代表 **70%–90%** 遗传多样性（**待核实**，因物种与群体而异）。
- 建库策略：按地理来源、生态型、农艺性状分组 → 组内随机/聚类取样 → 用分子标记验证代表性。
- 延伸：**微核心种质**（mini-core）、**精选核心种质**（core elite）。

### 4.2 评价鉴定层次

| 层次 | 内容 | 方法 |
|---|---|---|
| 基本性状 | 生育期、株型、产量构成 | 田间观察与考种 |
| 抗逆/抗病 | 耐盐、抗旱、耐冷、抗病 | 人工接种/胁迫鉴定、分级标准 |
| 品质 | 外观、食味、加工、营养/功能成分 | 理化分析、感官评价、仪器检测 |
| 分子评价 | 遗传多样性、指纹、功能位点 | SSR/SNP/InDel、KASP、测序 |

> 抗性与品质鉴定的具体指标、分级与接种方法属**重点待核实项**，应与检测专家及现行鉴定标准衔接（详见 `抗性与品质育种.md`）。

## 五、遗传多样性与群体结构

### 5.1 常用遗传多样性参数

| 参数 | 符号/英文 | 含义 |
|---|---|---|
| 多态性位点比例 | P | 多态位点占比 |
| 观测/期望杂合度 | Ho / He | 实际与理论杂合度 |
| 有效等位基因数 | Ne | 等位基因数目的等效值 |
| 多态信息含量 | PIC | 标记多态性信息量 |
| Nei's 基因多样性 | H | 群体遗传多样性 |
| Shannon 信息指数 | I | 多样性丰富度 |

### 5.2 群体结构分析

- **群体分层**：STRUCTURE/ADMIXTURE、PCA、系统发育树（NJ/UPGMA）。
- **分化程度**：固定指数 Fst、分子方差分析 AMOVA、遗传距离。
- **连锁不平衡（LD）**：LD 衰减距离影响关联分析分辨率（见 `分子育种与智能育种.md`）。
- **瓶颈与漂变**：有效群体大小 Ne、杂合度变化。

> 标记数量、样本量与分析参数需按研究目的设定；结果受标记类型与样本代表性影响，**结论以实测数据为准**。

## 六、引种原则

### 6.1 基本原理

| 原则 | 要点 |
|---|---|
| 气候相似论 | 原产地与引种地气候（温度、降水、光照）相近者易成功 |
| 光温反应 | 纬度/海拔变化改变生育期与光周期响应 |
| 春化需求 | 需低温春化的作物引种需匹配当地冬季条件 |
| 生态适应性 | 抗逆性、病虫害谱、土壤条件匹配 |
| 循序渐进 | 少量试种 → 多点试验 → 示范推广 |

### 6.2 纬度与光周期规律（经验规律，具体因作物而异）

- **短日照作物**：低纬（南）→ 高纬（北）引种，日照变长 → 生育期**延长**、可能贪青迟熟；反之早熟。
- **长日照作物**：北 → 南引种，日照变短 → 生育期延长或不能抽穗。
- **春化型（冬性）作物**：北方冬性品种引至南方，低温不足 → 抽穗推迟或不抽穗。
- 高原→平原、山区→平原：温度升高、生育期缩短，需重新评价熟期与产量。

> 上述为方向性规律，**具体临界日长、春化温度与天数因物种/品种而异，须实测**。

## 七、检疫隔离、驯化与风土适应

### 7.1 引种检疫

- 依据《植物检疫条例》及进境植物检疫相关规定实施（**具体名录与审批流程待核实**）。
- 境外种质须办理**进境检疫审批**，在指定隔离场/检疫圃种植观察。
- 关注**检疫性有害生物**（真菌、细菌、病毒、线虫、昆虫、杂草种子）。
- 隔离种植期间开展病虫害监测，合格后方可释放使用。

### 7.2 驯化与风土适应（acclimatization）

- **驯化（domestication）**：从野生到栽培的遗传改变与选择。
- **风土适应**：引入材料在新环境经多代选择、逐步适应的过程。
- 策略：阶梯式引种（逐步过渡）、混合选择、回交导入、异地加代加速稳定。
- 观察指标：出苗、越冬/越夏、抽穗开花、结实、产量与品质稳定性。

## 八、种质资源共享与知识产权

| 主题 | 依据/机制（示例） | 要点 |
|---|---|---|
| 国际交换 | ITPGRFA、标准材料转移协议（SMTA） | 用于粮食与农业研究；商业化须惠益分享 |
| 遗传资源获取 | 《生物多样性公约》（CBD）、《名古屋议定书》 | 事先知情同意（PIC）+ 共同商定条件（MAT） |
| 农民权利 | ITPGRFA / 国内相关规定 | 保存、利用、惠益分享 |
| 国内共享 | 国家作物种质资源平台/种质库 | 依申请提供，签协议 |
| 品种权 | 《植物新品种保护条例》 | 与种质资源利用区分（见 `品种审定登记与制种.md`） |
| 专利 | 基因/方法专利 | 与品种权保护边界不同 |

> 种质资源引入与利用应**留存来源凭证与协议文本**，避免权属与合规争议；对外提供需遵守国家有关规定（**具体办法待核实**）。
