# 抗性与品质育种

> 整理范围：抗病（抗源、抗性类型、垂直/水平抗性、接种鉴定、分子标记）、抗虫（Bt/抗虫基因与评价）、抗逆（抗旱/耐盐碱/耐冷/耐热/耐涝/耐弱光的鉴定指标与筛选）、品质育种（外观/食味/加工/营养/功能成分）、遗传力与选择策略、G×E 互作与多点鉴定。
> 主要依据：作物抗病抗逆与品质育种公开教材/综述；植物病理学与生理学公开资料；稻米/果蔬品质评价相关研究方法与现行标准（版本待核实）。
> 说明：鉴定指标阈值、分级标准、病情指数、含量范围等为经验/参考量级，实际以实测与现行标准为准；不确定处标注"待核实"。

## 一、抗病育种

### 1.1 抗源（resistance source）

| 来源 | 特点 |
|---|---|
| 主栽/骨干品种 | 背景优、易利用，但抗谱可能窄 |
| 地方品种 | 与病原长期协同进化、抗性多样 |
| 野生近缘种 | 抗性丰富，需远缘杂交导入 |
| 外源基因/工程抗性 | R 基因、防御基因转化 |

### 1.2 抗性类型

| 分类维度 | 类型 | 说明 |
|---|---|---|
| 反应程度 | 免疫（immune） | 完全不发病 |
| | 高抗（HR） | 病斑少而小 |
| | 中抗（MR） | 中等病斑 |
| | 耐病（tolerant） | 带菌但不显著减产 |
| | 感病（S） | 发病重 |
| 抗性机制 | 抗侵入、抗扩展、抗繁殖 | 各自阻断侵染环节 |
| 专化性 | **垂直抗性**（vertical） | 主效/单基因、小种专化、易被克服 |
| | **水平抗性**（horizontal） | 微效多基因、广谱、较持久 |
| 表达 | 质量抗性 / 数量抗性 | 前者分级明确，后者连续 |

### 1.3 抗性机制（示例）

- **基因对基因**：R 基因（多含 NBS-LRR 结构）识别病原 Avr（无毒）效应子。
- 过敏性坏死反应（HR）、胼胝质沉积、木质素化、活性氧爆发。
- 防御酶（POD、PPO、PAL）、病程相关蛋白（PR）、植保素。
- 系统获得抗性（SAR）、诱导系统抗性（ISR）。

### 1.4 抗性鉴定与接种

| 方法 | 方式 | 记录指标 |
|---|---|---|
| 人工接种 | 喷雾、注射、灌根、离体叶片、点接种 | 病斑、病情指数（DI）、潜伏期 |
| 病圃自然诱发 | 高湿/诱发行/病原接种圃 | 发病率、病情指数、严重度 |
| 分子检测 | 病原定量 PCR | 病原载量 |

- 分级：常用 **0–9 级或 0–5 级**（**因作物/病害待核实**）；病情指数 `DI = Σ(病级×株数)/(最高级×总株数)×100`。
- 需设**抗、感对照**与重复，减少环境误差。

### 1.5 抗性丧失与应对

- 垂直抗性易因**小种变异**丧失；对策：**抗源多样化、多基因聚合、抗性基因布局（基因轮换/多系品种）**、合理种植。
- 分子标记辅助筛选 R 基因/QTL（如稻瘟病 Pi、小麦锈病 Yr/Lr/Sr 等，**具体位点待核实**）。

## 二、抗虫育种

### 2.1 抗虫机制与抗源

- **组成型抗性**（结构/有毒物质）与**诱导型抗性**（受害后产生）。
- 抗源：地方品种、野生近缘、外源基因。

### 2.2 抗虫基因

| 类别 | 代表 | 说明 |
|---|---|---|
| Bt 基因 | Cry1Ab/Cry1Ac、Cry2Aa、Vip3A | 来自苏云金芽孢杆菌，对鳞翅目等有效 |
| 蛋白酶抑制剂 | CpTI、PI | 抑制昆虫消化 |
| 凝集素/淀粉酶抑制剂 | 如雪花莲凝集素 GNA | 抑制取食 |
| RNAi | 针对昆虫关键基因 | 新型特异防控 |

### 2.3 抗性评价

- 室内：离体喂养/取食量、幼虫死亡率、体重抑制、发育历期。
- 田间：虫口密度、受害率、产量损失。
- 抗性治理：**庇护所（refuge）策略**、多基因/多机制聚合，延缓抗性演化。
- 转基因抗虫须按现行**转基因安全管理**评价与标识（**待核实**）。

## 三、抗逆育种

### 3.1 主要胁迫与鉴定指标

| 胁迫 | 生理/农艺指标 | 筛选方法 |
|---|---|---|
| 抗旱 | 相对含水量（RWC）、叶片水势、气孔导度、冠层温度、渗透调节物、抗旱系数、胁迫/非胁迫产量比 | 控水试验、PEG 模拟、旱棚、多点旱区 |
| 耐盐碱 | 发芽率、存活率、Na⁺/K⁺ 比、电导率、脯氨酸/可溶性糖、盐害分级、SPAD | 不同浓度 NaCl/混合盐、沙培/水培、盐碱地 |
| 耐冷 | 电解质渗漏率、LT₅₀、萌发/苗期冷害、结实率、灌浆 | 低温萌发、人工气候箱、冷水灌溉 |
| 耐热 | 花粉活力、结实率、冠层温度、膜热稳定性 | 花期高温处理、人工气候箱 |
| 耐涝 | 存活率、通气组织、不定根、产量 | 淹水处理、涝渍地 |
| 耐弱光 | 净光合速率、叶绿素 b/a、光补偿点、光饱和点 | 遮阴棚、梯度遮光 |

> 抗逆性具**生育期差异**（如苗期耐盐≠全生育期稳产），须**分期鉴定**；阈值与分级**待核实**。

### 3.2 抗逆相关基因/QTL（示例）

| 性状 | 基因/QTL（示例） | 说明 |
|---|---|---|
| 耐涝 | Sub1（Sub1A） | 水稻耐淹（待核实具体位点） |
| 耐盐 | SKC1/OsHKT、HKT 家族 | Na⁺/K⁺ 稳态 |
| 抗旱/渗透 | DREB/CBF、NAC、bZIP | 转录因子调控 |
| 抗氧化 | SOD、CAT、APX | 活性氧清除 |
| 避旱/根系 | DRO1 等 | 根系构型 |

> 以上为公开示例，**具体基因-性状对应与效应须以原始文献与本地验证为准**。

## 四、品质育种

### 4.1 品质维度

| 维度 | 指标示例 | 检测方法 |
|---|---|---|
| 外观 | 粒形、色泽、光滑度、果形、着色 | 图像/感官/量具 |
| 食味 | 香气、软硬、黏弹性、风味 | 感官品评、食味计、质构仪 |
| 加工 | 出糙率、精米率、整精米率、出粉率、硬度 | 制米/制粉设备 |
| 营养 | 蛋白质、脂肪、维生素、矿质元素 | 理化分析（凯氏、ICP 等） |
| 功能成分 | 花青素、类黄酮、多糖、三萜、膳食纤维 | 分光/色谱/质谱 |
| 安全 | 重金属、真菌毒素、抗营养因子 | 按现行限量（见 `标准规范与法规-育种.md`） |

### 4.2 稻米食味（示例）

- 关键指标：**直链淀粉含量（AC）**、**胶稠度（GC）**、**碱消值（ASV）**、蛋白质含量、RVA 糊化特性。
- 香气：**2-乙酰-1-吡咯啉（2-AP）**，受 `Badh2` 基因影响。
- 食味计：可快速综合评价（仪器型号差异需校准）。

### 4.3 果蔬风味与品质（示例）

- 可溶性固形物（SSC，°Brix）、可滴定酸（TA）、**固酸比**、硬度、色泽（L*a*b*）、货架期。
- 功能性：番茄红素、花青素、多酚、维生素 C。
- 感官评价需**标准化品评小组**与统一评分表。

> 具体阈值（如食味评分、SSC 分级）**因作物、市场与标准而异，须以现行标准与订单要求为准**。

## 五、遗传力、选择策略与 G×E

### 5.1 遗传力与选择策略

| 性状 | 典型遗传力（参考） | 选择建议 |
|---|---|---|
| 熟期、株高、粒形 | 高（0.6–0.9） | 早代选择 |
| 抗病/抗虫 | 中—高（质量性状高） | 接种鉴定 + 标记辅助 |
| 抗逆 | 低—中 | 高代、多点、胁迫环境 |
| 产量 | 低（0.2–0.5） | 高代、多环境、GS |
| 品质成分 | 中—高 | 仪器检测 + 标记 |

> 遗传力数值因群体与环境而异，**以本群体实测估计为准**。

### 5.2 G×E 互作与多点鉴定

- **基因型×环境互作（G×E）**：品种在不同环境表现排序变化。
- 分析：方差分析、AMMI、**GGE 双标图**、稳定性参数（回归系数、Shukla 方差）。
- 设计：**多年多点、随机区组、重复 + 对照**，覆盖目标生态区。
- 意义：选育**广适性**或**特定生态区适应**品种；区域试验即 G×E 的系统评价（见 `品种审定登记与制种.md`）。
