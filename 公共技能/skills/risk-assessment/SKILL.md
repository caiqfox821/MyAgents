# 风险评估通用方法技能（跨域）

## 何时使用

- 需要回答 **"风险有多大"**（科学评估），而不是"是否超标/怎么管"（合规与管理）。
- 需要**定量暴露**：EDI/ESTI/IESTI、点评估、概率（Monte Carlo）评估。
- 需要**风险表征**：HQ、%ADI、MOE、ILCR、风险分级。
- 需要**推导或引用健康指导值**：ADI/TDI/ARfD/PTWI、POD/BMDL、UF。
- 需要**风险排序**：多危害—多食品组合，资源有限时定优先级。
- 需要**不确定性/敏感性分析**与评估报告。

**不适用（转给对应专家）**：
- 判"是否超 GB 2763/2762 限量"、合规结论、处置建议 → **食品安全专家**（风险管理侧）。
- 出实测浓度、方法、不确定度 → **检测/质谱专家**。
- 毒理试验数据解读、POD/BMD 建模、TTC/read-across 证据权重 → **毒理专家**。
- 营养摄入是否满足 DRIs、配餐 → **营养专家**（其营养充足性与 UL 侧另有口径）。

## 五条硬规则（违反会得到"看起来对"的错误结论）

1. **先定性再定量**：未完成危害识别与剂量-反应，不得直接算 HQ。数字自洽不等于结论成立。
2. **单位全链一致**：`mg/kg` vs `µg/kg`、`kg/人·d` vs `g/d`、`mg/kg bw/d`。90% 的错误来自单位与体重口径。脚本会做显式换算，**手算必须逐步写单位**。
3. **暴露与指导值必须同口径**：慢性暴露 ↔ ADI/TDI；急性（<24 h）↔ ARfD；有蓄积物用 PTWI/PTMI 时，暴露须换算到同一时间单位。
4. **不得臆造指导值**：ADI/TDI/MRL/HBGV 必须来自 JECFA/JMPR/JEMRA/EFSA/CFSA/国家标准，**注明机构、年份、版本**；查不到就写"无可用权威指导值"，改用 MOE/TTC 并说明。
5. **结论必须带不确定性**："可接受/需关注/高风险"之外，必须写明关键假设、数据缺口、以及哪个参数主导结果（敏感性）。
6. **先查证据条目，再回原文**：方法学默认值与判定语言（UF=100 及 EFSA 拆 4×2.5×10、BMR 10%/5%、IESTI 情形与 0.025 kg、vf=3、P97.5 大份餐、删失下/上/中界、TTC 五层阈值、MOE ≥300/≥1500）**一律先查** `公共知识/技术指南/风险评估-证据条目与出处.md`（逐条带页码/PMCID）；条目不足时用 `公共知识/书库/tools/search_books.py`、`read_page.py` 回原文取证；仍无证据则写"书库无此证据"并给官方复核入口，**不得凭印象给数值**。

## 工作流（六步）

```
0 界定  → 1 危害识别 → 2 剂量-反应 → 3 暴露 → 4 表征 → 5 排序/沟通 → 6 报告
```

### 0. 界定评估问题（Problem formulation）
写清四要素，缺一项不进入下一步：

| 要素 | 必须明确 |
|---|---|
| 危害物 | 化学物/微生物/物理因素，形态与规格 |
| 基质 | 哪些食品/农产品/环境介质 |
| 人群 | 一般人群、儿童、孕妇、高消费人群 |
| 目的 | 筛查 / 精细评估 / 排序 / 预警 / 支持标准制定 |

### 1. 危害识别
证据来源优先级：权威评估结论（JECFA/EFSA/CFSA/IARC）> 系统评价/流行病学 > 动物试验 > 体外/QSAR。产出**危害清单 + 定性判断 + 证据强度**。细节见 `references/01`、`04`。

### 2. 剂量-反应（危害特征描述）
- 有阈值物质：定 POD（优先 **BMDL**，其次 NOAEL/LOAEL）→ 除以 UF → HBGV。
- 无阈值（遗传毒性致癌物等）：不设 HBGV，走 **MOE**（BMDL₁₀/暴露）。
- 数据不足：**TTC** 筛查（Cramer 分级），并声明局限。
- 公式与 UF 分解、CSAF、BMD 建模四步见 `references/03`；深度毒理交 **毒理专家**。

### 3. 暴露评估

```
暴露量 = Σ(食品中浓度 × 该食品消费量) / 体重
```

| 场景 | 浓度 | 消费量 | 指标 |
|---|---|---|---|
| 慢性 | 均值/中位数/P95 组合 | 多日平均（调整个体内变异） | EDI/NEDI/GECDE |
| 急性 | HR（最高残留）或 P95 | 大份餐 P97.5（单日不平均） | ESTI/IESTI/GEADE |
| 筛查 | 均值或上限 | 均值 | 点评估 |
| 精细 | 分布 | 分布 | 概率评估 |

- 农药残留急性：按 **IESTI Case 1/2a/2b/3** 选式（`references/02`）。
- 检出限以下：1/2 LOD、1/√2 LOD 或概率替代，**必须声明**。
- 消费量数据源：CFSA 食物消费量调查/总膳食研究；WHO **GEMS/Food**；EFSA 消费库 + DietEx；FAO **GIFT**。

### 4. 风险表征

| 物质类型 | 指标 | 判据（参照，非绝对） |
|---|---|---|
| 有阈值 | `HQ = 暴露/HBGV`、`%ADI` | HQ ≤ 1 一般可接受；> 1 需关注 |
| 无阈值 | `MOE = POD/暴露` | **≥ 10 000 → low concern**（EFSA SC 2025，*EFSA J* 23(8):e9606，**本库已核实**；**须 RP＝动物 BMDL₁₀**，含义为"风险管理优先级低"**而非"无害"**）；个案阈值 ≥1500/≥300/≥385/≥633 须并列报告。见 `references/03` §五、条目 **3-11/3-12/3-13** |
| 有斜率因子 | `ILCR = CDI × SF` | ≤ 10⁻⁶ 可接受；10⁻⁶~10⁻⁴ 关注；> 10⁻⁴ 高 |
| 微生物 | 感染/发病概率 | 依 QMRA 情景目标（如 ALOP/FSO） |

同类毒性物质须做**累积暴露**（类别 ADI/共同机制）。分级表述见 `references/04`。

### 5. 排序与沟通
排序用矩阵法（可能性×严重度）或赋分/MCDA，权重须说明来源（专家咨询/AHP）。对外表述区分**科学结论**与**管理建议**，避免绝对化。

### 6. 报告
套 `templates/风险评估报告模板.md`；计算留痕用 `scripts/riskcalc.py`。

## 可执行脚本 `riskcalc.py`

纯 Python 标准库（无第三方依赖），位置：`scripts/riskcalc.py`（全局安装后为
`~/.config/opencode/skills/risk-assessment/scripts/riskcalc.py`）。

```bash
python3 riskcalc.py edi --conc 0.08,0.25 --cr 0.12,0.35 --bw 60
python3 riskcalc.py hq  --exp 1.6e-4 --hbgv 0.02
python3 riskcalc.py moe --pod 0.5 --exp 5e-5
python3 riskcalc.py ilcr --cdi 2e-5 --sf 0.5
python3 riskcalc.py iesti --case 2a --u 0.10 --lp 0.50 --hr 0.30 --vf 3 --bw 60
python3 riskcalc.py mc  --conc lognormal:0.08:0.05 --cr empirical:0.12,0.2,0.35 --bw normal:60:8 --n 20000
python3 riskcalc.py ttc --exp 0.002 --class III
python3 riskcalc.py demo
```

| 子命令 | 作用 |
|---|---|
| `edi` | 多点（浓度×消费量）求和 / 体重 |
| `hq` / `moe` / `ilcr` | 三种表征 + 判据分级 |
| `iesti` | 农药急性 IESTI 四情形 |
| `mc` | Monte Carlo 概率暴露（lognormal/normal/uniform/empirical/point），输出均值/中位/P95/P99 与超 HBGV 概率 |
| `sens` | 单因素（OAT）+ 秩相关敏感性筛查 |
| `ttc` | TTC 阈值比较（Cramer I/II/III、有机磷） |
| `hbgv` | `POD / UF` 推导健康指导值 |

输出默认人读格式，`--json` 输出机读。**脚本只做算术与分布抽样，不内置任何限量/ADI 数值**——指导值必须由使用者按权威来源输入并注明出处。

## 跨域适用速查

| 领域 | 关键差异 | 注意事项 |
|---|---|---|
| 食品化学危害 | 四步法标准流程 | 慢性为主，注意加工因子 |
| 农药残留 | 急性 IESTI + 慢性 IEDI | HR/STMR、vf=3、LP=P97.5 |
| 兽药残留 | 急性 GEADE / 慢性 GECDE | 可食组织 MRL 与暴露口径 |
| 食品添加剂 | ADI + 摄入量评估 | 使用范围×含量×消费量，注意类别 ADI |
| 新食品原料 | 无历史暴露 | 需建暴露情景，TTC/证据权重先行 |
| 营养（UL） | 评估"过量"侧 | 与营养专家的充足性评估分开 |
| 微生物 | QMRA：暴露→剂量-反应→疾病负担 | 指数/Beta-Poisson 模型，交毒理/食品安全协同 |
| 生态/环境 | 不同受体与终点 | 本技能方法可迁移，参数体系另查 |
| 职业暴露 | 吸入/皮肤途径为主 | 需与膳食途径分开，勿混算 |

## 与其他技能的边界

- `food-safety`（食品安全专家私有）：GB 限量、合规判定、HACCP。本技能出"风险多大"，它出"是否合规/怎么管"。
- `nutrition` / `nutritionist`（营养专家）：DRIs/NRV、配餐、营养标签。
- `detection-analysis` / `mass-spectrometry`：数据产生侧。
- `toxicology`（毒理专家）：POD/HBGV 的毒理学依据与证据权重。

## 交付前自检清单

- [ ] 评估问题四要素（危害物/基质/人群/目的）已写明
- [ ] 每个指导值都标了机构+年份+版本，或明确写"无可用权威值"
- [ ] 暴露与指导值同为慢性或同为急性口径
- [ ] 单位与体重口径全链一致（脚本或逐步单位推导）
- [ ] 浓度统计值选择与评估类型匹配（急性用高端值）
- [ ] LOD 以下处理方式已声明
- [ ] 高风险人群/亚人群单独评估
- [ ] 同类毒性做了累积暴露（如适用）
- [ ] 不确定性与主导参数已给出（敏感性）
- [ ] 结论分级 + 局限 + 不越界到合规判定
