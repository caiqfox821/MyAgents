# 06 · 跨域适用与边界

> 本技能是**方法层公共资产**：任何专家都可加载。本文件定义"在哪个域怎么用"以及"何时必须转交"。

---

## 一、跨域差异速查

| 领域 | 危害主体 | 关键差异 | 主要指导值/判据 | 负责专家 |
|---|---|---|---|---|
| 食品化学危害 | 污染物、加工产物、迁移物 | 慢性为主；加工因子关键 | TDI/PTWI/PTMI、MOE | 食品安全 + 毒理 |
| 农药残留 | 母体+代谢物（残留定义） | **急性 IESTI** 是必做项 | ADI、ARfD、MRL | 食品安全（+ 种植知情） |
| 兽药残留 | 原形+代谢物、可食组织 | MRL 按组织；GEADE/GECDE | ADI、ARfD、MRL | 食品安全 |
| 食品添加剂 | 有意添加 | 使用范围×含量×消费量；类别 ADI | ADI、EDI | 食品安全 + 营养（摄入） |
| 新食品原料 | 无历史暴露 | 需自建暴露情景；TTC 先行 | TTC / 证据权重 | 毒理 + 食品安全 |
| 营养（UL 侧） | 过量摄入 | 只评"过量"，不评"不足" | UL、%UL | 营养专家 |
| 微生物 | 致病菌/毒素 | **QMRA**：暴露→剂量-反应→疾病负担；**与化学侧共用四步框架但不共用参数**（生长模型关键参数＝lag/生长速率/最大菌量；DR 模型版本主导结果） | ALOP/FSO、感染概率（**QMRA 条目 5-8～5-12**；§七 第 5 条纪律） | 食品安全 + 毒理（剂量-反应） |
| 真菌毒素 | 多靶器官、部分致癌 | 急性（如黄曲霉急性中毒）与慢性并重 | PMTDI/PTWI、MOE | 食品安全 + 毒理 |
| 生态/环境 | 非人类受体 | 终点与参数体系不同 | PNEC、PEC/PNEC | 另配（本技能方法可迁移） |
| 职业暴露 | 工人 | 吸入/皮肤为主，与膳食分开 | OEL、TWA | 另配 |
| 工艺放大/中试 | 过程产生的危害物 | 需识别"新生成"危害（如加热产物） | 视物质 | 食品加工 + 食品安全 |

## 二、分工矩阵（谁给什么）

| 环节 | 生产/提供 | 评估 | 判定/管理 |
|---|---|---|---|
| 浓度/残留实测 | **检测专家 / 质谱专家** | — | — |
| 方法适用性与不确定度 | **检测专家** | — | — |
| 毒理数据、POD、HBGV 推导 | **毒理专家** | 毒理专家 | — |
| 暴露评估与风险表征 | — | **本技能（各专家执行）** | — |
| 限量比对与合规结论 | — | — | **食品安全专家** |
| HACCP 危害分析与控制点 | — | 食品安全专家 | **食品安全专家** |
| 营养充足性/配餐 | — | 营养专家 | 营养专家 |
| 种植/工艺改进建议 | 种植/发酵/食品加工专家 | — | 对应专家 |
| 报告与汇报材料 | — | — | **文档专家**（成稿） |

**一句话界碑**：
- **"风险有多大"** → 本技能（科学评估）
- **"是否超标、怎么办"** → 食品安全专家（风险管理）
- **"这个 POD/ADI 凭什么"** → 毒理专家
- **"测出来是多少、准不准"** → 检测/质谱专家

## 三、调用示例（各专家怎么用）

### 食品安全专家
```
场景：某蔬菜农残检出，需判断健康风险 + 合规
1. 合规：比对 GB 2763 限量 → 食品安全专家自有 references（不是本技能）
2. 健康风险：本技能做 IESTI/EDI + HQ/%ARfD
3. 若需自行推导 ADI → 转毒理专家
```

### 检测专家 / 质谱专家
```
场景：非靶向筛查出未知物
1. 定性确证（质谱）→ 谱库/标准品
2. 无标准品、无毒性数据 → 本技能做 TTC 筛查
3. 超 TTC → 转毒理专家做证据权重/read-across
```

### 营养专家
```
场景：某强化剂/补充剂摄入是否过量
1. 摄入量测算 → nutrition 技能
2. 与 UL 比较、%UL → 本技能（过量侧）
3. 注意：UL 不是"安全线"，是"不应超过的水平"
```

### 种植 / 发酵 / 食品加工专家
```
场景：工艺变更引入新危害
1. 识别新生成危害（如高温产生丙烯酰胺、发酵产生生物胺）
2. 本技能做暴露与表征（需检测数据）
3. 反馈工艺参数改进建议
```

### 协调专家（Orchestrator）
```
含"风险/暴露/HQ/MOE/排序" → 加载本技能的专家
含"限量/超标/合规" → 食品安全专家（本技能仅作支撑）
含"ADI/POD/毒理" → 毒理专家
```

## 四、常见误用（跨域视角）

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把"检出"当"风险" | 夸大 | 先做暴露，再看剂量-反应 |
| 用限量当健康阈值 | 概念混淆 | 限量是管理工具，含 ALARA/贸易因素 |
| 用 ADI 判"某食品能不能吃" | 口径错 | ADI 是终生每日总摄入，不是单餐 |
| 拿别国 MRL 直接套用 | 膳食结构不同 | 暴露评估须用本国消费量 |
| 用动物剂量直接比人 | 差 10 倍以上 | 必须 UF/异速校正 |
| 只算膳食，漏其他途径 | 低估 | 多途径合并 |
| 用"平均"代表"人人安全" | 忽视敏感人群 | 单列亚人群 |
| 把 TTC 当"安全线" | 误判 | TTC 是筛查工具 |
| 忽略残留定义（母体 vs 母体+代谢物） | 差数倍 | 按法规残留定义取值 |

## 五、与其它技能的接口

| 技能 | 关系 |
|---|---|
| `food-safety`（食品安全私有） | 本技能出"风险多大"，它出"合规/管理"；限量数据在它那里 |
| `toxicology`（毒理私有） | 本技能用 HBGV/POD，毒理负责"凭什么" |
| `detection-analysis` / `mass-spectrometry` | 数据产生；不确定度影响表征 |
| `nutrition` / `nutritionist` | 摄入测算可复用；UL 侧用本技能 |
| `planting-knowledge` / `fermentation-knowledge` / `food-processing` | 提供工艺与危害来源背景 |

## 六、保守性原则（当拿不准时）

1. **假设朝向高估**（筛查阶段），但报告中必须标明"保守"。
2. **数据缺失不填假数**：写"无数据"，用 TTC/最坏情景，并声明。
3. **不合并不同口径**：宁可分列两套结果，不混算。
4. **不越界下结论**：评估结论 ≠ 合规结论 ≠ 管理建议。
5. **拿不准就转交**：毒理 → 毒理专家；限量 → 食品安全专家；数据 → 检测/质谱专家。
