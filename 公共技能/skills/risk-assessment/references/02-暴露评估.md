# 02 · 暴露评估

> 依据：CFSA《食品安全风险评估技术指南》（2023）、WHO/FAO EHC 240 Ch.6（2020 更新，**全文已入 `公共知识/书库/guides/`，177 页**）、JMPR IESTI 方法、EFSA 膳食暴露指南、Codex CXG 3-1989。

> 暴露评估是**最容易算错**的一步，错误几乎全部来自单位、口径与统计值选择。

## 一、基本公式与单位

```
膳食暴露量 = Σ (食品中危害物浓度 × 该食品消费量) / 体重
             i
```

| 量 | 常用单位 | 陷阱 |
|---|---|---|
| 浓度 | mg/kg、µg/kg、mg/L | µg 与 mg 混用（1000 倍） |
| 消费量 | kg/人·d、g/人·d、kg/餐 | g 与 kg（1000 倍）；"人·d" vs "餐" |
| 体重 | kg | 用成人 60 kg 评儿童 |
| 暴露量 | mg/kg bw/d、µg/kg bw/d | 报告须显式写 bw 与 d |

**手算三步法**（必须逐步写单位）：

```
第1步 单项：c [mg/kg] × CR [kg/d] = [mg/d]
第2步 求和：Σ [mg/d]
第3步 归一：Σ [mg/d] ÷ bw [kg] = [mg/kg bw/d]
```

**多途径合并**：膳食 + 饮水 + 土壤/尘 + 空气（吸入）+ 皮肤。不同途径的**吸收率**不同，需要时先算"内暴露"再加和。不得把不同途径的"外暴露"直接相加而不说明。

## 二、常用指标

| 缩写 | 全称 | 用途 | 与谁比较 |
|---|---|---|---|
| EDI | 估计每日摄入量 | 慢性、一般暴露 | ADI/TDI |
| NEDI | 国家估计每日摄入量 | 各国自评慢性 | ADI/TDI |
| IEDI | 国际估计每日摄入量 | JMPR 慢性（国际） | ADI |
| ESTI | 估计短期摄入量 | 急性 | ARfD |
| IESTI | 国际估计短期摄入量 | JMPR 农药急性 | ARfD |
| NESTI | 国家估计短期摄入量 | 各国自评急性 | ARfD |
| GEADE | 全球急性膳食暴露估计 | 兽药残留急性 | ARfD |
| GECDE | 全球慢性膳食暴露估计 | 慢性模型膳食 | ADI/TDI |

**口径必须配对**：EDI↔ADI/TDI（慢性）；ESTI/IESTI↔ARfD（急性）。用 EDI 比 ARfD 或反之，是最常见的逻辑错误。

---

## 三、急性 vs 慢性

| 维度 | 急性（<24 h） | 慢性（终生） |
|---|---|---|
| 比较对象 | ARfD | ADI / TDI / PTWI |
| 浓度取值 | HR（最高残留）、P95/P97.5、最大值 | 均值、中位数、P95 组合 |
| 消费量取值 | 大份餐 P97.5，**单日不平均** | 多日调查平均，调整个体内变异 |
| 关注人群 | 高消费个体（"大胃王"） | 一般人群 + 敏感亚人群 |
| 方法 | IESTI / NESTI / GEADE | 点评估、概率评估、模型膳食 |
| 典型高估来源 | 假设同一餐吃到多份最高残留 | 高端值组合（P95×P95） |

**慢性评估的"通常摄入"**：单日调查数据含大量零值（未食用），直接用会低估；需用统计方法（如 NCI 法、ISUF、Beta-Binomial-Normal）估计"长期平均摄入"，并按个体内/个体间变异调整。简化处理时须声明。

## 四、农药急性 IESTI（JMPR 四情形）

**核心思想**：按食品**逐一**计算；假设个体不会在一餐/24 h 内同时食用多份"均含最高残留"的大份餐；大份餐取 **P97.5**（单消费者日，不做多日平均）。

| 情形 | 判定条件 | 公式 |
|---|---|---|
| **Case 1** | 单位重 < 0.025 kg；或动物产品/谷物/加工后无单位概念 | `IESTI = (LP × HR) / bw` |
| **Case 2a** | 单位重 ≥ 0.025 kg 且 **U < LP**（如苹果） | `IESTI = [U × HR × vf + (LP − U) × HR] / bw` |
| **Case 2b** | 单位重 ≥ 0.025 kg 且 **U ≥ LP**（如西瓜） | `IESTI = (U × HR × vf) / bw` |
| **Case 3** | 加工/混合产品（油、面粉、果汁、奶） | `IESTI = (LP × STMR) / bw` |

| 符号 | 含义 | 默认/来源 |
|---|---|---|
| LP | 大份餐（large portion），P97.5 消费量 | GEMS/Food 或国家调查 |
| HR | 最高残留（highest residue，规范试验） | JMPR 评估报告 |
| STMR | 规范试验中位残留 | JMPR 评估报告 |
| U | 单位重量（可食部分） | GEMS/Food 单位重量表 |
| vf | 变异系数（variability factor） | **默认 3**（JMPR 自 2003 起） |
| bw | 体重 | 国际评估用各国调查平均体重 |

**Case 2a 的逻辑**：先吃到的"最坏那一口"浓度可能高于整体均值（前 U 部分按 vf 放大），其余部分按 HR。**U ≥ LP 时 2a 会算负值或无意义**，故改用 2b。

**注意**：IESTI 逐食品算完后，**不是简单相加**——JMPR 明确不考虑同一餐多种食品同时达最高残留；需要合并时另做概率评估。

## 五、点评估 vs 概率评估

| 对比项 | 点（确定性） | 概率（Monte Carlo） |
|---|---|---|
| 输入 | 各参数单点统计值 | 参数概率分布 |
| 组合 | 直接代入 | 随机抽样 N 次（≥10 000） |
| 输出 | 单一值 / HQ | 分布、P95/P99、超限概率 |
| 偏差 | P95×P95 严重高估；均值×均值可能低估 | 更接近真实 |
| 敏感性 | 不可量化 | 可量化（见 `05`） |
| 数据要求 | 低 | 高（需分布拟合） |

**两种典型组合的偏差方向**：

- **高端组合**（P95 浓度 × P95 消费）→ 系统性**高估**（两个 P95 同时发生的概率 << 5%）。用于筛查可接受，用于结论须说明。
- **均值组合**（均值 × 均值）→ 对**偏态分布**会**低估**高端个体。用于一般人群可行，不能代表高消费人群。

## 六、统计值选择速查（CFSA）

| 评估类型 | 浓度取值 | 消费量取值 |
|---|---|---|
| 急性（短期） | 高端值（P95/P97.5）或最大值 | 高端值（P97.5）或最大值 |
| 慢性（长期） | 均值、中位数、P95 等组合 | 均值、中位数、P95 等组合 |
| 营养素（不足侧） | — | 关注 P25 等低端值 |
| 筛查 | 均值或最高值 | 均值或高值 |

**原则**：保守性应与目的匹配。筛查越保守越好；结论性评估应给出"一般人群"与"高端人群"两套结果。

## 七、数据来源

### 7.1 浓度

- 国家食品安全风险监测、总膳食研究（TDS）、专项调查。
- 企业自检/出厂检验（注意：非随机抽样，可能有选择偏倚）。
- 文献（注意年份、地区、检测方法、样本量、是否代表性）。
- 加工因子（processing factor）：生→熟、去皮、浸泡、发酵、烹饪对浓度的影响。**未考虑加工因子是常见高估来源**（如谷物→面粉→面包、茶叶→茶汤）。

### 7.2 消费量

| 来源 | 内容 | 备注 |
|---|---|---|
| CFSA 食物消费量调查 / 中国居民膳食调查 | 个体 24 h 回顾、称重记录 | 国内首选 |
| 中国总膳食研究（TDS） | 混合膳食样品 | 与浓度数据配套 |
| WHO **GEMS/Food** | 大份餐 P97.5、单位重量、cluster diets | 国际评估标准源 |
| FAO **GIFT** | 食物成分与消费 | 辅助 |
| EFSA 食物消费数据库 + DietEx | 欧盟细化数据 | 欧洲评估 |
| 各国膳食指南/平衡膳食宝塔 | 理论消费量 | 只用于情景假设，非实测 |

### 7.3 体重

- 优先用**调查人群实测**（同一年代、同一地区）。
- 国际评估（JMPR）用各国平均体重；儿童评估必须用年龄别体重。
- 中国成人常用 60 kg 仅为**示例默认值**，报告须写明来源；孕妇、儿童、老人另取。

## 八、检出限（LOD）以下的处理

| 方法 | 做法 | 影响 |
|---|---|---|
| 零替代（zero） | <LOD 记为 0 | **低估**（尤其多项目、高检出率低时） |
| 1/2 LOD | 记为 LOD/2 | 常用折中，简单 |
| 1/√2 LOD | 记为 0.707×LOD | 某些统计场景更合理 |
| 概率替代 | 在 0~LOD 间按分布抽样 | 概率评估首选 |
| 上限法（upper bound） | 记为 LOD | **高估**，筛查常用 |

**必须声明**采用哪种，并说明对结论方向的影响。混合使用不同方法会导致不可比。

## 九、常见错误清单

- [ ] µg 当 mg（1000 倍）／g 当 kg（1000 倍）
- [ ] 急性暴露拿去比 ADI，或慢性暴露比 ARfD
- [ ] 用成人 60 kg 评儿童／孕妇
- [ ] 忘乘加工因子（茶叶、谷物、油料）
- [ ] 把"检出"直接当"超标"或"有风险"
- [ ] P95×P95 当作"高端人群真实暴露"而不加说明
- [ ] 只算单一食品，实际应算总膳食（多食品累加）
- [ ] 只算膳食，漏掉饮水/土壤/职业等并存途径
- [ ] 消费量用"人均供应量"（food balance sheet）当"摄入量"（前者含损耗与浪费，偏高）
- [ ] LOD 处理未声明
- [ ] 多个农药/污染物未做累积暴露却下"总体安全"结论

> 算完先做**量级合理性检查**：成人每日食品总摄入约 1~2 kg；若单项消费量算出 5 kg/d，先怀疑单位。
