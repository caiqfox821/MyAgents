# 05 · 不确定性与概率建模

> 依据：WHO/FAO EHC 240、CFSA 技术指南、**EFSA 不确定性分析指南系列（`PMC7009727`、`PMC7009645`，全文已入 `公共知识/书库/papers/txt/`）**、Codex CXG 3-1989。
> 原著逐条证据与页码/PMCID 见 `公共知识/技术指南/风险评估-证据条目与出处.md` **§四（条目 4-1～4-6）**；复现：`grep -o '.\{0,140\}uncertainty.\{0,140\}' 公共知识/书库/papers/txt/PMC7009727.txt`。
> 核心区分：**变异性（variability）不可消除，不确定性（uncertainty）可通过数据降低。**

---

## 一、不确定性来源

| 来源 | 典型表现 | 处理 |
|---|---|---|
| **数据** | 样本量不足、代表性差、<LOD 处理、数据缺失 | 说明、敏感性分析、保守假设 |
| **模型** | 剂量-反应模型选择、外推模型 | 模型平均、多模型比较 |
| **情景假设** | 消费量假设、加工因子、体重默认值 | 明确列出，做情景对比 |
| **科学认知** | 机制不明、联合毒性、敏感亚人群 | 说明"知识缺口"，不假装已知 |

**报告写法**：逐项列出 + 标注它对结果的**方向**（偏高/偏低/双向）与**幅度**（若有）。

## 二、Monte Carlo 概率暴露

### 2.1 五步

```
1 为每个输入指定分布（浓度、消费量、体重）
2 从各分布独立抽样，代入暴露公式 → 一次暴露值
3 重复 N 次（≥10 000）→ 暴露分布
4 输出均值、中位数、P95、P99、超过 HBGV 的概率
5 敏感性分析，找出主导参数
```

### 2.2 分布选择

| 参数 | 常用分布 | 说明 |
|---|---|---|
| 食品中浓度 | 对数正态、经验分布、Gamma | 右偏；拟合检验（KS/AD）后再用 |
| 消费量 | 经验分布（个体数据） | 含大量零值，勿强行拟合连续分布 |
| 体重 | 正态/对数正态，按年龄性别分层 | 用实测均值与 SD |
| 加工因子 | 对数正态或经验 | 数据少时可作点值并做敏感性 |

**"独立抽样"是强假设**：浓度与消费量若相关（如高消费人群偏好某品牌），独立抽样会低估高端暴露。有相关证据时须用**copula 或分层抽样**。

### 2.3 脚本用法

```bash
python3 riskcalc.py mc \
  --conc lognormal:-2.6:0.6 \
  --cr empirical:0.05,0.12,0.2,0.35 \
  --bw normal:60:8 \
  --n 20000 --hbgv 0.02 --json
```

- `lognormal:mu:sd` 的 mu/sd 是**自然对数空间**参数：`mu = ln(中位数)`，`sd = ln(GSD)`。
- 输出含 `p_exceed_hbgv`（超限概率）与 `hq_p95`。
- **脚本不做分布拟合**；分布参数须来自数据拟合（如 fitdistrplus、Python scipy.stats），并记录拟合优度。

### 2.4 结果解读

| 输出 | 含义 | 误用 |
|---|---|---|
| 均值 | 人群平均暴露 | 不能代表高端个体 |
| P95 | 95% 个体低于此值 | 不是"安全上限" |
| 超限概率 5% | 约 5% 个体/日次超过 HBGV | **不等于"5% 的人会生病"** |
| P99 + 尾部 | 关注极端个体 | 样本不足时尾部不可靠 |

## 三、敏感性分析

| 方法 | 原理 | 优点 | 局限 |
|---|---|---|---|
| **单因素（OAT）** | 每次只变一个参数 ±10% | 快速、直观 | 忽略交互 |
| **相关系数**（Pearson/Spearman） | 输出与输入的相关 | 简单 | 仅线性/单调；相关≠贡献 |
| **标准化回归系数** | 多元回归 | 可处理相关输入 | 需线性假设 |
| **Sobol 指数** | 方差分解 | 可量化主效应与交互 | 需大量样本与专门工具 |
| **二维 Monte Carlo** | 分离变异与不确定性 | 最严谨 | 计算量大、需两层抽样 |

### 3.1 Sobol 指数（概念）

```
Si  = Var[E(Y | Xi)] / Var(Y)          一阶：Xi 单独贡献
STi = 1 − Var[E(Y | X∼i)] / Var(Y)     总效应：含交互
```

- 严格计算用 R `sensitivity` / Python `SALib`。本技能脚本只给**秩相关筛查**，并明确标注这一局限。
- 报告建议至少给：**OAT + 秩相关 + 主导参数结论**。

### 3.2 脚本用法

```bash
python3 riskcalc.py sens --conc 0.08 --cr 0.12 --bw 60 --delta 0.1
```

输出各输入的弹性（elasticity）：参数变动 1% 时输出变动百分之几。暴露公式中浓度/消费量的弹性约为 +1，体重约 −1——**若算出的弹性明显偏离，先怀疑单位或公式错**。

## 四、变异性 vs 不确定性（二维 Monte Carlo）

| | 变异性（variability） | 不确定性（uncertainty） |
|---|---|---|
| 本质 | 人群真实个体差异 | 知识不足 |
| 能否消除 | **不能**，只能更好刻画 | 能，靠更多数据 |
| 举例 | 有人爱吃苹果、有人不吃 | 苹果中农药浓度的真实均值未知 |
| 处理 | 内层抽样（个体维度） | 外层抽样（参数维度） |

二维 MC：内层对个体抽样、外层对参数分布抽样，得到"暴露分布的**置信区间**"，而不是"一个暴露分布"。适合标准制定与高风险决策。

## 五、不确定性报告的写法

```
不确定性来源 | 方向 | 幅度 | 对结论的影响 | 处理
-----------|------|------|-------------|------
浓度数据仅 12 个样品 | 双向 | 可能 ±30% | HQ 仍在 1 以下 | 加强监测
未考虑加工因子 | 偏高 | 可能 2~5 倍 | 属保守 | 声明
消费量用成人默认 60 kg | 对儿童偏低 | 可达 2 倍 | 儿童 HQ 可能 >1 | 单列儿童评估
```

**结论是否翻转**（robustness）：写明"在最不利假设下结论如何变化"。若核心结论在高/低假设间翻转，必须明说，不能只报有利情景。

## 六、常见错误

- [ ] 只报点评估结果，不报不确定性与关键假设
- [ ] 用 Monte Carlo 但不做分布拟合检验（凭感觉给分布参数）
- [ ] 抽样次数 < 10 000 却报 P99
- [ ] 把"超限概率"解读为"发病人数比例"
- [ ] 忽略输入间相关性（独立抽样假设未声明）
- [ ] 敏感性只做 OAT，却下"某参数是主导因素"的强结论
- [ ] 混淆变异性与不确定性，导致"数据再多也降不下来"的误判
