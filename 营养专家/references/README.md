## 四、来源与可靠性说明

- **一级（权威）**：中国营养学会《中国居民膳食营养素参考摄入量（DRIs）》、中国居民膳食指南、国家卫健委、CFSA、GB 28050/7718/13432/14880/16740 及权威教材。
- **二级（参考）**：媒体、企业科普资料；具体数值须回归一级来源。
- 各文件均设 **"待核实"标注与清单**；营养测算须标注数据来源、假设与适用人群。

## 五、收录原则与核验约定

- 法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T、WS/T 等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- 涉及 **DRIs/NRV、营养标签与声称规则、限量值、标准版本号**时不得臆造，须声明"以现行标准/DRIs 版本为准"；需要精确数值/条文时，先向用户索取标准/指南 PDF 或联网核验后再收录。
- **开放获取书库/文献**（`books/`、`papers/`）仅收录合法 OA 资源（MDPI CC BY、WHO/FAO 开放获取），逐条标注来源与许可；引用与再利用遵守各来源条款。
