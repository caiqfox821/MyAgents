# 标准规范与法规（营养相关）

> 整理范围：中国营养领域的核心指南、标准与法规索引，包括 DRIs、膳食指南、《国民营养计划》、营养标签、特殊膳食、保健食品、营养强化剂、特殊医学用途配方食品、学生餐营养指南等，并附合规与计算工作清单。
> 说明：**重要提示**：标准与法规更新频繁，本文件仅作**索引与框架**；**具体编号、版本年份、实施日期、限量与阈值一律以国家官方平台现行有效版本为准**，不得据本文件臆造数值；不确定处标注"待核实"。
> 复核入口：
> - 国家标准全文公开系统：`https://openstd.samr.gov.cn`
> - 全国标准信息公共服务平台：`https://std.samr.gov.cn`
> - 食品安全国家标准数据检索平台（CFSA）：`https://sppt.cfsa.net.cn`
> - 国家卫生健康委员会：`http://www.nhc.gov.cn`
> - 中国营养学会：`https://www.cnsoc.org`
> - 国家法律法规数据库：`https://flk.npc.gov.cn`

## 二、中国居民膳食指南

| 文件 | 内容 | 备注 |
|---|---|---|
| 《中国居民膳食指南》 | 一般人群平衡膳食准则 + 平衡膳食宝塔 | 中国营养学会，版本待核实 |
| 特定人群膳食指南 | 婴幼儿、儿童青少年、孕产妇、乳母、老年、素食等 | 随主指南发布 |
| 《中国居民膳食宝塔》 | 分层推荐量与可视化 | 推荐量以现行版为准 |

> 指南是**配餐与膳食结构设计的主要依据**；具体推荐量、适用能量水平以现行版为准（见《膳食结构与食物成分.md》《配餐与食谱设计.md》）。

## 三、《国民营养计划》与营养政策

- 《国民营养计划》（**年份与全称待核实**，由国务院办公厅发布）：提出营养健康目标、重点人群与行动（如生命早期 1000 天、学生营养、老年营养、临床营养行动等）。
- 相关：《健康中国行动》合理膳食行动、营养不良与超重肥胖防控目标。
- 地方配套实施方案与营养健康食堂/学校建设要求。

> 具体目标值（如贫血率、生长迟缓率下降幅度）**以现行文件为准（待核实）**。

## 五、特殊膳食用食品与特殊医学用途配方食品

| 类别 | 标准/依据（编号待核实） | 要点 |
|---|---|---|
| 婴儿配方食品 | GB 10765 等 | 适用 0–6 月，营养素与安全指标 |
| 较大婴儿和幼儿配方食品 | GB 10767 等 | 6–36 月 |
| 特殊医学用途配方食品（FSMP） | GB 29922 等 | 适用于进食受限/消化吸收障碍/代谢紊乱人群；需注册 |
| 特殊医学用途婴儿配方食品 | GB 25596 等 | 婴儿 FSMP |
| 辅助营养补充品/运动营养食品 | GB 24154（运动营养食品通则，待核实）等 | 运动人群营养补充 |
| 其他特殊膳食 | 相应 GB | 如糖尿病、肾病等专用（以现行标准为准） |

> FSMP 在中国实行**注册管理**，标签须标示适用人群、食用方法与警示；**具体标准号与版本待核实**。

## 六、保健食品

| 主题 | 依据（框架） |
|---|---|
| 产品标准 | GB 16740《食品安全国家标准 保健食品》（编号待核实） |
| 注册与备案 | 《保健食品注册与备案管理办法》 |
| 功能声称 | 允许保健功能目录（现行目录待核实） |
| 标签标识 | "蓝帽子"标志、适宜/不适宜人群、食用量与方法 |
| 原料 | 可用于保健食品的原料目录、禁用物质名单 |
| 广告与宣称 | 不得涉及疾病预防、治疗功能 |

> 保健食品≠普通食品，也≠药品；**功能声称用语以国家发布的允许目录为准（待核实）**。

## 七、营养强化剂与营养相关卫生标准

| 标准（待核实） | 主题 |
|---|---|
| GB 14880 | 食品营养强化剂使用标准（强化剂品种、使用范围、强化量） |
| GB 2760 | 食品添加剂使用标准 |
| GB 5009 系列 | 理化检验方法（能量、蛋白、脂肪、碳水、钠、维生素等） |

## 九、学校供餐与学生餐

- 《学生餐营养指南》（WS/T，编号待核实）：按学段规定能量、蛋白质、脂肪、碳水与食物供应量。
- 《学校食品安全与营养健康管理规定》：供餐安全与营养管理要求。
- 农村义务教育学生营养改善计划相关要求。
- 校园营养健康食堂建设与带量食谱要求。

> 学生餐配餐须同时满足**营养（本角色）**与**安全（食品安全专家）**双重要求，并符合现行标准。

## 十、合规与计算工作清单

### 10.1 营养标签/声称合规清单

- [ ] 确认产品是否属于豁免营养标签的情形
- [ ] 确定核心营养素与标示基准（100 g / 100 mL / 份）
- [ ] 核算含量并计算 NRV%（对照现行 NRV 表）
- [ ] 按修约规则取整，校验能值反算
- [ ] 核对营养声称/功能声称是否符合阈值与标准用语
- [ ] 核对 GB 7718 强制标示项目、配料表与致敏提示
- [ ] 特殊膳食/保健食品核对对应标准与注册备案要求

### 10.2 配餐/膳食评价合规清单

- [ ] 对照现行 DRIs 与膳食指南
- [ ] 能量与三大营养素目标、餐次分配
- [ ] 平衡膳食宝塔各层覆盖与食物多样性
- [ ] 钠、添加糖、饱和脂肪、反式脂肪受控
- [ ] 特殊人群/慢病个体化调整并转介临床
- [ ] 数据来源、版本与假设标注

### 10.3 强化/特殊食品清单

- [ ] 强化剂是否在 GB 14880 允许范围与用量内
- [ ] 是否存在多来源叠加超 UL 风险
- [ ] FSMP 是否已注册、标签是否合规
- [ ] 保健食品功能声称是否为允许用语

## 十一、来源与待核实

**一级（权威）**
1. 国家卫生健康委员会、国家市场监督管理总局、中国营养学会、CFSA 官方发布。
2. 国家标准全文公开系统、全国标准信息公共服务平台、食品安全国家标准数据检索平台的现行标准。
3. 国家法律法规数据库与国务院/部委政策文件原文。
4. 《中国居民膳食营养素参考摄入量（DRIs）》《中国居民膳食指南》。

**二级（参考）**
1. 行业媒体、协会与培训机构的解读与科普（仅作检索线索）。
2. 标准解读类文章（须回归标准原文核实）。

**待核实清单**
1. DRIs 与膳食指南的现行版本年份及全部推荐量。
2. 《国民营养计划》的准确全称、发布年份与目标值。
3. GB 28050、GB 7718、GB 13432、GB 14880、GB 16740 的现行编号/年份与条文（尤其附录阈值）。
4. 各类特殊膳食与 FSMP 标准（GB 10765、GB 10767、GB 25596、GB 29922 等）的现行版本与适用范围。
5. WS/T 554 等营养相关行业标准的编号、名称与版本。
6. 保健功能允许目录与可用于保健食品原料目录的最新版本。
7. 学校供餐相关管理规定与营养改善计划的现行要求。
