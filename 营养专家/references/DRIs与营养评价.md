# DRIs 与营养评价

> 整理范围：膳食营养素参考摄入量（DRIs）四指标框架、能量需要（BMR/TDEE/EER）、宏量营养素可接受范围（AMDR）、主要营养素推荐与上限要点、营养状况评价四法与膳食调查方法。
> 主要依据：中国营养学会《中国居民膳食营养素参考摄入量（DRIs）》（版本待核实，以现行版本为准）；WHO/FAO 能量与宏量营养素报告；营养与食品卫生学通用教材。
> 说明：文中数值为参考量级，**具体 DRIs 数值、上限与版本年份一律以现行 DRIs 为准**；不确定处标注"待核实"。能量系数统一取碳水 4、蛋白 4、脂肪 9、酒精 7 kcal/g。

## 一、DRIs 的四类指标

膳食营养素参考摄入量（Dietary Reference Intakes, DRIs）是一组用于评价与计划膳食的参考值，核心四指标如下：

| 指标 | 英文/缩写 | 含义 | 主要用途 |
|---|---|---|---|
| 平均需要量 | EAR（Estimated Average Requirement） | 满足某年龄性别组 50% 个体需要的摄入量 | 评价群体摄入不足比例；推导 RNI |
| 推荐摄入量 | RNI（Recommended Nutrient Intake） | 满足绝大多数（约 97%–98%）个体需要的摄入量 | 个体摄入目标；一般 = EAR + 2SD |
| 适宜摄入量 | AI（Adequate Intake） | 数据不足时由观察/实验估计的适宜量 | 个体目标；不能用于评价群体不足比例 |
| 可耐受最高摄入量 | UL（Tolerable Upper Intake Level） | 几乎对所有个体不致健康危害的最高平均每日摄入量 | 防过量风险，非推荐目标 |

> 补充概念（各版本命名可能不同，均**待核实**）：
> - **宏量营养素可接受范围（AMDR）**：见第三节。
> - **预防非传染性慢性病的建议摄入量（PI-NCD）** 与 **特定建议值（SPL）**：如钠、钾、植物甾醇等，用于慢病预防。
> - RNI 无数据时用 AI 替代；EAR 缺失时无法计算群体不足率，改用 AI 做定性判断。

### 1.1 应用逻辑

- **个体评价**：摄入量长期低于 EAR → 不足风险高；介于 EAR 与 RNI → 不足风险较低但不确定；达到 RNI/AI → 基本充足；超过 UL → 过量风险。
- **群体评价**：用 EAR 切点法估算不足比例；用 UL 评估过量比例。
- **膳食计划**：个体以 RNI/AI 为目标，群体用 EAR 规划。

## 二、能量需要量（EER）与 TDEE

### 2.1 能量需要量（EER）

能量需要量（Estimated Energy Requirement, EER）指维持能量平衡、保持健康体重的平均摄入量。核心构成：

```
EER ≈ BMR（基础代谢） + TEF（食物热效应） + 身体活动消耗 + 生长发育/特殊生理需要
TDEE（每日总能量消耗） ≈ BMR × 活动系数（PAL）
```

- **食物热效应（TEF）**：约占总能量 10%（蛋白较高、脂肪较低）。
- **身体活动水平（PAL, Physical Activity Level）**：见 2.3。

### 2.2 基础代谢率（BMR/BEE）常用公式

**Mifflin-St Jeor 公式（常用）**

- 男性：`BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄(岁) + 5`
- 女性：`BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄(岁) − 161`

**Harris-Benedict 修订公式（旧版常用）**

- 男性：`BMR = 13.397×W + 4.799×H − 5.677×A + 88.362`
- 女性：`BMR = 9.247×W + 3.098×H − 4.330×A + 447.593`
（W=kg，H=cm，A=岁）

> 两式均为估算；肥胖、肌肉量大、甲亢/甲减等人群误差较大，建议结合间接测热法或体成分数据校正。**公式适用人群与系数以原始文献为准（待核实）**。

### 2.3 身体活动水平（PAL）与活动系数

| 活动强度 | 描述 | 活动系数（PAL，参考） |
|---|---|---|
| 极轻 | 久坐办公、极少运动 | 1.2 左右 |
| 轻度 | 轻度活动/每周运动 1–3 次 | 1.375 左右 |
| 中度 | 中等活动/每周运动 3–5 次 | 1.55 左右 |
| 高度 | 高强度活动/每周运动 6–7 次 | 1.725 左右 |
| 极高 | 体力劳动或一日两练 | 1.9 左右 |

> 系数为通用参考量级，**具体分级与取值以现行 DRIs 或权威文献为准（待核实）**。计算示例见《配餐与食谱设计.md》。

## 三、宏量营养素可接受范围（AMDR）与供能比

| 营养素 | 常见参考供能比（%E，待核实） | 说明 |
|---|---|---|
| 蛋白质 | 10%–15%（可到 20%） | 儿童、孕乳母、运动人群可上调 |
| 脂肪 | 20%–30% | 饱和脂肪宜 <10%E；反式脂肪尽量 <1%E（待核实） |
| 碳水化合物 | 50%–65% | 添加糖宜 <10%E，最好 <5%E（待核实） |

- **供能比计算**：某营养素 %E = 该营养素供能 ÷ 总能量 × 100%。
- 三大营养素供能：碳水与蛋白各 4 kcal/g，脂肪 9 kcal/g，酒精 7 kcal/g。

## 四、主要营养素推荐与上限要点

> 下列数值为量级提示，**逐项数值与适用人群以现行 DRIs 为准（待核实，以现行版本为准）**。

### 4.1 蛋白质

- 一般成人 RNI：约 1.0–1.2 g/kg·d（按体重计，待核实）。
- 老年人、运动/增肌人群可上调（见《人群与运动营养.md》）。
- 优质蛋白（蛋奶肉鱼豆）宜占 1/3 以上；关注氨基酸评分（PDCAAS/DIAAS）。

### 4.2 脂肪与脂肪酸

- 总脂肪供能 20%–30%E；饱和脂肪酸 <10%E。
- 亚油酸（n-6）、α-亚麻酸（n-18:3 n-3）为必需脂肪酸，有 AI 值（待核实）。
- 反式脂肪酸供能 <1%E（待核实）；关注植脂末、起酥油来源。

### 4.3 碳水化合物与膳食纤维

- 碳水供能 50%–65%E；优先全谷物、杂豆、薯类。
- 添加糖 <50 g/d，最好 <25 g/d（待核实，与 WHO 建议一致方向）。
- 膳食纤维 AI：成人约 25–30 g/d（待核实）；来源为全谷、蔬果、豆类。

### 4.4 钠、钾与食盐

- 钠 AI 与 PI-NCD：成人建议 <2000 mg/d（约食盐 <5 g/d，待核实）。
- 钾 AI：成人约 2000 mg/d 量级（待核实）；多摄蔬果、薯类、豆类。
- 1 g 食盐 ≈ 393 mg 钠；1 g 钠 ≈ 2.54 g 食盐（换算系数，用于标签与配餐）。

### 4.5 维生素与矿物质要点

| 类别 | 关注点 |
|---|---|
| 脂溶性维生素 A/D/E/K | 可在体内蓄积，注意 UL；维生素 D 关注日照不足人群 |
| 水溶性维生素 B 族/C | 易随烹调流失，需每日充足摄入 |
| 钙 | 与骨骼健康、乳制品摄入相关；有 RNI 与 UL |
| 铁 | 育龄女性、婴幼儿需求高；血红素铁吸收率高 |
| 锌、碘、硒 | 有 RNI/AI 与 UL；碘与食盐加碘政策相关 |
| 叶酸 | 备孕/孕早期关键，有 RNI 与补充建议 |

> 各维生素/矿物质具体 RNI/AI/UL 数值差异大，**须逐项查现行 DRIs 表（待核实）**，本文件不列具体数字以免误用。

## 五、营养状况评价四法

| 方法 | 内容 | 常用指标 |
|---|---|---|
| 膳食调查 | 了解摄入量与结构 | 24h 回顾、FFQ、称重法、膳食史 |
| 人体测量 | 体格与体成分 | 身高、体重、BMI、腰围、皮褶厚度、体脂率 |
| 生化检验 | 血液/尿液营养素水平 | 血红蛋白、血清铁蛋白、维生素 D、血脂、血糖 |
| 临床检查 | 症状与体征 | 消瘦、水肿、口角炎、佝偻病体征等 |

> 综合四法可提高评价可靠性；单一指标易受短期波动影响。

### 5.1 常用人体测量指标

- **体质指数（BMI）**：`BMI = 体重(kg) / 身高(m)²`。
  - 中国成人参考分类（**待核实，以现行标准为准**）：低体重 <18.5；正常 18.5–23.9；超重 24.0–27.9；肥胖 ≥28.0 kg/m²。
  - 国际 WHO 分类切点不同（超重 ≥25、肥胖 ≥30），跨国比较需说明标准。
- **腰围**：中国成人中心性肥胖参考切点（待核实）：男 ≥90 cm、女 ≥85 cm。
- **儿童青少年**：用年龄性别别 BMI 百分位/标准差评分（WHO 或中国标准），**不宜直接套用成人切点**。

## 六、膳食调查方法与摄入评估

### 6.1 常用膳食调查方法

| 方法 | 原理 | 优点 | 局限 |
|---|---|---|---|
| 24 小时回顾法 | 回顾前 1 日全部进食 | 简便、应答率高 | 依赖记忆，单日变异大，需多次 |
| 食物频率问卷（FFQ） | 询问一定时期各类食物频次与份量 | 反映长期习惯、可流行病学分析 | 设计依赖、份量估计误差 |
| 称重法（称重记账） | 逐餐称量记录 | 精度高 | 工作量大，可能改变进食行为 |
| 膳食史法 | 结合习惯与近期摄入 | 反映长期模式 | 耗时、需专业人员 |
| 化学分析法 | 实验室测定实际摄入 | 最准确 | 成本高，难推广 |

> 实践中常用"**24h 回顾 + FFQ**"组合，兼顾近期与长期；评价个体宜多次 24h 回顾（如 3 天含 1 个周末日）。

### 6.2 摄入量计算与评价

1. 记录食物种类与生重/熟重（明确可食部）。
2. 查《中国食物成分表》换算能量与各营养素（详见《膳食结构与食物成分.md》）。
3. 汇总每日摄入，与 DRIs 比较：
   - 能量：与 EER 比较，判断能量平衡。
   - 蛋白质/维生素/矿物质：与 RNI/AI 比较，算达标率。
   - 与 UL 比较，评估过量风险。
4. 计算供能比与餐次分配，评估结构合理性。

### 6.3 营养不足与过剩判断

| 状态 | 判断线索 |
|---|---|
| 能量不足 | 摄入 < EER、体重下降、BMI 偏低 |
| 能量过剩 | 摄入 > EER、超重/肥胖、腰围超标 |
| 蛋白质-能量营养不良（PEM） | 消瘦/水肿、血清白蛋白低等 |
| 微量营养素不足 | 摄入长期低于 EAR、生化指标异常、缺乏症状 |
| 过量风险 | 长期超 UL（如维生素 A/D、钠、部分矿物质） |

> 判断需结合摄入、体格、生化与临床，避免仅凭单一数值下结论。
