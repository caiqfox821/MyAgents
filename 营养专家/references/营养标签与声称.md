# 营养标签与声称

> 整理范围：GB 28050 预包装食品营养标签（核心营养素、NRV%、格式与豁免）、GB 7718 预包装食品标签通则相关要求、营养声称与营养成分功能声称的条件框架、特殊膳食用食品（GB 13432）与保健食品标签、营养标签核算规则与 NRV 使用/修约框架。
> 主要依据：GB 28050《食品安全国家标准 预包装食品营养标签通则》、GB 7718《食品安全国家标准 预包装食品标签通则》、GB 13432《食品安全国家标准 预包装特殊膳食用食品标签》（**各标准版本号与年份待核实，以现行有效版本为准**）；中国营养学会《中国居民膳食营养素参考摄入量（DRIs）》。
> 说明：本文件仅为**框架与索引**，**所有数值阈值、NRV 值、格式条文与版本号一律以现行标准原文为准**；标注"待核实"处不得据本文件臆造。

## 一、GB 28050 营养标签框架

### 1.1 适用范围与原则

- 适用于**预包装食品**的营养标签；营养标签是标签的一部分。
- 原则：真实、客观、科学，不得虚假、夸大。
- 核心内容是**营养成分表**，可含营养声称与功能声称。

### 1.2 核心营养素（"1+4"及扩展，待核实）

| 项目 | 说明 |
|---|---|
| 能量 | 必需标示 |
| 蛋白质 | 必需 |
| 脂肪 | 必需 |
| 碳水化合物 | 必需 |
| 钠 | 必需 |
| 饱和脂肪（酸） | 条件性标示（如进行相应声称时） |
| 糖 | 条件性标示 |
| 反式脂肪（酸） | 条件性标示 |
| 胆固醇、膳食纤维、维生素、矿物质 | 条件性/自愿标示 |

> 中国现行要求的"核心营养素"以 GB 28050 原文为准（**待核实**）；不同国家/地区核心项不同（如美国含胆固醇/膳食纤维等）。

### 1.3 营养成分表格式

- 通常为**表格形式**，含"项目、每 100 g（或 100 mL）、NRV%"等列。
- 可标示"每 100 g""每 100 mL""每份"或"每份 + 每 100 g"。
- 含有"营养素参考值%"（NRV%）列。
- 字体、单位、修约等有明确规定（**以标准原文为准，待核实**）。

### 1.4 豁免标示的情形（框架，待核实）

- 生鲜食品（如未经加工的肉、菜、水果、蛋、鱼等）。
- 乙醇含量 ≥ 一定阈值的饮料酒（数量待核实）。
- 包装总表面积 < 某阈值的小包装食品（可仅标示部分）。
- 现制现售、非直接提供给消费者的部分情形等。

> 具体豁免范围与阈值条件以 GB 28050 原文为准。

## 二、NRV 与 NRV% 计算

### 2.1 定义

- **营养素参考值（Nutrient Reference Value, NRV）**：用于标签标示与比较的参考值，通常对应每日推荐量级。
- **NRV%** = `某营养素含量 ÷ 该营养素 NRV × 100%`，表示每 100 g/份产品提供的营养素占每日参考值的比例。

### 2.2 计算步骤

1. 确定标示基准（每 100 g 或每份）。
2. 取得该产品该营养素的**实测/计算含量**（按标准规定的检测与计算规则）。
3. 查现行 NRV 表取对应 NRV 值。
4. 计算：`NRV% = 含量 / NRV × 100%`。
5. 按标准规定的**修约规则**取整（多为取整到个位，规则待核实）。

### 2.3 示例（假设数值，仅演示方法）

> 假设某食品每 100 g 含蛋白质 6.0 g，NRV(蛋白质) 取假设值 60 g（**实际值待核实**）：
> `NRV% = 6.0 / 60 × 100% = 10%`。

### 2.4 能量计算

- 能量 = 蛋白×4 + 脂肪×9 + 碳水×4 + 膳食纤维（可选）×系数 + 酒精×7 + 有机酸等（kcal/g）。
- 单位可同时标 kJ 与 kcal；换算：`1 kcal ≈ 4.184 kJ`。
- 膳食纤维、糖醇、有机酸的能量系数以标准规定为准（**待核实**）。

> NRV 具体数值（如能量 8400 kJ/2000 kcal、蛋白 60 g、脂肪 60 g、碳水 300 g、钠 2000 mg 等常见框架值）**必须查现行 GB 28050 附录，不得臆造（待核实）**。

## 三、GB 7718 标签通则相关

- 预包装食品标签的**强制标示内容**（食品名称、配料表、净含量、生产者信息、日期、贮存条件、生产许可证号、标准号等）。
- **配料表**：按加入量递减排列；配料定量标示规则；食品添加剂标示方式。
- **日期标示**：生产日期、保质期/保存期。
- **致敏物质提示**：含致敏成分的提示（范围与方式以标准原文为准，待核实）。
- 营养标签（GB 28050）是 GB 7718 标签体系中的组成部分，二者需同时满足。
- 进口食品标签、特殊食品标签另有相应规定。

> 具体强制标示项目、顺序、字体大小与禁止性表述以现行 GB 7718 原文为准。

## 四、营养声称与功能声称的条件框架

### 4.1 营养声称分类

| 类型 | 含义 | 示例 |
|---|---|---|
| 含量声称 | 描述营养素含量水平 | "低脂肪""无糖""高钙""富含膳食纤维" |
| 比较声称 | 与参考食品比较 | "减少 25% 脂肪""增加钙" |
| 营养成分功能声称 | 描述营养素对机体功能的作用 | "钙有助于骨骼和牙齿健康" |

### 4.2 含量声称的条件框架（阈值待核实）

- 声称"低"某营养素：需满足"低"的**阈值**（如低脂、低钠、低糖、低能量）。
- 声称"无/不含"：需满足"无"的阈值（可能允许极微量本底）。
- 声称"高/富含/来源"：需满足相应**高含量**要求或达到 NRV% 的一定比例。
- 声称"减少"：比较声称需有参考食品且差异达到规定比例。

> **所有具体阈值（如固体/液体每 100 g 或 100 mL 的限值）与 NRV% 比例要求一律以 GB 28050 附录为准（待核实）**。本文件只给出框架，不列具体数字。

### 4.3 功能声称的合规要点

- 只能使用标准规定的**标准用语**，不得自行改写或夸大。
- 声称的营养素须在营养成分表中标示。
- 不得声称治疗、预防疾病功能（食品不得有药品声称）。
- 需符合"含量声称/功能声称"的前置条件。

### 4.4 判定流程

```
① 确定声称类型 → ② 核对是否使用标准允许用语
→ ③ 核对营养素含量是否满足对应阈值/NRV% 要求
→ ④ 核对营养成分表已标示该营养素
→ ⑤ 核对整体标签无违法声称（疾病、绝对化用语等）
```

## 五、特殊膳食用食品与保健食品标签

### 5.1 特殊膳食用食品（GB 13432）

- 范围：为满足特定生理/疾病/医学状况人群营养需要而特殊加工的食品，如**婴幼儿配方食品、特殊医学用途配方食品**等。
- 标签要求：需标示适用人群、食用方法、能量与营养素含量、注意事项等。
- 具体项目与格式以 GB 13432 及相关产品标准原文为准（待核实）。
- 特殊医学用途配方食品（FSMP）另见 GB 29922 等（见《标准规范与法规-营养.md》）。

### 5.2 保健食品标签

- 需标注**保健功能、适宜人群、不适宜人群、食用量与食用方法、保健食品标志（"蓝帽子"）**等。
- 保健食品注册或备案管理；标签与说明书不得涉及疾病预防、治疗功能。
- 营养标签方面参照 GB 28050 及注册/备案要求（**具体以现行规定为准，待核实**）。

## 六、营养标签核算规则

### 6.1 数据来源与优先顺序

1. 产品检测数据（最高优先）。
2. 配方计算（原料成分表 + 加工损失折算）。
3. 权威食物成分数据库。

> 计算法标示时应对结果负责；建议留出安全裕量以应对检测波动。

### 6.2 配料与原料折算

| 情形 | 处理要点 |
|---|---|
| 单一原料 | 直接按原料成分换算 |
| 复合配料 | 展开计算各配料贡献（有国标/行标且添加量低者可能有简化规则） |
| 生鲜原料 | 注意可食部、水分变化 |
| 加工损失 | 维生素等热敏成分考虑损失率（损失率数据待核实） |
| 水分变化 | 浓缩/干燥/复水导致营养素密度变化，按成品重量折算 |
| 带入原则 | 原料/添加剂带入的营养素是否计入，按标准规定 |

### 6.3 修约与允差

- NRV% 通常修约到整数（规则待核实）。
- 能量与各营养素修约位数按标准规定。
- 实际检测值相对标示值的允许误差范围按 GB 28050 规定（**待核实**）。

### 6.4 营养标签核算工作步骤

```
① 确定标示单元与基准（每 100 g/份）
② 列配方与各配料用量、查成分数据
③ 按配料贡献加权求和→得成品每 100 g 含量
④ 考虑加工损失与水分变化校正
⑤ 计算 NRV% 与能量（并做能值反算校验）
⑥ 按修约规则取整
⑦ 核对声称与功能声称条件
⑧ 复核标签格式与强制项目完整性
```

## 七、常见误区与风险提示

- 混淆"每 100 g"与"每份"导致误读。
- 忽略"无糖/无脂"的阈值与"无"的本底允许量。
- 用国外 NRV 值计算国内标签（数值体系不同）。
- 声称功能性用语但营养成分表未标示对应营养素。
- 复合配料未展开导致含量计算偏差。
- 修约过度造成不实标示。
