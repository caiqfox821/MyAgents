# 人群与运动营养

> 整理范围：生命各阶段（婴幼儿、儿童青少年、孕产妇、乳母、老年）营养关键需求；运动营养（能量与宏量分配、蛋白、碳水补糖、水合与电解质、常见补剂）；体重管理（能量缺口、体成分、行为干预）；营养与免疫/肠道菌群概论。
> 主要依据：中国营养学会《中国居民膳食指南》特定人群篇与《中国居民膳食营养素参考摄入量（DRIs）》（版本待核实）；ACSM/ISSN 等运动营养共识；WHO 身体活动与营养建议。
> 说明：数值为参考量级，**具体推荐量与补充剂适用性以现行 DRIs、共识与个体化评估为准（待核实）**；补剂使用应遵医嘱或注册营养师建议。能量系数：碳水 4、蛋白 4、脂肪 9、酒精 7 kcal/g。

---

## 一、生命各阶段营养关键需求

### 1.1 婴幼儿（0–3 岁）

| 阶段 | 关键点 |
|---|---|
| 0–6 月 | 纯母乳喂养为最优（或适宜配方奶）；母乳提供抗体与适宜比例营养素；补充维生素 D（依建议，待核实） |
| 6–12 月 | 及时添加辅食（富铁食物优先），由泥糊到碎块过渡；继续母乳/配方奶 |
| 1–3 岁 | 食物多样、少盐少糖；奶类保证；关注铁、锌、钙、维生素 A/D |

- 关注**生长曲线**（身长/体重/头围百分位），而非单次数值。
- 避免蜂蜜（1 岁前肉毒杆菌风险）、整粒坚果（窒息风险）、高盐高糖。

### 1.2 儿童青少年

- 能量与优质蛋白支持生长发育与学习；早餐不可省略。
- 钙、铁、锌、碘、维生素 D 为关键；青春期需求上升。
- 限制含糖饮料、油炸与高盐零食；保证蔬果与奶类。
- 培养规律运动与健康饮食行为，预防超重与挑食。

### 1.3 孕产妇

- 备孕/孕早期：叶酸充足（**补充剂量遵医嘱，待核实**）；戒烟酒。
- 孕中晚期：能量、蛋白质、铁、钙、碘、DHA 需求增加；少食多餐。
- 关注妊娠期体重增长适宜范围（依孕前 BMI 分级，待核实）。
- 妊娠糖尿病、妊娠高血压需临床营养管理。

### 1.4 乳母

- 能量与蛋白需求高于非孕；保证钙与水分以支持泌乳。
- 增加 DHA、维生素 A 等；限制酒精、咖啡因与某些药物。
- 均衡膳食优于进补，避免过度"下奶"高脂饮食。

### 1.5 老年人

- 能量需求下降，但**蛋白质相对需求提高**以延缓肌少症（见运动营养）。
- 钙与维生素 D 防骨质疏松；关注维生素 B12 吸收下降。
- 食物细软易咀嚼、足量饮水；必要时强化或补充剂（遵医嘱）。
- 关注吞咽障碍、慢病共存与多重用药的膳食交互。

## 二、运动营养

### 2.1 能量与宏量营养素分配

- 运动员/规律运动者能量需求可显著高于一般人群（随项目与训练量变化）。
- 宏量供能比常见框架：碳水 45%–65%、蛋白 10%–20%（力量/耐力可更高）、脂肪 20%–35%（**按项目个体化，待核实**）。

### 2.2 蛋白质

| 人群 | 蛋白推荐（g/kg·d，参考，待核实） |
|---|---|
| 一般成人 | 1.0–1.2 |
| 耐力运动 | 1.2–1.6 |
| 力量/增肌 | 1.6–2.0 |
| 减脂期保肌 | 1.6–2.2（可更高，个体化） |

- 优质蛋白、分次摄入（每餐约 0.3 g/kg 量级，待核实）。
- 关注亮氨酸等必需氨基酸与训练后窗口期。

### 2.3 碳水化合物与运动前后补糖

| 时机 | 建议方向（待核实） |
|---|---|
| 运动前 | 适量易消化碳水，避免高脂高纤 |
| 运动中 | 长时间（>1 h）可补充碳水，常用 30–60 g/h 量级 |
| 运动后 | 及时补糖（配合蛋白）促进糖原恢复 |
| 日常 | 训练日碳水充足；关注糖原储备 |

- 补糖量、浓度与频率依运动时长/强度个体化（**具体阈值待核实**）。

### 2.4 水合与电解质

- 运动前、中、后补水；以体重变化估算失水量（每减 1 kg 约需补水 1.0–1.5 L 量级，待核实）。
- 长时间/大量出汗或高温环境需补充**钠、钾、镁**等电解质。
- 观察尿液颜色与口渴感；避免过度饮水导致低钠血症。
- 运动饮料适用于长时间高强度；日常短时运动白水即可。

### 2.5 常见运动补剂：证据与风险提示

| 补剂 | 主要作用 | 证据等级/提示 |
|---|---|---|
| 蛋白粉（乳清/大豆等） | 便捷补蛋白，助肌肉合成 | 证据较充分；普通饮食充足者可不必；乳糖不耐受者选分离乳清/植物蛋白 |
| 肌酸（一水肌酸） | 提升高强度短时表现、增肌 | 证据较强；注意水分滞留、肾病人群慎用；遵建议剂量（待核实） |
| 咖啡因 | 提升耐力与警觉 | 证据较强；注意剂量、耐受、睡眠影响；过量致心悸（上限待核实） |
| β-丙氨酸 | 缓冲肌肉酸性，助高强度 | 中等证据；常见皮肤刺痛感；长期效果有限 |
| 维生素 D | 骨骼、肌肉与免疫 | 缺乏者补充有效；日照不足人群关注；**避免超 UL**（待核实） |
| 复合维生素/矿物质 | 弥补膳食不足 | 饮食均衡者获益有限；避免叠加超量 |
| 其他（HMB、BCAA 等） | 争议较大 | 证据不一致，优先保证总蛋白与训练 |

> **补剂不能替代膳食**；使用前评估必要性、剂量、纯度（避免兴奋剂污染）与禁忌；特殊人群（孕、哺乳、青少年、慢病、用药者）须咨询专业人员。

## 三、体重管理

### 3.1 能量缺口与摄入

- 减重核心：能量摄入 < 消耗，形成持续缺口。
- 温和缺口约 300–500 kcal/d；过快减重易致瘦体重流失与反弹（**具体值待核实**）。
- 结合食物体积大、能量密度低（蔬果、全谷、瘦蛋白）提高饱腹感。

### 3.2 体成分监测

- 关注**体脂率、腰围、瘦体重**，而非仅体重。
- 方法：生物电阻抗（BIA）、皮褶厚度、DEXA（参考）等。
- 减脂期保留蛋白摄入 + 抗阻训练有助于维持肌肉。

### 3.3 行为干预

- 目标设定（SMART）、自我监测（饮食/体重记录）、触发因素管理。
- 环境调整（减少高能量零食可得性）、社会支持。
- 规律作息与睡眠、压力管理；长期生活方式改变优于短期节食。

### 3.4 运动量与身体活动

- 对标 WHO 建议：成人每周中等强度有氧约 150–300 min 或等效，加上每周 ≥2 次力量训练（**具体以现行指南为准，待核实**）。
- 用 MET·min/周 量化：`MET·min/周 = Σ(MET × 分钟 × 每周频次)`（见《DRIs与营养评价.md》）。

## 四、营养与免疫 / 肠道菌群概论

### 4.1 营养与免疫

- 能量-蛋白质营养不良削弱免疫功能；肥胖与代谢紊乱亦影响免疫。
- 关键微量营养素：维生素 A、C、D、E，锌、硒、铁（缺乏降低免疫，过量亦有害）。
- 膳食模式（蔬果、全谷、优质蛋白、n-3 脂肪酸）整体影响免疫与炎症。
- **食物不能声称治疗/预防疾病**，相关表述需合规（见《营养标签与声称.md》）。

### 4.2 肠道菌群

- 膳食纤维、抗性淀粉、多酚等为肠道菌群提供底物，产生短链脂肪酸（SCFA）。
- 发酵食品与益生菌可影响菌群组成（菌株特异性，证据不一）。
- 多样化的植物性食物有助菌群多样性；长期高脂高糖不利。
- 菌群检测与个性化干预尚在发展，**结论待更多证据（待核实）**。

## 五、协作与转介

- 特殊人群与慢病的治疗性膳食：转介**临床营养师/医师**。
- 产品配方营养化与标签：与**食品加工专家**协作。
- 食品安全与膳食安全：与**食品安全专家**协作（生熟分开、烧熟煮透、过敏原）。
- 报告与科普输出：与**文档格式化专家**协作。

## 六、来源与待核实

1. 中国营养学会《中国居民膳食指南》特定人群篇与《中国居民膳食营养素参考摄入量（DRIs）》。
2. 国家卫生健康委员会、中国疾病预防控制中心营养与健康所相关文件。
3. WHO 身体活动与营养建议、ACSM/ISSN 运动营养共识。
4. 临床营养学与运动营养学国家级规划教材。

**二级（参考）**
1. 权威期刊综述与运动营养专业科普（仅作线索）。
2. 补剂厂商资料（须谨慎，不作为数值来源）。

**待核实清单**
1. 各生命阶段能量与营养素 RNI/AI/UL 具体值。
2. 孕期体重增长适宜范围与叶酸/铁/钙/碘/DHA 补充建议。
3. 运动人群碳水/蛋白推荐区间、补糖量（g/h）与补水速率。
4. 咖啡因、肌酸、β-丙氨酸等补剂的推荐剂量与安全上限。
5. WHO 身体活动推荐与 MET·min/周 阈值的现行表述。
6. 老年人蛋白质补充与肌少症干预的共识数值。
7. 菌群与免疫相关结论的证据等级。
