# 方法学与仪器分析

> 整理范围：分析方法选择决策、色谱（GC/HPLC/UPLC 及检测器）、质谱（电离源、质量分析器、MRM、同位素内标）、光谱与元素分析（UV-Vis/荧光/AAS/ICP-OES/ICP-MS/AFS/FTIR/NIR/拉曼）、免疫与快检、微生物检测、技术适用速查与联用策略。
> 主要依据：检测分析通用方法学、仪器分析原理与行业通行做法；GB 5009 / GB 23200 / GB 4789 等系列方法框架。
> 说明：文中浓度、参数、性能量级为**经验/参考量级**，实际以现行标准方法正文与实验室验证为准；涉及具体标准号、年份、限量一律标注"（待核实，以现行版本为准）"。

## 一、分析方法选择决策

### 1.1 决策要素（五问）

| 维度 | 关键问题 | 对方法的影响 |
|---|---|---|
| 目标物性质 | 挥发/半挥发？极性？热稳定？分子大小？ | 挥发、热稳定、弱极性 → GC；极性、热不稳定、大分子 → LC；元素 → 光谱/质谱 |
| 含量水平 | 痕量（μg/kg、ng/mL）？常量（% ~ mg/kg）？ | 痕量优先质谱/高灵敏检测器；常量可用滴定、光谱、常规色谱 |
| 基质 | 水、果蔬、谷物、肉蛋奶、油脂、土壤、生物样本？ | 决定提取溶剂、净化方式与基质效应大小 |
| 时效与场景 | 现场快筛还是实验室确证？批量还是单样？ | 快检（免疫/便携）用于初筛，确证用色谱-质谱 |
| 结果用途 | 合规判定、研发、风险监测、纠纷仲裁？ | 合规/仲裁须用标准方法或经确认的等效方法 |

### 1.2 方法选择决策树（提要）

1. **元素/无机物** → ICP-MS（痕量多元素）> ICP-OES（mg/L 级多元素）> AAS（单元素）> AFS（Hg/As/Se 等）> 分光光度法（常量）。
2. **挥发/半挥发有机物、农残、持久性污染物** → GC-MS/MS；无质谱时 GC-FID/ECD/NPD/FPD。
3. **极性/热不稳定有机物、兽残、毒素、添加剂** → LC-MS/MS（首选）；无质谱时 HPLC-DAD/FLD。
4. **大分子/生物活性（蛋白、多肽、核酸、糖）** → LC-MS、SEC、CE、生物传感器、免疫法。
5. **现场快筛** → ELISA、胶体金/荧光侧向层析、便携光谱、生物传感器；**阳性须确证**。
6. **微生物** → 计数用平板/MPN/显色培养基；鉴定/致病基因用 PCR/qPCR/ddPCR、测序/宏基因组。

### 1.3 方法层级与效力

| 层级 | 说明 | 适用 |
|---|---|---|
| 标准方法（法定） | 国标/行标/国际标准规定的方法 | 合规判定、执法取证 |
| 等效/替代方法 | 经方法比对证明与标准方法等效 | 常规检测，须有等效性数据 |
| 非标方法（自建） | 实验室自行开发，经完整验证 | 无标准可依的研发/特殊基质 |
| 快速检测方法 | 免疫/生化/物理快检 | 初筛，阳性须用确证方法复核 |

> **原则**：执法与合规判定以标准方法/确证方法为准；快检阳性仅作线索。

## 二、色谱分析

### 2.1 气相色谱（GC）

适用于沸点较低、热稳定、可气化的化合物（脂肪酸、有机酸、醇、残留溶剂、农残、多环芳烃等）。

**常用检测器**

| 检测器 | 原理/响应 | 选择性 | 典型用途 |
|---|---|---|---|
| FID（氢火焰离子化） | 有机物在氢焰中电离 | 通用、对烃灵敏 | 脂肪酸、溶剂、醇类 |
| ECD（电子俘获） | 对电负性原子灵敏 | 含卤素/硝基 | 有机氯农残、多氯联苯 |
| NPD（氮磷检测） | 碱金属盐对 N、P 响应 | 含 N、P | 有机磷/含氮农残 |
| FPD（火焰光度） | 对 S、P 发光响应 | 含 S、P | 有机磷、含硫农残 |
| TCD（热导） | 热导率差异 | 通用、灵敏度较低 | 常量气体/溶剂 |
| MS | 质荷比 | 可定性 | 确证与多残留（GC-MS） |

**关键条件（参考）**
- 进样口温度：通常 200~280 ℃（依目标物，确保气化而不分解）。
- 色谱柱：弱极性/非极性 **DB-5MS / HP-5MS**（30 m × 0.25 mm × 0.25 μm）等多残留首选；中等极性柱用于特定分离。
- 载气：He（恒流/恒压）；程序升温（如 50→300 ℃ 分段）。
- 分流比、进样量、溶剂延迟（质谱）需按目标物与基质优化。

### 2.2 高效/超高效液相色谱（HPLC / UPLC）

适用于极性、热不稳定、大分子化合物（添加剂、维生素、兽残、毒素、药物、生物胺等）。

**常用检测器**

| 检测器 | 原理 | 适用 |
|---|---|---|
| DAD/UV-Vis（二极管阵列/紫外） | 紫外-可见吸收 | 有发色团的目标物；DAD 可做光谱纯度检查 |
| FLD（荧光） | 荧光发射 | 本身或衍生后具荧光的物质（黄曲霉毒素、维生素 B₂ 等），灵敏度高 |
| RID（示差折光） | 折光率差 | 无发色团（糖、醇等）；灵敏度低、对温度敏感 |
| 电化学/库仑 | 氧化还原 | 酚类、儿茶素等 |
| MS | 质荷比 | 确证与痕量定量（LC-MS/MS） |

**关键条件（参考）**
- 色谱柱：反相 **C18 / C8**（如 150~250 mm × 4.6 mm × 5 μm；UPLC 用 2.1 mm × 1.7~1.8 μm 亚二微米柱）。
- 流动相：水/缓冲盐 + 甲醇/乙腈；注意 pH、缓冲盐浓度与柱耐受性。
- 梯度洗脱用于多组分分离；柱温通常 25~40 ℃。
- 正相/离子交换/HILIC 用于糖、离子型、强极性化合物。

### 2.3 其他色谱

| 技术 | 说明 | 典型应用 |
|---|---|---|
| 离子色谱（IC） | 离子交换分离 + 电导检测 | 阴/阳离子、亚硝酸盐、溴酸盐 |
| 凝胶渗透色谱（GPC） | 按分子大小分离 | 大分子基质净化（油脂、色素） |
| 薄层色谱（TLC） | 平面分离、半定量 | 快速筛查、鉴别 |
| 毛细管电泳（CE） | 电泳迁移分离 | 大分子、手性、离子型 |

### 2.4 色谱系统适用性（参考）

| 指标 | 参考要求 |
|---|---|
| 理论塔板数 N | 满足分离需要（方法规定值） |
| 分离度 Rs | 一般 ≥ 1.5（相邻峰） |
| 拖尾因子 T | 常在 0.8~1.5（方法规定） |
| 重复进样 RSD | 峰面积 %RSD 常 ≤ 2%（痕量可放宽） |

## 三、质谱分析

### 3.1 电离方式

| 电离源 | 机制 | 适用 |
|---|---|---|
| EI（电子轰击） | 70 eV 电子轰击，硬电离、碎片丰富 | GC-MS，可匹配标准谱库 |
| CI（化学电离） | 试剂气分子-离子反应，软电离 | GC-MS，分子离子信息 |
| ESI（电喷雾） | 溶液离子化，软电离 | LC-MS，极性/大分子/多电荷 |
| APCI（大气压化学电离） | 电晕放电，软电离 | LC-MS，中低极性/弱极性 |
| APPI（大气压光电离） | 光子电离 | 弱极性、非极性化合物 |
| ICP（电感耦合等离子体） | 高温原子化/离子化 | ICP-MS/OES 元素分析 |

### 3.2 质量分析器对比

| 类型 | 分辨率/精度 | 定性能力 | 典型用途 |
|---|---|---|---|
| 单四极杆（Q） | 低分辨（单位质量） | 有限（SIM） | 常规定量 |
| 三重四极杆（QqQ） | 低分辨，MRM 灵敏度高 | 离子对定性 | 痕量多残留定量（首选） |
| 离子阱（IT） | 低~中分辨，可多级 MSⁿ | 结构解析 | 定性研究 |
| 飞行时间（TOF） | 高分辨（如 > 2 万），质量精度高 | 精确质量、库匹配 | 筛查/未知物 |
| 四极杆-飞行时间（Q-TOF） | 高分辨 + 二级 | 高置信筛查/确证 | 非靶向筛查 |
| 静电场轨道阱（Orbitrap） | 高分辨、高质量精度 | 高置信筛查/组学 | 非靶向、代谢组 |

### 3.3 多反应监测（MRM）与确证

- **MRM/SRM**：选择母离子 → 碰撞碎裂 → 选特征子离子，实现高选择性与高灵敏度。
- **确证判据（参考，具体以标准为准）**：至少 2 个离子对（定量离子 + 定性离子），离子丰度比与标准品一致，保留时间匹配；高分辨质谱用精确质量偏差（如 < 5 ppm）辅助确证。
- **同位素内标（SIL-IS）**：如氘代/¹³C/¹⁵N 标记目标物，**在提取前加入**，校正提取损失、基质效应与仪器波动，是痕量定量的金标准。

### 3.4 质量精度与定量策略

| 概念 | 说明 |
|---|---|
| 质量准确度 | 实测质量与理论质量之差（ppm） |
| 分辨率 | 区分相邻质量峰的能力（FWHM） |
| 外标法 | 用独立标准曲线定量，简单但受基质影响 |
| 内标法 | 同位素内标最优；非同位素内标次之 |
| 基质匹配标准曲线 | 用空白基质配制，抵消基质效应 |
| 标准加入法 | 复杂基质无空白时使用 |

## 四、光谱与元素分析

### 4.1 技术对比

| 技术 | 原理 | 检出能力（量级，参考） | 特点 |
|---|---|---|---|
| UV-Vis 分光光度法 | 分子吸收 | mg/L ~ % | 设备普及、常需显色反应 |
| 荧光分光光度法 | 分子荧光 | μg/L ~ ng/L | 灵敏度高、选择性好 |
| AAS（原子吸收） | 基态原子吸收 | μg/L ~ mg/L | 单元素、成熟、受基质干扰 |
| 原子荧光（AFS） | 原子荧光 | μg/L 级 | Hg、As、Se、Sb 等，价态需处理 |
| ICP-OES | 原子发射 | mg/L ~ μg/L | 多元素同时、抗基体好 |
| ICP-MS | 等离子体质谱 | ng/L ~ μg/L | 痕量多元素、可同位素比，需防干扰 |
| FTIR/NIR | 分子振动吸收 | 常量（定性与定量） | 无损/快速、需化学计量学建模 |
| 拉曼 | 分子散射 | 常量~微量 | 无损、可穿透包装、荧光干扰 |

### 4.2 元素分析要点

- **样品前处理**：湿法消解（HNO₃/HClO₄/H₂O₂）、微波消解（密闭、高效、易挥发元素损失少）、干灰化（注意 Hg/As 挥发损失）。
- **干扰控制**：
  - ICP-MS：同量异位素干扰、多原子离子干扰（如 ⁴⁰Ar³⁵Cl⁺ 对 ⁷⁵As）、基体效应 → 用碰撞/反应池（He/H₂）、内标（Sc/Ge/In/Rh/Bi）、稀释或标准加入校正。
  - AAS：化学干扰、电离干扰 → 基体改进剂、石墨炉平台。
  - AFS：价态与氢化物发生条件控制。
- **形态分析**：As、Hg、Se、Cr 等需区分价态/形态时，采用 **HPLC/IC 与 ICP-MS 联用**。

### 4.3 分子光谱与无损快检

- **NIR/FTIR/拉曼**：用于原辅料鉴定、真伪鉴别、掺假筛查、水分/蛋白/脂肪等定量；须建立**化学计量学模型**（PLS 等）并持续维护与验证。
- **光谱指纹 + 多变量统计**：用于产地溯源、掺杂识别；模型需独立样本集验证，警惕过拟合。

## 五、免疫分析与快速检测

| 技术 | 原理 | 优点 | 局限 |
|---|---|---|---|
| ELISA（酶联免疫吸附） | 抗原-抗体特异结合 + 酶显色 | 高通量、成本低、灵敏 | 交叉反应、基质干扰、半定量 |
| 胶体金免疫层析 | 金标抗体层析显色 | 现场、快速、无需仪器 | 定性/半定量、易假阳/假阴 |
| 荧光/时间分辨荧光层析 | 荧光标记层析 | 灵敏度高于胶体金 | 需读数仪 |
| 化学发光免疫 | 化学发光信号 | 灵敏度高、线性宽 | 试剂与设备成本 |
| 免疫亲和柱（IAC） | 抗体特异捕获 | 高选择性净化 | 单目标/单类，成本高 |
| 生物传感器 | 生物识别 + 信号转换 | 快速、可在线 | 稳定性/寿命有限 |
| 电子鼻/电子舌 | 传感器阵列 + 模式识别 | 无损、整体风味/品质 | 需建模、受环境漂移影响 |

> **快检定位**：现场初筛与过程监控；**阳性/疑似阳性必须用标准确证方法（GC-MS/MS、LC-MS/MS 等）复核后方可判定**。

## 六、微生物检测

| 技术 | 原理 | 结果表达 | 适用 |
|---|---|---|---|
| 平板计数 | 活菌在培养基上形成菌落 | CFU/g、CFU/mL | 菌落总数、霉菌酵母、特定菌 |
| MPN（最可能数） | 系列稀释发酵管统计 | MPN/100 g、MPN/g | 大肠菌群、低浓度菌 |
| 显色培养基 | 特异性酶底物显色 | CFU/g | 快速鉴别（如大肠杆菌、沙门） |
| 免疫/生化鉴定 | 抗原/代谢特征 | 定性 | 菌种初筛 |
| PCR / qPCR | 核酸扩增（qPCR 定量） | 定性/定量（拷贝数） | 致病基因、快速筛查 |
| ddPCR（微滴数字 PCR） | 微滴分割绝对定量 | 拷贝数/体积 | 精确定量、低丰度 |
| 测序 / 宏基因组 | 核酸测序 | 序列/物种丰度 | 鉴定、溯源、菌群分析 |

**要点**
- 微生物样品须**无菌取样与操作**，防交叉污染；结果报告注明培养基、温度、培养时间与计数方式。
- 分子方法不能完全替代传统培养法用于法定判定（视标准要求，**待核实**）；阳性/可疑结果按标准要求确认。
- 致病菌检测按 GB 4789 系列与 GB 29921（预包装食品致病菌限量）执行（**版本待核实**）。

## 七、技术适用速查表

| 检测目标 | 首选技术 | 备选技术 | 前处理要点 |
|---|---|---|---|
| 农残多残留 | LC-MS/MS、GC-MS/MS | GC-ECD/NPD、酶抑制快检 | QuEChERS、SPE |
| 兽残（抗生素等） | LC-MS/MS | ELISA、微生物法 | 提取+SPE/QuEChERS |
| 真菌毒素 | LC-MS/MS、HPLC-FLD | ELISA、荧光快检 | 免疫亲和柱净化 |
| 重金属与有害元素 | ICP-MS | ICP-OES、AAS、AFS | 微波消解 |
| 添加剂/防腐剂/甜味剂 | HPLC-DAD、LC-MS/MS | 分光光度 | 提取、沉淀除蛋白 |
| 维生素 | HPLC-DAD/FLD、LC-MS/MS | 微生物法、分光光度 | 避光、皂化/酶解 |
| 功效/有效成分 | HPLC、LC-MS/MS | 分光光度、TLC | 超声/回流提取 |
| 脂肪酸/有机酸 | GC-FID、GC-MS | HPLC | 甲酯化/衍生化 |
| 蛋白质/氨基酸 | 凯氏定氮、HPLC、LC-MS | 分光光度 | 消解/水解 |
| 微生物 | 平板计数、MPN、qPCR | 显色培养基、测序 | 无菌均质、增菌 |
| 真伪/掺杂/溯源 | NIR、拉曼、稳定同位素、代谢指纹 | 高分辨质谱 | 无损或简单提取 |

## 八、联用与正交策略

| 联用技术 | 价值 |
|---|---|
| GC-MS / GC-MS/MS | 挥发物分离 + 质谱定性定量，可匹配谱库 |
| LC-MS/MS | 极性物痕量多残留首选确证 |
| LC-QTOF / LC-Orbitrap | 非靶向筛查、未知物鉴定、代谢物 |
| HPLC/IC-ICP-MS | 元素形态分析（As、Hg、Se、Cr 价态） |
| LC-NMR | 复杂结构解析（较少用） |
| 色谱 + 免疫亲和柱 | 毒素等高选择性净化与富集 |

**正交验证思路**：用原理不同的方法（如免疫法 + 质谱法）互为佐证；异常/争议结果用高分辨质谱确证。
