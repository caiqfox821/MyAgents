# 方法验证与质量控制

> 整理范围：方法验证参数与接受标准、方法确认/验证/转移、标准曲线、质控样、室内质控图与 Westgard 判异、能力验证与实验室间比对（z 比分数）、期间核查、原始记录与数据完整性（ALCOA+）、常见问题排查。
> 主要依据：GB/T 27404、GB/T 27417、GB/T 27025 / ISO/IEC 17025、CNAS 相关认可准则框架。
> 说明：文中接受标准为**经验/参考值**，实际以现行标准、确认指南与实验室质量文件为准；标准号与版本标注"（待核实，以现行版本为准）"。

---

## 一、方法验证参数与接受标准

### 1.1 参数总览

| 参数 | 含义 | 参考接受标准（经验，视含量水平调整） |
|---|---|---|
| 专属性/选择性（Specificity/Selectivity） | 共存物不干扰目标物 | 空白与干扰物处无干扰峰；分离度满足要求 |
| 线性与范围（Linearity/Range） | 响应与浓度关系、适用区间 | r² ≥ 0.995（痕量可 ≥ 0.99）；覆盖 0.5~2 倍限量/目标区间 |
| 准确度/回收率（Accuracy/Recovery） | 加标测定值与加标量之比 | 常 70%~120%（痕量可 60%~120%，视水平与标准） |
| 精密度-重复性（Repeatability） | 同条件短期一致 | %RSD ≤ 15%（痕量可 ≤ 20%） |
| 精密度-中间精密度（Intermediate） | 不同日/人/仪器 | %RSD 通常 ≤ 15%~20% |
| 精密度-再现性（Reproducibility） | 实验室间 | 用 HorRat 或标准规定评判 |
| 检出限/定量限（LOD/LOQ） | 可检出/可定量最低水平 | S/N≥3 / S/N≥10；或空白 SD 法 |
| 稳健性（Robustness） | 小变动不影响结果 | 变动后结果在可接受范围 |
| 基质效应（Matrix Effect） | 基质对响应影响 | 评估并校正（基质匹配/同位素内标） |
| 测量不确定度 | 结果分散性 | 评估主要来源，扩展 k=2 |
| 系统适用性（System Suitability） | 仪器系统状态 | 按方法（N、Rs、拖尾因子、RSD） |

> 回收率/精密度接受限与目标物浓度相关：浓度越低，允许的相对偏差越大（如 CODEX、欧盟 SANTE 指南按 μg/kg 分级给出范围）。**具体限值以现行标准/指南为准。**

### 1.2 验证层次

| 概念 | 定义 | 场景 |
|---|---|---|
| 方法确认（Verification） | 实验室证实能正确操作**已确立标准方法** | 引入标准方法时，做关键性能（准确度、精密度、LOQ 等） |
| 方法验证（Validation） | 证实**自建/非标方法**适用于预期用途 | 方法开发、新基质、非标方法 |
| 方法转移（Transfer） | 方法在实验室/仪器间转移并保持性能 | 多实验室、仪器更新、方法推广 |
| 方法再验证（Revalidation） | 条件变化后重新验证 | 关键参数变更、目标物/基质改变 |

### 1.3 方案设计要点

- **加标水平**：至少低、中、高三个水平，覆盖预期使用范围；低水平常接近 LOQ。
- **重复数**：每水平通常 ≥ 3~6 个平行（依标准要求）。
- **基质**：覆盖不同基质类型（含高脂/高色素/高蛋白等挑战性基质）。
- **对照**：空白、基质空白、溶剂标准、基质匹配标准。

## 二、标准曲线

### 2.1 类型

| 类型 | 配制 | 优点 | 局限 |
|---|---|---|---|
| 溶剂外标 | 纯溶剂配标 | 简单、快 | 受基质效应影响 |
| 基质匹配外标 | 空白基质配标 | 抵消基质效应 | 需空白基质 |
| 内标法 | 加内标（同位素最优） | 校正损失/基质/波动 | 内标选择与成本 |
| 标准加入法 | 样品中加标外推 | 无空白时可用 | 工作量大、线性要求高 |

### 2.2 回归与加权

- **最小二乘法**：考察斜率、截距、r²、残差分布。
- **加权回归**：当浓度范围宽、低端方差小/高端方差大（异方差）时，用 1/x 或 1/x² 加权，改善低端准确性。
- **截距检验**：截距显著不为 0 时，不可强行过原点；报告应说明。
- **残差诊断**：残差随机分布为佳；出现规律/弯曲 → 检查线性范围或模型。

### 2.3 校准管理

- 每批做**校准核查**（单点/多点），偏离超限须重校。
- 曲线有效期与核查频率写入质量文件。
- 记录：标准品来源、批号、纯度、称量、稀释链、仪器响应。

## 三、质量控制（QC）

### 3.1 每批质控

| 质控样 | 目的 | 频次建议 |
|---|---|---|
| 试剂空白 | 监控试剂/器皿/环境污染 | 每批 |
| 基质空白 | 监控基质本底 | 每批/每基质 |
| 加标回收样 | 监控准确度 | 每批（低/中水平） |
| 平行样 | 监控精密度 | 每批（≥ 10% 样品） |
| 标准物质/质控样（CRM/QC） | 监控准确度与溯源 | 定期或每批 |
| 校准曲线中间点核查 | 监控曲线漂移 | 每批 |
| 溶剂空白/仪器空白 | 监控系统污染 | 每序列 |

### 3.2 质控图与 Westgard 规则

- 以均值为中心线（CL），设置 ±2SD、±3SD 控制限；定期更新由足够数据估计的均值和 SD。
- **Westgard 多规则（常用）**：

| 规则 | 判异条件 | 含义 |
|---|---|---|
| 1₂ₛ | 1 个点超出 ±2SD | 警告 |
| 1₃ₛ | 1 个点超出 ±3SD | **失控**（随机误差） |
| 2₂ₛ | 连续 2 个点同侧超出 ±2SD | **失控**（系统误差） |
| R₄ₛ | 同批 2 点极差 > 4SD（一正一负） | **失控**（随机误差） |
| 4₁ₛ | 连续 4 个点同侧超出 ±1SD | **失控**（系统误差） |
| 10ₓ | 连续 10 个点同侧 | **失控**（系统误差） |
| 7ᴛ | 连续 7 个点递增或递减 | 趋势，需关注 |

> 失控处置：停止报告该批结果 → 查明原因（试剂、仪器、人员、环境）→ 纠正 → 重新分析并记录。Westgard 具体规则与限值须在质量文件中定义。

### 3.3 能力验证与实验室间比对

- **能力验证（PT, Proficiency Testing）**：由认可机构组织，用**z 比分数**评判：

| z 值范围 | 评价（参考） |
|---|---|
| \|z\| ≤ 2 | 满意 |
| 2 < \|z\| < 3 | 有问题（警告） |
| \|z\| ≥ 3 | 不满意（离群） |

- z = (x − 指定值) / 能力评定标准差；指定值可为参考值或参加者共识值。
- 不满意结果须分析原因、采取纠正措施，必要时重新参加。
- **实验室间比对**用于无合适 PT 计划时，评估实验室间一致性。

## 四、期间核查与量值溯源

- **期间核查**：对关键设备、标准物质、质控样在两次检定/校准之间进行，确认状态稳定；方法、频率与判据写入质量文件。
- **量值溯源**：标准物质应有证书与不确定度；天平、移液器、温度计、pH 计等定期检定/校准，形成溯源链。
- **标准物质管理**：等级（有证标准物质 CRM / 参考物质）、储存条件、有效期、使用记录。

## 五、原始记录与数据完整性

### 5.1 ALCOA+ 原则

| 要素 | 含义 |
|---|---|
| Attributable 可归因 | 记录谁做的、何时做的 |
| Legible 清晰 | 可读、不潦草、不涂改 |
| Contemporaneous 同步 | 操作当时记录 |
| Original 原始 | 原始数据或真实副本 |
| Accurate 准确 | 真实、无误、无篡改 |
| + Complete 完整 | 含所有数据（含异常/删除） |
| + Consistent 一致 | 时间顺序、审核痕迹一致 |
| + Enduring 持久 | 长期可读 |
| + Available 可获取 | 需要时可调阅 |

### 5.2 记录要求

- 记录**不可擦除、可追溯**；更正须划改并签名注明原因与日期，不得涂改/覆盖。
- 电子数据须有审计追踪、权限管理与备份。
- 图谱、原始数据、计算过程、质控数据一并留存，满足复核与复现。

## 六、常见问题排查

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 回收率偏离 | 前处理损失/基质效应/标准品问题 | 内标校正、优化前处理、核标准品 |
| 校准曲线线性差 | 浓度范围过宽、点配制误差、仪器漂移 | 缩小范围、加权回归、重新配标 |
| 质控样失控 | 试剂/仪器/人员/环境变化 | 溯源排查、纠正、重分析 |
| 空白偏高 | 试剂/器皿/环境污染 | 换试剂、酸洗器皿、做空白扣除 |
| 精密度差 | 操作不一致、仪器不稳、样品不均 | SOP 培训、维护仪器、充分均质 |
| 能力验证不满意 | 系统偏差、方法不当 | 根因分析、纠正、再参加 |
| 结果与复检不符 | 样品不均、方法差异、污染 | 复核流程、留样复测、方法比对 |
