# 标准规范与法规（检测分析）

> 整理范围：食品/农产品检测相关国家标准与法规索引——GB 5009 系列（理化检验）、GB 4789 系列（微生物检验）、GB 23200 系列（农残）、GB 31650（兽残）、GB 2760/2761/2762/2763（限量）、GB/T 27404/27417（质控与确认）、GB/T 27025 / ISO 17025、CNAS 认可准则（CL01 等）、CMA 资质认定（RB 系列）、抽样检验与机构监督管理办法，并附"检测方案/能力建设合规清单"。
> 主要依据：国家标准全文公开系统、全国标准信息公共服务平台、CFSA、CNAS、国家市场监管总局公开信息。
> 说明：**本文件仅为索引与框架**，不臆造标准版本号/年份/限量数值；所有具体指标、限量、版本号与实施日期**一律以官方平台现行有效版本为准**，不确定处标注"（待核实，以现行版本为准）"。

## 一、标准体系总览

| 层级 | 类型 | 示例 |
|---|---|---|
| 法律 | 食品安全法、农产品质量安全法 | 基本法 |
| 行政法规 | 农药管理条例、兽药管理条例等 | 配套法规 |
| 部门规章 | 抽样检验、机构资质认定与监督管理办法 | 市场监管总局/农业农村部令 |
| 强制性国标（GB） | 限量标准 + 检验方法 | GB 2760/2761/2762/2763/31650/29921、GB 5009/4789 |
| 推荐性国标（GB/T） | 方法、质控、确认、管理 | GB/T 27404、GB/T 27417、GB/T 27025 |
| 行业标准 | NY/T、SN/T、SB/T 等 | 农业农村/海关/行业方法 |
| 国际/国外 | ISO、AOAC、CAC/Codex、EU、US EPA | 等效性参考 |

> **强制性 GB 与推荐性 GB/T**：限量与安全指标通常为强制性；方法标准有强制性（GB）也有推荐性（GB/T）；使用前须确认现行有效性。

## 二、食品理化检验方法（GB 5009 系列）

GB 5009 系列为食品安全国家标准**理化检验方法**，覆盖成分、添加剂、污染物、毒素、营养强化剂等。

| 方向 | 典型内容（示例） | 备注 |
|---|---|---|
| 一般成分 | 水分、灰分、蛋白质、脂肪、膳食纤维、碳水化合物 | 凯氏定氮、索氏抽提等 |
| 元素与污染物 | Pb、Cd、As、Hg、Cr、Sn、Al 等 | AAS/ICP-MS/ICP-OES/AFS |
| 添加剂 | 防腐剂、甜味剂、着色剂、抗氧化剂 | HPLC/LC-MS/MS |
| 真菌毒素 | 黄曲霉毒素、脱氧雪腐镰刀菌烯醇、赭曲霉毒素等 | LC-MS/MS、HPLC-FLD、免疫法 |
| 维生素 | 脂溶/水溶性维生素 | HPLC、LC-MS/MS、微生物法 |
| 其他 | 亚硝酸盐、多环芳烃、氯丙醇、丙烯酰胺等 | 依具体标准 |

> 每一项指标对应一个（或多个）GB 5009 编号方法，**具体编号、年份与适用范围须逐条在国家标准全文公开系统核对**（待核实，以现行版本为准）。

## 三、微生物检验方法（GB 4789 系列）

GB 4789 系列为食品微生物学检验方法。

| 方向 | 典型项目 | 方法要点 |
|---|---|---|
| 卫生指标菌 | 菌落总数、大肠菌群、霉菌和酵母 | 平板计数、MPN |
| 致病菌 | 沙门氏菌、单核细胞增生李斯特菌、金黄色葡萄球菌、志贺氏菌、副溶血性弧菌、大肠埃希氏菌 O157 等 | 增菌+分离+生化/血清/分子确证 |
| 乳酸菌/益生菌 | 乳酸菌计数等 | 特定培养基与厌氧培养 |
| 其他 | 产气荚膜梭菌、蜡样芽胞杆菌、克罗诺杆菌等 | 依具体标准 |

**相关限量/判定**：GB 29921《预包装食品中致病菌限量》（**版本待核实**）；微生物采样方案常用 n、c、m、M（二级/三级采样）。

> 具体项目的 GB 4789 编号、增菌/分离培养基与判定，须以现行标准正文为准（待核实）。

## 四、农药残留（GB 23200 系列）

GB 23200 系列为食品安全国家标准**农药残留检测方法**，覆盖气相色谱、气相色谱-质谱、液相色谱-质谱等。

| 技术路线 | 适用 |
|---|---|
| GC / GC-MS / GC-MS/MS | 有机氯、有机磷、拟除虫菊酯等挥发/半挥发农残 |
| LC-MS/MS | 极性、热不稳定、多残留（含代谢物） |
| QuEChERS / SPE 前处理 | 果蔬、谷物、茶叶等 |

**相关限量**：GB 2763《食品安全国家标准 食品中农药最大残留限量》（**版本待核实**）及 GB 2763.1 等补充。

> 方法编号、目标物清单、多残留分组须逐条核对现行版本（待核实）。

## 五、兽药残留（GB 31650 等）

| 文件 | 内容 |
|---|---|
| GB 31650《食品安全国家标准 食品中兽药最大残留限量》 | 兽药 MRL 与部分禁用/停用规定（**版本及是否有补充文件待核实**） |
| GB 31650.1 等 | 兽药残留相关方法或补充（**编号/范围待核实**） |
| 农业农村部公告 | 禁用/停用兽药清单、最大残留限量补充（**公告号待核实**） |
| 检测方法 | 多采用 LC-MS/MS；部分用微生物法/免疫法初筛 |

**相关法规**：《兽药管理条例》（**修订版本待核实**）；动物性食品中兽药残留监控计划。

## 六、污染物、毒素与添加剂限量（GB 2760/2761/2762/2763 等）

| 标准 | 主题 | 说明 |
|---|---|---|
| GB 2760 | 食品添加剂使用标准 | 允许品种、使用范围与最大使用量/残留量（**以现行版本为准**） |
| GB 2761 | 食品中真菌毒素限量 | 黄曲霉毒素、脱氧雪腐镰刀菌烯醇、赭曲霉毒素 A 等 |
| GB 2762 | 食品中污染物限量 | Pb、Cd、As、Hg、Sn、Cr、苯并[a]芘、N-亚硝胺等 |
| GB 2763 | 食品中农药最大残留限量 | 农残 MRL 与检测方法索引 |
| GB 31650 | 食品中兽药最大残留限量 | 兽残 MRL |

| GB 2760 相关 | 食品营养强化剂使用标准等 | 营养强化剂 |

> **限量一律不在此臆造**；判定时以现行标准文本中的具体数值、食品类别与备注为准（待核实，以现行版本为准）。

## 十一、检测方案/能力建设合规清单

### 11.1 检测方案合规清单

- [ ] 明确检测对象、目标物、基质与结果用途（合规/研发/监测）
- [ ] 选择**现行有效**的标准方法（核对标准号+年份+适用范围）
- [ ] 确认方法适用基质与目标物，必要时做方法确认/验证
- [ ] 制定前处理与仪器条件，评估基质效应与不确定度
- [ ] 确定 LOD/LOQ、回收率与精密度接受标准
- [ ] 设计质控方案（空白/加标/平行/CRM/校准核查）
- [ ] 核对限量依据（GB 2760/2761/2762/2763/31650/29921 等）
- [ ] 结果表达：单位、LOD、不确定度、与限量比较
- [ ] 样品与记录可追溯，满足数据完整性要求

### 11.2 能力建设合规清单

- [ ] 组织与人员：公正性、授权、培训与能力评价
- [ ] 设备与量值溯源：校准/检定、期间核查
- [ ] 设施环境：满足方法要求并监控
- [ ] 方法管理：现行有效、验证/确认、偏离受控
- [ ] 样品管理：抽样、标识、流转、储存、留样
- [ ] 结果有效性：质控、能力验证、比对
- [ ] 报告与标识：要素完整、授权签发、CMA/CNAS 标识合规
- [ ] 体系运行：内审、管评、不符合与纠正、风险管理
- [ ] 法规符合：抽样检验、机构监督、安全管理
- [ ] 资质维护：CMA 复查/换证、CNAS 监督/复评
