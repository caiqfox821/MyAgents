# 数据处理与不确定度

> 整理范围：数据统计基础、校准与回归、检出限/定量限计算、回收率与基质效应校正、测量不确定度评定（GUM 流程）、显著性检验与方法比对、有效数字与结果表达。
> 主要依据：ISO/IEC Guide 98-3（GUM）、JJF 1059、GB/T 27404/27417、分析化学统计方法。
> 说明：文中公式与数值为**通用方法与示例**，示例中的假设值仅用于演算说明，不代表真实数据；标准号与版本标注"（待核实，以现行版本为准）"。

---

## 一、数据统计基础

### 1.1 常用统计量

| 统计量 | 公式/说明 | 用途 |
|---|---|---|
| 均值 \bar{x} | Σxᵢ / n | 中心位置 |
| 标准差 s | √[Σ(xᵢ−\bar{x})² / (n−1)] | 分散程度（样本） |
| 相对标准偏差 %RSD | (s / \bar{x}) × 100% | 精密度表达 |
| 中位数 | 排序后中间值 | 抗异常值 |
| 极差 R | 最大值 − 最小值 | 快速离散度 |
| 标准误 SEM | s / √n | 均值的不确定度 |
| 置信区间 CI | \bar{x} ± t·s/√n | 均值的区间估计（t 依自由度、置信水平） |

### 1.2 异常值判别

| 方法 | 适用 | 要点 |
|---|---|---|
| Grubbs 检验 | 单侧/双侧单个异常值 | 计算 G 统计量，与临界值比较 |
| Dixon（Q）检验 | 小样本单个异常值 | 计算差距比 |
| Cochran 检验 | 多组方差中最大方差组 | 用于实验室间精密度检验 |
| 箱线图 / 1.5 IQR | 探索性筛查 | 直观，标注可疑点 |

> 异常值**不得随意剔除**：须查明技术原因（记录错误、污染、仪器故障），有根据方可剔除并在报告中说明；统计剔除须注明方法。

## 二、校准与回归

### 2.1 最小二乘回归

对 y = a + bx，用最小二乘法估计斜率 b 与截距 a：

- b = Σ[(xᵢ−\bar{x})(yᵢ−\bar{y})] / Σ(xᵢ−\bar{x})²
- a = \bar{y} − b·\bar{x}
- 决定系数 r² = 1 − SS_res/SS_tot

**诊断**
- 残差图：残差随机分布为佳；系统弯曲 → 非线性或范围不当。
- 截距显著性：t 检验判断截距是否显著不为 0。
- 杠杆点/影响点：谨慎处理高杠杆标准点。

### 2.2 加权回归

当浓度范围宽、方差随浓度变化（异方差）时，采用加权最小二乘，权重常取 w = 1/x 或 1/x²，提升低端准确度。

### 2.3 由曲线求浓度与不确定度

- 反推浓度 x = (y − a) / b。
- 曲线引入的不确定度与斜率、截距、响应重复性及标准点数量有关，可经公式或自助法（bootstrap）估计。

## 三、检出限与定量限

### 3.1 常用计算法

| 方法 | 公式/说明 | 适用 |
|---|---|---|
| 信噪比法 | LOD: S/N = 3；LOQ: S/N = 10 | 色谱/光谱直观估计 |
| 空白标准差法 | LOD = 3·s_blank；LOQ = 10·s_blank（s_blank 为空白多次测定 SD） | 空白可测、本底稳定 |
| 校准曲线法 | LOD = 3·s_y/b；LOQ = 10·s_y/b（s_y 为曲线残差 SD，b 为斜率） | 有校准曲线 |
| 低浓度加标法 | 能可靠检出的最低加标浓度，经多批验证 | 方法验证常用 |
| IUPAC 定义 | 与判据（α、β 错误）关联 | 严格统计定义 |

### 3.2 报告与判定

- **未检出（< LOD）**：结果表述为"未检出"并注明 LOD；不得写"0"。
- **低于 LOQ**：可表述"检出但低于定量限（< LOQ）"，不定量或作半定量并说明。
- LOD/LOQ 须与方法、基质、仪器状态绑定；换基质/方法应重新评估。
- 不同实验室/方法 LOD 不可直接比较。

## 四、回收率与基质效应校正

### 4.1 回收率

- 回收率 R(%) = (加标样品测定值 − 本底值) / 加标量 × 100%。
- 回收率用于**评价准确度**，可对结果做回收率校正（是否校正须按方法/标准规定并在报告中声明）。
- **同位素内标法**：以内标响应比定量，同时校正回收与基质效应，痕量定量首选。

### 4.2 基质效应因子

- ME(%) 或 ME 因子 = 基质匹配标液响应 / 纯溶剂标液响应。
- ME ≈ 1（100%）无显著效应；< 1 抑制；> 1 增强。
- 对策见《样品前处理》第六章。

### 4.3 校正策略选择

| 策略 | 何时用 |
|---|---|
| 外标法 | 基质简单、效应小 |
| 基质匹配外标 | 有空白基质、效应中等 |
| 同位素内标 | 痕量、复杂基质、要求高准确度 |
| 标准加入法 | 无空白基质、基质极复杂 |

## 五、测量不确定度评定（GUM 流程）

### 5.1 评定步骤

1. **定义被测量**：明确测量对象、公式与结果单位。
2. **识别不确定度来源**：人、机、料、法、环、测各环节。
3. **量化各分量**：A 类（统计）与 B 类（证书/经验/假设分布）。
4. **合成**：合成标准不确定度 u_c。
5. **扩展**：U = k·u_c，常取 k = 2（约 95% 置信）。
6. **报告**：结果 ± U（单位），并说明包含因子与置信水平。

### 5.2 A 类与 B 类

| 类别 | 来源 | 评定 |
|---|---|---|
| A 类 | 重复测量、曲线拟合残差 | 统计方法（SD / √n） |
| B 类 | 校准证书、标准品纯度、量具体积、温度、方法偏差 | 依证书/经验转换为标准不确定度（均匀分布常除 √3） |

### 5.3 常见来源与贡献

| 来源 | 说明 |
|---|---|
| 取样 | 样品不均、抽样偏差 |
| 前处理 | 提取/净化损失、衍生化不完全、定容 |
| 称量 | 天平校准与分辨率 |
| 体积 | 移液器、容量瓶校准与温度 |
| 标准品 | 纯度、称量、稀释链 |
| 校准曲线 | 斜率/截距、拟合残差 |
| 回收率 | 不完全回收 |
| 基质效应 | 响应偏差 |
| 重复性 | 随机误差 |
| 仪器 | 漂移、校准 |

### 5.4 合成与扩展

对不相关分量：

u_c = √(u₁² + u₂² + … + uₙ²)

U = k·u_c（k = 2）

**相对贡献度**：各分量 (uᵢ/u_c)² ×100%，用于识别主导来源并改进。

### 5.5 示例演算（**假设值，仅示意**）

设某方法测量结果 x = 1.00 mg/kg，各相对标准不确定度分量（假设）：

| 分量 | 相对标准不确定度 u_rel |
|---|---|
| 重复性 | 2.0% |
| 标准品纯度 | 1.0% |
| 称量 | 0.5% |
| 定容体积 | 0.8% |
| 校准曲线 | 1.5% |
| 回收率 | 3.0% |

合成相对不确定度：
u_c,rel = √(0.020² + 0.010² + 0.005² + 0.008² + 0.015² + 0.030²)
≈ √(0.0004 + 0.0001 + 0.000025 + 0.000064 + 0.000225 + 0.0009)
≈ √0.001714 ≈ 0.0414 ≈ 4.1%

扩展不确定度（k=2）：U ≈ 8.3%，即结果约 **1.00 ± 0.08 mg/kg**（k=2）。

> 以上为**演示性假设数据**，不构成任何实际方法的性能结论。

### 5.6 与限量比较的判定

- 结果接近限量时，应结合不确定度评估合规/超标的稳健性，避免临界误判。
- 判定规则（如"结果 > 限量 + U 才判超标"或按法规规定的判定原则）须依**监管规定/标准**，不得自行设定（**待核实**）。

## 六、显著性检验与方法比对

| 检验 | 用途 | 要点 |
|---|---|---|
| t 检验（单样本/配对） | 均值与参考值比较、方法间配对比较 | 配对 t 检验消除样品间差异 |
| 双样本 t 检验 | 两组均值比较 | 注意方差齐性 |
| F 检验 | 两组方差比较 | 精密度比较 |
| 单因素/多因素 ANOVA | 多组均值比较 | 因素效应分析 |
| 回归/Passing-Bablok | 两方法一致性 | 斜率/截距与 1/0 比较 |
| Bland-Altman | 两方法一致性 | 偏差与一致性界限 |
| 等效性检验（TOST） | 判定方法等效 | 预设等效限 |

**方法比对建议**：用同一批样品在两种方法上平行测定，做配对 t / 回归 / Bland-Altman；差异应小于预设等效限方可判定等效。

## 七、有效数字与结果表达

- **有效数字**：由测量不确定度决定，通常保留至与扩展不确定度末位对齐。
- **修约规则**：按 GB/T 8170（数值修约规则，**版本待核实**）执行。
- **结果表达**：
  - 带单位（μg/kg、mg/kg、mg/L、%RSD、CFU/g、MPN/100 g 等）。
  - 报告：结果 ± 扩展不确定度（k=2），并注明 LOD/LOQ。
  - 未检出写"未检出（< LOD，LOD = …）"，不写"0"。
  - 区分"检出"与"超标"；超标结论须与法规限量比较并考虑不确定度。
- **数据取舍**：不得选择性报告；异常值处理与校正均须记录并说明。
