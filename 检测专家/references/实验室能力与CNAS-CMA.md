# 实验室能力与 CNAS/CMA

> 整理范围：质量管理体系（ISO/IEC 17025、ISO 9001、CMA 资质认定）、体系要素（组织人员/设备溯源/设施环境/方法确认/抽样/样品/技术记录/报告/投诉/不符合与纠正/内审与管理评审/风险管理）、能力验证、质量监督与人员能力、CNAS 与 CMA 区别、申请流程与常见不符合项、实验室安全与危化品/废弃物管理。
> 主要依据：ISO/IEC 17025（GB/T 27025）、CNAS-CL01 系列认可准则、检验检测机构资质认定（CMA）相关管理办法与通用要求（RB 系列）。

## 一、质量管理体系概览

### 1.1 三大体系定位

| 体系 | 性质 | 对象 | 关系 |
|---|---|---|---|
| ISO/IEC 17025（GB/T 27025） | 实验室能力通用要求 | 检测/校准实验室 | 能力认可（CNAS）的技术基础 |
| ISO 9001 | 质量管理体系要求 | 各类组织 | 通用质量管理，非实验室专用 |
| CMA 资质认定 | 中国行政许可/资质 | 检验检测机构 | 依法出具**具有证明作用**数据的法定资质 |

> 17025 强调**技术能力**（方法、人员、设备、溯源、结果质量）；ISO 9001 强调**质量管理过程**；CMA 是中国的**法定市场准入**资质。

## 二、ISO/IEC 17025 体系要素

### 2.1 结构（通用要求）

| 板块 | 主要内容 |
|---|---|
| 通用要求 | 公正性、保密性 |
| 结构要求 | 法律实体、组织与管理、职责 |
| 资源要求 | 人员、设施与环境、设备、计量溯源性、外部提供的产品与服务 |
| 过程要求 | 要求/标书/合同评审、方法选择验证确认、抽样、样品处置、技术记录、测量不确定度评定、结果有效性保证、报告结果、投诉、不符合工作、数据控制与信息管理 |
| 管理要求 | 体系文件、文件控制、记录控制、应对风险和机遇的措施、改进、纠正措施、内部审核、管理评审 |

### 2.2 关键要素要点

**组织与人员**
- 明确法律地位与组织架构，保证**公正性、独立性、保密性**，识别并管理利益冲突。
- 人员：能力要求、培训、授权（上岗证）、监督、能力监控与评价；关键岗位（技术负责人、质量负责人、授权签字人）职责清晰。

**设备与量值溯源**
- 设备台账、唯一性标识、校准/检定计划、期间核查、维护与故障处理。
- **量值溯源**：通过有证标准物质（CRM）与经校准的测量设备溯源至国家/国际基准；出具溯源链。
- 设备使用前确认满足要求；影响结果的设备须校准并标识状态。

**设施与环境**
- 满足方法要求（温湿度、洁净、供电、通风、防振、防交叉污染）；必要时监控并记录。
- 区域划分（样品接收、前处理、仪器、试剂、微生物无菌区）；微生物与痕量分析注意交叉污染。

**方法选择、验证与确认**
- 优先现行有效标准方法；非标/自建方法须验证；标准方法引入须确认。
- 方法偏离须经技术判断、授权并告知客户（必要时）。

**抽样、样品处置**
- 抽样方案与程序文件化；样品标识、状态、流转、储存与处置记录完整。
- 样品接收检查、唯一编号、防混淆与防污染。

**技术记录与数据控制**
- 记录及时、可追溯、防篡改；电子记录有审计追踪与权限管理。
- 数据完整性遵循 ALCOA+（见《方法验证与质量控制》）。

**结果有效性与报告**
- 结果有效性：质控样、能力验证、比对、复测、核查。
- 报告要素：委托方、样品信息、方法依据、结果与单位、LOD/LOQ、不确定度、判定结论、签发人、日期、公章/资质标识。
- 结果发布前经授权签字人审核签发。

**不符合工作、纠正措施、改进**
- 不符合识别 → 处置与影响评估（必要时暂停/召回报告）→ 根因分析 → 纠正措施 → 验证有效性。
- 持续改进：利用质控、内审、管理评审、客户反馈、风险分析。

**内部审核与管理评审**
- 内审：覆盖体系全要素，由具备资格且独立于被审活动的人员实施；形成报告与不符合项跟踪。
- 管理评审：最高管理者主持，评审体系适宜性/有效性/充分性，输入输出形成文件。

**应对风险与机遇**
- 识别影响结果与体系的风险，制定措施并评估有效性（风险登记表/措施跟踪）。

## 三、能力验证、质量监督与人员评价

| 活动 | 目的 | 要点 |
|---|---|---|
| 能力验证（PT） | 评价实验室特定项目能力 | z 比分数评判（见另文）；不满意须纠正并再参加 |
| 实验室间比对 | 无 PT 时的补充 | 评估一致性 |
| 内部质控 | 日常监控 | 质控图、加标、平行、CRM |
| 质量监督 | 监控人员与方法执行 | 现场观察、记录检查、盲样 |
| 人员能力评价 | 授权与持续胜任 | 培训+考核+监督+盲样；定期复评 |

- **授权签字人**：具备相应技术能力与资格，经考核授权，对报告技术内容负责。
- **关键岗位备份**：防止人员离职导致能力中断。

## 四、CNAS 与 CMA 的区别与衔接

| 维度 | CNAS 认可 | CMA 资质认定 |
|---|---|---|
| 性质 | 自愿性、能力认可（国际互认） | 强制性/行政许可（中国境内法定） |
| 依据 | ISO/IEC 17025、CNAS 认可准则 | 资质认定管理办法 + RB/T 通用要求 |
| 对象 | 实验室（检测/校准） | 检验检测机构 |
| 目的 | 证明技术能力，获国际互认 | 依法出具具有证明作用的数据/结果 |
| 标识 | CNAS 认可标识 | CMA 标志（**依法取得后可标注**） |
| 有效期 | 通常有期限，需复评 | 有期限，需复查/换证（**期限待核实**） |
| 监管部门 | CNAS（认可委员会） | 市场监管部门 |

**衔接要点**
- 两者要求高度重叠（组织、人员、设备、溯源、方法、记录、报告、内审、管评），可**一体化建设**、避免两张皮。
- 取得 CMA 是依法开展**向社会出具具有证明作用数据**活动的前提；CNAS 是能力与互认的体现。
- 标识使用须符合对应规则，不得超范围、超能力使用。

## 五、认可/认定申请流程与常见不符合项

### 5.1 通用流程（参考）

1. 体系建立与运行（文件发布、人员培训、设备溯源、方法确认、内审、管评）。
2. 运行满足规定时间（如体系运行 ≥ 数月）并完成内审与管评。
3. 提出申请，提交质量手册、程序文件、能力范围、人员/设备清单、典型报告等。
4. 受理与文件评审。
5. 现场评审（含见证试验、人员考核、设备溯源核查、记录抽查）。
6. 不符合整改与跟踪验证。
7. 批准发证；后续监督评审/复评。

> 具体时限、材料清单与流程以**CNAS/市场监管部门现行规则**为准（**待核实**）。

### 5.2 常见不符合项（经验归纳）

| 类别 | 典型问题 |
|---|---|
| 人员 | 授权/培训记录缺失、能力监控不足、关键岗位空缺 |
| 设备 | 未校准/超期、溯源链不完整、期间核查缺失、状态标识不清 |
| 环境 | 温湿度未监控、交叉污染风险、微生物区不符 |
| 方法 | 未验证/确认、偏离未授权、版本失效仍在用 |
| 记录 | 涂改、缺签名/日期、电子数据无审计追踪、原始记录不全 |
| 质控 | 质控样缺失、失控未处置、能力验证不满意未纠正 |
| 报告 | 信息不全、不确定度缺失、超范围、标识使用不当 |
| 体系 | 内审/管评流于形式、纠正措施无根因与验证、文件不受控 |
| 样品 | 标识/流转不清、储存条件不符、留样不规范 |

## 六、实验室安全与危化品/废弃物管理

| 方面 | 要点 |
|---|---|
| 安全责任 | 明确安全责任人；安全培训与应急预案 |
| 危化品 | 分类储存（酸碱/氧化剂/易燃/剧毒分区）、台账、双人双锁（剧毒/易制爆）、MSDS 可及 |
| 易制毒/易制爆 | 按法规备案与管控（**以公安/应急管理要求为准**） |
| 气瓶 | 固定、分类、防泄漏、定期检验；氢/乙炔等注意防爆 |
| 通风与防护 | 通风橱、护目镜、手套、实验服、洗眼器、应急喷淋 |
| 废弃物 | 分类收集（有机废液、无机废液、含重金属、生物废弃物）；委托有资质单位处置并留台账 |
| 生物安全 | 微生物实验室按生物安全等级要求运行与灭菌 |
| 辐射/特种设备 | 依相关法规管理 |
| 记录 | 安全检查、培训、事故、废弃物处置记录保存 |
