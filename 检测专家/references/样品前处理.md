# 样品前处理

> 整理范围：采样与制样、提取（索氏/超声/微波/ASE/超临界 CO₂/QuEChERS/液液萃取）、净化（SPE/GPC/分散净化/凝胶）、衍生化、元素消解、基质效应与对策、按目标物分类的前处理速查方案。
> 主要依据：样品前处理通用原理与 GB 5009 / GB 23200 / GB 4789 等方法框架中的前处理章节。
> 说明：文中溶剂配比、温度、时间、体积为**经验/参考量级**，实际以现行标准方法正文与实验室验证为准；标准号与版本标注"（待核实，以现行版本为准）"。

## 一、采样与制样

### 1.1 采样原则

| 原则 | 要点 |
|---|---|
| 代表性 | 覆盖批次的时空分布；分层/随机；避免只取表层或单点 |
| 最小样品量 | 满足检测最小取样量 + 平行 + 加标 + 复检备份 + 留样 |
| 防止污染 | 洁净惰性器具（不锈钢、玻璃、PTFE）；不用含目标物或干扰物的容器 |
| 防损失/变化 | 避光、低温、防挥发、防吸湿、防微生物繁殖；及时处理 |
| 程序可追溯 | 记录抽样依据、编号、基数、时间、地点、封样状态、交接 |

### 1.2 制样与缩分

- **均质化**：固体样品粉碎/研磨/匀浆，液体样品混匀；高脂/高水分样品注意分层。
- **缩分**：按标准方法用分样器或四分法缩分，保证子样代表母样。
- **防交叉污染**：每样之间清洗/更换刀头、容器；粉碎机定期空白检查。
- **特殊基质**：
  - 谷物/油料：粉碎后过筛，注意油脂氧化。
  - 果蔬：匀浆后冷冻保存，测农残时避免酶解。
  - 肉类/水产：绞碎混匀，注意脂肪分布不均。
  - 乳品：混匀后取样，测微生物时无菌操作。

### 1.3 储存条件（参考）

| 样品/目标物 | 参考储存 |
|---|---|
| 易腐食品、微生物样品 | 0~4 ℃ 短期；冷冻 ≤ −18 ℃ 长期；微生物样品冷藏并尽快检测 |
| 农残/兽残/毒素 | 冷冻或冷藏、避光；部分目标物需避光防降解 |
| 元素样品 | 洁净容器，防吸附/污染；酸化保存（视元素） |
| 挥发/易氧化组分 | 低温、密闭、避光、尽快分析 |
| 水分/易吸湿 | 干燥器或密封，防吸湿 |

> 储存时限依目标物稳定性与标准要求，**以方法正文/作业指导书为准**。

## 二、提取技术

### 2.1 技术对比

| 技术 | 原理 | 优点 | 局限 | 典型应用 |
|---|---|---|---|---|
| 索氏提取（Soxhlet） | 溶剂回流循环 | 提取完全、经典 | 耗时长、溶剂多 | 脂肪、脂溶性目标物 |
| 超声辅助提取（UAE） | 空化作用 | 快速、设备简单 | 效率受功率/温度影响 | 农残、有效成分 |
| 微波辅助提取（MAE） | 微波加热 | 快、省溶剂 | 需控温、设备 | 有机物、元素（微波消解） |
| 加速溶剂萃取（ASE） | 高温高压溶剂 | 快、省溶剂、自动化 | 设备成本 | 农残、环境污染物 |
| 超临界 CO₂（SFE） | 超临界流体溶解 | 绿色、选择性可调 | 需设备、对极性物弱 | 脂溶性、风味、农残 |
| QuEChERS | 盐析 + 分散净化 | 快速、通用、批量 | 净化能力有限 | 农残多残留 |
| 液液萃取（LLE） | 溶剂分配 | 通用、简单 | 乳化、溶剂多 | 半挥发/极性目标物 |
| 固相萃取（SPE） | 固相吸附-洗脱 | 净化+富集 | 需优化柱型 | 兽残、毒素、添加剂 |
| 顶空/吹扫捕集 | 气相富集 | 无溶剂、适合挥发物 | 仅挥发物 | 残留溶剂、风味 |

### 2.2 提取溶剂选择原则

- **相似相溶**：非极性目标物→正己烷/乙酸乙酯/二氯甲烷；极性目标物→甲醇/乙腈/水。
- **提取效率 vs 共提取**：溶剂越强提取越完全，但共提取杂质越多，净化负担越重。
- **酸碱调节**：离子型/酸碱敏感目标物需调 pH 提高中性分子比例（如碱化提取酚类、酸化提取酸性农残）。
- **盐析**：加入 NaCl/MgSO₄ 促相分离、提高回收。
- **内标加入时机**：**同位素内标应在提取前加入**，校正提取与净化损失。

### 2.3 QuEChERS 流程（参考）

1. **提取**：均质样品 + 乙腈（可含 1% 乙酸）+ 盐包（MgSO₄ + NaCl 等），振荡、离心。
2. **分散固相净化（d-SPE）**：上清液 + MgSO₄ + PSA（去糖/有机酸/色素）+ C18/GCB（去脂/色素）。
3. **过滤/稀释**后进样（LC-MS/MS 或 GC-MS/MS）。

> 盐包/净化剂配比与 pH 依目标物类别（如酸性农残需缓冲盐包）调整，**以现行标准方法为准**。

## 三、净化技术

| 技术 | 原理 | 常用柱型/材料 | 适用 |
|---|---|---|---|
| 固相萃取（SPE） | 吸附-洗脱 | C18、C8、PSA、NH₂、HLB、SCX/SAX、硅胶、弗罗里硅土 | 兽残、毒素、添加剂 |
| 分散固相萃取（d-SPE） | 吸附剂分散于提取液 | PSA、C18、GCB、Z-Sep | QuEChERS 净化 |
| 免疫亲和柱（IAC） | 抗体特异捕获 | 单克隆抗体柱 | 真菌毒素等高选择性净化 |
| 凝胶渗透色谱（GPC） | 按分子大小分离 | 交联葡聚糖/聚苯乙烯凝胶 | 去大分子（脂、色素、蛋白） |
| 分子印迹（MISPE） | 模板特异识别 | 分子印迹聚合物 | 特定目标物富集 |
| 液液分配净化 | 分配系数差异 | 溶剂体系 | 去脂、去极性干扰 |
| 低温冷冻净化 | 脂肪低温析出 | — | 高脂样品辅助净化 |

**SPE 通用步骤**：活化 → 上样 → 淋洗（去干扰） → 洗脱（目标物） → 浓缩/复溶。

> 柱型、上样量、洗脱溶剂与体积须按目标物与基质优化并验证。

## 四、衍生化

### 4.1 目的

- 提高挥发性（GC）、热稳定性、检测灵敏度（荧光/紫外/质谱响应）或改善色谱行为。

### 4.2 GC 衍生化

| 反应 | 试剂（示例） | 目标基团 |
|---|---|---|
| 硅烷化 | MSTFA、BSTFA、TMS 试剂 | —OH、—COOH、—NH₂ |
| 酰化 | 乙酸酐、三氟乙酸酐（TFAA） | —OH、—NH₂ |
| 酯化 | 甲醇/三氟化硼、重氮甲烷 | 脂肪酸、有机酸 |
| 烷基化 | 烷基卤 | 酚、酸 |

### 4.3 LC 衍生化

| 目的 | 试剂类别 | 应用 |
|---|---|---|
| 荧光标记 | 丹磺酰氯、OPA、FMOC | 氨基酸、胺类、毒素 |
| 紫外标记 | 苯甲酰氯、PITC | 氨基酸、胺类 |
| 提高质谱响应 | 电荷/疏水标签 | 痕量代谢物 |

> 衍生化须做**衍生完全性**与**稳定性**考察；空白与试剂本底需监控。

## 五、元素分析消解

| 方法 | 原理 | 优点 | 注意 |
|---|---|---|---|
| 湿法消解 | 强酸（HNO₃/HClO₄/H₂SO₄）+ H₂O₂ 加热 | 通用、设备简单 | 高氯酸易爆、需控温；Hg/As 易挥发损失 |
| 微波消解 | 密闭高压 + 微波 | 快速、损失小、空白低 | 需控压控温；加酸量/程序需优化 |
| 干灰化 | 高温灰化后酸溶 | 适合大量有机基质 | 高温致 Hg/As/Se 损失；需灰助剂 |
| 高压罐消解 | 密闭 + 外加热 | 减少挥发损失 | 操作繁琐 |

**要点**
- 使用优级纯/电子级酸，做试剂空白；容器酸洗去污染。
- 消解完全判据：溶液澄清、无残渣（视基质）。
- 测 Hg 宜用微波消解/密闭体系并加稳定剂；测 As 注意价态与氢化物发生条件。
- 消解液定容后尽快测定，防吸附/沉淀。

## 六、基质效应与对策

### 6.1 基质效应的来源与表现

- 共提取物在离子源中与目标物竞争电荷/影响喷雾 → **离子抑制或增强**（LC-MS/MS 常见）。
- GC 进样口活性位点吸附 → 峰形变差、响应降低。
- 结果偏差：外标定量在基质中偏离真实值。

### 6.2 评估方法

| 方法 | 说明 |
|---|---|
| 基质效应因子（ME） | ME = 基质匹配标液响应 / 纯溶剂标液响应；ME≈1 无效应，<1 抑制，>1 增强 |
| 后柱注入法 | 比较基质与溶剂中响应 |
| 提取后加标法 | 评价提取后基质影响 |

### 6.3 对策

| 对策 | 适用 |
|---|---|
| 基质匹配标准曲线 | 通用、最实用 |
| 同位素内标 | 痕量定量首选，校正基质与回收 |
| 稀释 | 降低基质浓度（注意牺牲灵敏度） |
| 标准加入法 | 无空白基质时 |
| 改善净化 | 减少共提取物 |
| 切换电离源/流动相 | 改变离子化行为 |

## 七、按目标物的前处理速查

| 目标物 | 提取 | 净化 | 备注 |
|---|---|---|---|
| 农药多残留 | 乙腈/乙酸乙酯；QuEChERS | d-SPE（PSA/C18/GCB） | 酸性/碱性农残选相应缓冲盐包 |
| 兽药残留（抗生素、激素） | 乙腈/缓冲液 + 酶解 | SPE（HLB/C18）、QuEChERS | 部分需 β-葡萄糖醛酸酶解 |
| 真菌毒素 | 甲醇/水或乙腈/水 | 免疫亲和柱、SPE | 避光；黄曲霉毒素需衍生/FLD |
| 食品添加剂/防腐剂 | 水/甲醇超声 | 沉淀蛋白、SPE | 注意基质与 pH |
| 甜味剂/色素 | 水/甲醇/乙醇 | 聚酰胺/SPE | 色素可先脱脂 |
| 重金属/有害元素 | 微波消解/湿法 | — | 内标校正、防污染 |
| 维生素 | 酶解/皂化/超声 | SPE、稀释 | 避光、防氧化；脂溶/水溶分别处理 |
| 功效成分/有效成分 | 甲醇/乙醇/水超声或回流 | SPE、稀释 | 依极性选柱 |
| 生物胺 | 酸提取（如 HClO₄/TCA） | 衍生 + SPE/LLE | GC/LC 衍生化 |
| 亚硝酸盐/硝酸盐 | 水/硼砂提取 | 沉淀蛋白、除脂 | 显色或 IC |
| 脂肪酸 | 脂质提取（氯仿-甲醇） | 甲酯化 | GC-FID |
| 残留溶剂/挥发物 | 顶空/吹扫捕集 | — | GC |
| 过敏原/蛋白 | 缓冲液提取 | 免疫法/LC-MS | 注意变性与基质 |

> 上表为**方向性速查**，具体溶剂、体积、时间、净化顺序以**现行标准方法正文**为准。

## 八、常见问题排查

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 回收率偏低 | 提取不足、净化损失、降解、吸附 | 优化溶剂/pH、控温、加内标、减少净化步骤 |
| 回收率偏高 | 基质增强、共流出、污染 | 基质匹配、加强净化、做空白 |
| 重复性差 | 均质不足、相分离不全、蒸发损失 | 充分均质、控温离心、定容准确 |
| 乳化 | 高脂/表面活性基质 | 加盐、离心、冷冻、改用 SPE |
| 基质抑制严重 | 共提取物多 | 稀释、SPE、同位素内标、切换源 |
| 色谱峰形差 | 进样口活性、柱污染、溶剂强度不当 | 去活衬管、换柱、调整复溶溶剂 |
| 空白本底高 | 试剂/器皿/环境污染 | 优级试剂、酸洗器皿、做试剂空白 |
| 目标物不稳定 | 光/热/氧/酶解 | 避光、低温、加抗氧化剂、当日处理 |
