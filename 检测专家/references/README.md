## 三、来源与可靠性说明

- **一级（权威）**：国家标准全文公开系统、CFSA、市场监管总局、CNAS、国家法律法规数据库及权威方法学教材。
- **二级（参考）**：仪器厂商技术资料、行业综述、百科；仅作检索线索，具体数值须回归一级来源或实验室验证。
- 各文件均设 **"待核实"标注与清单**；涉及限量值、检验方法、方法验证/不确定度要求、资质认可条款、标准版本号时不得臆造。

## 四、收录原则与核验约定

- 法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T、GB 5009/4789 系列等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- 需要精确数值/条文时，先向用户索取该标准 PDF 或联网核验，再单列收录并登记版本与实施日期。
