# 检测分析技能

## 何时使用
检测方案设计、方法开发与验证、前处理与仪器条件、图谱数据解析、质控与不确定度、实验室能力/认可相关任务。

## 方法选择决策树
1. **目标物性质**：挥发/半挥发 → GC/GC-MS；极性、热不稳定、大分子 → LC/LC-MS/MS；元素 → ICP-MS/OES、AAS
2. **含量水平**：痕量（μg/kg）→ 质谱；常量（%）→ 滴定/光谱/色谱
3. **现场/快速**：ELISA、胶体金、便携光谱、生物传感器
4. **微生物**：计数 → 平板/MPN；鉴定/致病基因 → PCR/qPCR/测序

## 仪器适用速查
| 目标 | 推荐技术 |
|---|---|
| 农兽药多残留 | LC-MS/MS、GC-MS/MS、QuEChERS |
| 重金属 | ICP-MS、ICP-OES、AAS、原子荧光 |
| 真菌毒素 | LC-MS/MS、ELISA、荧光快检 |
| 添加剂/防腐剂 | HPLC-UV/DAD、LC-MS/MS |
| 功效成分/维生素 | HPLC、LC-MS/MS、分光光度 |
| 微生物 | 平板计数、qPCR、测序 |
| 真伪/掺杂 | NIR、拉曼、稳定同位素、代谢指纹 |

## 前处理速查
- 提取：溶剂选择（相似相溶）、超声/微波/加速溶剂萃取（ASE）、均质
- 净化：QuEChERS、SPE（C18、PSA、HLB）、GPC、免疫亲和柱（真菌毒素）
- 衍生化：GC 需硅烷化/酰化；LC 需荧光/紫外标记
- 消解：湿法/微波消解（测元素）
- 定容与稀释：注意基质匹配

## 方法验证参数与接受标准（参考）
| 参数 | 典型接受标准 |
|---|---|
| 线性 | r² ≥ 0.995；覆盖目标浓度 |
| 准确度（回收率） | 70–120%（痕量可 60–120%） |
| 精密度（RSD） | ≤ 15%（痕量 ≤ 20%） |
| LOD/LOQ | S/N≥3 / S/N≥10 或按标准 |
| 选择性/特异性 | 无干扰峰 |
| 基质效应 | 评估并校正（基质匹配/同位素内标） |
| 耐用性 | 小变动下结果稳定 |

## 质量控制
- 每批：试剂空白、基质空白、加标回收、平行样
- 定期：标准物质/质控样、校准核查、能力验证（PT）
- 记录：原始数据、图谱、称量/定容记录，保证可追溯

## 不确定度评定
- 识别来源：称量、体积、校准曲线、回收率、重复性、标准物质
- 合成：A 类（统计）+ B 类（证书/经验）→ 合成标准不确定度 → 扩展（k=2）

## 常见问题排查
| 现象 | 可能原因 | 对策 |
|---|---|---|
| 回收率低 | 提取不足、净化损失、降解 | 优化溶剂、内标校正、控温 |
| 基线漂移 | 柱污染、流动相/温度不稳 | 冲洗柱、恒温、换流动相 |
| 基质抑制/增强 | 共流出物 | 基质匹配、同位素内标、稀释 |
| 保留时间漂移 | 流动相/pH/柱老化 | 重新平衡、换柱 |
| 假阳性 | 干扰、交叉污染 | 确证离子对/高分辨、加空白 |

## 标准体系
- 理化：GB 5009 系列、GB 23200 系列、GB/T 5009
- 微生物：GB 4789 系列
- 毒理/保健食品：GB 15193、GB 16740
- 通用能力：GB/T 27025 / ISO/IEC 17025；CMA/CNAS

## 交付前自检清单（结论/依据区必含）
- [ ] 标准号**带年份**，并声明「以现行标准正文为准」及复核入口（`references/README.md`）
- [ ] 与限量比较时给出限量值与来源；不得臆造版本号或限值
- [ ] 每个结果带单位、LOD/LOQ 与不确定度 U（k=2）
- [ ] 区分「未检出（< LOD）」「检出」「超标」；接近限量时结合不确定度判定
- [ ] 附质控数据（空白/加标/平行/质控样）与可追溯记录
- [ ] 多残留筛查附「目标物—平台」覆盖矩阵，注明清单来源
