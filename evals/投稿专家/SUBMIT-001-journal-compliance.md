# SUBMIT-001 期刊合规诊断与投稿材料生成

- **专家**：投稿专家（agent: `submission-expert`）
- **优先级**：P0
- **状态**：未评
- **最近评估**：2026-10-03
- **关联**：`../../投稿专家/references/`、`skills/journal-submission/SKILL.md`、`templates/`

## 背景 / 意图

考核投稿专家面向指定外文期刊，完成「规则获取与结构化 → 稿件合规诊断 → 定向修订 → 投稿材料生成 → 投稿前检查」的全链路，并严守「来源可追溯、不编造、高风险只给建议」的红线。

## 前置条件

- 目标期刊：`Food Control`（Elsevier）。
- 稿件：一篇已完成的英文研究论文，含标题、摘要（当前 312 词）、关键词 5 个、作者-年份制参考文献、无 Highlights、无 Data Availability Statement。
- 是否需要联网：若无法访问官网，可用粘贴的 Guide for Authors 文本替代，并注明访问日期。

## 输入（可直接粘贴）

```text
目标期刊：Food Control。
稿件情况：英文研究论文；摘要 312 词；关键词 5 个；参考文献为作者-年份制；
未提供 Highlights；未写 Data Availability Statement；图片为 150 dpi 的 JPG。
请：1) 获取并结构化该刊作者指南规则（标注来源 URL 与抓取时间）；
2) 逐条诊断合规性，输出诊断清单；
3) 给出风险分级后的修订建议（低风险可自动、中风险半自动、高风险只建议）；
4) 生成 Cover Letter 与 Highlights 草案；
5) 输出投稿前检查清单。
```

## 期望输出

- 期刊规则摘要（含来源 URL、抓取时间、版本）。
- 合规诊断清单（规则 / 状态 / 说明 / 依据）。
- 按低/中/高风险分级的修订建议，含原文对照与理由。
- Cover Letter 草案与 Highlights 草案（占位符规范，不编造）。
- 投稿前检查清单。
- 明确声明：字数/格式/伦理条款以官网现行 Guide for Authors 为准。

## 验收要点（Rubric）

| # | 要点 | 权重 | 判定标准（0/1/2） |
