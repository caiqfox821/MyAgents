## 背景 / 意图

用户已将部分物质参考谱下载到本地，需要**自建技能做自动比对**。本用例考核：
1. **流程纪律**：是否**先候选过滤（前体 ppm/加合物/极性/CE）再打分**，而非跨条件硬比；
2. **打分选型**：EI 用匹配因子、ESI MS² 用熵相似度，能否说清理由与阈值；
3. **置信度**：能否落回 **Schymanski 五级**，并明确 **MS² 库匹配最高 Level 2**、同分异构须 RT/CCS；
4. **可复现**：给出的命令/脚本能否实际跑出确定性结果（表头固定）。

## 前置条件

- 本地有 `质谱专家/skills/spectral-matching/scripts/`（纯 Python + numpy，无需联网）。
- 有真实峰表：`质谱专家/references/参考谱图-人参皂苷Rg1_Rg3/peaks_all.csv`（8 条 MassBank 记录）。

## 输入（可直接粘贴）

```text
我下载了人参皂苷 Rg1/Rg3 的 MassBank 参考谱（见 references/参考谱图-人参皂苷Rg1_Rg3/peaks_all.csv，8 条记录）。
请用人参皂苷 Rg1 的一条参考谱（MSBNK-RIKEN-PR307813）与库里全部记录比对：
1. 给出你能实际运行的命令与结果（Top-3），说明为什么必须先做候选过滤；
2. 解释为何"同一化合物但不同加合物"的 cosine 很低、而 entropy 更稳；
3. 用 Rg3(S) 与 Rg3(R) 的比对结果说明"MS² 库匹配能否区分立体异构"；
4. 给出结论应标注的置信度级（Schymanski）与必须补充的正交证据。
要求：所有数值来自实际运行，不得臆造；说明库覆盖边界。
```

## 期望输出

- **命令**：`build_index.py` + `match.py --method entropy,cosine_greedy`（或等价 Python 调用），并给出**实际排序**（正确记录 rank 1）。
- **候选过滤**：说明前体 ppm + 极性 + 加合物 + CE 必须一致；否则分数无意义（不同加合物 cosine 可低至 ~0.5）。
- **熵 vs 余弦**：说明熵相似度对强度分布/仪器差异更稳；余弦跨条件脆弱。
- **异构**：Rg3(S) vs Rg3(R) **MS² 熵相似度 ≈0.92，无法区分**，须 RT / 离子淌度 CCS / 标准品。
- **置信度**：库匹配 → **Level 2（推定）**；Level 1 需标准品 + RT。
- **边界**：声明"查不到 ≠ 不存在"，库数据质量需核对。
