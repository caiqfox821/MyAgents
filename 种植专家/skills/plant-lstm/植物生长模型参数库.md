# 植物生长模型参数库

本文件是 **通用植物生长 LSTM 模型**（`scripts/plant_lstm.py`）的参数来源。
每个植物一个 `json` 配置块，脚本会自动解析所有含 `plant` / `features` / `outputs` 的代码块。

## 1 配置结构说明

```text
{
  "plant": "名称",
  "description": "说明",
  "features": [
    {"key": "temperature", "cn": "温度", "min": 10, "max": 35, "unit": "°C"}
  ],
  "outputs": [
    {"key": "plant_height", "cn": "株高", "min": 0, "max": 300, "unit": "cm", "group": "growth"},
    {"key": "lycopene", "cn": "番茄红素", "min": 3, "max": 14, "unit": "mg/100g", "group": "component"}
  ],
  "network": {"layers": [16], "fc_dim": 24, "lr": 0.05, "adaptive": true,
              "min_layers": 1, "max_layers": 3, "min_hidden": 12, "max_hidden": 48},
  "training": {"epochs": 150, "window": 4, "shuffle": true, "sample_weight": 1.0,
               "forget": 0.95, "global_keep": 0.98}
}
```

- `features`：环境/栽培输入，`min`/`max` 用于归一化到 0–1。
- `outputs`：模型预测目标，`group` 取 `growth`（长势/胁迫）或 `component`（功效成分，单独统计损失）。
- `network`：网络结构，`layers` 为各 LSTM 层神经元数，`fc_dim` 全连接宽度，`lr` 学习率，`adaptive` 是否自动增减层/神经元。
- `training`：`epochs` 训练轮次，`window` 时序窗口，`shuffle` 是否打乱，`sample_weight` 学习率缩放，`forget` 单季遗忘因子（默认 0.95），`global_keep` 跨季保留系数（默认 0.98）。
- 所有输出（模型、图片、数据）默认写入**当前工作目录**。

## 2 使用方式
- 列出植物：`python3 scripts/plant_lstm.py list`
- 查看参数：`python3 scripts/plant_lstm.py config --plant 番茄`
- 生成模拟数据：`python3 scripts/plant_lstm.py gen_data --plant 番茄 --weeks 40 --out 番茄_data.json`
- 训练：`python3 scripts/plant_lstm.py train --plant 番茄 --data 番茄_data.json --model 番茄_model.json`
- 自定义结构与训练参数：`train --plant 番茄 --data ... --layers 16,24 --fc-dim 32 --lr 0.03 --epochs 300 --window 6 --adaptive false`
- 预测：`python3 scripts/plant_lstm.py predict --model 番茄_model.json --data 最近数据.md --weeks 12 --plot 番茄_prediction.png`

数据文件支持 `.json`（周记录数组）或 `.md`（含 json 数组代码块，或 markdown 表格，列名=特征/输出 key）。
