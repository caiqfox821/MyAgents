## 三、检索与引用

```bash
# 全文检索（多词 AND，返回 书|页码|原文）
python3 references/books/tools/search_books.py "rice blast" --context 1
python3 references/books/tools/search_books.py "nitrogen use efficiency" --books   # 各书命中统计
python3 references/books/tools/search_books.py "transplanting" --book rice          # 限定水稻分区
# 命中页码后按页读原文
python3 references/books/tools/read_page.py Rice_Almanac 120
```

- 引用格式：`作者/编者. 书名. 出版社, 年份. 许可. 页码.`
- 水稻相关田间方案优先参考 IRRI《Rice Almanac》、Springer《Rice Improvement》《Closing Rice Yield Gaps in Asia》、CGIAR/AfricaRice 手册与 WUR《ORYZA》模型；再结合 `references/` 中文知识文件与现行标准。

## 四、许可与合规

- IntechOpen / MDPI / Springer OA：**CC BY**，可自由使用与再分发，署名即可。
- CGIAR（CGSpace）、IRRI（AgEcon Search）、IITA、WUR、USAID、ICRISAT：开放获取；使用时保留出处。
- 仅收录开放获取资源；商业版权教材（如《Rice: Origin, History, Technology and Production》等）不含在内，建议图书馆/正规渠道获取。
