# 主要粮经作物栽培技术（粮油作物）

> 面向种植专家的原料端知识库。覆盖水稻、小麦、玉米、大豆、马铃薯、油菜六大粮油作物的生育时期、品种与种子处理、播种期与密度、施肥、水分管理、病虫草害绿色防控、收获与产量构成。

## 适用范围与使用说明

1. **适用对象**：从事粮油作物田间生产、原料基地建设、种植方案编制与田间诊断的技术人员。
2. **计量单位**：采用国标单位，面积用 **kg/亩、株/亩、万株/亩**，1 亩 = 667 m²；养分用量均以**纯养分**（N、P₂O₅、K₂O）计，实物量需按肥料有效含量折算。
3. **数据来源与时效**：本文参数主要摘自农业农村部、全国农业技术推广服务中心、农业农村部专家指导组及省级农业农村部门近年发布的**技术指导意见/防控技术方案**（见文末"资料来源"）。这些文件多为**全国分区方案**或**某年度某区域方案**，年际与区域间存在差异；实际应用须结合本地土壤、品种、茬口与当年气候调整。
4. **施用原则**：施肥遵循"测土配方、总量控制、分期调控、有机无机结合"；植保遵循"预防为主、综合防治，绿色防控优先、达标用药"；用药须核对农药登记标签（登记作物/防治对象/剂量/安全间隔期）。
5. **安全间隔期说明**：国家防控方案通常只给出推荐药剂而未逐一列出安全间隔期。**除文中明确标注外，农药安全间隔期一律以所用农药登记标签为准**；本文未核实具体天数的以"待核实"标注，不得套用其他作物数据。
6. **区域缩写**：东北 = 黑龙江/吉林/辽宁/内蒙古东部；黄淮海 = 河北/河南/山东/皖北/苏北等；长江中下游 = 湖北/湖南/江西/安徽/江苏/浙江等；西南 = 四川/重庆/贵州/云南等。

## 一、水稻

### 1. 生育时期划分
单季稻 / 双季稻均按以下物候阶段划分（具体天数因品种、纬度、熟制而异）：

| 阶段 | 主要标志 | 备注 |
|---|---|---|
| 播种育秧期 | 浸种催芽→播种→成秧 | 机插秧秧龄一般 20—25 d、叶龄 3—4 叶（湖北，2026） |
| 移栽返青期 | 移栽→新叶展开、返青成活 | 手插/抛栽秧龄可延至 30 d 以内（湖北，2026） |
| 分蘖期 | 分蘖发生、够苗 | 含有效分蘖与无效分蘖阶段，够苗期晒田 |
| 拔节孕穗期 | 拔节→幼穗分化→孕穗 | 穗肥关键期 |
| 抽穗扬花期 | 抽穗→开花授粉 | 稻曲病/穗颈瘟预防关键期 |
| 灌浆结实期 | 灌浆→乳熟→蜡熟 | 干湿交替灌溉 |
| 成熟收获期 | 黄熟→完熟 | 适期收获 |

> 全生育期天数与积温指标随熟制不同差异较大，**具体品种天数待核实**（参考当地品种审定公告）。

### 2. 品种与种子处理
- **品种**：因地制宜选用抗（耐）稻瘟病、白叶枯病、条纹叶枯病、稻曲病、黑条矮缩病、褐飞虱、白背飞虱等品种，避免种植高（易）感品种；依据当地病原菌优势小种合理布局不同遗传背景品种（全国农技中心，2024）。
- **种子处理**：
  - 播前药剂浸种或拌种，预防恶苗病、细菌性病害、稻瘟病、线虫病、稻飞虱传播的病毒病、稻蓟马、立枯病等种传/苗期病虫。
  - 秧苗移栽前 **3 d 内**施用内吸性药剂，**带药移栽**，预防螟虫、稻叶瘟、稻蓟马、稻飞虱及传播的病毒病。
  - 水稻线虫病发生区：苗床土壤处理 + 移栽前药剂浸根。
  - 病毒病流行区、二化螟重发区秧田：采用 **20—40 目防虫网**或 **15—20 g/m² 无纺布**全程覆盖育秧，或工厂化集中育秧（全国农技中心，2024）。
- **壮秧**：秧苗期施用赤·吲乙·芸苔等植物生长调节剂或氨基寡糖素等诱抗剂，提高抗逆性（全国农技中心，2024）。

### 4. 施肥（N-P-K 用量与时期）
依据《2022 年水稻科学施肥指导意见》（全国农技中心、农业农村部科学施肥专家指导组），分区如下（纯养分）：

| 稻区 | N（kg/亩） | P₂O₅（kg/亩） | K₂O（kg/亩） | N 分期（基:蘖:穗） |
|---|---|---|---|---|
| 东北寒地单季稻 | <500 kg/亩产量 6—7；500—600 为 7—8；>600 为 8—9 | 2.5—4.5 | 3—6 | 基 30%—40%、蘖 30%—40%、穗 30% |
| 东北吉辽蒙单季稻 | <500 为 7—8；500—600 为 8—10；>600 为 10—12 | 3—5 | 3—6 | 基 35%—40%、蘖 35%—40%、穗 20%—30% |
| 长江上游单季稻 | <450 为 6—8；450—550 为 8—10；550—650 为 10—12；>650 为 12—14 | 4—6 | 5—8 | 基 50%—60%、蘖 20%—30%、穗 20%—30% |
| 长江中游单双季稻 | <350 为 6—7；350—450 为 7—8；450—550 为 8—10；>550 为 10—12 | 4—7 | 4—8 | 基 50%—60%、蘖 20%—25%、穗 20%—25% |
| 长江下游单季稻 | <500 为 8—10；500—600 为 10—12；>600 为 12—18 | 2—3（<500）；3—4（500—600）；5—6（>600） | 3—4（<500）；4—5（500—600）；6—8（>600） | 基 40%—50%、蘖 20%—30%、穗 20%—30% |
| 江南丘陵山地单双季稻 | <450 为 7—11；450—550 为 11—13；>550 为 13—15 | 2—3 / 3—4 / 4—5 | 2—3 / 3—4 / 4—5 | 基 35%—50%、蘖 25%—35%、穗 20%—30% |
| 华南双季早稻 | <450 为 7—11；450—550 为 11—13；>550 为 13—15 | 2—3 / 3—4 / 4—5 | 3—4 / 4—5 / 5—6 | 基 40%—50%、蘖 20%—30%、穗 20%—30% |

要点：
- **磷肥、有机肥全部基施**；钾肥基施 50%—60%、穗肥 40%—50%（华南/江南 >600 kg 田块钾肥基施 80%、穗粒肥 20%）。
- 缺锌田块基肥/返青肥施硫酸锌 **1—2 kg/亩**；酸性土（pH<5.5）整地施含硅碱性肥料或生石灰 **30—50 kg/亩**。
- 秸秆全量还田田块钾肥用量减少 30%，穗肥减氮 10%；施用缓释肥作基肥时氮肥减少 10%。
- 推荐机插秧同步**侧深施肥**，同等产量下基蘖肥减少 10%，穗肥不变。
- 长江下游推荐基肥配方 20—10—15，江南/华南推荐 19—13—13、18—12—16（N—P₂O₅—K₂O）。

### 5. 灌溉与水分管理
- 通用原则：浅水勤灌促分蘖 → 够苗（达到目标穗数 80% 左右）**晒田**控无效分蘖 → 孕穗至抽穗期**保持水层** → 灌浆期**干湿交替、湿润灌溉** → 黄熟期落干。
- **具体水层深度、晒田程度与灌溉定额随土壤与地区不同，待核实**（以当地节水灌溉技术意见为准）。

### 6. 主要病虫草害与绿色防控
来源：全国农技中心《2024 年水稻重大病虫害防控技术方案》（绵阳市农业农村局转载）。2024 年预测水稻病虫害发生面积 12.4 亿亩次，二化螟偏重至大发生，稻飞虱、稻纵卷叶螟、纹枯病偏重发生。

**防治指标（达标用药）**：

| 病虫 | 防治指标 |
|---|---|
| 二化螟 | 分蘖期枯鞘丛率 8%—10% 或枯鞘株率 3% |
| 稻飞虱 | 分蘖至孕穗期百丛 1000 头；穗期百丛 1500 头 |
| 稻纵卷叶螟 | 分蘖期百丛束叶尖 150 个；孕穗后 60 个 |
| 纹枯病 | 分蘖末期至孕穗期病丛率 20% |
| 稻瘟病 | 叶瘟初见病斑即防；穗瘟破口期防，齐穗期第二次 |

**绿色防控（优先）**：
- 性信息素诱控：交配干扰每 3 亩 1 套；群集诱杀每亩 1 套诱捕器，底端距地面 50—80 cm。
- 释放赤眼蜂：每代 2—3 次、间隔 3—5 d、每亩每次 8000—10000 头，均匀 5—8 点。
- 稻鸭共育：分蘖初期每亩放 15—20 日龄雏鸭约 10 只，齐穗时收鸭。
- 农艺：翻耕灌水灭蛹（浸没稻桩 7—10 d）、适时晒田、低茬收割、清洁田园。

**推荐药剂（生物农药优先）**：

| 对象 | 推荐药剂 |
|---|---|
| 二化螟 | 苏云金杆菌、金龟子绿僵菌 CQMa421、印楝素；化学可选氯虫苯甲酰胺类等 |
| 稻飞虱 | 金龟子绿僵菌 CQMa421、球孢白僵菌、苦参碱；化学：三氟苯嘧啶、烯啶虫胺、氟啶虫胺腈、呋虫胺、醚菊酯 |
| 稻纵卷叶螟 | 苏云金杆菌、短稳杆菌、甘蓝夜蛾核型多角体病毒、球孢白僵菌、颗粒体病毒；化学：茚虫威、乙基多杀菌素、多杀霉素、四氯虫酰胺 |
| 稻瘟病 | 枯草芽孢杆菌、春雷霉素、多抗霉素、申嗪霉素、井冈·蜡芽菌；化学：三环唑、丙硫唑、吡唑醚菌酯、嘧菌酯、咪铜·氟环唑 |
| 纹枯病 | 井冈霉素 A、井冈·蜡芽菌、枯草芽孢杆菌、多抗霉素、氟环唑、噻呋酰胺 |
| 稻曲病/穗腐病 | 井冈·蜡芽菌、氟环唑、申嗪霉素、苯甲·丙环唑、肟菌·戊唑醇；**破口前 7—10 d** 施药 |
| 细菌性病害 | 噻唑锌、噻霉酮；台风暴雨前后预防 |

**用药注意**：稻田**禁用含拟除虫菊酯类成分农药**，慎用有机磷类；分蘖期尽量不用甲维盐/阿维菌素，破口抽穗期慎用三唑类，扬花期慎用新烟碱类；稻渔/稻虾/稻鸭及桑蚕区慎重选药。**安全间隔期按标签执行（待核实）**。

### 7. 收获与产量构成
- **产量构成**：有效穗数 × 每穗实粒数 × 结实率 × 千粒重。
- 收获适期：黄熟末期至完熟期；机收宜在蜡熟末期至完熟期，控制损失率与破碎率。
- 具体适宜收获含水率、产量水平指标依品种与区域而定，**待核实**。

## 二、小麦

### 1. 生育时期划分

| 阶段 | 主要标志 |
|---|---|
| 播种出苗期 | 播种→出苗 |
| 分蘖期 | 分蘖发生、冬前壮苗 |
| 越冬期 | 日均温降至 0 ℃ 左右，停止生长 |
| 返青起身期 | 春季恢复生长、起身 |
| 拔节孕穗期 | 拔节→孕穗（肥水临界期） |
| 抽穗扬花期 | 抽穗→开花授粉（赤霉病预防关键期） |
| 灌浆成熟期 | 灌浆→蜡熟→完熟 |

### 2. 品种与种子处理
- **品种布局**：按"品种类型与生态区域相适应、产量水平与地力匹配、早中晚熟与播期结合、抗性与气象协调"原则。黄淮和北部选丰产抗逆强筋/中强筋品种；长江中下游选耐湿耐渍、抗赤霉病、抗穗发芽的弱筋/中筋品种；西南重点推广抗条锈病品种；西北选抗旱、抗倒春寒品种（农业农村部，2019）。
- **种子处理**：推广种子包衣/药剂拌种，减少"白籽"下地。
  - 纹枯病、茎基腐病、根腐病等：含戊唑醇、苯醚甲环唑、咯菌腈、嘧菌酯、氟唑环菌胺、井冈霉素、枯草芽孢杆菌等成分。
  - 全蚀病：硅噻菌胺、嘧菌酯、苯醚甲环唑。
  - 孢囊线虫病：阿维菌素种子处理。
  - 地下害虫、苗期蚜虫、黄矮病：吡虫啉、噻虫嗪、噻虫胺、毒死蜱、辛硫磷拌种/包衣（全国农技中心，2023）。

### 4. 施肥（N-P-K 用量与时期）
来源：邹城市《2024 年小麦科学施肥增效技术指导意见》；养分需求比例约为 N:P₂O₅:K₂O = 3:1:3。

| 产量水平（kg/亩） | N（kg/亩） | P₂O₅（kg/亩） | K₂O（kg/亩） | 运筹 |
|---|---|---|---|---|
| 400—500 | 12 | 6 | 5 | 磷钾底施；氮 60% 底施、40% 起身期追 |
| 500—600 | 12—15 | 7—8 | 5—6 | 磷钾底施；氮 50% 底施、50% 拔节期追 |
| >600 | 14—16 | 7—8 | 5—7 | 磷肥底施；氮钾 40%—50% 底施、50%—60% 拔节期追 |

- 有机肥：高产田亩施腐熟有机肥 2500—3000 kg 或商品有机肥 200—300 kg；中低产田腐熟有机肥 3000—4000 kg。
- 微肥：缺锌/锰基施硫酸锌或硫酸锰 1—2 kg/亩；缺硼基施硼砂 0.5—1 kg/亩。
- **基肥**：基施氮素占全生育期总氮 **50%—60%**，磷、钾 50%—100% 底施（农业农村部，2019）。
- 追肥：分蘖肥（2 叶期/壮蘖肥）、返青拔节肥、孕穗肥、灌浆叶面喷肥；后期可结合"一喷三防"喷施尿素/磷酸二氢钾。

### 5. 灌溉与水分管理
来源：农业农村部，2019。
- **越冬水**：黄淮、北方、西北缺墒田及秸秆还田悬空田块，**11 月底至 12 月上旬**、日均温稳定 **3—4 ℃**、"夜冻昼消"时浇，忌大水漫灌，灌后划锄。
- 12 月初麦田 **0—40 cm** 土层相对含水量 **≥70%** 且整地质量高、群体适宜的，冬前可不浇越冬水。
- **开沟防渍（长江中下游、西南）**：每 2.5—3 m 一条竖沟（宽 20 cm、深 25—30 cm）；较长田块每 50 m 增开腰沟（宽 20 cm、深 35—40 cm）；田头出水沟宽 25 cm、深 40—50 cm，确保"三沟"相通。

### 6. 主要病虫草害与绿色防控
来源：全国农技中心《2023—2024 年度小麦主要病虫害全程防控技术方案》。

**分区防控重点**：
- 黄淮海麦区：锈病、赤霉病、纹枯病、茎基腐病、白粉病、麦蚜、麦蜘蛛、吸浆虫、地下害虫。
- 长江中下游麦区：赤霉病、锈病、纹枯病、白粉病、麦蚜。
- 西南麦区：条锈病、麦蚜。
- 西北麦区：条锈病、茎基腐病、赤霉病、麦蚜、吸浆虫。
- 华北及东北麦区：白粉病、茎基腐病、纹枯病、黑穗病、麦蚜、吸浆虫。

**防治指标与推荐药剂**：

| 病虫 | 防治指标 | 推荐药剂 |
|---|---|---|
| 条锈病 | 病叶率 0.5%—1% | 三唑酮、烯唑醇、戊唑醇、氟环唑、丙环唑、腈菌唑 |
| 白粉病 | 病叶率 10% | 三唑类、甲氧丙烯酸酯类 |
| 纹枯病 | 病株率 10% | 井冈霉素、噻呋酰胺、氰烯·己唑醇、三唑类（茎基部喷施，7—10 d 1 次，连喷 2—3 次） |
| 茎基腐病 | 病株率 5% | 参照《小麦茎基腐病防控技术指导意见》 |
| 赤霉病 | 抽穗扬花期遇连阴雨>2 d 主动预防 | 氰烯菌酯、丙硫菌唑、氟唑菌酰羟胺、戊唑醇、叶菌唑、咪鲜胺 |
| 麦蜘蛛 | 33 cm 行长 200 头或每株 6 头 | 阿维菌素、联苯菊酯 |
| 麦蚜 | 百穗蚜量 800 头（益害比<1:150） | 啶虫脒、吡虫啉、抗蚜威、氟啶虫胺腈、苦参碱、绿僵菌 |
| 吸浆虫 | 10 复网次成虫 10 头 | 高效氯氟氰菊酯、毒死蜱（毒土/喷雾） |

**关键提示**：赤霉病施药后 **6 h 内遇雨须补喷**；"一喷三防"在灌浆期混配杀菌剂+杀虫剂+叶面肥/调节剂。**安全间隔期：一般在收获前 15 天停止使用农药**（全国农技中心，2023）。

### 7. 收获与产量构成
- **产量构成**：穗数 × 穗粒数 × 千粒重。
- 收获适期：蜡熟末期机械收获；具体机收含水率指标**待核实**。

## 三、玉米

### 1. 生育时期划分
| 阶段 | 主要标志 |
|---|---|
| 播种出苗期 | 播种→出苗 |
| 苗期 | 出苗→拔节 |
| 穗期 | 拔节→抽雄（含小喇叭口、大喇叭口期，需肥高峰） |
| 花粒期 | 抽雄→成熟（开花、吐丝、灌浆、乳熟、蜡熟） |

### 2. 品种与种子处理
- 选用通过国家或省级审定的高产稳产、抗病抗虫、抗逆广适、适宜机械化的品种，杜绝越区种植（农业农村部，2018）。
- 选购高质量**包衣种子**，预防地下害虫和苗期病虫害。
- 种子处理剂：含噻虫嗪等新烟碱类与氯虫苯甲酰胺/溴氰虫酰胺/丁硫克百威复配；防病可用精甲·咯菌腈、苯醚甲环唑、吡唑醚菌酯或戊唑醇（内蒙古农牧厅，2024）。

### 3. 播种期与密度
| 区域 | 播期 | 密度 |
|---|---|---|
| 东北春玉米 | 气温回升、适墒精播 | 一般**亩保苗 4000 株**；肥力好、水肥条件好的耐密品种 **4500—5000 株/亩**（农业农村部，2018） |
| 黄淮海夏玉米 | 中南部 **6 月 15 日前**、北部 **6 月 20 日前**完成播种 | 一般 **4000—4500 株/亩**；大豆玉米带状复合种植地块约 **4500 株/亩**，60 cm 等行距（农业农村部，2022） |

- 播深与种肥隔离、镇压适度，争取一播全苗；墒情不足播后浇"蒙头水"。

### 4. 施肥（N-P-K 用量与时期）
来源：南通市《2024 年玉米科学施肥指导意见》（南方/长江下游参考）；黄淮海施肥运筹见农业农村部 2022。

| 项目 | 用量/比例 |
|---|---|
| 全生育期 N | 12—16 kg/亩 |
| 全生育期 P₂O₅ | 3—7 kg/亩 |
| 全生育期 K₂O | 3—7 kg/亩 |
| 有机肥替代（以氮计） | 20%—30% |
| 基肥氮占比 | 40%—60%（磷肥一次性施入） |

- **基肥**：推荐种肥同播，施高氮型配方肥（如 40%（30-5-5）、40%（28-6-6）、45%（25-12-8）），种肥分离防烧苗。
- **追肥**：拔节期至乳熟期肥水齐攻；种肥同播配配方肥的，于拔节期、大喇叭口期、抽雄开花期趁水追肥 1—3 次，追肥氮占 40%—60%。
- **水肥一体化**：70%—80% 氮肥及 40% 钾肥于拔节至灌浆期分 3—4 次随水追施；缺锌地块一水硫酸锌 1 kg/亩。
- **黄淮海**：1/3 氮肥与全部钾肥、微肥随播种侧深施，其余 2/3 氮肥于小喇叭口期前后机械侧深施（深约 10 cm）。

### 5. 灌溉与水分管理
- 东北春旱区可采用地膜覆盖、膜下滴灌、水肥一体化、"坐水种"等抗旱造墒播种（农业农村部，2018）。
- 黄淮海夏播墒情不足时播后及时浇"蒙头水"；有条件推行水肥一体化，按需分次灌水施肥（农业农村部，2022）。
- **具体灌溉定额与生育期灌水指标随区域不同，待核实**。

### 6. 主要病虫草害与绿色防控
来源：内蒙古自治区农牧厅《2024 年玉米重大病虫害防控技术方案》（全国农技中心方案转发）。

| 防治对象 | 绿色防控/推荐药剂 |
|---|---|
| 玉米螟、粘虫 | 秸秆粉碎还田；杀虫灯+性诱剂；产卵初期释放赤眼蜂；心叶期低龄幼虫用球孢白僵菌或四氯虫酰胺、氯虫苯甲酰胺、甲维盐、乙基多杀菌素、茚虫威 |
| 地下害虫、苗期蚜虫 | 噻虫嗪等新烟碱类与氯虫苯甲酰胺/溴氰虫酰胺复配种子处理剂拌种包衣 |
| 大斑病等叶斑病 | 枯草芽孢杆菌、球孢白僵菌或苯醚甲环唑、丁香菌酯、吡唑醚菌酯、丙环·嘧菌酯，心叶末期喷施 |
| 叶螨（红蜘蛛） | 播种至出苗前清除田边杂草；点片发生时选用唑螨酯、哒螨灵、噻螨酮喷雾，重点喷田块周边玉米中下部叶背及地头杂草 |
| 双斑长跗萤叶甲 | 玉米吐丝授粉期平均单穗花丝超 5 头时，甲维盐、噻虫嗪、吡虫啉、高效氯氟氰菊酯喷施果穗花丝等部位 |
| 茎腐病等 | 抗耐病品种、及时排涝；精甲·咯菌腈、苯醚甲环唑、吡唑醚菌酯、戊唑醇种子处理 |

**赤眼蜂防虫技术**：玉米螟产卵初期至盛期，每亩 2 个释放点、每亩放蜂 **1.5 万—2 万头**，分 2 次释放；越冬代化蛹率达 20% 后推 10 d 第一次放蜂，间隔 7 d 第二次。
**注意**：当季使用过烟嘧磺隆除草剂的地块，避免使用有机磷农药，以防药害。**安全间隔期按标签执行（待核实）**。

### 7. 收获与产量构成
- **产量构成**：穗数 × 穗粒数 × 百粒重。
- 收获适期：籽粒**乳线消失、黑层出现**后适时晚收；机收尽量降低损失率与破碎率，及时晾晒/烘干防霉变（农业农村部，2022）。

## 四、大豆

### 1. 生育时期划分
| 阶段 | 主要标志 |
|---|---|
| 播种出苗期 | 播种→出苗 |
| 苗期 | 出苗→分枝（营养生长为主） |
| 花荚期 | 开花→结荚→鼓粒（需水临界期） |
| 成熟期 | 鼓粒完成→黄熟→完熟 |

### 2. 品种与种子处理
来源：黑龙江省农业农村厅《2025 年全省大豆春播技术指导意见》。
- 选优质高产、抗逆、广适品种或高油/高蛋白专用品种，杜绝越区种植；播前精选种子，剔除病粒、瘪粒、破损粒。
- **种衣剂**：推荐含**咯菌腈+精甲霜灵**成分或**宁南霉素**水剂；镰孢菌根腐病地块加**三氟吡啶胺**；兼防根潜蝇/蛴螬/地老虎可用含**噻虫嗪**种衣剂；胞囊线虫病可用含**苏云金杆菌**或**甲维盐**种衣剂。
- **根瘤菌接种**：可减轻重茬影响、提高固氮能力并适当减氮。

### 3. 播种期与密度
来源：黑龙江省农业农村厅，2025。

| 项目 | 指标 |
|---|---|
| 播种温度 | 5 cm 地温稳定通过 **8 ℃** 即可播种 |
| 播期（第 1、2 积温带） | 4 月 28 日—5 月 5 日 |
| 播期（第 3、4 积温带） | 5 月 3 日—12 日 |
| 播期（第 5、6 积温带） | 5 月 8 日—20 日 |
| 密度（黑龙江北部、西北部） | 亩保苗 **2.2—2.5 万株** |
| 密度（黑龙江东部） | 亩保苗 **1.8—2.1 万株** |
| 密度（黑龙江中南部） | 亩保苗 **1.7—2.0 万株** |
| 播种深度 | 3—5 cm（墒情差可适当深播、浅覆土、重镇压） |

> 黄淮海夏大豆播期与密度**待核实**（可参考安徽省农科院《2026 年安徽省夏大豆播种技术指导意见》）。

### 4. 施肥（N-P-K 用量与时期）
**黑龙江（2025）**：一般亩施化肥 **12—18 kg**，N:P₂O₅:K₂O ≈ **1:1.1—1.5:0.5—0.8**；接种根瘤菌可适当减氮；底肥分层侧深施（种侧 5 cm，上层占 1/3 施于种下 5—7 cm，下层占 2/3 施于种下 10—12 cm）。

**江苏扬中（2022，按产量水平）**：

| 产量水平（kg/亩） | N（kg/亩） | P₂O₅（kg/亩） | K₂O（kg/亩） |
|---|---|---|---|
| 150—200 | 1.5—2.5 | 2—3 | 1.5—2.5 |
| 200—250 | 2—3 | 2.5—3.5 | 2—3 |
| >250 | 2—3 | 3—4.5 | 2.5—3.5 |

- 高肥力土 N:P:K = 1:1.5:1.2；低肥力土 = 1:1.2:1；氮磷钾作种肥一次性施于种子侧下方 4—6 cm；基施腐熟有机肥 1000 kg/亩或商品有机肥 150 kg/亩。
- 初花前有徒长风险时可用烯效唑或调环酸钙化控防倒。

### 5. 灌溉与水分管理
- 大豆需水关键期为开花期至鼓粒期，此期干旱将显著减产；东北春旱区注意保墒。
- **具体灌溉制度与灌水定额待核实**（以当地节水灌溉技术意见为准）。

### 6. 主要病虫草害与绿色防控
来源：黑龙江省农业农村厅，2025。
- **病害**：根腐病（种衣剂包衣 + 后期百菌清/甲基托布津/多菌灵）、胞囊线虫病（播种前苏云金杆菌 HAN055 沟施）、菌核病（封垄前喷氟唑菌酰羟胺、异菌脲、咯菌腈、咪鲜胺、腐霉利、菌核净）、霜霉病（霜脲·锰锌、噁霜·锰锌、氟菌·霜霉威）、灰斑病/褐斑病（嘧菌酯、吡唑醚菌酯、丙环唑、氟环唑，"一喷多防"）、细菌性斑点病（解淀粉芽孢杆菌、王铜、噻唑锌、噻霉酮）。
- **虫害**：蚜虫、红蜘蛛、食心虫、地下害虫；灯光/色板诱杀 + 生物农药 + 天敌保护；地下害虫可沟施噻虫嗪、白僵菌、金龟子绿僵菌。
- **草害**：
  - 播后苗前封闭：乙草胺、（精）异丙甲草胺混配嗪草酮、异噁草松、噻吩磺隆、唑嘧磺草胺、丙炔氟草胺、2,4-滴异辛酯等。
  - 苗后茎叶（大豆 1—3 片复叶、禾本科杂草 3—5 叶、阔叶杂草 2—4 叶）：烯草酮、高效氟吡甲禾灵、精喹禾灵、精吡氟禾草灵、烯禾啶与氟磺胺草醚、灭草松、异噁草松等混配。
- **安全间隔期按标签执行（待核实）**。

### 7. 收获与产量构成
- **产量构成**：株数 × 每株荚数 × 每荚粒数 × 百粒重。
- 收获适期：完熟期（豆荚变黄、籽粒变硬）；机收宜在完熟初期，**具体含水率指标待核实**。

## 五、马铃薯

### 1. 生育时期划分
| 阶段 | 主要标志 |
|---|---|
| 萌发期 | 播种→幼芽萌动出土 |
| 出苗期 | 出苗→幼苗 |
| 幼苗期 | 出苗→团棵（孕蕾） |
| 块茎形成期 | 现蕾→开花（块茎开始形成） |
| 块茎膨大期 | 开花→茎叶停止生长（产量关键期） |
| 淀粉积累期 | 茎叶衰老→薯块淀粉积累 |
| 成熟收获期 | 茎叶枯黄→收获 |

### 2. 品种与种子处理
来源：农业农村部薯类专家指导组、全国农技中心《2020 年秋作马铃薯生产技术指导意见》；科普中国。
- 选用脱毒种薯（原种或一级种薯），避免用食用薯做种；中原二季作选早熟、休眠期短、结薯早、薯块膨大快品种，以 **30—50 g 优质脱毒小整薯**为宜。
- **催芽**：播前 15—25 d 晒种醒薯，12—18 ℃ 催芽，芽长 1—2 cm 见光绿化；切块以 **20—30 g** 为宜，纵切保证带顶端芽眼。
- **切刀消毒**：75% 酒精、3% 来苏水或 0.5% 高锰酸钾浸泡 5—10 min，多刀轮换。
- **拌种**：甲基硫菌灵、咯菌腈、氟环·咯菌腈、霜脲氰、吡醚·咯·噻虫等，或春雷霉素、中生菌素等生物药剂，预防土传/种传病害与地下害虫（全国农技中心，2026）。

### 3. 播种期与密度
来源：农业农村部，2020；科普中国。

| 区域/模式 | 播期 | 密度与规格 |
|---|---|---|
| 中原二季作（秋作） | 8 月上中旬—9 月上旬 | 约 **5000 株/亩**；行距 60 cm、株距 20 cm，覆土 10—15 cm；宽垄双行垄宽 80—90 cm |
| 西南一二季混作（秋作） | 云贵低海拔 7 月中下旬—8 月上旬；川渝 8 月上旬—9 月上旬 | **4000—4500 株/亩**，单垄单行 |
| 早春保护地 | 1 月中下旬—2 月上旬 | 一般栽培水平约 **6000 株/亩**（科普中国） |

- 原则：使结薯盛期处于日均温 **15—25 ℃**；播后覆土，垄高 10—20 cm。

### 4. 施肥（N-P-K 用量与时期）
- **中原二季作**：播前深翻结合亩施**商品有机肥 100—150 kg + 马铃薯专用配方肥 50—70 kg**；出苗后团棵前连续追肥 2 次，每次亩施**硫酸钾型复合肥 10 kg**（农业农村部，2020）。
- **通用参考（科普中国）**：中等肥力土壤可亩施腐熟农家肥 3000—3500 kg + 45% 硫酸钾复合肥 100—150 kg + 生物有机肥 100—150 kg；或有机肥 1000—1500 kg + 过磷酸钙 15—25 kg + 草木灰 100—150 kg。基肥占总用肥量 3/5—2/3，施于 20—30 cm 土层。
- 养分特点：**钾 > 氮 > 磷**；忌用含氯肥料，优先硫酸钾型。

### 5. 灌溉与水分管理
- 中原二季作：播后至出苗保持土壤湿润，"土干即浇小水、见干见湿"；结薯期保持垄土湿润、"垄沟不干不浇"；**收获前 7 天停止浇水**（农业农村部，2020）。
- 西南秋作：播时"三沟"配套防湿害，注意清沟排渍防涝。
- 雨大及时排水；**具体灌溉定额待核实**。

### 6. 主要病虫草害与绿色防控
来源：全国农技中心《2026 年马铃薯重大病虫害防控技术方案》（2026 年晚疫病总体中等发生，西南及武陵山区、西北中西部、华北东北局部偏重）。
- **种薯处理**：见上；土传病害重发田随播种沟施嘧菌酯或噻呋酰胺；疮痂病沟施解淀粉芽孢杆菌；地下害虫可沟施氟氯氰·噻虫胺、氯虫·噻虫胺或辛硫磷颗粒剂。
- **苗期**：提前喷代森锰锌或苦参碱预防晚疫病；杀虫灯/性信息素诱杀地下害虫成虫。
- **块茎形成期/膨大期**：
  - 晚疫病：保护性药剂代森锰锌、氟啶胺、氰霜唑、噁唑菌酮；内吸治疗剂烯酰吗啉、氟菌·霜霉威、丁子香酚、氟噻唑吡乙酮、霜脲氰；**施药间隔一般 7—10 d**，喷后遇雨补喷。
  - 早疫病：苯甲·丙环唑、啶酰菌胺、肟菌·戊唑醇、苯甲·嘧菌酯。
  - 二十八星瓢虫：成虫盛期高效氯氰菊酯叶面喷雾，间隔 7—10 d。
  - 蚜虫：氟啶虫酰胺、噻虫嗪、吡蚜酮、高效氯氟氰菊酯。
  - 黑胫病/青枯病：噻唑锌、噻霉酮、春雷霉素、中生菌素滴灌或灌根。
- **收获至贮藏期**：收获前 **7—10 d 机械杀秧**，杀秧后至收获前喷 1 次杀菌剂（烯酰吗啉、氢氧化铜、噁酮·霜脲氰），防止病菌侵染伤口。
- **安全间隔期按标签执行（待核实）**。

### 7. 收获与产量构成
- **产量构成**：单位面积株数 × 单株结薯数 × 单薯重（群体与单株产量存在负相关，需合理密植）。
- 收获：地上部茎叶枯死（或霜冻后/按市场）择晴天收获，剔除病、烂、畸形、青头薯，分级包装；防止过晚收获冻伤薯块（农业农村部，2020）。

## 六、油菜

### 1. 生育时期划分
| 阶段 | 主要标志 |
|---|---|
| 播种出苗期 | 播种→出苗（直播/育苗移栽） |
| 苗期 | 出苗→现蕾（冬前壮苗关键期） |
| 现蕾抽薹期 | 现蕾→抽薹（薹肥关键期） |
| 开花期 | 初花→盛花→终花（菌核病防治关键期） |
| 角果发育成熟期 | 结角→灌浆→成熟 |

### 2. 品种与种子处理
来源：全国农技中心、农业农村部油菜专家指导组《2025 年全国油菜秋冬种技术意见》；全国农技中心，2023。
- 选用近五年新选育高产高含油品种，**含油量 45%（干基）以上、亩产潜力 200 kg 以上**；稻油轮作选高产高油、耐渍耐密抗倒品种；丘陵旱坡地选耐旱耐低硼品种；稻稻油三熟区选极早熟品种；根肿病重发区选抗根肿病品种。
- **种子处理**：推广噻虫嗪类型种子处理剂包衣，控制冬前黄曲跳甲、蚜虫、小菜蛾；防病可用多粘芽孢杆菌、枯草芽孢杆菌包衣/拌种。
- 根肿病常发区可用石灰氮（氰氨化钙）土壤处理，育苗移栽采取苗床消毒、无菌土育苗、适度晚播。

### 3. 播种期与密度
来源：全国农技中心，2025。

| 项目 | 指标 |
|---|---|
| 直播播期 | 9 月下旬—10 月中旬 |
| 移栽播种/移栽 | 9 月中旬 / 10 月下旬 |
| 行距×株距 | 20—30 cm × 3—6 cm |
| 播种深度 | 0.5—2.5 cm |
| 机械直播用种 | 200—300 g/亩 |
| 无人机飞播用种 | 300—400 g/亩 |
| 直播保苗 | **3—4 万株/亩** |
| 移栽密度 | **0.5—0.6 万株/亩**（迟播迟栽增 20%—30%） |

### 4. 施肥（N-P-K 用量与时期）
来源：全国农技中心，2025；南阳市《2026 年冬油菜春季科学施肥技术指导意见》。

**基肥/种肥**：推荐氮磷钾配比 **25—7—8** 的油菜专用缓释肥（含硼），或 20—10—18 三元复合肥 + 硼肥 1 kg；稻茬田亩施 **50 kg**、旱坡地亩施 **30 kg**，与种子同播施于土壤下 5—10 cm。

**追肥**：
- 三叶期亩追尿素 5 kg；冬至前后追尿素 3—5 kg（腊肥）。
- **薹肥**（薹高 15—25 cm，弱苗提前至 10—15 cm）：长江上游（川渝云贵）亩施 N 2—4 kg、K₂O 1—2 kg、硼砂 0.1 kg；南方（湘赣桂）N 2—3 kg、K₂O 2—3 kg、硼砂 0.2 kg；华中（鄂湘赣北）N 3—5 kg、K₂O 2—3 kg、硼砂 0.1 kg；长江下游（苏浙皖）N 4—5 kg、K₂O 2—3 kg；北方（甘豫陕）以氮为主 N 3—5 kg。目标亩产 >200 kg 时氮钾增 10%—15%。
- 缺镁/缺硼：角果初期喷硫酸镁 0.2—0.3 kg/亩，或结合"一促四防"喷硼镁肥。
- 防冻：冻害前 5—7 d 或后 3—5 d 叶面喷磷酸二氢钾、硫酸镁、硼砂、腐殖酸/芸薹素内酯等。

### 5. 灌溉与水分管理
来源：全国农技中心，2025。
- 播前/花期**开好"三沟"**（厢沟≥20 cm、腰沟和围沟≥30 cm），排灌畅通，防渍害。
- 受渍田块亩追尿素 5 kg + 氯化钾 2 kg 促进恢复。
- 干旱：清理沟渠，抽水漫灌或喷灌，叶面喷碧护、新美洲星等抗逆调节剂。
- **具体灌溉定额待核实**。

### 6. 主要病虫草害与绿色防控
来源：全国农技中心《2023—2024 年度油菜主要病虫害全程防控技术方案》（恩施州农业农村局转载）。
- **主要对象**：长江流域冬油菜区菌核病、蚜虫偏重，根肿病扩大；春油菜区跳甲、茎象甲、露尾甲、角野螟偏重。
- **农业防治**：水旱轮作或与禾本科轮作；深耕深翻、清洁田园；合理密植、深沟高畦、清沟排渍；土壤处理用盾壳霉、木霉菌、枯草芽孢杆菌；根肿病用石灰氮调 pH。
- **防治指标与药剂**：

| 病虫 | 指标 | 推荐药剂 |
|---|---|---|
| 蚜虫 | 百株蚜量 500 头（秋苗）/有蚜枝率 10%（花角期） | 金龟子绿僵菌 CQMa421、溴氰菊酯、噻虫嗪、吡蚜酮 |
| 菌核病 | 叶病株率 10% 或茎病株率 1%（初花期） | 氟唑菌酰羟胺、啶酰菌胺、腐霉利、咪鲜胺、异菌脲、菌核净、多菌灵、盾壳霉/芽孢杆菌 |
| 霜霉病 | 病株率 20% | 代森锌、乙蒜素乳油 |
| 白粉病 | 发病株率 20% | 氟唑菌酰羟胺、丙唑·多菌灵 |
| 根肿病 | — | 抗病品种、石灰氮、氰霜唑/氟啶胺浇苗定根、芽孢杆菌 |
| 跳甲/猿叶甲 | — | 溴虫苯甲酰胺、乙基多杀菌素（跳甲）；辛硫磷（猿叶甲） |

- **花期防菌核病**：初花期（主茎开花率约 80%）施药，连阴雨或花期长时盛花期（75% 植株开花）第二次施药，药液喷至茎基部；可加磷酸二氢钾、速效硼和碧护等实现"一促四防"。
- **保护蜜蜂**：油菜花期停用噻虫嗪等对蜜蜂高毒的新烟碱类药剂。
- **抗性治理**：苯并咪唑类抗性区停用多菌灵、甲基硫菌灵。
- **安全间隔期按标签执行（待核实）**。

### 7. 收获与产量构成
- **产量构成**：株数 × 每株角果数 × 每角粒数 × 千粒重。
- 收获适期：角果黄熟、籽粒变褐；机收宜在黄熟期，**具体含水率指标待核实**。
