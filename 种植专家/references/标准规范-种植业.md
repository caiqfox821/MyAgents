# 种植业相关标准与规范要点

## 适用范围与使用说明

- 本文面向种植业（大田作物、蔬菜、果树、茶叶、棉花及设施栽培等）的生产管理、投入品使用、质量安全与认证工作，汇总当前主流标准与法规的核心要点。
- 用途：制定种植方案、申报绿色食品/有机产品/GAP 认证、开展农药肥料合规审查、建立农事记录与追溯体系、开展测土配方施肥与农产品质量安全管理。
- **重要提示**：标准与法规会持续修订与替代，使用前请以全国标准信息公共服务平台、国家标准全文公开系统及农业农村部最新公告为准。文中凡无法逐一核实到发布/实施日期的条目，均标注"**待核实**"，不臆造标准号与年份。
- 本文只整理要点与索引，不替代标准原文；涉及限量值、检测方法、禁用清单时，务必查阅现行标准正文。

### 标准层级/代号说明

| 代号 | 层级 | 约束力 | 说明 |
|---|---|---|---|
| **GB** | 强制性国家标准 | 必须执行 | 保障人身健康、生命财产安全、国家安全、生态环境安全等，如 GB 2763 |
| **GB/T** | 推荐性国家标准 | 推荐执行（被法规或合同引用则具约束力） | 如 GB/T 20014、GB/T 19630 |
| **GB/Z** | 国家标准化指导性技术文件 | 指导性 | 供参考 |
| **NY/T** | 农业行业标准（推荐性） | 推荐执行 | 农业农村部发布，如 NY/T 391、NY/T 393 |
| **NY** | 农业行业标准（强制性，较少） | 必须执行 | 现多已转为推荐性或并入食品安全国标 |
| 法规/规章 | 法律、行政法规、部门规章 | 必须执行 | 如《农产品质量安全法》《农药管理条例》 |

## 一、良好农业规范 GAP（GB/T 20014 系列）

### 1.1 系列构成（现行主要部分）

| 标准号 | 名称 | 状态 |
|---|---|---|
| GB/T 20014.1-2005 | 良好农业规范 第1部分：术语 | 现行 |
| GB/T 20014.2-（年份待核实） | 良好农业规范 第2部分：农场基础控制点与符合性规范 | 现行（待核实） |
| GB/T 20014.3-2013 | 良好农业规范 第3部分：作物基础控制点与符合性规范 | 现行 |
| GB/T 20014.4-2013 | 良好农业规范 第4部分：大田作物控制点与符合性规范 | 现行 |
| GB/T 20014.5-2013 | 良好农业规范 第5部分：水果和蔬菜控制点与符合性规范 | 现行 |
| GB/T 20014.12-2013 | 良好农业规范 第12部分：茶叶控制点与符合性规范 | 现行 |
| GB/T 20014.28-2025 | 良好农业规范 第28部分：棉花控制点与符合性规范 | 现行（2025 年发布） |

> 该系列另含畜禽（第6～10部分）、水产（第13～24部分）、蜜蜂（第27部分）等；水果蔬菜类第5部分、作物基础第3部分、大田作物第4部分是种植业最常用部分。GB/T 20014 为推荐性国家标准，但一旦用于 GAP 认证或合同约定即须执行。

### 1.2 GAP 核心要求（种植业）

| 模块 | 核心要求 |
|---|---|
| **产地环境与选址** | 评估土壤、水源、大气及周边污染源；历史土地利用（重金属、农药残留风险）；建立地块档案与平面图 |
| **种子与繁殖材料** | 使用来源可追溯、质量合格、符合检疫要求的种子种苗；转基因材料须符合法规并标识 |
| **投入品管理** | 农药、肥料采购验收与台账；按标签/登记范围使用；禁限用投入品清单管控；剩余药剂安全处置 |
| **农事记录** | 逐地块记录播种、施肥、灌溉、用药（品名、浓度、用量、日期、操作人）、采收等；记录保存不少于规定年限 |
| **可追溯体系** | 批次化/地块化管理，产品可正向追踪与反向溯源；出入库与销售记录衔接 |
| **采收与采后处理** | 遵守农药安全间隔期；采收、清洗、包装、贮运卫生与冷链控制；防止交叉污染 |
| **人员与设施** | 员工培训与健康安全、施药防护；农机具、灌溉设施维护校准 |
| **投诉与召回** | 建立投诉处理、不合格品控制与产品召回程序 |

### 1.3 认证与符合性

- 控制点分为一级、二级、三级，包含"必须符合"与"建议符合"两类；一级控制点通常为否决项。
- GAP 认证通常按"农场/生产者组织"申请，需通过有资质认证机构的现场审核并接受年度监督。
- 强调**食品安全、可追溯、环境可持续、工人健康安全与动物福利**五大支柱。

## 二、绿色食品

绿色食品由中国绿色食品发展中心负责标志许可与监督管理，分 **A 级**（限量使用限定化学合成生产资料）与历史沿用的 **AA 级**（接近有机，现已基本并入有机产品体系）。

### 2.1 核心标准

| 标准号 | 名称 | 用途 | 状态/备注 |
|---|---|---|---|
| NY/T 391-2021 | 绿色食品 产地环境质量 | 规定产地生态环境、隔离保护、环境质量通用要求 | 现行，代替 NY/T 391-2013 |
| NY/T 393-2020 | 绿色食品 农药使用准则 | 有害生物防治原则、农药选用与使用规范、残留要求 | 现行，2020-07-27 发布、2020-11-01 实施，代替 NY/T 393-2013 |
| NY/T 394-2023 | 绿色食品 肥料使用准则 | 肥料使用原则、肥料种类及使用规定 | 现行，代替 NY/T 394-2021 |
| NY/T 658-2015 | 绿色食品 包装通用准则 | 包装基本、安全卫生、环保、标志标签要求 | 现行，代替 NY/T 658-2002 |
| NY/T 1056-2021 | 绿色食品 储藏运输准则 | 绿色食品储藏与运输要求 | 现行，代替 NY/T 1056-2006 |

### 2.2 要点

- **产地环境（NY/T 391）**：空气、灌溉水、土壤等环境质量须达标；设置缓冲/隔离带防止污染；兼顾环境可持续。绿色食品**产地环境要求高于普通农产品，严于无公害**。
- **农药（NY/T 393）**：坚持"预防为主、综合防治"；优先农业/物理/生物防治；仅允许使用准则规定的农药品种，禁用高毒、高残留农药；严格执行剂量、次数与**安全间隔期**。
- **肥料（NY/T 394）**：以有机肥、微生物肥、矿物源肥料和经许可的化学肥料为主；控制氮肥用量，防止硝酸盐与重金属超标；禁止使用城市垃圾、污泥及含超标有毒有害物质的肥料。
- **包装与贮运（NY/T 658、NY/T 1056）**：包装材料安全卫生、可回收/易降解；贮运防潮、防污染、控温控湿，不与有毒有害物混装混运。
- **产品标准**：具体产品按对应 NY/T 产品标准（如 NY/T 743 绿色食品 绿叶类蔬菜、NY/T 844 绿色食品 温带水果等，具体以最新目录为准）。

### 2.3 绿色食品标志申请要点

| 环节 | 要点 |
|---|---|
| 申请人条件 | 能独立承担民事责任；具有绿色食品生产的**环境条件和生产技术**；有完善的质量管理/生产管理制度；**申请前三年内无质量安全事故和不良诚信记录** |
| 申报流程 | 提交申请 → 材料审查 → 环境监测与产品检测 → 现场核查 → 中国绿色食品发展中心综合审查 → 签订标志使用协议 → 颁发证书及编号 |
| 标志使用 | 标志使用许可通常有效期 **3 年**，期满需续展；须规范使用标志、编号并纳入追溯 |
| 法律依据 | 《绿色食品标志管理办法》（农业部令，**令号待核实**） |

## 三、有机产品（GB/T 19630）

### 3.1 核心标准

| 标准号 | 名称 | 状态/备注 |
|---|---|---|
| GB/T 19630-2019 | 有机产品 生产、加工、标识与管理体系要求 | 现行，2019-08-30 发布、2020-01-01 实施；代替 GB/T 19630.1～.4-2011 |
| 《有机产品认证管理办法》 | 认证监管规章 | 现行版本以市场监管总局最新修订为准（**令号/年份待核实**） |

> GB/T 19630-2019 将原分部分标准整合为一项，覆盖**生产、加工、标识与管理体系**全过程要求。GB/T 为推荐性国家标准，但为有机认证的唯一依据，认证产品必须符合。

### 3.2 生产要求要点

| 要点 | 内容 |
|---|---|
| **转换期** | 一年生作物：转换期自播种前起**至少 24 个月**；多年生作物（果园、茶树等）：**至少 36 个月**；牧草/草场：至少 24 个月。转换期从有机生产管理开始计算 |
| **禁限用投入品** | 禁止使用化学合成农药、化肥、生长调节剂、饲料添加剂、转基因技术及辐照；仅允许附录清单内的天然/矿物源物质与生物防治手段 |
| **缓冲带** | 有机地块与常规地块之间须设置**有效隔离/缓冲带**，防止禁用物质漂移、渗漏污染 |
| **种子种苗** | 优先使用有机种子和繁殖材料；在无法获得时按规定例外使用常规材料（不得使用禁用处理） |
| **土壤与养分** | 以轮作、绿肥、有机肥、生物固氮维持地力；明确畜禽粪肥来源、腐熟与使用限制 |
| **产品标识** | 仅认证产品可使用有机产品认证标志和"有机"字样；**转换期产品不得标注"有机"**；须标注认证机构、有机码，实现"一品一码"追溯 |
| **管理体系** | 建立有机生产/加工管理手册、操作规程、记录与内部检查制度，接受年度认证检查 |

## 四、测土配方施肥技术规范与肥料登记/限量

### 4.1 测土配方施肥

| 标准号 | 名称 | 状态/备注 |
|---|---|---|
| NY/T 2911-2025 | 测土配方施肥技术规程 | 现行，2025-05-01 实施；代替 NY/T 2911-2016 |
| NY/T 1118（年份待核实） | 测土配方施肥技术规范 | 部分内容已被 NY/T 2911 覆盖，以现行版本为准 |

**技术环节**：

1. **肥料效应田间试验**：常采用"3414"方案，确定最佳施肥量与养分比例。
2. **土壤与植株样品采集、制备与测试**：按网格/地块采样，规范制备与检测（有机质、氮磷钾、中微量元素等）。
3. **肥料用量确定与配方设计**：以目标产量法/养分平衡法计算，形成区域或地块配方。
4. **配方肥合理施用**：确定施肥时期、方式（基肥/追肥）、深度与配合比例。
5. **效果评价与数据管理**：建立土壤养分数据库和施肥建议通知单，开展肥效反馈与评价。

### 4.2 肥料登记与限量

| 文件/标准 | 要点 |
|---|---|
| 《肥料登记管理办法》 | **农业农村部令 2022 年第 1 号**修订（2022-01-07 公布并施行）；规定肥料登记范围、程序与监督管理，部分肥料（如部分有机肥、微生物肥等）实行备案或免登记，具体以目录为准 |
| GB 38400-2019（肥料中有毒有害物质的限量要求，**建议核实现行有效性**） | 强制性国家标准，规定肥料中重金属、有害物质限量，配合 NY/T 相关标准使用 |
| NY/T 525-2021 | 有机肥料（现行，代替 NY/T 525-2012） |
| GB 20287-2006 | 农用微生物菌剂（现行） |

> 施肥合规三要素：**肥料产品合格 + 用量科学（配方施肥）+ 不超有害物质限量**。绿色食品、有机产品另有更严格的肥料使用清单（见第二、三章）。

## 五、农药安全使用

### 5.1 登记与管理法规

| 法规/规章 | 要点 |
|---|---|
| 《农药管理条例》 | **国务院令第 677 号**，2017-02-08 国务院常务会议修订通过，**自 2017-06-01 起施行**；涵盖农药登记、生产、经营、使用、监管与法律责任 |
| 农药登记证 | 农药生产前须取得登记；登记证标注有效成分、剂型、登记作物与防治对象、使用方法和**安全间隔期** |
| 生产许可 / 经营许可 | 农药生产须取得生产许可证；限制使用农药实行**定点经营、实名购买**；经营单位须建台账 |
| 农药标签 | 标签须标注登记证号、使用范围与方法、剂量、安全间隔期、注意事项、毒性标识等；不得擅自扩大使用范围 |

> 俗称"**农药三证**"：农药登记证、农药生产许可证、农药产品标准（或生产批准证）；购买与使用须核对产品合规性。

### 5.2 禁用/限用农药

- 我国对高毒、高风险农药实行**名录管理**（《禁限用农药名录》）。
- 截至 **2022 年 3 月底**，已禁限用农药 **70 种**：其中**禁止使用 50 种**（含六六六、滴滴涕、甲胺磷、对硫磷、久效磷、百草枯、甲拌磷等），**限制使用 20 种**（如克百威、氧乐果等，禁止在蔬菜、果树、茶叶、中草药材上使用）。
- **名录动态更新，最新版数量与品种以农业农村部最新公告为准**（有报道称 2026 年名录调整为禁止 60 种、限制 20 种，**具体待核实**）。
- 违规使用禁用农药、超范围使用限用农药将承担法律责任，并直接影响产品合格判定与追溯。

### 5.3 安全间隔期与最大残留限量

| 概念/标准 | 说明 |
|---|---|
| **安全间隔期** | 最后一次施药至农产品采收（或放牧、食用）的最短间隔天数，保证残留量降至最大残留限量以下；由农药标签和合理使用准则规定 |
| GB/T 8321（所有部分） | 农药合理使用准则（系列推荐性国标），按作物/农药规定用药量、次数、安全间隔期；部分如 GB/T 8321.10-2018 |
| NY/T 1276（年份待核实） | 农药安全使用规范 总则 |
| **GB 2763-2021** | 食品安全国家标准 食品中农药最大残留限量（强制性国标）；2021-09-03 实施，规定各食品中农药 MRL |
| GB 2763.1-2022 | 食品安全国家标准 食品中 2,4-滴丁酸钠盐等 112 种农药最大残留限量（GB 2763-2021 的增补），2023-05-11 实施 |

> **逻辑关系**：农药标签规定"安全间隔期"→ 按间隔期采收 → 使农残 ≤ GB 2763 规定的 MRL → 产品判为合格。**超 MRL 即不合格**，是农产品质量安全监管与追溯的核心判定依据。

## 六、农产品质量安全

### 6.1 《中华人民共和国农产品质量安全法》要点

| 要点 | 内容 |
|---|---|
| 施行时间 | 2022-09-02 全国人大常委会修订通过，**自 2023-01-01 起施行** |
| 监管原则 | 源头治理、风险管理、全程控制；建立**从田间到餐桌**的全过程全链条监管 |
| 标准体系 | 健全农产品质量安全标准（农兽药残留、检测方法等），并与食品安全国家标准衔接 |
| 产地与生产 | 加强产地环境管理、农业投入品管理、生产过程控制；生产者是第一责任人 |
| **承诺达标合格证** | 新法**正式确立**农产品质量安全承诺达标合格证制度：农产品生产企业、农民专业合作社、从事收购的单位或个人应按规定开具/收取并保存合格证 |
| 追溯管理 | 推动建立农产品质量安全追溯体系，实现来源可查、去向可追、责任可究 |
| 监督检查与处罚 | 强化监督抽查、风险监测与信用管理；对违法行为设定相应法律责任 |

### 6.2 承诺达标合格证

- **开具主体**：农产品生产企业、农民专业合作社、从事农产品收购的单位或个人。
- **覆盖品种（重点）**：蔬菜、水果、畜禽、禽蛋、养殖水产品等。
- **内容**：生产者信息、产品信息、数量、开具日期、承诺事项（未使用禁用农药、符合安全标准等）。
- **意义**：实现"**带证上市、凭证追溯**"，是产地准出与市场准入衔接的重要凭证。
- 配套规章：《农产品质量安全承诺达标合格证管理办法》，据检索信息 **2026-02-01 起施行**（**施行日期待核实**，请以农业农村部正式公布为准）。

### 6.3 追溯与监测

| 事项 | 要点 |
|---|---|
| 国家追溯平台 | 依托国家农产品质量安全追溯管理信息平台，实现主体注册、产品赋码与查询 |
