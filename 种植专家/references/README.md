## 六、原文获取与核验

- **收录原则**：法规、规章、政府公告等官方文件（不受著作权保护）可收录全文；**标准类（GB/GB/T/NY/T 等）只收"要点 + 标准号 + 版本状态 + 查询入口"**，不整篇下载，避免版权风险与版本过期。
- **权威查询入口**：
  - 国家标准全文公开系统：<https://openstd.samr.gov.cn>
  - 全国标准信息公共服务平台：<https://std.samr.gov.cn>
  - 国家法律法规数据库：<https://flk.npc.gov.cn>
  - 农业农村部（技术意见/公告/登记）：<http://www.moa.gov.cn>
- **行为约定**：涉及**限量值、检测方法、禁限用清单、标准版本号**时不得凭本目录条目臆造，须声明"以现行标准正文为准"；需要精确数值/条文时，先向用户索取该标准 PDF 或联网核验，再单列收录并登记版本与实施日期。
