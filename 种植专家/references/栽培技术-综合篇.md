# 综合栽培技术（通用篇）

> **适用范围**：本文件汇总大田作物、蔬菜、果树及设施栽培通用的栽培技术要点，供种植方案制定、田间诊断与技术培训参考。
> **使用说明**：
> 1. 文中数值为**典型值/推荐区间**，均标注来源编号（见第九节）与适用区域/条件；实际应用须结合本地土壤测试、气候与品种校准。
> 2. 无法从公开资料核实的具体数值一律标注 **"待核实"**，不得直接作为生产处方。
> 3. 施肥、用药方案必须遵循：**用量、时期、方法、安全间隔期** 四要素齐全；农药使用以最新版标签和 GB 2763《食品安全国家标准 食品中农药最大残留限量》为准。
> 4. 单位遵循国标：**1 亩 = 667 m²**；养分以纯量 N、P₂O₅、K₂O 计。
> 5. 本文件为通用框架，具体作物/生态区应配套专用方案；品种选育与种苗脱毒请交由育种、育苗专家。
> 6. **原著数据级证据**（含出处与页码，需要具体数值/试验结论时优先取用）：综合农学见 `作物栽培-综合证据条目与出处.md`（养分与 4R、保护性耕作、植保与生物防治、非生物胁迫、小麦、分子育种）；水稻见 `水稻栽培-证据条目与出处.md`。

## 一、土壤与施肥

### 1.1 测土配方施肥的计算（养分平衡法 / 目标产量法）

测土配方施肥的核心是**"以土定产、以产定肥、因缺补缺"**：由土壤测试确定土壤供肥量，从目标产量所需养分量中减去土壤供应量，差额即为需通过施肥补充的养分量。[1][3]

**基本公式（目标产量法，养分平衡法）：**

```
施肥量（kg/亩） = [目标产量 × 作物单位产量养分吸收量 − 土壤养分供应量]
                 ÷ （肥料中养分含量 × 肥料当季利用率）
```

其中：

- **目标产量**（kg/亩）：一般取当地前 3 年平均产量上浮 10%～15%，或按地力水平确定 [3]；
- **作物单位产量养分吸收量**：见表 1-1；
- **土壤养分供应量** = 土壤速效养分测定值（mg/kg）× 0.15 × 土壤有效养分校正系数（0.15 为耕层 20 cm、容重约 1.15 g/cm³ 时的换算系数，**具体取值以当地技术规范为准**）[1]；
- **肥料当季利用率**：氮肥约 30%～40%、磷肥约 15%～25%、钾肥约 40%～50%（**典型值，待按当地校验**）；水肥一体化条件下利用率较高，配方应相应下调 [9]。

**由推荐施肥量换算实际肥料用量（单质肥）：** [2]

```
应施肥数量 = （推荐施肥量 ÷ 化肥有效含量）× 100
```

> 示例（来源 [2]）：推荐纯 N 8.5 kg/亩，尿素含氮 46%，则应施尿素 = (8.5 ÷ 46) × 100 ≈ 18.4 kg/亩。

**复合肥与单质肥配合：** 先用推荐量中最少的养分计算复合肥用量，再补足其余两种养分。[2]

```
复合肥用量 = （推荐量中最少的养分量 ÷ 复合肥中该养分百分含量）× 100
补充单质肥 = （推荐量 − 已由复合肥提供的量）÷ 单质肥有效含量 × 100
```

> 示例 [2]：推荐 N 8.5、P₂O₅ 4.8、K₂O 6.5 kg/亩。以 15-15-15 复合肥计，先按最少的 P₂O₅ 算：(4.8÷15)×100 = 32 kg/亩；尚需补尿素 (8.5−4.8)÷46% ≈ 8 kg，补硫酸钾 (6.5−4.8)÷50% ≈ 3.4 kg。

### 1.2 大量元素与中微量元素的施用与分次比例

- **原则**：有机无机结合、基肥与追肥结合、大量元素与中微量元素结合；化肥总量的 **30%～45% 作基肥**，其余通过追肥（优先水肥一体化）分次施入。[9]
- **氮（N）**：一般基肥占 30%～50%，其余在拔节/开花/膨果等关键期分次追施；沙质土"少量多次"。
- **磷（P₂O₅）**：移动性差，宜作基肥/种肥一次性深施，全部基施比例可占 70%～100%。
- **钾（K₂O）**：基追结合，追施比例 30%～50%，重点在果实/籽粒形成期。
- **钙、镁（Ca、Mg）**：酸性土/沙质土易缺，可基施石灰（补 Ca 并调酸）、钙镁磷肥或硫酸镁；叶面补 Ca 宜在幼果期，Mg 于缺镁初期。
- **微量元素（B、Zn、Fe、Mn、Cu、Mo）**：以缺补缺，优先叶面喷施与种肥（如硼砂、硫酸锌）。**叶面肥浓度与安全用量须按产品标签，具体数值待核实。**
- **分次施用总思路**（以蔬菜/果菜为例）：基肥 30%～45% + 苗期轻追 + 花果期重追（分 3～6 次），与灌溉同步。[9]

### 1.3 有机肥替代化肥

- **政策目标**：据《开展果菜茶有机肥替代化肥行动方案》，果菜茶优势产区化肥用量减少 **20% 以上**、核心产区与知名品牌生产基地减少 **50% 以上**（以原方案为准）[5][16]。
- **技术要点**：
  - 有机肥**充分腐熟**后施用（未腐熟易带菌、烧根、堵塞滴灌）。
  - 有机肥氮替代化肥氮的适宜比例，多项研究建议在 **10%～30%** 区间内产量与品质较优（如设施番茄新建大棚试验，**具体比例按土壤与有机肥氮含量计算，待本地校验**）[16]。
  - 用量示例（豇豆基肥）：充分腐熟有机肥 **500～1000 kg/亩** + 复合肥 25～30 kg/亩 + 生物菌肥 5～10 kg/亩 [7]。

### 1.4 盐碱地与酸化土壤改良

**盐碱地改良**（"改、用、留"分级修复；水利、化学、物理、生物四类措施并重）[11][12][19]：

| 类别 | 主要措施 | 备注 |
|---|---|---|
| 水利工程 | 地下渗管排盐、沟渠+深井排水、灌水洗盐、微咸水调控 | 防返盐；需有排水出路 [12] |
| 化学改良 | 石膏、磷石膏、脱硫石膏、硫磺、腐殖酸、糠醛渣 | 针对碱化土（钠质），Ca²⁺ 代换 Na⁺，降低 pH 与碱化度 [12][19] |
| 物理改良 | 平整土地、客土、压沙、松土、抬田起垄覆膜 | 破坏毛细作用、阻断盐分表聚；客土成本高 [12] |
| 生物改良 | 种植耐盐作物、种植水田、增施有机肥、生物菌剂 | 提高有机质、改善结构 [12] |

- 具体施用量（如脱硫石膏 t/亩、洗盐灌水量 m³/亩）**依土壤全盐量与离子组成确定，待核实**。
- **酸化土壤改良**：施用石灰/白云石粉（补钙调酸）、增施有机肥与生物炭、选用生理碱性肥料；石灰用量依土壤 pH 与缓冲能力确定，**待核实**。

## 二、水分管理

### 2.1 灌溉制度的基本原则

- 遵循 **"底足、前控、中促、后保"** 与 **"关键期保障、分期补灌"** 原则；把有限水量用在需水临界期。[9]
- **需水临界期示例**：冬小麦返青—拔节期、孕穗—抽穗期 [9]；玉米大喇叭口期—抽雄期为需水临界期，宜保持土壤相对含水量 **70%～80%**（**典型值，待核实**）。
- **灌水定额示例（宝鸡市冬小麦，微喷灌，产量 550～650 kg/亩）** [9]：
  - 底墒不足：播后灌 **20～25 m³/亩**；底墒充足：**10～15 m³/亩**。
  - 全生育期通过滴灌/微喷 **分 4～6 次**随水追肥。
  - 每次施肥按 **"先清水 15～20 min → 注肥 → 后清水 20～30 min"** 冲洗管道。

### 2.2 水肥一体化：EC / pH 目标

- 水肥一体化通过管道将水肥精准输送到根区，具有节水节肥、省工省力、提质增效等优点 [9][14][20]。
- **EC（电导率，dS/m 或 mS/cm）**：
  - 一般适宜区间 **0.2～2.0 dS/m**，随作物与生育期动态调节（检索资料，待核实）；
  - **番茄营养液 EC 常维持在 2.5～3.5 dS/m**，冬季偏高（3～3.5）、夏季偏低（2.5～3）[检索资料，待核实]。
  - 作物耐盐性不同：草莓、蓝莓宜偏低（约 1.0～1.5 dS/m），**以本地营养液配方为准**。
- **pH**：多数作物根区 pH 宜 **5.8～6.5**；蓝莓等喜酸作物 **4.5～5.5**（详见 `skills/plant-lstm/植物生长模型参数库.md`）。
- **肥液浓度**：控制在 **0.1%～0.3%**（约 1 kg 肥料兑水 300～1000 kg），忌过高烧根；多种肥料混用先做兼容性试验，溶解顺序为先磷、后氮、最后钾。[9]

### 2.3 灌溉频次与单次水量（参考）

- 蔬菜大棚滴灌：**大田蔬菜单次用水量约 10～15 m³/亩**（受作物、生育期、土质、气候影响大）[检索资料，待核实]。
- 沙土、高温强光：少量多次（如每 1～3 天一次）；黏土、低温：适当延长间隔、增大单次量。
- **判据**：以土壤墒情（张力计/手持墒情仪）、田间持水量百分比或作物萎蔫点为依据，避免"按天定时"盲目灌溉。

## 三、育苗与移栽

### 3.1 种子处理与催芽

- 选用适合当地、抗（耐）性强的品种；播前进行**温汤浸种、药剂拌种**消毒。[7]
- 温汤浸种：一般先用 55 ℃ 左右温水浸种（**具体温度/时间因种而异，待核实**），可钝化部分种传病害；药剂拌种针对土传病害与苗期害虫（如噻虫嗪拌种防蓟马）[7]。
- 催芽：在适温、保湿、通气条件下至露白；瓜类、茄果类适温不同，**待按品种查询**。

### 3.2 基质与穴盘

- 穴盘基质育苗成苗快、不伤根、适宜远距离运输，是蔬菜集约化育苗的主流方式 [检索资料]。
- **基质要求**：有机质丰富、质地疏松、保肥保水且通气，pH 与 EC 适配作物（如蔬菜 pH 5.5～7.0，**待按作物核实**）。
- **穴盘选择**：按苗龄与作物选孔数（如茄果类常用 50～72 孔、叶菜 105～128 孔，**典型值，待核实**）；护根育苗用穴盘或营养钵 [7]。
- 苗期环境：放风口布设防虫网，培育**无病虫壮苗**；带药定植，保持适宜密度。[7]

### 3.3 壮苗标准（示例）

| 蔬菜 | 壮苗特征（定植时） | 来源 |
|---|---|---|
| 番茄 | 株高 15～20 cm，具 7～9 片真叶，节间短粗，现花蕾，根系发达 | [15] |
| 辣椒 | 茎秆粗壮、节间短，茎粗约 0.3～0.4 cm | [15] |
| 通用（冬春育苗） | 苗龄 60～80 d，株高约 15 cm，7～9 片真叶，叶厚色深，根系好 | [15] |
| 通用（部分蔬菜） | 株高 20～25 cm，茎粗 0.6 cm 以上且上下一致，主根长、侧根多 | [15] |

> 判定维度：根系（白根、发达）、茎（短粗有韧性）、叶（厚、色正常）、无病虫害、生长整齐。不同作物标准不同，**以专用育苗方案为准**。

### 3.4 移栽密度

- 密度由**作物、品种、地力、水肥条件、种植方式**共同决定；水肥一体化+高肥力可适当增密、单株负载下降。
- 合理密植是粮油作物大面积增产的重要途径（"合理增密、水肥调控"）[20]。
- 具体株行距（如番茄 2500～3000 株/亩、玉米 4000～5000 株/亩等）因生态区差异大，**待按作物/区域核实**。

## 四、设施环境调控

### 4.1 温度（昼/夜）

- 变温管理：白天维持光合适温，夜间适当降温以降低呼吸消耗、促进物质积累。
- **典型目标值**（来自设施模型参数与地方技术资料，作为区间参考）：

| 作物 | 昼温（℃） | 夜温（℃） | 来源/备注 |
|---|---|---|---|
| 番茄 | 22～26 | 15～18 | `skills/plant-lstm/植物生长模型参数库.md` |
| 草莓 | 20～24 | 10～15 | `skills/plant-lstm/植物生长模型参数库.md` |
| 蓝莓 | 22～25 | 15～18 | `skills/plant-lstm/植物生长模型参数库.md` |
| 芹菜（保护地） | 15～20（>25 ℃ 及时放风） | ≥10 | [8] |
| 蝴蝶兰等兰科 | 约 23 | — | `skills/plant-lstm/植物生长模型参数库.md` |

### 4.2 光照

- 目标以 **DLI（日累积光量，mol·m⁻²·d⁻¹）** 衡量：番茄/蓝莓 20～30，草莓 15～25（`skills/plant-lstm/植物生长模型参数库.md`）。
- 弱光季节/连阴天：清洁棚膜、铺设反光膜、人工补光（LED）；夏季强光：遮阳网降温、防日灼。
- 遮阳：一般遮光率 30%～50%，**按作物与季节调整，待核实**。

### 4.3 湿度

- 番茄 60%～70%，草莓 60%～75%，蓝莓 60%～70%（`skills/plant-lstm/植物生长模型参数库.md`）。
- 芹菜保护地：白天相对湿度 50%～60%，夜间 ≤80% [8]。
- 高湿（尤其 >85% 且结露）是灰霉病等气传病害的关键诱因，应及时通风、控水、地膜覆盖降湿。

### 4.4 CO₂ 浓度

- 正常大气约 380～420 ppm；植物光合最适 **1100～1500 ppm**。[10]
- 设施番茄增施 CO₂ 至 **800～1000 ppm** 可改善品质，**1200 ppm** 条件下平均单果重、前期商品果产量、总产量及可溶性固形物显著增加，并可减轻叶霉病。[10]
- 施肥时段一般在日出后至通风前（**时长与起止时间待按设施条件核实**），阴天/弱光不宜施。

### 4.5 通风与调控

- 通风是调节温、湿、CO₂ 的核心手段：晴天中午温度超过上限即放风（如芹菜 >25 ℃）[8]；放风口加装 **40～60 目防虫网**阻隔害虫 [7][8]。
- 冬季"保温与换气"矛盾突出，宜采用**顶部间歇放风+CO₂ 补充**组合。

## 五、植保绿色防控

### 5.1 绿色防控总原则

农作物病虫害绿色防控指采用**生态调控、生物防治、物理防治和科学用药**等环境友好型措施控制病虫危害，贯彻 **"预防为主、综合防治"** 植保方针。[6]

### 5.2 防治优先级（由高到低）

1. **农业/健康栽培**：抗（耐）病品种、轮作（最好水旱轮作）、健康种苗、深翻晒垡、高垄覆膜、平衡水肥、清理田园。[6][7][8]
2. **生态调控**：保护生物多样性、田埂种植蜜粉源植物（波斯菊、芝麻等）、间套作、天敌诱集带。[6][7]
3. **物理/理化诱控**：防虫网阻隔、色板诱杀、性信息素诱捕与迷向、杀虫灯、银灰膜驱避。[6][7][8]
4. **生物防治**：以虫治虫、以菌治虫、以菌治菌（赤眼蜂、捕食螨、绿僵菌、白僵菌、苏云金杆菌 BT、枯草芽孢杆菌、木霉菌、核型多角体病毒 NPV 等）。[6][7][8]
5. **科学用药（精准化学防治）**：选用高效、低毒、低残留、登记药剂，轮换用药，严守安全间隔期。[6][8]

### 5.3 病害判别（真菌 / 细菌 / 病毒）

| 类型 | 典型症状 | 主要传播/诱因 | 防控侧重 |
|---|---|---|---|
| 真菌性 | 叶斑、霜霉、白粉、灰霉（生霉层/粉状物）、枯萎 | 高湿、结露、气流/雨水溅 | 控湿通风、保护性+内吸杀菌剂轮换 |
| 细菌性 | 水渍状、软腐、青枯、溃疡、菌脓 | 伤口、雨水飞溅、种子/病残体 | 轮作、种子消毒、铜制剂/生物菌剂 |
| 病毒性 | 花叶、皱缩、黄化、条斑、矮化 | 蚜虫/粉虱/蓟马等介体、汁液 | 防介体（防虫网/黄蓝板）、拔除病株、免疫诱抗剂 |

> 判别应结合症状+环境+发生规律，必要时送检，**不可仅凭单株症状定性**。

### 5.4 监测与防治阈值（示例）

- **色板监测**：黄板诱蚜虫、粉虱、斑潜蝇；蓝板（或蓝板+蓟马信息素）诱蓟马。色板下缘高出作物冠层 **10～15 cm**，间距 **≥5 m**。[7]
- **性诱监测**：诱捕器间隔 **≥50 m**，每亩 **1～2 个**；豇豆荚螟用钟罩倒置漏斗式（高约 1 m），夜蛾类用圆筒菱形入口式（进虫口高约 1.2 m）。[7]
- **防治决策**：坚持 **"抓早治小"**，在病害即将发生/发生初期、害虫卵（若虫）期或低龄幼虫期施药；具体防治阈值（头/株、病叶率）**因作物而异，待核实**。[7]
- 防控目标示例（芹菜）：主要病虫害防治处置率 ≥90%，总体防控效果 ≥85%，危害损失率 ≤10%。[8]

### 5.5 用药三要素与安全间隔期

- **三要素**：**剂量**（按标签）、**次数**（按标签，避免超用）、**安全间隔期**（最后一次施药至采收的最小间隔天数）。[6][7][8]
- **安全间隔期示例**：豇豆采摘期优先选生物农药及**安全间隔期 3 天以内**的化学农药 [7]；采摘期害虫防治 **7～10 天用药一次** [7]。
- 药剂示例（须选用当地**登记**药剂并轮换）[7][8]：
  - 蚜虫：苦参碱、吡虫啉、吡蚜酮、啶虫脒、噻虫嗪；
  - 甜菜夜蛾：苦皮藤素、甜菜夜蛾核型多角体病毒；
  - 斑枯病/叶斑病/菌核病：咪鲜胺、苯醚甲环唑、吡唑醚菌酯、丙环唑、戊唑醇；
  - 蓟马：绿僵菌、乙基多杀菌素；土传/根结线虫：木霉菌、枯草芽孢杆菌、淡紫拟青霉等。
- **残留合规**：以 **GB 2763《食品安全国家标准 食品中农药最大残留限量》** 为准，严禁使用禁限用农药。[6][8]
- **施药技巧**：均匀喷施植株上下部、叶片正反面及地面；按害虫活动高峰施药（如蓟马抢在上午 10 点花瓣闭合前）。[7]

## 六、逆境胁迫应对

> 各类胁迫均按 **"预警指标 → 应急措施 → 恢复管理"** 三阶段组织。具体阈值需结合本地区/作物校准，标注待核实者为通用经验值。

### 6.1 干旱

| 阶段 | 要点 |
|---|---|
| 预警指标 | 土壤相对含水量低于田间持水量 60%（**待核实**）；叶片中午萎蔫、气孔导度下降；需水临界期（小麦返青—抽穗、玉米大喇叭口—抽雄） |
| 应急措施 | 关键期及时补灌（参见 2.1）；覆盖秸秆/地膜减少蒸发；叶面喷施抗蒸腾剂/磷酸二氢钾+尿素；优先滴灌、微喷灌 |
| 恢复管理 | 少量多次复水，避免猛灌造成根损伤；随水补施速效肥；监测恢复后病虫害 |

### 6.2 渍涝

| 阶段 | 要点 |
|---|---|
| 预警指标 | 连续降雨/积水 >24 h；土壤缺氧、根系发黑、叶片黄化脱落 |
| 应急措施 | **第一时间排水**，开挖/疏通排水沟，机械强排；破除板结、中耕散墒 |
| 恢复管理 | 排水后叶面追肥（尿素+磷酸二氢钾）恢复长势；防根腐/青枯等土传病害；及时补种/改种短季作物 |

### 6.3 低温 / 霜冻

| 阶段 | 要点 |
|---|---|
| 预警指标 | 气象预报降温、近地气温降至 0～5 ℃（霜冻临界）；作物为喜温作物（如番茄 <10 ℃ 受冷害） |
| 应急措施 | **灌水**（浇水后 10 d 内有一定保温效果，但**霜冻当天不宜浇**）；**熏烟**（凌晨低温时段）；**覆盖**（地膜、无纺布、草帘）；设施加温、补光 [检索资料] |
| 恢复管理 | 冻后缓慢升温、忌骤热；剪除冻伤组织；喷施芸苔素内酯/氨基寡糖素等免疫诱抗剂与叶面肥；防次生病害 [7] |

### 6.4 高温

| 阶段 | 要点 |
|---|---|
| 预警指标 | 气温 >35 ℃、强光、干热风；叶片卷曲、日灼、落花落果 |
| 应急措施 | 遮阳网、通风、喷雾降温；早晚灌溉、小水勤浇；设施湿帘/风机降温 |
| 恢复管理 | 增施钾肥与钙肥增强抗性；注意高温高湿后病害流行 |

### 6.5 盐碱

| 阶段 | 要点 |
|---|---|
| 预警指标 | 土壤全盐量、pH、碱化度（ESP）超标；出苗率低、叶缘焦枯、生长停滞 [11][12] |
| 应急措施 | 灌水洗盐（需排水出路）、覆盖抑盐、增施有机肥/生物菌剂、施石膏类改良剂 [12][19] |
| 恢复管理 | 种植耐盐作物/绿肥、水旱轮作、持续培肥；分级修复（改、用、留）[11] |

### 6.6 弱光

| 阶段 | 要点 |
|---|---|
| 预警指标 | 冬季/连阴天 DLI 低于作物下限（如番茄 <15 mol·m⁻²·d⁻¹）；节间徒长、叶色淡、落花 |
| 应急措施 | 清洁棚膜、反光膜、人工补光（LED）；适当稀植与整枝改善透光；控水控氮防徒长 |
| 恢复管理 | 转晴后逐步见光防"闪苗"；叶面补肥；加强病害防控（弱光高湿易发病） |

## 七、生长模型要点

### 7.1 Logistic 与 Gompertz 方程

两类 S 型（Sigmoid）曲线常用于描述作物株高、生物量、叶面积等的**时间累积生长**过程。[17]

**Logistic 方程：**

```
y(t) = K / (1 + a · e^(−b t))
```

**Gompertz 方程：**

```
y(t) = K · exp(−a · exp(−b t))
```

**参数含义：**

| 参数 | 含义 |
|---|---|
| K | 环境容纳量 / 最大生长量（渐近值），由品种与资源供给决定 |
| a | 与初始生长状态有关的尺度参数（a 越大，起势越缓） |
| b | 内禀生长速率相关参数（b 越大，越早进入旺长期） |

**特征点对比：**

| 特征 | Logistic | Gompertz |
|---|---|---|
| 生长拐点（最大速率） | y = K/2 | y = K/e ≈ 0.368K（出现更早） |
| 拐点时间 t* | t* = (ln a)/b | t* = (ln a)/b |
| 最大生长速率 | bK/4 | bK/e |
| 适用 | 对称 S 型、资源受限 | 非对称 S 型、早期生长相对更快 |

### 7.2 拟合流程

1. **数据采集**：等间隔（如每 7 d）记录生长指标（株高、茎粗、叶面积、干重等）与环境因子。
2. **选模型**：比较 Logistic 与 Gompertz 拟合残差/决定系数（R²）、AIC，择优。
3. **参数估计**：常用非线性最小二乘（Python `scipy.optimize.curve_fit`、MATLAB `lsqcurvefit`、SPSS 非线性回归）[17]。
4. **诊断**：残差图、R²、参数标准误；剔除异常点。
5. **应用**：以拟合曲线预测生长节点、确定管理窗口（如最大生长速率期加强水肥）。
6. **进阶（时序预测）**：可用 LSTM 等对多因子时序建模，参数与流程见独立技能 `plant-lstm`（`skills/plant-lstm/植物生长模型参数库.md` 与 `skills/plant-lstm/植物生长LSTM模型-使用说明书.md`）。
